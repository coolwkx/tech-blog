# 01 基础语法与数据类型
> **一句话总结**：Python 的四个内置容器（list / tuple / dict / set）加上"可变 vs 不可变"这条主线，构成了后面所有代码的词汇表；搞不清它们，后面学函数默认参数、闭包、深浅拷贝时都会反复踩坑。
> **前置知识**：会安装并运行 Python（3.8+）；知道变量、`print`、`input` 的基本用法；了解 `int / float / str / bool` 四种标量类型。

> 1. 面对一个真实需求，能立刻判断该用 list、tuple、dict 还是 set，并说出理由；
> 2. 熟练写出增删查改、切片、拆包、词频统计、嵌套结构遍历这些"肌肉记忆"级代码；
> 3. 能解释"可变对象赋值"造成的别名（aliasing）副作用，并知道用 `copy` 或推导式规避。

## 1. 核心概念
### 1.1 变量、对象与"三要素"
Python 里**变量不是盒子，而是贴在对象上的标签**。执行 `a = [1, 2, 3]` 时，解释器先创建列表对象，再让名字 `a` 指向它。每个对象有三个要素：

| 要素 | 查看方式 | 说明 |
| --- | --- | --- |
| 身份 identity | `id(obj)` | 对象在内存中的地址，生命周期内不变 |
| 类型 type | `type(obj)` | 决定这个对象支持哪些操作 |
| 值 value | `obj` 本身 | 可变对象的值可以原地改变，身份不变 |
```python
a = [1, 2, 3]
print(id(a)) # 例如 140234...（每次运行不同）
a.append(4) # 原地修改
print(id(a)) # 与上面完全相同：还是同一个对象
```
> 一句话记忆：**``=` 只改变"名字指向谁"，`append` / `+=` 这类方法可能改变对象本身。**

### 1.2 可变类型 vs 不可变类型（本课最核心的一张表）
| 类型 | 可变性 | 赋值/修改行为 | 典型坑 |
| --- | --- | --- | --- |
| `int` `float` `bool` `str` | 不可变 | 任何"修改"都会创建新对象 | 循环里拼字符串性能差 |
| `tuple` `frozenset` | 不可变 | 不能增删改元素 | 单元素元组漏写逗号 |
| `list` `dict` `set` | 可变 | 原地修改，所有引用者都看得见 | 函数传参被"意外"改动 |
| `bytearray` | 可变 | 原地修改字节 | 与 `bytes` 混用 |
```python
s = "hello"
print(id(s))
s = s + "world" # 创建了新字符串，s 指向新对象
print(id(s)) # id 变了 → 证明 str 不可变

lst = [1, 2, 3]
print(id(lst))
lst.append(4)
print(id(lst)) # id 没变 → 证明 list 可变
```
**推论**：把可变对象传给函数，函数内部修改会影响外部；把不可变对象传进去，函数内部的影响出不来。这条推论直接决定了后面"函数与作用域""深浅拷贝"两章的理解。

### 1.3 四大容器选型表
| 容器 | 语法 | 有序 | 可重复 | 可变 | 查找复杂度 | 典型场景 |
| --- | --- | --- | --- | --- | --- | --- |
| `list` | `[1, 2, 3]` | ✅ | ✅ | ✅ | O(n) | 有序序列、需要下标、频繁追加 |
| `tuple` | `(1, 2, 3)` | ✅ | ✅ | ❌ | O(n) | 函数返回多值、字典键、坐标等常量 |
| `dict` | `{"k": 1}` | ✅（3.7+ 保序） | 键唯一 | ✅ | O(1) 平均 | 映射关系、结构化记录、计数 |
| `set` | `{1, 2, 3}` | ❌ | ❌（自动去重） | ✅ | O(1) 平均 | 去重、成员判断、集合运算 |

### 1.4 序列的通用操作（list / tuple / str 都支持）
| 操作 | 写法 | 结果（以 `nums = [0,1,2,3,4,5]` 为例） | 备注 |
| --- | --- | --- | --- |
| 索引 | `nums[0]` / `nums[-1]` | `0` / `5` | 越界抛 `IndexError` |
| 切片 | `nums[1:4]` | `[1, 2, 3]` | **包左不包右** |
| 省略端点 | `nums[:3]` / `nums[4:]` | `[0,1,2]` / `[4,5]` | 切片不会越界报错 |
| 步长 | `nums[::2]` | `[0, 2, 4]` | 第三个参数是 step |
| 逆序 | `nums[::-1]` | `[5,4,3,2,1,0]` | 返回新对象，不改原序列 |
| 成员判断 | `3 in nums` | `True` | list 是 O(n)，set 是 O(1) |
| 长度 | `len(nums)` | `6` | — |

### 1.5 list 的增删改查
| 目的 | 方法 | 说明 |
| --- | --- | --- |
| 增（1 个） | `lst.append(x)` | **只能接一个参数**，追加到末尾 |
| 增（多个） | `lst.extend(iterable)` | 逐个追加，等价于 `lst += iterable` |
| 增（指定位置） | `lst.insert(i, x)` | 在索引 i 处插入，原元素后移 |
| 删（按下标） | `del lst[i]` / `lst.pop(i)` | `pop` 会返回被删元素 |
| 删（按值） | `lst.remove(v)` | 只删第一个匹配项；不存在则 `ValueError` |
| 删（清空） | `lst.clear()` | — |
| 查 | `lst.index(v)` / `v in lst` | `index` 找不到抛异常，`in` 返回布尔 |
| 改 | `lst[i] = x` / `lst[1:3] = [a, b]` | 切片赋值可以改变列表长度 |
| 排序 | `lst.sort(key=..., reverse=...)` | **原地**排序，返回 `None` |
| 排序（新表） | `sorted(lst)` | 返回新列表 |

### 1.6 tuple：不可变带来的三个价值
1. **函数返回多个值**——`return x, y` 本质就是返回元组。
2. **可以做字典的键 / 放进 set**——因为不可变所以可哈希（hashable）。
3. **数据保护**——坐标 `(x, y)`、RGB 颜色这类"天然成组且不该被改"的数据。
```python
t = (5) # 这是 int，不是 tuple！
t = (5,) # 单元素元组必须带逗号
```
**拆包（unpacking）**：把序列元素分别绑定到多个名字，是 Python 最优雅的语法之一。

| 写法 | 含义 | 示例结果 |
| --- | --- | --- |
| `a, b = (1, 2)` | 严格等长拆包 | `a=1, b=2` |
| `a, = (5,)` | 单元素元组拆包 | `a=5` |
| `first, *rest = [1,2,3,4]` | `*` 收集剩余元素为 **list** | `first=1, rest=[2,3,4]` |
| `*head, last = [1,2,3,4]` | `*` 在前 | `head=[1,2,3], last=4` |
| `a, b = b, a` | 交换变量（底层就是元组拆包） | 无需临时变量 |

### 1.7 dict：把"查表"这件事做到 O(1)
- **键必须是可哈希的**：`str / int / float / bool / tuple` 可以，`list / dict / set` 不行。
- 常用方法：

| 方法 | 作用 | 备注 |
| --- | --- | --- |
| `d[key]` | 取值 | 键不存在抛 `KeyError` |
| `d.get(key, default)` | 安全取值 | 键不存在返回 `default`（默认 `None`） |
| `d[key] = v` | 新增或覆盖 | 键存在即修改 |
| `d.update(other)` | 批量合并 | 同名键会被覆盖 |
| `del d[key]` / `d.pop(key)` | 删除 | `pop` 返回被删的值 |
| `d.keys() / d.values() / d.items()` | 视图对象 | `items` 最常用，配合 `for k, v in ...` |
| `key in d` | 成员判断 | **判断的是键**，不是值 |

**词频统计范式**（务必背下来，后面 NLP 章节仍在使用）：
```python
word_count = {}
for word in text.split():
 word_count[word] = word_count.get(word, 0) + 1
```
### 1.8 set：去重与集合运算
```python
nums = {1, 2, 3, 2, 4} # 自动去重 → {1, 2, 3, 4}
empty = set # 空集合必须这样写，{} 是空字典！
nums.add(8) # 添加元素用 add，不是 append
nums.remove(1) # 不存在会报 KeyError
nums.discard(999) # 不存在也不报错
```
| 运算 | 运算符 | 方法 | 含义 |
| --- | --- | --- | --- |
| 并集 | `a \| b` | `a.union(b)` | 两边都算 |
| 交集 | `a & b` | `a.intersection(b)` | 两边都有 |
| 差集 | `a - b` | `a.difference(b)` | 只在 a 中 |
| 对称差 | `a ^ b` | `a.symmetric_difference(b)` | 只在一侧 |

### 1.9 引用、浅拷贝与"别名"
```python
a = [1, 2, 3]
b = a # 别名：两个名字，一个对象
b.append(4)
print(a) # [1, 2, 3, 4] ← 很多 bug 的源头

c = a.copy # 浅拷贝：新列表，元素还是原引用
c.append(5)
print(a) # 不受影响
```
- `list.copy` / `dict.copy` / `set.copy` 都是**浅拷贝**；
- 嵌套结构要真正隔离必须用 `copy.deepcopy`（第 03 篇详述）。

## 2. 最小可运行示例
下面这段代码覆盖了本篇所有主线，可直接复制运行（Python 3.8+ 输出一致）。
```python
# ---------- 1) 字典遍历 + 条件表达式：items 一次拿到键和值 ----------
scores = {"语文": 88, "数学": 92, "英语": 79}
for subject, score in scores.items():
 level = "优秀" if score >= 90 else ("及格" if score >= 60 else "不及格")
 print(f"{subject}: {score} -> {level}")
# 语文: 88 -> 及格
# 数学: 92 -> 优秀
# 英语: 79 -> 及格
# ---------- 2) 词频统计：dict.get 的经典用法 ----------
text = "hello world hello python world hello"
word_count = {}
for word in text.split():
 word_count[word] = word_count.get(word, 0) + 1
print(word_count) # {'hello': 3, 'world': 2, 'python': 1}

# ---------- 3) set 去重（顺序不保证，所以排序后打印） ----------
print(sorted(set(text.split()))) # ['hello', 'python', 'world']

# ---------- 4) 拆包：*rest 收集"剩下全部" ----------
first, *rest = [10, 20, 30, 40]
print(first, rest) # 10 [20, 30, 40]

# ---------- 5) 切片三件套 ----------
nums = [0, 1, 2, 3, 4, 5]
print(nums[1:4], nums[::2], nums[::-1])
# [1, 2, 3] [0, 2, 4] [5, 4, 3, 2, 1, 0]
# ---------- 6) 别名 vs 拷贝 ----------
a = [1, 2, 3]
b = a # 别名
b.append(4)
print("aliasing:", a) # aliasing: [1, 2, 3, 4]

c = a.copy # 浅拷贝
c.append(5)
print("copy:", a, c) # copy: [1, 2, 3, 4] [1, 2, 3, 4, 5]

# ---------- 7) 二维结构：两种写法，只有一种是对的 ----------
bad = [[0] * 3] * 3 # 三行其实是同一个列表对象
bad[0][0] = 1
print("bad matrix:", bad) # [[1, 0, 0], [1, 0, 0], [1, 0, 0]]

good = [[0] * 3 for _ in range(3)] # 每行独立
good[0][0] = 1
print("good matrix:", good) # [[1, 0, 0], [0, 0, 0], [0, 0, 0]]

# ---------- 8) tuple 作字典键：坐标映射 ----------
points = {(0, 0): "origin", (1, 2): "A"}
print(points[(1, 2)]) # A
```
**关键点说明**

| 行 | 关键点 | 为什么这么写 |
| --- | --- | --- |
| `scores.items()` | 返回 `(key, value)` 二元组视图 | 比 `for k in d: d[k]` 少一次哈希查找 |
| `word_count.get(word, 0) + 1` | 缺省值 0 | 避免 `KeyError`，一行完成"初始化 + 计数" |
| `sorted(set(...))` | set 无序 | 想稳定输出必须排序或转 list 后处理 |
| `first, *rest` | `*` 收集为 list | 注意收集结果是 list，不是 tuple |
| `b = a` | 别名，非拷贝 | 想独立就 `.copy` / `list(a)` / `a[:]` |
| `[[0]*3]*3` | 外层 `*` 复制的是引用 | 二维以上一律用嵌套推导式 |

## 3. 常见坑
| 坑 | 现象 | 原因 | 正确做法 |
| --- | --- | --- | --- |
| `lst.append(a, b)` | `TypeError: append takes exactly one argument` | `append` 只接收一个元素 | 用 `lst.append([a, b])` 或 `lst.extend([a, b])` |
| 单元素元组漏逗号 | `t = (5)`，`type(t)` 是 `int` | 圆括号只是分组符号 | 写成 `t = (5,)` |
| 空集合写成 `{}` | `type({})` 是 `dict` | `{}` 被解析为空字典 | 用 `set` |
| 集合用 `append` | `AttributeError: 'set' object has no attribute 'append'` | 集合的方法是 `add` / `update` | `s.add(x)`、`s.update([x, y])` |
| 用 list 当字典键 | `TypeError: unhashable type: 'list'` | list 可变，哈希值不稳定 | 先转 `tuple(lst)` 再当键 |
| `remove` 删不存在的值 | `ValueError: list.remove(x): x not in list` | `remove` 严格匹配 | 先 `if v in lst` 判断，或改用 `discard` 风格的过滤 |
| 遍历 list 时删除元素 | 有元素被跳过 | 删除导致下标整体前移 | 用推导式生成新列表：`[x for x in lst if 条件]` |
| `lst.sort()` 返回值赋给变量 | 得到 `None` | `sort` 是原地排序，返回 `None` | 用 `sorted(lst)` 拿新列表 |
| `a = b` 以为是拷贝 | 改 `b` 后 `a` 也变了 | 两个名字指向同一对象 | `b = a.copy` 或 `copy.deepcopy(a)` |
| `[[0]*n]*m` 建二维表 | 改一行全变 | 外层乘法复制的是同一引用 | `[[0]*n for _ in range(m)]` |
| 切片赋值长度不匹配的误解 | `nums[1:3] = [9]` 列表变短 | 切片赋值是"替换区间"，长度可以不同 | 明确意图：替换用切片赋值，插入用 `insert` |
| set 输出顺序每次不同 | 打印结果看着"乱" | set 无序（哈希表实现） | 需要顺序时 `sorted(s)` |
| 中文字符串按"字符"切片没问题，但编码要统一 | 文件读写乱码 | 默认编码随平台变化 | 文件操作一律显式 `encoding="utf-8"` |

## 4. 面试问答
<details><summary>参考答案</summary>

**Q1：list 和 tuple 都能存序列，为什么还要保留 tuple？**

三点：①**可哈希**——只有不可变对象才能做 dict 的键、进 set，所以 `{(0,0): "origin"}` 这种坐标映射只能靠 tuple；②**语义表达**——tuple 表示"一条固定记录"（如函数返回的 `(name, age)`、数据库一行），list 表示"可变集合"，选哪个本身就在向读代码的人传递意图；③**性能与安全**——tuple 内存更小、创建更快，且不会被误改；元素不可变意味着它天然线程安全，可以放心共享。另外函数 `return a, b` 返回的就是 tuple，拆包语法 `x, y = f` 依赖这一点。

</details>

<details><summary>参考答案</summary>

**Q2：为什么 dict 的键必须是不可变类型？**

dict 底层是哈希表：存值时用 `hash(key)` 算出槽位，取值时再算一次。如果键能被原地修改，它的哈希值就会变，取值时会落到错误的槽位上，导致"明明存进去了却查不到"。所以 Python 要求键实现 `__hash__`，而 `list / dict / set` 都显式把 `__hash__` 设为 `None`，一用就报 `TypeError: unhashable type`。需要组合键时改用 `tuple`（元素也必须全部可哈希）或 `frozenset`。顺带一提，自定义类默认可用作键（用 `id` 参与哈希），但一旦重写 `__eq__` 就必须同时重写 `__hash__`，否则对象也会变得不可哈希。

</details>

<details><summary>参考答案</summary>

**Q3：`a = [1, 2]; b = a; b.append(3)` 之后 `a` 是什么？如果要让 `a` 不变该怎么做？**

`a` 是 `[1, 2, 3]`。赋值语句只让 `b` 这个新名字指向了 `a` 所指的**同一个列表对象**，`append` 是原地修改，所以通过任何别名都能看到变化。要让 `a` 不受影响，需要用拷贝：`b = a.copy`、`b = list(a)`、`b = a[:]` 三种写法等价，都是**浅拷贝**（新列表，但元素仍是原引用）。如果列表是嵌套的（如 `[[1, 2], [3, 4]]`），浅拷贝后 `b[0].append(...)` 依然会影响 `a`，这时必须 `import copy; b = copy.deepcopy(a)`。

</details>

## 5. 自测题
<details><summary>1. 写出三种从一个 list 去重并保持原顺序的方法，并说明复杂度。</summary>
```python
nums = [3, 1, 3, 2, 1]

# 方法一：seen 列表 + 判重（O(n²)，小数据够用，逻辑最直观）
seen, result = [], []
for n in nums:
    if n not in seen:
        seen.append(n); result.append(n)

        # 方法二：set 判重 + list 保序（O(n)，推荐）
        seen, result = set, []
        for n in nums:
            if n not in seen:
                seen.add(n); result.append(n)

                # 方法三：dict.fromkeys 一行写法（Python 3.7+ 字典保序）
                result = list(dict.fromkeys(nums))
```
三者结果都是 `[3, 1, 2]`。直接 `set(nums)` 虽然也是 O(n)，但会丢掉顺序。

</details>

<details><summary>2. `nums = [1, 2, 3, 4, 5]`，`nums[1:4]`、`nums[-2:]`、`nums[::2]`、`nums[::-1]` 分别是什么？</summary>

`[2, 3, 4]`、`[4, 5]`、`[1, 3, 5]`、`[5, 4, 3, 2, 1]`。
记忆口诀：切片是 `seq[start:stop:step]`，**包左不包右**；负索引从 -1 开始数；`step` 为负时默认从尾部往前取。

</details>

<details><summary>3. 下面的代码输出什么？为什么？</summary>
```python
matrix = [[0] * 3] * 2
matrix[0][1] = 9
print(matrix)
```
输出 `[[0, 9, 0], [0, 9, 0]]`。`[[0]*3]` 先创建一个内层列表，`* 2` 只是把这个**引用**复制了两份，所以 `matrix[0]` 和 `matrix[1]` 是同一个对象，改一处两处都变。正确写法是 `[[0] * 3 for _ in range(2)]`。

</details>

<details><summary>4. 如何用一行代码统计一段文本中每个单词出现的次数？</summary>
```python
from collections import Counter
Counter(text.split())
```
`collections.Counter` 是 dict 的子类，`Counter(text.split()).most_common(3)` 能直接取 Top-N。手写版本（`dict.get(word, 0) + 1`）要理解，生产代码优先用 `Counter`。

</details>

<details><summary>5. `d = {"a": 1}`；`d.get("b")` 和 `d["b"]` 有什么区别？</summary>

`d.get("b")` 返回 `None`（可指定默认值 `d.get("b", 0)`），不会中断程序；`d["b"]` 抛 `KeyError`。统计类场景用 `get` 更省事，而"这个键本该存在"的业务校验场景应该让它抛错，便于尽早发现问题。

</details>
