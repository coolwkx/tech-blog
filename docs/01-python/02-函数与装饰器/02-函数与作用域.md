## 1. 核心概念
### 1.1 函数定义与调用：三个最容易含混的点
| 概念 | 说明 | 常见误解 |
| --- | --- | --- |
| 函数定义 `def f: ...` | 把一段代码封装成**对象**，绑定到名字 `f` | 以为"定义"就是"执行"，其实函数体此时不执行 |
| 函数调用 `f` | 创建栈帧、绑定实参、执行函数体、返回结果 | 漏写括号 → 拿到的是函数对象而不是结果 |
| 函数名 `f` | 一个变量，指向函数对象（可以打印出地址） | 以为函数名是"特殊语法"，其实它就是普通名字 |
| docstring | 紧跟 `def` 的字符串字面量，可用 `f.__doc__` 读取 | 用 `#` 注释当文档，无法被 `help` 读取 |
```text
def greet: # 定义：只创建对象，不执行 print
 print("Hello")

print(greet) # <function greet at 0x...> ← 函数是对象
greet # 调用：这时才打印 Hello
```
### 1.2 返回值：`return` 的四种形态
| 写法 | 返回值 | 类型 | 说明 |
| --- | --- | --- | --- |
| 没有 `return` | `None` | `NoneType` | 隐式返回，不是"没有返回值" |
| `return` | `None` | `NoneType` | 等价于提前结束函数 |
| `return x` | `x` | 任意 | 返回单个对象 |
| `return a, b` | `(a, b)` | `tuple` | **本质是返回一个元组**，靠拆包接住 |
```python
def sum_odd_even(numbers):
    odd = even = 0
    for n in numbers:
        if n % 2 == 0:
            even += n
        else:
            odd += n
            return odd, even # 返回元组 (odd, even)

        odd, even = sum_odd_even([1, 2, 3, 4, 5, 6, 7, 8])
        print(odd, even) # 16 20
```
> 为什么 `return a, b` 是元组？因为逗号本身构造元组，`return` 只是把这个元组交出去。理解这一点后 `x, y = f` 就是普通的元组拆包，不是特例。

### 1.3 参数四件套与"绑定顺序"
| 参数形式 | 写法 | 接收内容 | 注意 |
| --- | --- | --- | --- |
| 位置参数 positional | `def f(a, b)` | 按顺序一一对应 | 数量不匹配抛 `TypeError` |
| 关键字参数 keyword | `f(b=1, a=2)` | 按名字对应 | 提高了可读性，顺序可打乱 |
| 默认参数 default | `def f(a, b=10)` | 不传就用默认值 | **默认值在函数定义时求值一次** |
| 可变位置 `*args` | `def f(*args)` | 打包成 `tuple` | 名字可以是别的，`*` 才是关键 |
| 可变关键字 `**kwargs` | `def f(**kwargs)` | 打包成 `dict` | 同上 |
| 仅关键字参数 | `def f(a, *, b)` | `b` 只能按关键字传 | Python 3 特性，提高接口安全性 |
| 仅位置参数 | `def f(a, /, b)` | `a` 只能按位置传 | Python 3.8+，可用于 API 兼容 |

**定义时的书写顺序（背下来）**：
```text
位置参数 → 默认参数 → *args → 仅关键字参数 → **kwargs
def f(a, b=1, *args, c, d=2, **kwargs): ...
```
**调用时的传参规则**：关键字参数必须在位置参数之后；同一个参数不能既按位置又按关键字传（`f(1, a=1)` 会报 `TypeError: got multiple values for argument 'a'`）。

打包与解包是一对：
```python
def show(a, b, *args, **kwargs):
 return a, b, args, kwargs

nums = [1, 2, 3]
extra = {"x": 9}
print(show(*nums, **extra)) # (1, 2, (3,), {'x': 9})
```
- **打包**：定义时 `*args` 把多余的位置实参收进元组，`**kwargs` 把多余的关键字实参收进字典。
- **解包**：调用时 `*nums` 把列表"摊开"成多个位置实参，`**extra` 把字典摊开成多个关键字实参。

### 1.4 变量作用域与 LEGB 规则
Python 查找一个名字时，按 **LEGB** 四级顺序，找到就停：

| 层级 | 名称 | 范围 | 例子 |
| --- | --- | --- | --- |
| **L** | Local | 当前函数的局部变量 | 函数体内的赋值 |
| **E** | Enclosing | 外层函数的局部变量（闭包场景） | 嵌套函数的父函数变量 |
| **G** | Global | 当前模块的全局变量 | 模块顶层赋值 |
| **B** | Built-in | 内置命名空间 | `len`、`print`、`ValueError` |
```text
g = "global" # G

def outer:
 e = "enclosing" # E
 def inner:
 l = "local" # L
 print(l, e, g) # local enclosing global
 inner

outer
```
两个关键推论：

1. **"赋值即声明"**：函数体里只要对某名字赋值，该名字在整个函数体内就是**局部变量**，哪怕赋值语句在读取之后。所以下面会报 `UnboundLocalError`：
 ```python
 x = 10
 def f:
 print(x) # UnboundLocalError!
 x = 20 # 这一行让 x 变成了局部变量
 ```
2. **读取不需要声明，写入才需要**：读取外层变量天然可以（E/G 层都能读），但**想改写**就必须显式声明 `global` 或 `nonlocal`。

| 声明 | 作用 | 用在哪 |
| --- | --- | --- |
| `global x` | 让函数内的 `x = ...` 写到模块全局 | 全局计数器、配置开关 |
| `nonlocal x` | 让内层函数的 `x = ...` 写到外层函数 | 闭包中的可变状态（见 06 篇） |
| 不声明 | 在函数内新建一个局部变量，遮蔽外层同名变量 | 绝大多数场景的正确做法 |
```text
count = 0
def increment:
 global count
 count += 1

increment; increment
print(count) # 2
```
```text
def counter:
 n = 0
 def inc:
 nonlocal n # 没有这行会 UnboundLocalError
 n += 1
 return n
 return inc

c1, c2 = counter, counter # 两次调用各有独立的 n
print(c1, c1, c1, c2) # 1 2 3 1
```
> `c1` 和 `c2` 的 `n` 互不影响 —— 每次调用 `counter` 都会新建一个栈帧、一套局部变量。这正是闭包能"保存状态"的原理（06 篇展开）。

### 1.5 参数传递：到底是"传值"还是"传引用"
标准答案是 **call by object reference（传对象引用）**：

- 形参和实参指向**同一个对象**，所以函数内部对可变对象做原地修改（`append`、`d[k]=v`），外部能看见；
- 但如果函数内部对形参**重新赋值**（`x = x + 10`），只是把局部名字指向了新对象，外部变量不受影响。

| 传入类型 | 函数内 `lst.append(x)` | 函数内 `x = 新值` |
| --- | --- | --- |
| 可变（list / dict / set） | ✅ 外部可见 | ❌ 外部不可见 |
| 不可变（int / str / tuple） | ❌ 本就无法原地改 | ❌ 外部不可见 |

想避免"意外副作用"，可以在函数入口先 `lst = lst.copy`（浅拷贝）或改用返回值风格（传入 → 返回新对象）。

### 1.6 函数是"一等对象"与高阶函数
Python 里函数和整数、字符串地位相同，所以可以：

| 能力 | 代码 | 用途 |
| --- | --- | --- |
| 赋值给变量 | `f = greet` | 起别名、动态选择实现 |
| 放进容器 | `[greet, len, str.upper()]` | 注册表、插件表 |
| 作为实参 | `sorted(xs, key=abs)` | 回调函数、`key` 参数 |
| 作为返回值 | `return inner` | 闭包、装饰器 |
| 现场定义 | `lambda x: x * 2` | 一次性小函数 |

**接收函数作为参数、或返回函数的函数，叫高阶函数（higher-order function）**。

### 1.7 lambda：能做什么、不能做什么
| 维度 | `def` 函数 | `lambda` |
| --- | --- | --- |
| 名字 | 有名字 | 匿名（可赋给变量，但不推荐） |
| 函数体 | 多条语句 | **只能是一个表达式** |
| `return` | 显式写 | 隐式返回表达式的值 |
| 文档字符串 | 支持 | 不支持 |
| 调试 | 名字清晰、可断点 | 报错信息里只显示 `<lambda>` |
| 适用场景 | 有复用价值的逻辑 | `key=` / 一次性短逻辑 |
```python
students = [{"name": "王凯旋", "score": 90},
{"name": "刘浩存", "score": 100},
{"name": "王月半", "score": 10}]
students.sort(key=lambda s: s["score"], reverse=True)
```
> 工程建议：`lambda` 只在"一行能看懂"时使用。一旦出现条件判断嵌套或长度超过一行，就应该定义具名函数 —— 可读性和可测试性比少写几行更重要。

## 2. 最小可运行示例
```text
# ---------- 1) 可变默认参数：经典陷阱与正确写法 ----------
def add_item_bad(item, box=[]): # 默认列表在"定义时"创建一次，被所有调用共享
 box.append(item)
 return box

print(add_item_bad("a")) # ['a']
print(add_item_bad("b")) # ['a', 'b'] ← 上一次的结果还在！

def add_item_ok(item, box=None): # 用 None 做哨兵，每次调用重新建列表
 if box is None:
 box = []
 box.append(item)
 return box

print(add_item_ok("a")) # ['a']
print(add_item_ok("b")) # ['b'] ← 正确

# ---------- 2) 默认值在定义时求值，而不是调用时 ----------
x = 10
def f(v=x):
 return v
x = 99
print(f) # 10，不是 99

# ---------- 3) LEGB 名字查找 ----------
g = "global"
def outer:
 e = "enclosing"
 def inner:
 l = "local"
 print(l, e, g) # local enclosing global
 inner
outer

# ---------- 4) nonlocal 让闭包持有可变状态 ----------
def counter:
 n = 0
 def inc:
 nonlocal n
 n += 1
 return n
 return inc

c1, c2 = counter, counter
print(c1, c1, c1, c2) # 1 2 3 1

# ---------- 5) 参数顺序：位置 → 默认 → *args → 仅关键字 → **kwargs ----------
def show(a, b=2, *args, **kwargs):
 return a, b, args, kwargs

print(show(1)) # (1, 2, (), {})
print(show(1, 3, 5, 7, name="wkx")) # (1, 3, (5, 7), {'name': 'wkx'})
print(show(*[1, 2, 3], **{"x": 9})) # (1, 2, (3,), {'x': 9})

# ---------- 6) 高阶函数：函数作为实参 ----------
def execute(func, data):
 return func(data)

print(execute(lambda v: v ** 2, 5)) # 25

# ---------- 7) 函数自省属性 ----------
def greet(name):
 """打招呼"""
 return f"你好 {name}"

print(greet.__name__, greet.__doc__, greet.__defaults__, greet.__annotations__)
# greet 打招呼 None {}
# ---------- 8) 可变对象作为实参：原地修改会影响外部 ----------
def modify(lst):
 lst.append(99)

data = [1, 2]
modify(data)
print("修改后:", data) # 修改后: [1, 2, 99]
```
**关键点说明**

| 位置 | 关键点 | 为什么 |
| --- | --- | --- |
| `box=[]` | 默认值在**定义时**只创建一次，存在 `add_item_bad.__defaults__` 里 | 想"每次新建"必须用 `None` 哨兵 |
| `def f(v=x)` | 默认值在定义时求值 | 解释器执行 `def` 语句时就算好并存进 `__defaults__` |
| `print(l, e, g)` | 从内到外依次找到 L、E、G | 这就是 LEGB，找到即停 |
| `nonlocal n` | 声明"n 是外层函数的变量" | 否则 `n += 1` 会让 `n` 变成局部变量并报 `UnboundLocalError` |
| `c1, c2 = counter` | 每次调用产生**独立的** `n` | 闭包保存的是各自栈帧里的 cell |
| `show(*[1,2,3], **{"x":9})` | 调用时的解包 | `*` 摊开序列，`**` 摊开字典 |
| `greet.__defaults__` | 是 `None` 而不是 `` | 没有默认参数时该属性为 `None` |

## 3. 常见坑
| 坑 | 现象 | 原因 | 正确做法 |
| --- | --- | --- | --- |
| 可变默认参数 | 第二次调用时"记得"上次的数据 | 默认对象在 `def` 执行时创建一次，被所有调用共享 | `def f(x, box=None):` 然后 `if box is None: box = []` |
| 默认参数依赖运行期变量 | 改了全局变量，默认值不跟着变 | 默认值在定义时求值 | 传 `None` 哨兵，在函数体内取当前值 |
| 忘记写括号 | `print(greet)` 打印 `<function greet at ...>` | 拿到的是函数对象本身 | 打印结果要写 `print(greet)` |
| 赋值导致 `UnboundLocalError` | `print(x)` 报"referenced before assignment" | 函数体内有 `x = ...`，使 `x` 成为局部名 | 读取全局用 `global x` 声明，或读出到别的名字 |
| 在函数里"改"全局变量忘了声明 | 全局值没变 | 未声明时 `x = ...` 创建了局部变量 | 明确 `global x` |
| `nonlocal` 用在模块层 | `SyntaxError: no binding for nonlocal 'x' found` | 模块顶层没有"外层函数" | 顶层用 `global`；`nonlocal` 只能用于嵌套函数 |
| 参数顺序写错 | `SyntaxError: non-default argument follows default argument` | 默认参数必须写在位置参数之后 | 按"位置 → 默认 → `*args` → 仅关键字 → `**kwargs`"排列 |
| 同一参数传两次 | `TypeError: got multiple values for argument 'a'` | `f(1, a=2)` 同时按位置和关键字给了 `a` | 一个参数只用一种方式传 |
| 可变对象做默认值 + 原地改实参 | 外部变量"莫名其妙"被改 | 传对象引用，`append` 是原地操作 | 函数内部先 `lst = lst.copy`，或改成返回新对象 |
| `return a, b` 被当成两个返回值 | 拿到的是元组，`+=` 报类型错误 | 逗号构造元组 | 用拆包 `x, y = f`，或显式 `return (a, b)` |
| `lambda` 里写语句 | `SyntaxError: invalid syntax` | `lambda` 只能包含一个表达式 | 复杂逻辑改用 `def` |
| `lambda` 闭包延迟绑定 | 循环里创建的一堆 lambda 都用最后一个值 | 变量在调用时才查找 | 用默认参数钉住：`lambda i=i: i` |
| 修改可变实参后返回值混乱 | 函数既改外部又返回，语义不清 | 副作用与返回值混用 | 二选一：要么原地改并返回 `None`，要么不改并返回新对象 |
| 用 `is` 比较小整数/字符串 | 偶尔 True 偶尔 False | `is` 比较身份，`==` 比较值 | 比较值一律用 `==` |
| 函数名遮蔽内置函数 | `list = [1,2]` 后 `list("abc")` 报错 | 全局名遮蔽了内置命名空间（B 层最后查找） | 不要用 `list`、`sum`、`id`、`str` 做变量名 |

## 4. 面试问答
<details>
<summary><strong>Q1：为什么不能用可变对象（如 `[]`、`{}`）作为默认参数？</strong></summary>

因为 Python 的默认值在**函数定义时**求值一次，并被保存在函数的 `__defaults__` 属性里；之后每次不传该参数，函数拿到的都是**同一个对象**。如果函数体里对它做了原地修改（`append`、`[k]=v`），修改会留在这个共享对象上，被后续所有调用看到，表现为"函数记得上次的数据"。正确做法是用 `None` 当哨兵：
```python
def f(item, box=None):
    if box is None:
        box = []
        box.append(item)
        return box
```
注意：传不可变默认值（`0`、`""`、`None`）没有这个问题，因为不可变对象无法被原地修改。

</details>

<details>
<summary><strong>Q2：说说 Python 的作用域规则，`global` 和 `nonlocal` 有什么区别？</strong></summary>

Python 用 LEGB 顺序查找名字：Local（当前函数）→ Enclosing（外层函数）→ Global（当前模块）→ Built-in（内置）。**读取**时四层都能读，**写入**时默认只写 Local；一旦函数体内出现对某名字的赋值，这个名字在整个函数体内就被判定为局部变量，即使赋值在读取之后，也会导致 `UnboundLocalError`。

- `global x`：把 `x` 的写入目标指向模块全局，用于跨函数维护全局状态；
- `nonlocal x`：把写入目标指向**最近一层**定义了 `x` 的外层函数，只能用在嵌套函数里，是闭包持有可变状态的标准做法。

两者都只影响"赋值写到哪一层"，不影响读取顺序。

</details>

<details>
<summary><strong>Q3：`*args` 和 `</strong></summary>

kwargs` 的作用是什么？调用时 `*` 和 `**` 又是什么意思？**

定义处：`*args` 把"多出来的位置实参"打包成一个 `tuple`，`**kwargs` 把"多出来的关键字实参"打包成一个 `dict`。名字可以自定义，起作用的只是星号。它们让函数可以接受任意参数，是装饰器能通用于任何原函数的关键（见 06 篇）。

调用处是相反的操作——**解包**：`f(*[1,2,3])` 等价于 `f(1,2,3)`，`f(**{"a":1})` 等价于 `f(a=1)`。两者常一起出现在"转发参数"的场景：`return func(*args, **kwargs)`。

注意：`*` 单独作为参数出现（`def f(a, *, b)`）表示"后面的参数只能按关键字传"，属于 Python 3 的仅关键字参数语法，和 `*args` 不是一回事。

</details>

## 5. 自测题
<details>
<summary>1. 下面代码输出什么？如何修正？</summary>

```python
def append_to(element, target=[]):
 target.append(element)
 return target

print(append_to(1))
print(append_to(2))
```
输出 `[1]` 然后 `[1, 2]`。因为默认列表在定义时只创建了一次。修正：
```python
def append_to(element, target=None):
    if target is None:
        target = []
        target.append(element)
        return target
```

</details>

<details>
<summary>2. `x = 1` 在模块顶层；函数内先 `print(x)` 再 `x = 2`，会发生什么？为什么？</summary>

抛 `UnboundLocalError: cannot access local variable 'x' where it is not associated with a value`。原因是"赋值即声明"：函数体内存在 `x = 2`，编译器把 `x` 判定为局部变量，于是 `print(x)` 在局部命名空间里找不到它，**不会**回退去读全局的 `x`。想读全局只能先 `global x`（或改成只读不赋值）。

</details>

<summary>3. 写出一个函数，能接收任意个数的位置参数和关键字参数，并返回它们的总和。</summary>

```python
def total(*args, **kwargs):
 return sum(args) + sum(kwargs.values())

print(total(1, 2, 3, a=4, b=5)) # 15
```
要点：`args` 是元组可直接 `sum`；`kwargs` 是字典，必须取 `.values()`。

<details>
<summary>4. 一个函数既有 `return` 又有 `finally`，返回值以谁为准？</summary>

`try` 块里的 `return` 会先"计算返回值并存起来"，然后执行 `finally`；如果 `finally` 里也有 `return`，**它会覆盖**前面的返回值。
```text
def f:
 try:
 return 1
 finally:
 return 2

print(f) # 2
```
结论：`finally` 里不要写 `return`，它会吞掉异常和返回值，是非常隐蔽的 bug。详见 04 篇异常处理。

</details>

<details>
<summary>5. `sorted(data, key=lambda x: x[1])` 里的 `key` 参数是怎么工作的？</summary>

`sorted` 属于高阶函数：它先对每个元素调用一次 `key` 函数，得到"排序依据"（sort key），再按这些依据比较排序，最后返回**原元素**组成的新列表。所以 `key` 函数只需返回用于比较的值，不需要返回元素本身。
```python
data = [("b", 2), ("a", 3), ("c", 1)]
print(sorted(data, key=lambda x: x[1])) # [('c', 1), ('b', 2), ('a', 3)]
```
用 `key` 而不是 `cmp` 的好处：`key` 对每个元素只调用一次，复杂度是 O(n log n) 次比较但只有 n 次 key 调用，比 Python 2 的 `cmp` 快得多。

</details>
