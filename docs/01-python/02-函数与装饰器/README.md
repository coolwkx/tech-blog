## 本章要回答的问题

**2.1 函数与作用域**
- 写出带位置参数、关键字参数、默认参数、`*args` / `**kwargs` 的完整函数签名，并说清参数绑定的顺序规则；
- 说清 `return` 的三种情况（无 return、单值、多值）并解释"返回多值其实是返回元组"；
- 拿到一段看不懂的变量名，能按 LEGB 顺序推理它到底指向谁，并用 `global` / `nonlocal` 精确控制写入位置。

**2.2 装饰器与生成器**

- 写出带参数的装饰器，理解"三层结构"为什么是必需的；
- 用 `yield` 写生成器处理大文件/无限序列，并用 `@property` + `@x.setter` 实现带校验的属性读写。
