## 本章要回答的问题

**5.1 模块与包管理**
- 熟练使用 4 种 `import` 形式并说出各自的优缺点，能给模块和名字起别名；
- 解释 `__name__` 在"直接运行"和"被导入"两种场景下的不同取值，正确使用 `if __name__ == "__main__":`；
- 把一个单文件脚本拆成"包 + 模块 + 入口文件"的多文件工程，并用虚拟环境 + `requirements.txt` 管理依赖。

**5.2 迭代器与内置函数**
- 用 `__iter__` / `__next__` 手写一个可迭代对象，并说清"可迭代对象"和"迭代器"的区别；
- 用 `while` 手动复现 `for` 循环，解释迭代器为什么只能遍历一次；
- 熟练使用 20 个以上常用内置函数，并用 `key` 参数完成单级、多级、自定义排序。

**5.3 NumPy 入门**
- 熟练创建 `ndarray` 并读懂 `shape / ndim / size / dtype / itemsize`；
- 正确使用索引、切片、布尔索引、花式索引，并分清哪些操作返回**视图**、哪些返回**拷贝**；
- 用广播机制完成"列向量 × 行向量"这类矩阵级运算，并用 `axis` 参数做行列方向的聚合统计。

**5.4 Pandas 数据处理**
- 用 `read_csv` / `read_excel` 读数据，用 `loc` / `iloc` / 布尔 / `query` 精确取数；
- 处理缺失值（`isnull` / `dropna` / `fillna` / `interpolate`），并按"行键 / 列名"正确选择 `concat` 还是 `merge`；
- 用 `groupby.agg` / `pivot_table` / `crosstab` 做分组聚合，独立完成一个 RFM 用户分层案例。
