## 本章要回答的问题

**1.1 Linux 基础命令**
- 复制目录不加 `-r`
- 直接 `rm -rf 目录`
- 把 `-l` 记成 "line"

**1.2 Linux 实用操作**
- `usermod -G dev zhangsan` 漏掉 `-a`
- 目录权限只给 `r`
- 给文件 `w` 但没给目录 `w`

**1.3 MySQL 基础与 SQL 语法**
- `update`/`delete` 忘写 `where`
- `where 列 = null`
- `where` 里写聚合函数

**1.4 MySQL 进阶-索引与优化**
- 忘记写关联条件
- 把内连接当外连接用
- `over` 漏写 `partition by`
