# 机器学习核心概念与偏差方差分解

> **一句话总结**：监督学习是在假设空间里做（正则化的）经验风险最小化，而模型的期望泛化误差可以**精确分解**为 bias²、variance 与不可约噪声三项——"该加数据、该加特征还是该换模型"的答案，就是判断这三项里哪一项过大。
>
> **前置知识**：条件期望 $E[Y\mid X]$、方差、极大似然估计、矩阵最小二乘（正规方程）、训练/验证集切分与交叉验证。
>

> 1. 写出监督学习的形式化定义（真实分布、假设空间、损失、期望风险与经验风险），说清近似误差与估计误差的来源；
> 2. 独立推导"高斯噪声 $\Rightarrow$ MSE、伯努利 $\Rightarrow$ 交叉熵"和"高斯先验 $\Rightarrow$ L2、拉普拉斯先验 $\Rightarrow$ L1"；
> 3. 用 numpy 实验**测出** bias² 与 variance，并亲手验证 $E[(y-\hat f)^2]=\mathrm{Bias}^2+\mathrm{Var}+\sigma^2$；
> 4. 按学习曲线的四种形态，给出"先加数据 / 先加特征 / 先加模型复杂度 / 先加正则"的可执行决策顺序。

---

## 1. 为什么需要它

一个二分类模型，训练集 AUC 0.99，测试集 AUC 0.72。团队的第一反应通常是"过拟合了"，于是加 Dropout、加 L2、把模型换小——一周后 AUC 0.73，几乎没有变化。真实原因可能是：特征里缺少与标签强相关的信息（高偏差），或者标签本身噪声极大（噪声地板），或者切分方式泄漏了时间信息。这三种原因对应三种完全不同的动作，而在"过拟合"这一个标签下它们无法区分。

偏差-方差分解的价值，就是它把泛化误差拆成可以**分别测量、分别干预**的三部分：

| 误差项 | 通俗说法 | 有效干预 | 无效干预 |
| --- | --- | --- | --- |
| Bias² | 模型太笨，压根表达不了规律 | 加特征、加容量、降正则 | 加数据 |
| Variance | 模型太敏感，换个训练集就变样 | 加数据、加正则、集成、降容量 | 只加特征 |
| Noise $\sigma^2$ | 数据本身随机 / 标签有噪声 | 改问题定义、改标注质量、加协变量 | 任何建模技巧 |

不学这一章会踩的具体问题：把"过拟合"当成万能解释，于是所有问题都用加正则解决，欠拟合被长期忽视；动作方向搞反，明明是欠拟合却去加数据、明明是方差过大却去加特征把维度堆得更高；只看准确率不看基线，不知道"多数类基线"与"噪声地板"在哪，就无法判断 0.72 是好是坏；反复用测试集调参，把测试集也"训练"了，最终上线指标无法复现。

## 2. 核心思想

### 2.1 监督学习的形式化

设数据 $(x_i,y_i)\stackrel{\text{iid}}{\sim}P(X,Y)$，$P$ 未知且固定。回归的目标函数是条件均值 $f^\star(x)=E[Y\mid X=x]$（平方损失下的最优预测），分类的目标函数是条件概率 $\eta(x)=P(Y=1\mid X=x)$。我们用**假设空间** $\mathcal H=\{f_\theta:\theta\in\Theta\}$ 参数化候选模型，用**损失** $\ell(y,f(x))$ 度量单点误差，并定义：

$$R(f)=\mathbb E_{(X,Y)\sim P}\big[\ell(y,f(x))\big]\quad\text{(expected risk，期望风险)},\qquad
\hat R_n(f)=\frac{1}{n}\sum_{i=1}^{n}\ell\big(y_i,f(x_i)\big)\quad\text{(empirical risk，经验风险)}$$

**经验风险最小化（ERM）**：$\hat f=\arg\min_{f\in\mathcal H}\hat R_n(f)$；实际几乎总加正则项，$\hat f=\arg\min_{f\in\mathcal H}\big[\hat R_n(f)+\lambda\Omega(f)\big]$。$\hat R_n$ 是 $R$ 的无偏但高方差的估计（$n$ 个样本的均值），所以"训练误差小"与"期望风险小"是两件事。写严格就是泛化误差的两个来源：

$$R(\hat f)-R^\star=\underbrace{\big(R(f^\star_{\mathcal H})-R^\star\big)}_{\text{近似误差 approximation error}}+\underbrace{\big(R(\hat f)-R(f^\star_{\mathcal H})\big)}_{\text{估计误差 estimation error}}$$

其中 $R^\star=\inf_f R(f)$，$f^\star_{\mathcal H}=\arg\min_{f\in\mathcal H}R(f)$。近似误差只由假设空间决定（$\mathcal H$ 越大越小），估计误差由"用有限样本从 $\mathcal H$ 里挑一个"决定（$\mathcal H$ 越大、$n$ 越小则越大）。这与第 4 节的 bias-variance 是同一件事的两种说法。

### 2.2 极大似然估计：为什么回归用 MSE

设 $y=f_\theta(x)+\varepsilon$，$\varepsilon\sim\mathcal N(0,\sigma^2)$ 独立于 $x$。负对数似然为

$$-\log L(\theta)=\underbrace{\frac{n}{2}\log(2\pi\sigma^2)}_{\text{与 }\theta\text{ 无关}}+\frac{1}{2\sigma^2}\sum_{i=1}^{n}\big(y_i-f_\theta(x_i)\big)^2
\quad\Longrightarrow\quad \arg\max_\theta L(\theta)=\arg\min_\theta \text{MSE}$$

因为 $\frac{1}{2\sigma^2}$ 是正数常数，$\sigma^2$ 只影响似然的尺度而不影响最优参数。**MSE 不是随手选的，它是"高斯噪声假设下的极大似然估计"**。把噪声假设换成拉普拉斯分布 $p(\varepsilon)\propto e^{-|\varepsilon|/b}$，同样的推导得到 $\sum_i|y_i-f_\theta(x_i)|$，即 MAE（对离群点更稳健）。

### 2.3 伯努利似然：为什么分类用交叉熵

二分类里 $y\in\{0,1\}$，模型输出 $h_\theta(x)$ 表示 $P(Y=1\mid x)$，似然是伯努利分布：

$$-\log L(\theta)=-\sum_{i=1}^{n}\Big[y_i\log h_\theta(x_i)+(1-y_i)\log\big(1-h_\theta(x_i)\big)\Big]=\text{二元交叉熵}$$

多分类把伯努利换成 categorical 分布、把 sigmoid 换成 softmax，就得到 softmax 交叉熵。三个关键点：

1. **模型与数据匹配**：0/1 目标不是高斯变量，用高斯似然描述它等于假设了一个方差随均值变化的错误模型。
2. **梯度性质**：logistic + 交叉熵的 $\frac{\partial \ell}{\partial z}=h-y$，错得越离谱梯度越大；logistic + MSE 的 $\frac{\partial \ell}{\partial z}=(h-y)h(1-h)$，$h$ 饱和到 0 或 1 时梯度趋近 0（"错得最狠的样本几乎不产生梯度"），且损失关于 $z$ 非凸。
3. **信息论解释**：交叉熵 = 经验标签分布与预测分布之间的 KL 散度 + 常数。但要诚实说明：对概率输出用平方损失（Brier score）的最小化点同样是 $\eta(x)$，它也是 proper scoring rule；差别在于交叉熵对"自信地犯错"施加无界惩罚，而平方损失有界、对标签噪声更稳健，所以标签噪声很重时会见到 label smoothing 或 Brier 类替代损失。

### 2.4 最大后验：正则项就是先验

取负对数后，最大化后验（MAP）等价于最小化

$$-\log p(\theta\mid D)=\frac{1}{2\sigma^2}\sum_i\big(y_i-f_\theta(x_i)\big)^2\underbrace{-\log p(\theta)}_{\text{正则项}}+\text{const}$$

- 先验为高斯 $\theta\sim\mathcal N(0,\tau^2 I)$ 时 $-\log p(\theta)=\frac{1}{2\tau^2}\|\theta\|_2^2$，得到 **L2 / Ridge**，且 $\lambda=\sigma^2/\tau^2$：噪声越大或先验越强，正则越重；
- 先验为拉普拉斯 $p(\theta_j)\propto e^{-|\theta_j|/b}$ 时 $-\log p(\theta)=\frac{1}{b}\|\theta\|_1$，得到 **L1 / Lasso**。拉普拉斯先验在 0 处有尖峰，后验众数容易正好落在坐标轴上，这就是稀疏性的来源。

MLE 是 MAP 在均匀先验下的特例；MAP 是**有偏估计**——它主动引入偏差换取方差下降，这正是第 4 节要量化的交易。

| 数据假设（似然） | 等价损失 | 参数先验 | 等价正则项 | sklearn 对应 |
| --- | --- | --- | --- | --- |
| $y=f_\theta(x)+\mathcal N(0,\sigma^2)$ | MSE | 无（MLE） | 无 | `LinearRegression` |
| 高斯噪声 | MSE | 高斯 $\mathcal N(0,\tau^2)$ | $\lambda\|\theta\|_2^2$ | `Ridge` |
| 拉普拉斯噪声 | MAE | 无 | 无 | `QuantileRegressor(quantile=0.5)` |
| 高斯噪声 | MSE | 拉普拉斯 | $\lambda\|\theta\|_1$ | `Lasso` |
| 伯努利 $y\in\{0,1\}$ | 二元交叉熵 | 高斯 / 拉普拉斯 | L2 / L1 | `LogisticRegression(penalty=...)` |

## 3. 最小可运行示例

下面代码把期望泛化误差真正测出来：对同一分布重复采样 200 个训练集，在每个训练集上拟合多项式回归，然后统计**平均预测**（算 Bias²）与**预测抖动**（算 Variance）。真实函数 $f(x)=\sin(1.5\pi x)$，$x\sim U(0,1)$，噪声 $\varepsilon\sim\mathcal N(0,0.3^2)$。**第 4 节的其余代码块都复用这段定义的函数，放在同一个脚本里即可依次运行。**

```python
import numpy as np

SIGMA = 0.3 # 噪声标准差，sigma^2 = 0.09 是不可约项

def true_f(x):
    return np.sin(1.5 * np.pi * x)

def raw_design(x, degree):
    """[1, z, z^2, ..., z^d]，z = 2x-1 把输入压到 [-1, 1] 以改善数值条件。"""
    z = 2.0 * np.asarray(x, float) - 1.0
    return np.column_stack([np.ones_like(z)] + [z ** k for k in range(1, degree + 1)])

def fit_poly(x, y, degree, lam=0.0):
    """列标准化后最小二乘；lam > 0 时是岭回归（不惩罚截距）。"""
    X = raw_design(x, degree)
    mu, sd = X.mean(axis=0), X.std(axis=0) # 标准化统计量只能来自训练集
    sd[sd < 1e-12] = 1.0
    mu[0], sd[0] = 0.0, 1.0
    Xs = (X - mu) / sd
    if lam == 0.0:
        w = np.linalg.lstsq(Xs, y, rcond=None)[0]
    else:
        P = lam * np.eye(Xs.shape[1])
        P[0, 0] = 0.0 # 不惩罚截距
        w = np.linalg.solve(Xs.T @ Xs + P, Xs.T @ y)
        return w, mu, sd

    def predict(x, w, mu, sd, degree): # 用训练集的 mu/sd 变换测试点
        return ((raw_design(x, degree) - mu) / sd) @ w

    def bias_variance(degree, n=30, reps=200, grid=200, seed=0):
        rng = np.random.default_rng(seed)
        xg = np.linspace(0.0, 1.0, grid) # 固定的评估网格
        fg = true_f(xg)
        preds = np.empty((reps, grid))
        for r in range(reps): # 重复采样 reps 个训练集 D
            x = rng.uniform(0.0, 1.0, n)
            y = true_f(x) + rng.normal(0.0, SIGMA, n) # 每个 D 都是同一分布的新抽样
            w, mu, sd = fit_poly(x, y, degree)
            preds[r] = predict(xg, w, mu, sd, degree)
            mean_pred = preds.mean(axis=0) # E_D[f_hat(x)] 的蒙特卡洛估计
            return np.mean((mean_pred - fg) ** 2), np.mean(preds.var(axis=0))

        for d in (1, 9):
            b, v = bias_variance(d)
            print(f"degree={d}: bias^2={b:.4f} variance={v:.4f} "
            f"bias^2+var+sigma^2={b + v + SIGMA ** 2:.4f}")
```

实测输出（numpy 2.x，无其他依赖）：

```text
degree=1: bias^2=0.1838 variance=0.0235 bias^2+var+sigma^2=0.2973
degree=9: bias^2=0.0017 variance=8.4640 bias^2+var+sigma^2=8.5557
```

**逐行说明**：

| 代码 | 作用 | 容易误解的点 |
| --- | --- | --- |
| `SIGMA = 0.3` | 定义不可约噪声的标准差 | $\sigma^2=0.09$ 是误差下界，任何模型都压不到它下面 |
| `raw_design` | 构造 $[1,z,z^2,\dots,z^d]$ 多项式基 | 直接用 $x\in[0,1]$ 的幂次会让高阶设计矩阵条件数爆炸；$z=2x-1$ 只改善数值，不改变模型族 |
| `mu, sd = X.mean(0), X.std(0)` | 列标准化，弱化共线性 | **必须用训练集统计量去变换验证/测试集**，否则等于信息泄漏 |
| `np.linalg.lstsq` | 数值稳定的最小二乘（MSE 的解析解） | 不要写 `inv(X.T @ X) @ X.T @ y`，病态矩阵会放大误差 |
| `P[0, 0] = 0.0` | 岭回归不惩罚截距 | 惩罚截距等于把预测整体拉向 0，会凭空制造偏差 |
| `preds[r] = ...` | 保存第 $r$ 个训练集的整条预测曲线 | 关键是**每个训练集都换一批噪声**，只换特征不换噪声测不出 variance |
| `preds.var(axis=0)` | 蒙特卡洛估计 $\mathrm{Var}_D[\hat f(x)]$ | 用默认的 `ddof=0` 与理论分解一致；1 阶 bias² 主导（0.184 ≫ 0.024）、9 阶 variance 主导（8.46 ≫ 0.002） |

## 4. 深入机制

### 4.1 期望泛化误差的分解推导

设 $y=f(x)+\varepsilon$，$E[\varepsilon]=0$，$\mathrm{Var}(\varepsilon)=\sigma^2$，$\varepsilon$ 独立于 $x$ 与训练集 $D$，记训练集上学到的模型为 $\hat f_D$，$\bar f(x)=E_D[\hat f_D(x)]$。对同一个测试点 $x$ 的**全部随机性**取期望。

**第一步，分离噪声。** 展开 $(f+\varepsilon-\hat f_D)^2$，交叉项因 $\varepsilon\perp(D,x)$ 而消失：

$$E_{D,\varepsilon}\big[(y-\hat f_D(x))^2\big]=\underbrace{E_D\big[(f(x)-\hat f_D(x))^2\big]}_{\text{模型误差}}+\underbrace{\sigma^2}_{\text{Noise}}$$

**第二步，对模型误差加一项减一项。** 因 $f-\bar f$ 对 $D$ 是常数，再次展开后交叉项为零：

$$E_D\big[(f-\hat f_D)^2\big]=(f-\bar f)^2+E_D\big[(\bar f-\hat f_D)^2\big]+2(f-\bar f)\underbrace{E_D[\bar f-\hat f_D]}_{=0}$$

**第三步，合并并对 $x$ 取期望**，得到本章的核心恒等式：

$$\boxed{\;E_{x,y,D}\big[(y-\hat f_D(x))^2\big]=\underbrace{E_x\big[\big(E_D[\hat f_D(x)]-f(x)\big)^2\big]}_{\mathrm{Bias}^2}+\underbrace{E_x\big[\mathrm{Var}_D\big(\hat f_D(x)\big)\big]}_{\mathrm{Variance}}+\underbrace{\sigma^2}_{\mathrm{Noise}}\;}$$

- **Bias²（偏差平方）**：模型"平均预测"与真值之间的系统性偏离，衡量假设空间 $\mathcal H$ 能否表达 $f$。它与 $n$ 无关，只由模型族、特征、正则强度决定。
- **Variance（方差）**：不同训练集学到的模型之间的抖动，衡量模型对训练噪声的敏感度。线性回归下 $\mathrm{Var}[\hat f(x)]=\sigma^2x^\top(X^\top X)^{-1}x$，量级 $O(d_{\text{eff}}/n)$。
- **Noise（噪声）**：给定 $x$ 时 $y$ 的条件方差，是任何以 $x$ 为输入的预测器都无法消除的下界。严格说"不可约"是相对于当前特征集而言的：若能观测到更多与 $y$ 相关的协变量，条件方差会变小。

两点边界必须说清楚：(1) 该恒等式对**平方损失**严格成立，0-1 损失也有形式类似的分解，但 bias/variance 的定义不再唯一且需要额外处理最优贝叶斯误差项（Domingos, 2000）；(2) 推导用到"$\varepsilon$ 与 $D$ 独立"，即测试点与训练集同分布，**分布漂移**时等式失效，误差里会多出协变量偏移带来的偏差——这正是"离线指标好、线上差"的常见原因。

### 4.2 用实验验证分解恒等式

既然它恒等成立，我们就能**在同一点上重新采样 $y$** 估计左边，再与右边逐项相加对比。下面代码把 §3 的 `bias_variance` 扩展为同时给出经验期望误差与正则强度的版本：

```python
# 复用上面的 true_f / raw_design / fit_poly / predict / SIGMA

def decompose(degree, n, reps=300, grid=200, seed=0, lam=0.0):
    rng = np.random.default_rng(seed)
    xg = np.linspace(0.0, 1.0, grid)
    fg = true_f(xg)
    preds = np.empty((reps, grid))
    err = np.empty(reps)
    for r in range(reps):
        x = rng.uniform(0.0, 1.0, n)
        y = true_f(x) + rng.normal(0.0, SIGMA, n)
        w, mu, sd = fit_poly(x, y, degree, lam)
        preds[r] = predict(xg, w, mu, sd, degree)
        y_new = fg + rng.normal(0.0, SIGMA, grid) # 同一批 x 上重新采样一个 y
        err[r] = np.mean((y_new - preds[r]) ** 2) # 期望泛化误差的经验估计
        bias2 = np.mean((preds.mean(axis=0) - fg) ** 2)
        return bias2, np.mean(preds.var(axis=0)), err.mean

    header = f"{'degree':>6} | {'bias^2':>9} | {'variance':>9} | {'bias^2+var+noise':>16} | {'empirical EPE':>13}"
    print(header)
    print("-" * len(header))
    for d in (1, 2, 3, 5, 7, 9):
        b, v, e = decompose(d, n=30)
        print(f"{d:>6} | {b:>9.4f} | {v:>9.4f} | {b + v + SIGMA ** 2:>16.4f} | {e:>13.4f}")

        print("\n固定阶数，只改变训练样本量 n：")
        for d in (1, 9):
            for n in (20, 50, 200, 800):
                b, v, e = decompose(d, n)
                print(f" degree={d} n={n:>4} | bias^2={b:>8.4f} | variance={v:>9.4f} | test={e:>8.4f}")
```

实测输出：

```text
degree | bias^2 | variance | bias^2+var+noise | empirical EPE
-----------------------------------------------------------------
 1 | 0.1835 | 0.0229 | 0.2964 | 0.2968
 2 | 0.0328 | 0.0156 | 0.1384 | 0.1385
 3 | 0.0032 | 0.0161 | 0.1093 | 0.1090
 5 | 0.0003 | 0.0410 | 0.1313 | 0.1310
 7 | 0.0031 | 0.7238 | 0.8169 | 0.8186
 9 | 0.0733 | 37.9193 | 38.0826 | 38.0984
```

这张表同时验证两件事：**相加等于经验期望误差**（差值都在 $10^{-3}$ 量级的蒙特卡洛误差内），以及误差随容量呈 **U 型**——最低点在 3 阶（0.1093，已接近噪声地板 0.09 加残余偏差）。容量从 1 阶增到 3 阶买的是偏差下降（0.184 → 0.003，variance 几乎不变），从 5 阶增到 9 阶买到的却是方差失控（0.041 → 37.9）；并且阶数越高这两项估计越不稳（重尾），所以估方差时 `reps` 要够大，并换几个随机种子交叉验证。

### 4.3 偏差-方差权衡（bias-variance tradeoff）

以容量（阶数、树深、网络宽度）为横轴，bias² 单调下降、variance 单调上升，两者之和呈 U 型，最优容量满足 $\partial\,\mathrm{Bias}^2/\partial C=-\partial\,\mathrm{Var}/\partial C$。理论学习给出同一幅图：近似误差随 $\mathcal H$ 变大而下降，估计误差上界随 $\mathcal H$ 的复杂度（VC 维、Rademacher 复杂度）上升而上升、随 $n$ 上升而下降。工程上更常用的等价旋钮是正则强度 $\lambda$：$\lambda$ 小 = 容量大，$\lambda$ 大 = 容量小，调 $\lambda$ 与调模型大小动的是同一个东西。

一个必须知道的现代修正：**双下降（double descent）**。上述 U 型曲线的前提是容量通过固定假设空间或显式正则来控制；当模型参数量远超样本量（过参数化区间）时，测试误差在插值阈值附近先升后降，出现第二个下降段（Belkin 等, 2019；Nakkiran 等, 2019）。所以在深度学习里"参数越多越容易过拟合"不是普适规律；但第一段 U 型，以及"小样本 + 高容量 = 高方差"的结论依然成立。

### 4.4 为什么"更多数据只能降方差，不能降偏差"

看公式就清楚：$n$ 只出现在 variance 项里（线性模型下 $\propto d_{\text{eff}}/n$），bias² 与 $\sigma^2$ 都不含 $n$，因此

$$n\to\infty\;\Longrightarrow\;E[(y-\hat f_D(x))^2]\;\longrightarrow\;\mathrm{Bias}^2+\sigma^2$$

实测（沿用 4.2 节代码的第二个输出块）：

| 模型 | $n=20$ | $n=50$ | $n=200$ | $n=800$ |
| --- | --- | --- | --- | --- |
| 1 阶：bias² | 0.1851 | 0.1834 | 0.1834 | 0.1834 |
| 1 阶：variance | 0.0394 | 0.0123 | 0.0029 | 0.0007 |
| 1 阶：测试 MSE | 0.3162 | 0.2850 | 0.2747 | 0.2725 |
| 9 阶：bias² | 6.4003 | 0.0048 | 0.0000 | 0.0000 |
| 9 阶：variance | 782.95 | 1.0771 | 0.0055 | 0.0012 |
| 9 阶：测试 MSE | 789.41 | 1.1717 | 0.0954 | 0.0904 |

读法：1 阶（欠拟合）那三行里 bias² **纹丝不动**，variance 按 $\approx1/n$ 缩小，测试误差从 0.316 降到 0.2725 后**压平在 $0.1834+0.09\approx0.2734$ 附近**——这条平台线就是"加再多数据也过不去"的墙；工程含义是，**若验证误差随 $n$ 已走平而平台仍高于业务要求，继续采数据就是浪费**，应该去加特征、换假设空间，或重审标签质量与问题定义。9 阶（过拟合）那一列，同一个模型族靠 $n$ 从 20 涨到 800，测试误差从 789 降到 0.09，数据量把方差买了回来。

一个易被误读的点：9 阶的 bias² 也随 $n$ 下降（6.40 → 0.00），这不违反结论——小样本时参数估计被噪声推得极远，连"平均预测"都系统性偏离真值，这部分随 $n$ 消失的是**估计偏差**；只有纯粹的**近似误差**（假设空间表达不了 $f$）才不随 $n$ 变，1 阶那一行的 0.1834 才是它。另外，如果"更多数据"同时改变了特征的覆盖范围或分布（新增了原来没有的样本区域），它也会降低偏差，但此时收益来自"数据分布更接近部署分布"，而不是样本量本身。

### 4.5 学习曲线怎么读

学习曲线是"训练/验证误差 vs 训练样本量"的两条曲线，只判断形态就能定位问题：

| 训练误差 | 验证误差 | gap | 诊断 | 优先动作 |
| --- | --- | --- | --- | --- |
| 高 | 高，且与训练误差接近 | 小 | 欠拟合（高 bias），或已达噪声地板 | 加特征/提高容量/降正则；若平台 = 噪声地板则改问题定义 |
| 低 | 高 | 大，且验证曲线仍在下降 | 过拟合（高 variance） | 加数据、数据增强、加正则、集成、降容量 |
| 高 | 更高 | 中等且不随 $n$ 收窄 | 欠拟合叠加标签噪声/特征无效 | 检查标签质量与特征有效性；加容量没用 |
| 低 | 低 | 小且稳定 | 良好 | 检查验证集大小、切分方式、是否存在泄漏 |
| 高 | 高 | 大且两条平行 | 训练/验证分布不一致或泄漏 | 先修切分（`GroupKFold`、时间切分）与数据管道 |

下面代码（复用 §3 的函数）每个规模重复 20 次取平均，避免单次划分的噪声：

```python
# 复用上面的 true_f / raw_design / fit_poly / predict / SIGMA
rng = np.random.default_rng(0)
pool_x = rng.uniform(0.0, 1.0, 4000)
pool_y = true_f(pool_x) + rng.normal(0.0, SIGMA, 4000)
test_x = rng.uniform(0.0, 1.0, 2000)
test_y = true_f(test_x) + rng.normal(0.0, SIGMA, 2000)

for degree in (1, 5, 9):
    print(f"degree={degree}")
    for n in (15, 30, 60, 120, 400):
        train_mse, val_mse = [], []
        for _ in range(20): # 20 次不同抽样取平均
            idx = rng.permutation(len(pool_x))[:n]
            w, mu, sd = fit_poly(pool_x[idx], pool_y[idx], degree)
            train_mse.append(np.mean((pool_y[idx] - predict(pool_x[idx], w, mu, sd, degree)) ** 2))
            val_mse.append(np.mean((test_y - predict(test_x, w, mu, sd, degree)) ** 2))
            print(f" n={n:>4} | train={np.mean(train_mse):.4f} | "
            f"val={np.mean(val_mse):.4f} | gap={np.mean(val_mse) - np.mean(train_mse):+.4f}")
```

实测输出（每个规模 20 次重复的平均）：

| degree | $n=15$ | $n=30$ | $n=60$ | $n=120$ | $n=400$ |
| --- | --- | --- | --- | --- | --- |
| 1（train） | 0.2610 | 0.2669 | 0.2787 | 0.2643 | 0.2768 |
| 1（val） | 0.3202 | 0.3076 | 0.2838 | 0.2811 | 0.2735 |
| 5（train） | 0.0550 | 0.0754 | 0.0829 | 0.0885 | 0.0911 |
| 5（val） | 0.6029 | 0.1118 | 0.1042 | 0.0940 | 0.0913 |
| 9（val） | 9845.58 | 1.4556 | 0.1125 | 0.0988 | 0.0919 |

- **degree=1**：两条曲线**贴在一起且都很高**，val 从 0.32 缓慢降到 0.2735 就再也降不下去（≈ bias² 0.1834 + 噪声 0.09）。典型欠拟合：gap 小、两线都高。$n=400$ 时 gap 甚至是 $-0.0033$，说明欠拟合下 gap 本身很小、符号不稳定，**不要靠单次运行的 gap 符号下结论**。
- **degree=5**：$n=15$ 时 val 0.60、gap 0.55（高方差）；$n=400$ 时 val 0.0913、gap 0.0002（已到噪声地板）。这是"加数据能解决"的教科书形态。

### 4.6 正则化的统一视角

所有正则化方法都在做同一件事：**限制模型对训练集噪声的敏感度**，用一点 bias² 换更多的方差下降。对 $B$ 个两两相关性为 $\rho$ 的模型取平均（bagging 类方法）时 $\mathrm{Var}=\rho\sigma^2+\frac{1-\rho}{B}\sigma^2$，可见增大 $B$ 只压低第二项、偏差不变。

| 手段 | 数学形式 | 主要压什么 | 代价 | 使用注意 |
| --- | --- | --- | --- | --- |
| L2 / weight decay | $\lambda\|\theta\|_2^2$ | variance：缩小权重范数、改善条件数 | 系数整体等比收缩，不产生 0 | 特征需标准化；共线性强时首选 |
| L1 / Lasso | $\lambda\|\theta\|_1$ | variance + 特征选择（稀疏） | 有偏；相关特征只随机留一个 | 需标准化；想兼顾用 ElasticNet |
| 早停 | 迭代步数 $T$ 当容量旋钮 | variance：限制参数离初始点的距离 | 训练不充分会引入偏差 | 平方损失 + 梯度下降下与 L2 渐近等价 |
| Dropout | 训练时随机置零、推理缩放 | variance：近似模型平均/集成 | 有效容量下降、训练变慢 | 全连接层常用；与 BatchNorm 组合要小心 |
| 数据增强 | 用保持标签的变换扩大有效 $n$ | variance：直接增大有效样本量，并编码不变性先验 | 错误变换会抬高 bias² | 增强必须保持标签语义 |
| Bagging / 集成 | 平均多个模型 | variance：$\rho\sigma^2+\frac{1-\rho}{B}\sigma^2$ | 计算与存储成本 | 高方差低偏差模型收益最大 |

岭回归强度扫描（$n=30$、9 阶，复用 §3 的 `fit_poly` 与 4.2 节的 `decompose`）：

从 $\lambda=0$ 到 $10^{-1}$，variance 降了约 500 倍，bias² 只从 0.0733 变到 0.0011，总误差单调下降。原因是这个实验里真函数在假设空间内（9 阶多项式足以逼近 sin），正则几乎不引入偏差，属于"白拿"。**反例很重要**：若用 1 阶模型去拟合 sin，再加 L2 就只会抬高 bias²、让误差变差——正则从来不免费，它只是把误差预算从方差挪到偏差。

L1 的稀疏性（真模型只有 3 个非零系数，$n=50,d=9$）：

```python
import numpy as np

def soft_threshold(z, t):
    return np.sign(z) * np.maximum(np.abs(z) - t, 0.0)

def lasso_cd(X, y, lam, iters=1000):
    """min_w (1/(2n)) * ||y - Xw||^2 + lam * ||w||_1，坐标下降 + 软阈值。"""
    n, d = X.shape
    w = np.zeros(d)
    col_sq = (X ** 2).sum(axis=0)
    for _ in range(iters):
        for j in range(d):
            r = y - X @ w + X[:, j] * w[j] # 去掉第 j 个坐标后的残差
            w[j] = soft_threshold(X[:, j] @ r, lam * n) / col_sq[j]
            return w

        rng = np.random.default_rng(3)
        X = rng.normal(size=(50, 9)) # 50 个样本、9 个特征
        w_true = np.zeros(9)
        w_true[[0, 2, 5]] = [2.0, -1.5, 1.0] # 真模型只用了 3 个特征
        y = X @ w_true + rng.normal(0.0, 0.2, 50)

        w_ols = np.linalg.lstsq(X, y, rcond=None)[0]
        print(f"OLS 非零系数={int((np.abs(w_ols) > 1e-8).sum)} w={np.round(w_ols, 3)}")
        for lam in (0.02, 0.05, 0.1, 0.4):
            w = lasso_cd(X, y, lam)
            print(f"Lasso lam={lam:<5} 非零系数={int((np.abs(w) > 1e-8).sum)} w={np.round(w, 3)}")
```

实测输出：

```text

Lasso lam=0.02 非零系数=5 w=[ 1.984 0.04 -1.482 -0. 0. 0.937 -0. 0.015 -0. ]
Lasso lam=0.05 非零系数=4 w=[ 1.936 0.011 -1.434 -0. 0. 0.881 0. 0. -0. ]
Lasso lam=0.1 非零系数=3 w=[ 1.859 0. -1.358 -0. 0. 0.785 0. 0. 0. ]
Lasso lam=0.4 非零系数=3 w=[ 1.411 0. -0.911 -0. 0. 0.205 0. -0. 0. ]
```

$\lambda=0.1$ 时非零系数恰好 3 个，且支撑集 $\{0,2,5\}$ 就是真支撑；继续增大 $\lambda$ 不再提高稀疏度，只是把系数继续收缩（2.018 → 1.411），这就是偏差被主动引入的过程。

### 4.7 可操作的诊断流程

| 现象 | 判断 | 具体动作 |
| --- | --- | --- |
| 训练误差高、验证误差也高且接近 | 欠拟合（bias 主导） | 加特征/特征交叉、提高容量、降正则、延长训练；**加数据无效** |
| 训练误差低、验证误差高，验证曲线随 $n$ 仍下降 | 过拟合（variance 主导，数据不足） | 加数据/增强 → 加正则（L2、早停、Dropout）→ 集成 → 降容量 |
| 训练误差低、验证误差高，验证曲线已走平 | 过拟合但数据不是瓶颈 | 加正则、降容量、特征选择、集成；采数据优先级低 |
| 两条曲线都高，验证误差在某平台走平 | 噪声地板 / bias 地板 | 粗估 $\sigma^2$（同一样本重复标注或重复测量的方差）；检查标签噪声，确认问题本身可学 |
| 训练误差低、验证误差高，gap 不随 $n$ 收窄（两线平行） | 分布不一致或泄漏 | 查切分：时间序列用时间切分、分组数据用 `GroupKFold`、特征是否含未来信息 |
| 验证指标方差极大，或指标长期不涨只随换模型小幅涨 | 评估协议不稳 / 已接近可观测量上限 | K 折 + 多次重复并报均值与标准差；转向数据质量、特征、目标定义而非继续调参 |

**"先加数据、先加特征，还是先加模型复杂度"的决策顺序**（不看学习曲线无法回答，但看曲线后的顺序是固定的）：

1. **先固定评估协议**：独立测试集（只在最后用一次）+ 交叉验证 + 明确基线（多数类、随机、上一版模型）。没有基线，"验证误差高"没有意义。
2. **再看学习曲线**，用 4.5 节的四象限表定位 bias 主导还是 variance 主导。
3. **variance 主导**时按性价比排序：数据/增强 → 正则 → 集成 → 降容量。因为加数据同时改善后续所有选择的可靠性，而正则要额外调超参。
4. **bias 主导**时按信息量排序：加新特征/特征交叉 → 换更强的假设空间 → 降正则。此时加数据是把钱扔进平台里。
5. **两者都高、验证误差贴在平台上**时，先查标签与切分，再考虑换问题定义。这一步经常能解释"怎么调都不涨"。
6. **只有训练误差本身也高**（欠拟合）时，"加模型复杂度"才是正确动作；训练误差低而验证误差高时加容量只会让 gap 更大。

## 5. 常见坑

| 坑 | 现象 | 原因 | 正确做法 |
| --- | --- | --- | --- |
| 把"过拟合"当成万能解释 | 一见验证集差就加正则、加 Dropout | 欠拟合、噪声地板、分布漂移都会表现为"验证集差" | 先看学习曲线四象限，区分 bias/variance/noise 再动手 |
| 只看准确率不看基线 | 报告"准确率 0.93"就认为可用 | 类别不平衡时多数类基线可能就有 0.92 | 同时报告多数类/随机/上一版模型基线，配 AUC、F1、PR 曲线 |
| 测试集反复使用 | 调 30 轮超参后选测试集最好的一版上线，线上掉点 | 每用一次测试集选模型，它就参与了一次选择，形成隐性过拟合 | 测试集只用一次；调参用验证集/CV；需要反复评估时用嵌套 CV 或新的留出集 |
| 用训练误差挑模型 | 越复杂的模型训练误差越低，于是总选最复杂的 | 训练误差是分解里**被优化过**的量，不是泛化误差的估计 | 用验证集/交叉验证选择；训练误差只用来判断欠拟合 |
| 不标准化就加正则 | L2 只把量纲大的特征压小，结果比不加还差 | 惩罚项对系数尺度敏感，不同特征量纲不可比 | 正则前统一标准化；截距不惩罚 |
| 用极小验证集读学习曲线 | 曲线抖动剧烈，gap 符号都可能翻转 | 验证误差本身是高方差估计 | 多次重复划分并报均值与标准差；验证集样本量至少数百 |

三个最容易被误用的"结论"：

1. **"过拟合就是模型太复杂"**：在双下降区间更大的模型反而泛化更好；而线性模型 + 高维稀疏特征场景的过拟合通常来自特征泄漏，不是容量。
2. **"验证集比训练集差就是过拟合"**：欠拟合时训练误差本身也很高；正确定义要看 gap 大小 + 验证误差是否还能随 $n$ 下降。
3. **"测试集指标就是泛化能力"**：它只是泛化能力的一次含噪估计，反复使用之后这个估计本身就是有偏的。

## 6. 面试问答

**Q1：推导期望泛化误差的偏差-方差-噪声分解，并说明为什么噪声项不可约。**

<details markdown="1">
<summary markdown="1">参考答案</summary>

设 $y=f(x)+\varepsilon$，$E[\varepsilon]=0$，$\mathrm{Var}(\varepsilon)=\sigma^2$，$\varepsilon$ 独立于 $x$ 和训练集 $D$，$\bar f=E_D[\hat f_D]$。展开 $(f+\varepsilon-\hat f_D)^2$ 后交叉项因 $E[\varepsilon]=0$ 且独立而消失，得 $E[(y-\hat f_D)^2]=E[(f-\hat f_D)^2]+\sigma^2$；再对 $f-\hat f_D=(f-\bar f)+(\bar f-\hat f_D)$ 展开，交叉项因 $E_D[\bar f-\hat f_D]=0$ 消失，得 $E_D[(f-\hat f_D)^2]=(f-\bar f)^2+\mathrm{Var}_D(\hat f_D)$，合并即 $\mathrm{Bias}^2+\mathrm{Var}+\sigma^2$。

$\sigma^2=\mathrm{Var}(Y\mid X=x)$ 是给定 $x$ 时 $y$ 的条件方差，只由数据生成过程决定，与模型、参数、样本量都无关，所以任何以 $x$ 为输入的预测器都无法消除它。三点边界：该等式对平方损失严格成立，0-1 损失需要修正定义；它假设测试点与训练集同分布，分布漂移时失效；"不可约"是相对当前特征集而言的，加入新的相关协变量可以降低条件方差。

</details>

**Q2：为什么回归用 MSE、分类用交叉熵？请从 MLE 角度解释。**

<details markdown="1">
<summary markdown="1">参考答案</summary>

回归：假设 $y=f_\theta(x)+\varepsilon,\ \varepsilon\sim\mathcal N(0,\sigma^2)$，负对数似然为 $\frac{n}{2}\log(2\pi\sigma^2)+\frac{1}{2\sigma^2}\sum_i(y_i-f_\theta(x_i))^2$，第一项与参数无关，故 MLE 等价于最小化平方误差，$\sigma^2$ 只改变尺度。若噪声服从拉普拉斯分布，MLE 就变成最小化绝对误差。

分类：假设 $y\mid x\sim\mathrm{Bernoulli}(h_\theta(x))$，负对数似然 $-\sum_i[y_i\log h_i+(1-y_i)\log(1-h_i)]$ 就是二元交叉熵；多分类换成 categorical 分布与 softmax，得到 softmax 交叉熵。加分点：交叉熵对 logit 的梯度是 $h-y$，错得越远离梯度越大；logistic + MSE 的梯度是 $(h-y)h(1-h)$，在饱和区消失且损失非凸。同时要指出平方损失对概率输出（Brier score）也是 proper scoring rule、最小化点同样是 $\eta(x)$，只是对自信错误的惩罚有界、对标签噪声更稳健。

</details>

**Q3：训练样本量翻倍，期望误差会怎么变？什么情况下翻倍也没用？**

<details markdown="1">
<summary markdown="1">参考答案</summary>

只有方差项与 $n$ 有关（线性模型下 $\mathrm{Var}[\hat f(x)]=\sigma^2x^\top(X^\top X)^{-1}x\approx O(d_{\text{eff}}/n)$），所以 $n$ 增大会把方差按 $\approx1/n$ 压低，误差下限是 $\mathrm{Bias}^2+\sigma^2$。加数据无效的情况：已处于平台区（验证误差随 $n$ 走平且 gap 很小，误差由偏差或噪声主导）；偏差来自假设空间表达力不足（如用线性模型拟合强非线性关系），$n\to\infty$ 误差也停在 $\mathrm{Bias}^2+\sigma^2$；噪声地板高（标签噪声大）；训练/部署分布不一致，在旧分布上加数据不解决漂移。例外：若新增数据改变了特征覆盖范围、使训练分布更接近部署分布，它会同时降低偏差，但收益来自分布改善而非样本量。

</details>

**Q4：L1 与 L2 正则化的区别？为什么 L1 产生稀疏解？**

<details markdown="1">
<summary markdown="1">参考答案</summary>

优化角度：L2 的梯度是 $2\lambda\theta$，在 0 处梯度为 0，最优点只能趋近 0 而不精确等于 0；L1 在 0 处的次梯度是一个区间 $[-\lambda,\lambda]$，只要该坐标的梯度落入这个区间，最优解就精确取 0。几何上，L1 的约束域是顶点在坐标轴上的菱形，损失等高线容易首先碰到顶点；L2 的约束域是圆，接触点一般不在坐标轴上。相关特征上 L1 只保留其中一个（选择不稳定），ElasticNet 用 L1+L2 缓解。

贝叶斯角度：L2 对应高斯先验 $\theta\sim\mathcal N(0,\tau^2)$，L1 对应拉普拉斯先验 $p(\theta)\propto e^{-\|\theta\|_1/b}$，后者在 0 处有尖峰、尾部更厚，众数常落在坐标轴上。两者都是 MAP 估计，即用偏差换取方差下降。实践要点：正则前必须标准化特征，且不惩罚截距。

</details>

## 7. 自测题

1. 写出期望风险 $R(f)$ 与经验风险 $\hat R_n(f)$ 的定义，并解释为什么最小化 $\hat R_n$ 会带来泛化误差。
2. 已知真实噪声 $\sigma=0.3$，某模型的 $\mathrm{Bias}^2=0.25$、$\mathrm{Var}=0.10$，它的期望 MSE 是多少？不断加数据能把误差降到多少以下吗？
3. 你观察到训练误差 0.02、验证误差 0.35，学习曲线显示验证误差随训练样本量增加仍在明显下降。按 4.7 节的顺序，你的前三个动作是什么？
4. 为什么 L2 不能把系数压成精确的 0，而 L1 可以？给出优化与贝叶斯两种解释。
5. 你反复用同一个测试集调了 30 次超参数，最后选出的模型测试集准确率 0.91。这个 0.91 还能当作泛化能力的估计吗？为什么，怎么办？

<details markdown="1">
<summary markdown="1">参考答案</summary>

1. $R(f)=E_{(X,Y)\sim P}[\ell(y,f(x))]$，$\hat R_n(f)=\frac1n\sum_i\ell(y_i,f(x_i))$。$\hat R_n$ 只是 $R$ 的有限样本估计：它只覆盖 $n$ 个样本、方差不为零（估计误差），而我们又是在假设空间里取最小值，最小化过程会把训练集特有的噪声也拟合进去（优化偏差），所以训练风险低于期望风险。
2. $0.25+0.10+0.09=0.44$。加数据只能压低 variance 项，极限是 $0.25+0.09=0.34$，所以能把误差从 0.44 压到约 0.34 附近，但降不到 0.34 以下；要进一步降低必须改特征或换假设空间。
3. 先确认评估协议与基线（是否有泄漏、切分是否正确、基线指标是多少）；这是典型高方差形态（gap 大且验证曲线仍下行），优先加数据或数据增强；随后加正则（L2、早停、Dropout）与集成，最后才考虑降容量。加容量会加剧 gap，不要做。
4. 优化角度：L2 的梯度在 0 处为 0，最优点只能趋近 0；L1 在 0 处有次梯度区间，坐标一旦落入该区间就精确取 0。贝叶斯角度：L2 等价高斯先验（0 处光滑），L1 等价拉普拉斯先验（0 处有尖峰），后验众数容易落在坐标轴上。两者都是 MAP 估计，会用偏差换方差。
5. 不能作为无偏的泛化估计。每用测试集做一次选择就向测试集注入了一次信息，多轮选择后"最优"的那一版包含测试集噪声，产生隐性过拟合。正确做法：测试集只在最终评估使用一次；调参用验证集或交叉验证；确实需要反复评估时用嵌套交叉验证或另留一份新的留出集。

</details>
