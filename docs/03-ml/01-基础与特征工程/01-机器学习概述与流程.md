# 机器学习概述与流程

> **一句话总结**：机器学习是把"人工写规则"换成"从数据中估计参数"的工程范式，它的骨架是「数据 → 特征工程 → 模型 → 评估 → 调优 → 上线」这条闭环，而贯穿全流程的核心矛盾是**泛化**（generalization）——在没见过的数据上也能预测准。
> **前置知识**：Python 基础语法、numpy 数组与 pandas DataFrame 的基本操作、一点点高中函数与坐标系概念。
> **学完能做到**：
> 1. 说清 AI / ML / DL 的包含关系，并用"规则编程 vs 模型学习"区分两类问题；
> 2. 独立写出一个 scikit-learn 的完整建模脚本（加载 → 划分 → 标准化 → 训练 → 预测 → 评估）；
> 3. 用"训练误差 / 验证误差"两条曲线判断当前是欠拟合还是过拟合，并说出对应的解决方向。

---

## 1. 核心思想

### 1.1 从"写规则"到"学参数"

| 对比维度 | 基于规则的学习（rule-based） | 基于模型的学习（model-based） |
| --- | --- | --- |
| 知识来源 | 程序员手工编写的 `if-else` 经验 | 从历史数据中学到的统计规律 |
| 典型代码 | `if 有翅膀 and 会飞 and 会叫: print("鸟")` | `model.fit(X, y)` |
| 优点 | 可解释、可审计、无需数据 | 能处理难以显式描述的任务 |
| 缺点 | 规则爆炸、无法覆盖长尾 | 依赖数据质量，可能过拟合 |
| 适用任务 | 表单校验、风控硬规则、业务流程 | 图像/语音识别、NLP、推荐、预测 |

> 的关键判断：**图像识别、语音识别、自然语言处理这类问题写不出完备规则**，所以必须转向基于模型的学习。

"学习"在数学上就是一次**参数估计**：以房价预测为例，假设 $y = ax + b$，其中 $a,b$ 未知，用数据去求 $a,b$，这一对 $(a,b)$ 就叫**参数**（parameter），而 $y=ax+b$ 这个形式就叫**模型**（model）。

### 1.2 三大概念与包含关系

| 概念 | 英文 | 一句话定义 | 与相邻概念的关系 |
| --- | --- | --- | --- |
| 人工智能 | Artificial Intelligence, AI | 研究与构建"能智能行动的计算主体"的学科 | 最大的集合 |
| 机器学习 | Machine Learning, ML | 让计算机**无需显式编程**就能从数据中获得能力 | AI 的一种实现途径 |
| 深度学习 | Deep Learning, DL | 用多层神经元堆叠模拟复杂函数的机器学习方法 | ML 的一种具体方法 |

$$\text{AI} \supset \text{ML} \supset \text{DL}$$

- 机器学习识别车：**从数据中获取规律**，来一张新图 → 产生一个新预测。
- 人类识别车：**从经验中归纳特征**，来一张新图 → 靠记忆与常识判断。
- 深度学习：大脑仿生，一层层神经元去逼近任意复杂函数。

### 1.3 学习方式的分类（最重要的分类维度）

| 学习方式 | 数据是否带标签 | 目标任务 | 典型算法 | 典型场景 |
| --- | --- | --- | --- | --- |
| 监督学习 – 分类 | 有标签，标签**离散** | 预测类别 | KNN、逻辑回归、决策树、随机森林、XGBoost | 肿瘤良恶、客户流失、垃圾邮件 |
| 监督学习 – 回归 | 有标签，标签**连续** | 预测数值 | 线性回归、回归决策树、GBDT、XGBRegressor | 房价、电力负荷、销量 |
| 无监督学习 | 无标签 | 发现内在结构与相似性 | KMeans、DBSCAN、层次聚类、PCA | 用户分群、异常检测、降维 |
| 半监督学习 | 少量有标签 + 大量无标签 | 降低标注成本 | 自训练、协同训练 | 医学影像标注昂贵场景 |
| 强化学习 | 无标签，但有奖励信号 | 最大化累计回报 | Q-Learning、策略梯度 | AlphaGo、机器人控制、推荐策略 |

**半监督的运作原理**（原文思路）：
1. 请领域专家标注**少量**数据，训练出一个初始模型；
2. 用这个模型去"套用"未标注数据，得到伪标签；
3. 请专家比对模型结果，据此迭代改进模型。

**强化学习的四要素**：agent（智能体）、环境状态（state）、行动（action）、奖励（reward）。小孩子学走路的类比：小孩是 agent，地面是环境，迈步是 action，走了几步得到巧克力就是 reward。

### 1.4 常见术语速查

| 术语 | 含义 | 在表格中的位置 |
| --- | --- | --- |
| 样本 sample / 记录 | 一行数据 | 行 |
| 特征 feature / 属性 | 一列数据，刻画样本的某个维度 | 列（除标签列） |
| 标签 label / 目标 target | 模型要预测的那一列 | 最后一列 |
| 数据集 dataset | 样本的集合 | 整张表 |
| 训练集 training set | 用来拟合参数的部分 | 通常 70%~80% |
| 测试集 test set | 只用来评估，绝不参与训练 | 通常 20%~30% |

> **特征的关键理解**：特征不是"表里有的列"，而是**从原始数据中抽取出来的、对预测结果有用的信息**。这解释了为什么"特征工程决定上限"。

### 1.5 建模流程（本节的七步法）

```
① 获取数据 → ② 数据基本处理 → ③ 特征工程 → ④ 模型训练 → ⑤ 模型评估 → ⑥ 模型调优 → ⑦ 模型应用
```

| 阶段 | 主要工作 | 常见动作 | 产出 |
| --- | --- | --- | --- |
| ① 获取数据 | 明确数据源、字段含义、规模 | 读 CSV/数据库/API | DataFrame |
| ② 数据基本处理 | 缺失值、异常值、重复值、类型转换 | `dropna` / `fillna(mean)` / 去重 / one-hot | 干净的数据 |
| ③ 特征工程 | 提取、预处理、降维、选择、组合 | `StandardScaler`、`get_dummies`、`PCA`、`SelectKBest` | 特征矩阵 $X$ |
| ④ 模型训练 | 选算法、拟合参数 | `estimator.fit(X_train, y_train)` | 训练好的模型 |
| ⑤ 模型评估 | 用与训练无关的数据衡量 | MSE/RMSE/MAE、混淆矩阵、AUC、CH | 数值指标 |
| ⑥ 模型调优 | 调超参数、缓解过拟合 | `GridSearchCV`、正则化、剪枝、早停 | 最优超参数 |
| ⑦ 模型应用 | 部署、预测、监控 | `joblib.dump/load`、`predict` | 线上服务 |

**划分数据集的经验比例**：训练 : 测试 = 8 : 2 或 7 : 3。数据量大（百万级）时可以用 98 : 2；数据量很小（几百条）时必须配合交叉验证。

### 1.6 拟合问题：整门课的心跳

| 状态 | 训练集表现 | 测试集表现 | 本质 | 解决方向 |
| --- | --- | --- | --- | --- |
| 欠拟合 underfitting | 差 | 差 | 模型过于简单 / 特征太少 | 加特征、加多项式特征、换更复杂模型、减小正则化力度 |
| 拟合良好 | 好 | 好 | 复杂度与数据量匹配 | —— |
| 过拟合 overfitting | 好 | 差 | 模型过于复杂 / 数据太脏 / 数据太少 | 清洗数据、增加数据、正则化、降维、剪枝、早停 |

- **泛化（generalization）**：模型在新数据集（非训练数据）上的表现好坏的能力。训练误差小不等于泛化好。
- **奥卡姆剃刀原则**：若两个模型泛化误差相同，**取更简单的那个**。

## 2. 算法细节

### 2.1 监督学习的数学形式

给定训练集 $D = \{(\boldsymbol{x}_i, y_i)\}_{i=1}^{N}$，其中 $\boldsymbol{x}_i \in \mathbb{R}^{d}$ 是特征向量，$y_i$ 是标签：

- **分类任务**：$y_i \in \{c_1, c_2, \dots, c_K\}$，目标是学一个映射 $f: \mathbb{R}^d \to \{c_1,\dots,c_K\}$；
- **回归任务**：$y_i \in \mathbb{R}$，目标是学 $f: \mathbb{R}^d \to \mathbb{R}$。

学习的过程就是在一个**假设空间** $\mathcal{H}$ 中找 $f$，使得某个损失函数最小：

$$\hat{f} = \arg\min_{f \in \mathcal{H}} \frac{1}{N}\sum_{i=1}^{N} L\big(y_i,\ f(\boldsymbol{x}_i)\big)$$

**无监督学习**没有 $y$，只能优化"簇内紧、簇间散"这类**内部准则**（如 KMeans 的 SSE）：

$$\hat{C} = \arg\min_{C} \sum_{k=1}^{K}\sum_{\boldsymbol{x}\in C_k} \|\boldsymbol{x} - \boldsymbol{\mu}_k\|_2^2,\qquad \boldsymbol{\mu}_k = \frac{1}{|C_k|}\sum_{\boldsymbol{x}\in C_k}\boldsymbol{x}$$

### 2.2 偏差-方差分解（为什么会有过拟合）

对任意测试点 $\boldsymbol{x}$，期望泛化误差可以分解为三项：

$$\mathbb{E}\big[(y - \hat{f}(\boldsymbol{x}))^2\big] = \underbrace{\text{Bias}^2[\hat{f}(\boldsymbol{x})]}_{\text{偏差}^2} + \underbrace{\text{Var}[\hat{f}(\boldsymbol{x})]}_{\text{方差}} + \underbrace{\sigma^2}_{\text{不可约噪声}}$$

**手推思路（不用严格证明，抓住直觉）**：设 $y = f^*(\boldsymbol{x}) + \varepsilon$，$\mathbb{E}[\varepsilon]=0$，$\text{Var}[\varepsilon]=\sigma^2$。记 $\bar{f}(\boldsymbol{x}) = \mathbb{E}[\hat{f}(\boldsymbol{x})]$，则

$$
\begin{aligned}
\mathbb{E}[(y-\hat f)^2]
&= \mathbb{E}\big[(f^*+\varepsilon-\hat f)^2\big]\\
&= \mathbb{E}\big[(f^*-\hat f)^2\big] + 2\underbrace{\mathbb{E}[\varepsilon]}_{=0}\mathbb{E}[f^*-\hat f] + \mathbb{E}[\varepsilon^2]\\
&= \mathbb{E}\big[(f^*-\bar f + \bar f - \hat f)^2\big] + \sigma^2\\
&= (f^*-\bar f)^2 + \mathbb{E}[(\hat f-\bar f)^2] + \sigma^2
\end{aligned}
$$

**三项的含义与调参方向**：

| 项 | 含义 | 模型复杂度 ↑ 时 | 怎么降 |
| --- | --- | --- | --- |
| $\text{Bias}^2$ | 模型假设与真实规律的偏离 | 下降 | 加特征、加复杂度 |
| $\text{Var}$ | 模型对训练集扰动的敏感度 | 上升 | 正则化、加数据、bagging |
| $\sigma^2$ | 数据本身的噪声 | 不变 | 只能改善数据质量 |

**结论**：总误差是一条 U 形曲线，最优点在"偏差与方差平衡"处——这就是为什么**过拟合与欠拟合是同一枚硬币的两面**。

### 2.3 用学习曲线诊断（工程做法）

| 现象 | 训练误差 | 验证误差 | 二者差距 | 诊断 | 处方 |
| --- | --- | --- | --- | --- | --- |
| 曲线 A | 高 | 高（≈训练误差） | 小 | 欠拟合 | 更复杂的模型 / 更多特征 |
| 曲线 B | 低 | 高 | 大 | 过拟合 | 更多数据 / 正则化 / 剪枝 |
| 曲线 C | 低 | 低 | 小 | 理想 | 可以上线 |

**增加训练数据量的作用**：只有"过拟合"能从加数据中获益；模型已欠拟合时堆数据几乎无用。

## 3. 可运行示例

下面这段代码把"七步法"压进一个脚本，用鸢尾花数据集演示完整闭环。注意**标准化的纪律都遵守了**（只在训练集 fit，测试集只 transform）。

```python
# -*- coding: utf-8 -*-
"""机器学习建模流程最小可运行模板（scikit-learn）

覆盖：加载数据 -> 划分数据集 -> 特征预处理 -> 训练 -> 预测 -> 评估 -> 保存 -> 加载推理
"""
import joblib
import numpy as np
from sklearn.datasets import load_iris
from sklearn.metrics import accuracy_score, classification_report
from sklearn.model_selection import cross_val_score, train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.preprocessing import StandardScaler


def main():
    # ① 获取数据
    iris = load_iris()
    X, y = iris.data, iris.target # X: (150, 4) y: (150,)

    # ② 划分数据集：stratify=y 保证训练/测试集里各类别比例一致
    X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=22, stratify=y
    )

    # ③ 特征工程：标准化（Z-Score）
    # 关键：统计量只能从训练集学出来，否则测试集信息会"泄漏"进训练
    transfer = StandardScaler()
    X_train = transfer.fit_transform(X_train) # 训练集：fit + transform
    X_test = transfer.transform(X_test) # 测试集：只 transform

    # ④ 模型训练
    estimator = KNeighborsClassifier(n_neighbors=5)
    estimator.fit(X_train, y_train)

    # ⑤ 模型评估
    y_pred = estimator.predict(X_test)
    print("预测值 :", y_pred)
    print("真实值 :", y_test)
    print("准确率 :", accuracy_score(y_test, y_pred))
    print("estimator.score:", estimator.score(X_test, y_test))
    print(classification_report(y_test, y_pred, target_names=iris.target_names))

    # ⑥ 调优：交叉验证给出更稳的泛化估计（5 折）
    cv_scores = cross_val_score(estimator, X_train, y_train, cv=5)
    print("5 折交叉验证得分:", np.round(cv_scores, 4), "均值:", cv_scores.mean())

    # ⑦ 保存与推理
    joblib.dump(estimator, "knn_iris.pkl")
    model = joblib.load("knn_iris.pkl")

    # 模拟一条线上新样本：必须做同样的标准化！
    new_sample = np.array([[5.1, 3.5, 1.4, 0.2]])
    new_sample = transfer.transform(new_sample)
    print("新样本预测类别:", model.predict(new_sample))
    print("新样本各类别概率:", np.round(model.predict_proba(new_sample), 4))


    if __name__ == "__main__":
        main()
```

**预期输出要点**：准确率约 0.93 上下（`n_neighbors=5`、`random_state=22` 时通常 14/15 或 15/15）；`predict_proba` 返回 3 个概率且和为 1。

## 4. 常见坑

| # | 坑 | 错误写法 | 正确做法 | 后果 |
| --- | --- | --- | --- | --- |
| 1 | 先标准化再划分数据集 | `scaler.fit_transform(X)` 后再 `train_test_split` | **先划分，再 fit_transform 训练集、transform 测试集** | 测试集统计量泄漏，评估虚高 |
| 2 | 用测试集调参 | `GridSearchCV` 直接在测试集上评分 | `GridSearchCV` 只在**训练集**里做 CV，测试集只评一次 | 测试集变成验证集，泛化估计失真 |
| 3 | 类别不平衡仍用 `accuracy` | 99% 负样本，全预测负例 → 准确率 99% | 看 precision/recall/F1、AUC，或调 `class_weight` | 模型"看起来很好"但毫无价值 |
| 4 | 把 `random_state` 当无关紧要 | 每次结果都不同，无法复现 | 固定 `random_state`，记录在实验中 | 实验不可复现 |
| 5 | 回归问题也用 `stratify` | `stratify=y` 用于连续标签 | 分类才用 stratify/StratifiedKFold | 报错或分组无意义 |
| 6 | 只想靠"加数据"解决欠拟合 | 数据翻倍但模型仍是直线 | 欠拟合要加特征/加复杂度 | 白费算力 |
| 7 | 忽略标签列混进特征 | `X = df.iloc[:, :]` 把 target 也当特征 | `X = df.iloc[:, :-1]`，`y = df.iloc[:, -1]` | 模型"作弊"，准确率 100% |
| 8 | 特征量纲差异巨大直接上 KNN/线性回归 | 收入(万元) 与 年龄(岁) 同权 | 标准化/归一化后再训练 | 大量纲特征支配距离与系数 |
| 9 | 用 `dropna()` 无脑清数据 | 删完之后样本只剩一半 | 先统计缺失比例，决定是填还是删 | 数据量损失过大，引入偏差 |
| 10 | 把训练集准确率当成最终效果 | 只报告 `train` 分数 | 必须报告独立测试集分数 | 上线后效果崩盘 |

## 5. 面试问答

<details><summary>Q1：有监督学习和无监督学习的区别是什么？各自适合什么场景？</summary>

**参考答案**

| 维度 | 有监督学习 | 无监督学习 |
| --- | --- | --- |
| 训练数据 | 有标签 $(x, y)$ | 只有特征 $x$ |
| 优化目标 | 最小化预测值与标签的误差 | 最小化/最大化某种内部结构准则（SSE、轮廓系数等） |
| 输出 | 分类（离散）/ 回归（连续） | 簇划分、降维后的表示、异常分数 |
| 评估 | 有客观的"对/错"，可用准确率、MSE、AUC | 没有标准答案，需要用内部指标或业务验证 |
| 数据成本 | 标注成本高 | 无需标注，成本低 |

**选择依据**：能拿到标签、且任务目标是"预测某个已知量" → 监督学习；没有标签、目标是"发现结构/分群/降维/找异常" → 无监督学习。实务中常常**先用无监督做探索（聚类、降维），再对有标签部分做监督建模**。
</details>

<details><summary>Q2：什么是过拟合？如何判断？有哪些解决手段？</summary>

**参考答案**

**定义**：模型在训练集上表现很好、在测试集（新数据）上表现明显变差，本质是模型把训练数据中的**噪声和偶然规律**也学进去了，导致泛化能力差。用偏差-方差语言说，就是**方差过大**。

**判断方法**：
1. 对比训练集与验证集的指标，差距大（如训练 0.99 / 验证 0.72）即为过拟合；
2. 画学习曲线，看"训练误差低、验证误差高且两者间距大"；
3. 交叉验证各折得分方差很大，也是信号。

**解决手段**（按性价比排序）：
1. **增加训练数据 / 数据增强**：最有效但常常最贵；
2. **正则化**：L1（Lasso，可把系数压到 0，做特征选择）、L2（Ridge，把系数压小）、Dropout（深度学习）；
3. **降低模型复杂度**：决策树剪枝、限制 `max_depth`、减少多项式阶数、减少神经元数量；
4. **特征降维 / 特征选择**：PCA、方差过滤、相关系数过滤；
5. **早停 early stopping**：验证集误差不再下降就停；
6. **集成 + 交叉验证**：bagging（随机森林）天然降方差。
</details>

<details><summary>Q3：为什么"数据和特征决定了机器学习的上限，而模型和算法只是逼近这个上限"？</summary>

**参考答案**

这句话点出了工程现实中的**信息论约束**：模型能学到的信息全部来自数据与特征。如果特征里不含区分样本所必需的信息（例如用"身高、体重"预测"是否会写 Python"），再强的模型也无法突破信息量的天花板；反之，只要特征足够有判别力，简单模型（逻辑回归、KNN）也能取得不错效果。

工程上的三个推论：
1. **优先投入特征工程**：同一份数据，好的特征（组合特征、时间特征、交叉特征）往往带来比换模型更大的提升；
2. **模型选择是"逼近能力"的选择**：线性模型逼近能力弱、树模型/深度模型逼近能力强，但逼近能力强也意味着更容易过拟合，需要用正则化、数据量去配合；
3. **评估不可替代**：既然上限由数据决定，就必须用独立测试集/交叉验证才能知道"当前离上限还有多远"。
</details>

## 6. 自测题

<details><summary>1. AI、ML、DL 三者的包含关系是什么？请各举一个本节中出现的代表算法。</summary>

$\text{AI} \supset \text{ML} \supset \text{DL}$。机器学习是实现人工智能的一种途径，深度学习是机器学习的一种方法。
- AI 代表：专家系统、AlphaGo（更宽泛地看，符号推理也属于 AI）；
- ML 代表：KNN、逻辑回归、决策树、随机森林、XGBoost；
- DL 代表：多层神经网络、AlexNet、RNN/LSTM、Transformer。
</details>

<details><summary>2. 判断下列任务属于分类、回归还是聚类：(a) 预测下一小时电力负荷；(b) 把顾客按消费行为分成 5 群；(c) 判断肿瘤是良性还是恶性；(d) 预测红酒品质等级 0~5。</summary>

(a) **回归**（标签连续、数值）；(b) **聚类**（无标签、按相似性分群）；(c) **二分类**；(d) **多分类**（标签是离散等级，虽然用整数 0~5 表示，但类别之间没有大小关系，不能用回归去"平均"）。
</details>

<details><summary>3. 某模型训练集准确率 0.99、测试集 0.70，应优先尝试哪些措施？如果训练集 0.62、测试集 0.60 呢？</summary>

前者是典型的**过拟合**（训练高、测试低、差距大），优先尝试：增加数据/数据增强、加正则化（L1/L2）、降低模型复杂度（限制树深、剪枝）、降维、早停。

后者是典型的**欠拟合**（两者都低、差距小），优先尝试：增加更有判别力的特征、加入多项式/交叉特征、更换更强的模型（如从线性回归换成 GBDT）、减小正则化强度。此时加数据几乎无用。
</details>

<details><summary>4. 为什么测试集的准确率不能用来调超参数？正确的做法是什么？</summary>

因为一旦你**根据测试集分数反复调整**模型或超参数，测试集的信息就通过你的决策"泄漏"进了模型选择过程，测试集事实上变成了验证集，它给出的分数会**乐观偏置**，无法再代表真实泛化能力。

正确做法：把数据分成 **训练集 / 验证集 / 测试集**（如 6:2:2），或直接在训练集内部做 **K 折交叉验证 + 网格搜索**（`GridSearchCV`）来选超参数，测试集**只在最后评估一次**。
</details>

<details><summary>5. 什么是奥卡姆剃刀原则？它在模型选择中如何体现？</summary>

奥卡姆剃刀：**若两个模型的泛化误差相同，应选更简单的那个**。

体现方式：
- 决策树在精度相同时选更浅的树（所以有 `max_depth`、剪枝）；
- 线性模型在精度接近时优先于复杂集成模型（可解释、推理快、易维护）；
- 正则化本质上就是在"损失相同"的候选解中偏向系数更小的解；
- 特征选择优先剔除冗余特征。
</details>
