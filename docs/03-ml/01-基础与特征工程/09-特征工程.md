## 1. 核心思想

### 1.1 什么是特征工程

从两个角度看"特征"：

| 视角 | 特征是什么 |
| --- | --- |
| 数据集角度 | **一列一列的数据**就是特征 |
| 模型训练角度 | **对预测结果有用的属性**才是特征 |

**特征工程的定义**：利用专业背景知识和技巧处理数据，**让机器学习算法效果最好**的过程。

> 引用的经典论断：
> "Coming up with features is difficult, time-consuming, requires expert knowledge. 'Applied machine learning' is basically feature engineering."
> 意思是：特征工程困难、耗时、需要专业知识，**应用机器学习的本质就是特征工程**。

**为什么它决定上限**：模型能学到的信息全部来自特征。如果特征里不含区分样本所必需的信息（如用"身高、体重"预测"会不会写 Python"），再强的模型也无法突破信息量的天花板；反之只要特征有判别力，简单模型也能取得好效果。

### 1.2 特征工程的五大组成部分

| 组成部分 | 定义 | 是否改变原始数据取值 | 代表工具 |
| --- | --- | --- | --- |
| **特征提取** | 从原始数据中提取与任务相关的特征，构成特征向量 | 是（把非结构化变成结构化） | `DictVectorizer`、`CountVectorizer` |
| **特征预处理** | 把不同量纲的特征转换到同一范围，使各特征对模型影响一致 | 是（数值缩放） | `MinMaxScaler`、`StandardScaler` |
| **特征降维** | 把原始数据的维度降低 | **会丢失部分信息**，保留主要信息 | `PCA`、`TSNE` |
| **特征选择** | 从原始特征中选出一个重要子集 | **不会改变原来的数据**（只是挑列） | 相关系数、`VarianceThreshold`、`Lasso`、`feature_importances_` |
| **特征组合** | 把多个特征合并成一个特征（加法、乘法等） | 增加新列 | `PolynomialFeatures`、手工交叉 |

> **三个易混点的关键区别**：
> 1. **降维 vs 选择**：降维后的新特征**不再是原来的含义**（如 PCA 主成分），选择后的特征**仍是原来那列**；
> 2. **降维会丢信息**（要保证主要信息保留），选择只是丢弃不重要的列；
> 3. **组合是"造新特征"**，选择是"删旧特征"。

### 1.3 按数据类型选取处理方法

| 数据类型 | 例子 | 处理方法 |
| --- | --- | --- |
| 数值型（连续） | 年龄、收入、身高 | 标准化 / 归一化 / 分箱 / 对数变换 |
| 类别型（无序） | 性别、城市、支付方式 | one-hot 编码、`pd.get_dummies`、`DictVectorizer` |
| 类别型（有序） | 学历、红酒品质等级 | 序数编码（LabelEncoder）或 one-hot |
| 文本 | 评论、新闻标题 | 分词 + `CountVectorizer` / `TfidfVectorizer` |
| 时间 | 时间戳 | 提取小时、月份、星期、是否工作日、滑窗、同比/环比 |
| 图像 | 图片 | 像素展平、颜色直方图、CNN 特征 |

### 1.4 特征预处理的四种缩放方式对比

| 方法 | 公式 | 输出范围 | 对异常值 | 适用场景 |
| --- | --- | --- | --- | --- |
| **归一化** `MinMaxScaler` | $x' = \dfrac{x-\min}{\max-\min}$ | $[0,1]$（可指定） | **敏感**（min/max 被异常点拉动） | 传统精确小数据、图像像素 /255 |
| **标准化** `StandardScaler` | $x' = \dfrac{x-\mu}{\sigma}$ | 大致 $[-3,3]$ | 较稳健 | **通用首选**：KNN、SVM、逻辑回归、PCA |
| **RobustScaler** | $x' = \dfrac{x-\text{median}}{\text{IQR}}$ | 无固定范围 | **最稳健** | 异常值明显的数据 |
| 小数定标 | $x' = x / 10^k$ | —— | 敏感 | 快速粗略缩放（很少用） |

> **量纲问题为什么致命**：以银行信贷为例，`每月工资`（6000~13000）与 `房产面积`（55~90）做欧氏距离时，
> $$d^2 = (6000-8000)^2 + (55-65)^2 = 4{,}000{,}000 + 100$$
> 第二项被完全淹没——**量纲大的特征单独支配了结果**，量纲小的特征等于没参与。

## 2. 算法细节

### 2.1 归一化（Min-Max Normalization）

$$x' = \frac{x - \min(x)}{\max(x) - \min(x)}$$

**API**：`sklearn.preprocessing.MinMaxScaler(feature_range=(0, 1))`

| 方法/属性 | 含义 |
| --- | --- |
| `fit_transform(X_train)` | 学统计量并转换（训练集） |
| `transform(X_test)` | 用训练集的 min/max 转换（测试集） |
| `data_min_` / `data_max_` | 学到的每列最小值 / 最大值 |
| `inverse_transform(X)` | 反变换回原始量纲 |

**特点**：
- 让所有特征落在同一区间，**对量纲差异极其敏感的问题（如 KNN、神经网络）非常有效**；
- **受最大值与最小值的影响，容易受异常数据影响，鲁棒性较差**；
- 适合**传统精确小数据**场景；有异常点时结果会被严重压缩。

### 2.2 标准化（Z-Score Standardization）

$$x' = \frac{x - \mu}{\sigma},\qquad \mu = \frac{1}{N}\sum_i x_i,\qquad \sigma=\sqrt{\frac{1}{N}\sum_i(x_i-\mu)^2}$$

**API**：`sklearn.preprocessing.StandardScaler`

| 属性 | 含义 |
| --- | --- |
| `mean_` | 每列均值 $\mu$ |
| `var_` | 每列方差 $\sigma^2$ |
| `scale_` | 每列标准差 $\sigma$（含 `ddof=0` 的修正） |

**特点**：
- 变换后均值 0、标准差 1，**不保证落在 $[0,1]$**；
- "如果出现异常点，由于具有一定数据量，**少量的异常点对于平均值的影响并不大**"，因此比归一化稳健；
- **工程开发中一般倾向使用标准化**。

**为什么 $\mu$ 与 $\sigma$ 用"有偏"估计？** sklearn 使用 $\sigma=\sqrt{\frac1N\sum(x_i-\mu)^2}$（`ddof=0`）而非样本标准差 $\sqrt{\frac1{N-1}\sum(\cdot)}$。数据量大时二者差异可忽略。

### 2.3 公式效果对比（同一份数据做完再看）

以示例数据 `x = [[90, 2, 10, 40], [60, 4, 15, 45], [75, 3, 13, 46]]` 为例：

| 特征列 | 原始范围 | 归一化后 | 标准化后 |
| --- | --- | --- | --- |
| 第 1 列（90/60/75） | 60~90 | 1.0 / 0.0 / 0.5 | 1.069 / −1.069 / 0.0 |
| 第 2 列（2/4/3） | 2~4 | 0.0 / 1.0 / 0.5 | −1.0 / 1.0 / 0.0 |
| 第 3 列（10/15/13） | 10~15 | 0.0 / 1.0 / 0.6 | −1.069 / 1.069 / 0.0 |
| 第 4 列（40/45/46） | 40~46 | 0.0 / 0.833 / 1.0 | −0.928 / 0.464 / 0.464 |

**观察**：归一化把所有列压到 $[0,1]$，但**列内的相对间距被 min/max 差异扭曲**（第 4 列 45 和 46 几乎靠在一起）；标准化保留了"离均值多少个标准差"的信息，因此更适合统计模型。

### 2.4 类别型特征处理

**（1）one-hot 编码（独热编码）**

把有 $k$ 个取值的类别特征变成 $k$ 个 0/1 列。

```python
pd.get_dummies(data) # pandas 方式：category -> 0/1 多列
pd.get_dummies(data, columns=['Gender'])
```

| 优点 | 缺点 |
| --- | --- |
| 不引入虚假的大小关系 | 类别多时特征维度爆炸、矩阵稀疏 |
| 对线性模型/距离模型必要 | 高基数类别需要特殊处理（目标编码、哈希） |
| 与树模型兼容 | 存在**哑变量陷阱**（完全共线） |

> **哑变量陷阱（dummy variable trap）**：$k$ 个 0/1 列的和恒为 1，与截距列完全共线，使 $\boldsymbol{X}^\top\boldsymbol{X}$ 奇异。所以在代码里会删掉一列（`data.drop(['gender_Male', 'Churn_No'], axis=1)`）——每个类别组**删掉一个基准列**。

**（2）`DictVectorizer`（字典特征提取）**

把"字典列表"转成特征矩阵，**自动对字符串值做 one-hot**，最适合从 `DataFrame.to_dict(orient='records')` 抽取类别特征：

```python
from sklearn.feature_extraction import DictVectorizer

vec = DictVectorizer(sparse=False)
X_train = vec.fit_transform(X_train.to_dict(orient='records'))
X_test = vec.transform(X_test.to_dict(orient='records')) # 测试集只 transform！
print(vec.get_feature_names_out) # 如 ['Age', 'Pclass', 'Sex=female', 'Sex=male']
```

| 特点 | 说明 |
| --- | --- |
| 输入 | `list[dict]`，键为特征名 |
| 数值型 | 保持原值 |
| 字符串型 | 转成 `特征名=取值` 的 0/1 列 |
| 关键纪律 | 训练集 `fit_transform`、测试集只能 `transform`，否则特征列对不齐 |

**（3）LabelEncoder（序数编码）**——给类别分配整数编号：

```python
from sklearn.preprocessing import LabelEncoder
y = LabelEncoder.fit_transform(y) # [2,3] -> [0,1]
```

**注意**：只适合**有序类别**或**标签列**。直接对无序类别用整数编码会引入虚假的大小关系（"北京=1 < 上海=2"毫无意义），对线性模型和距离模型有害。红酒案例用它把标签 (2,3) 转成 (0,1)，属于**标签编码**的正确用法。

### 2.5 文本特征提取（CountVectorizer 与 TF-IDF）

**流程**：分词 → 去停用词 → 构建词频矩阵。

```python
import jieba
from sklearn.feature_extraction.text import CountVectorizer

stop_words = [line.strip for line in open('stopwords.txt', encoding='utf8')]
comment_list = [','.join(jieba.lcut(line)) for line in data['内容']]

transform = CountVectorizer(stop_words=stop_words)
x = transform.fit_transform(comment_list) # 稀疏矩阵
names = transform.get_feature_names_out # 词表
x = x.toarray # 需要稠密时再转
```

**TF-IDF**（扩展）——衡量一个词对某篇文档的重要性：

$$\text{TF}(t,d) = \frac{n_{t,d}}{N_d},\qquad
\text{IDF}(t) = \log\frac{|D|}{|\{d: t\in d\}|},\qquad
\text{TF-IDF} = \text{TF}\times\text{IDF}$$

| 符号 | 含义 |
| --- | --- |
| $n_{t,d}$ | 词 $t$ 在文档 $d$ 中出现的次数 |
| $N_d$ | 文档 $d$ 中所有词汇的总数 |
| $\lvert D\rvert$ | 语料库中的总文档数 |
| $\lvert\{d:t\in d\}\rvert$ | 包含词 $t$ 的文档数量 |

**直觉**：一个词在当前文档出现越多（TF 高）、在别的文档出现越少（IDF 高），它就越有代表性。这样能自动压低"的、是、了"这类高频停用词的影响（实践中还会直接用停用词表过滤）。

### 2.6 特征组合与多项式特征

**原理**：把多个特征通过加法、乘法合并成一个特征。对线性模型而言，**加入 $x_1x_2$、$x^2$ 可以让它拟合非线性关系**（因为线性回归的线性是关于**参数** $w$ 的，不是关于特征 $x$ 的）。

$$y = w_0 + w_1x_1 + w_2x_2 \ \longrightarrow\ y = w_0 + w_1x_1 + w_2x_2 + w_3x_1x_2 + w_4x_1^2 + w_5x_2^2$$

| 做法 | 代码 |
| --- | --- |
| 手工拼接（做法） | `X2 = np.hstack([X, X ** 2])` |
| 自动生成 | `PolynomialFeatures(degree=2, include_bias=False)` |

**代价**：$d$ 个特征生成 2 阶多项式后有 $O(d^2)$ 列，**极易过拟合**（实验中加 $x,\dots,x^{10}$ 后训练 MSE 反而更低但曲线剧烈抖动）。所以多项式扩展后**必须配正则化**（L1/L2）或降维。

### 2.7 特征选择

**目标**：从原始特征中选出对任务最有用的子集，**不改变数据本身的取值**。

| 方法族 | 具体做法 | 特点 |
| --- | --- | --- |
| **过滤式（Filter）** | 方差过滤 `VarianceThreshold`、相关系数、卡方检验、互信息 | 与模型无关、计算快；可能漏掉"单独弱但组合强"的特征 |
| **包裹式（Wrapper）** | 递归特征消除 RFE | 效果常更好，但计算量大（要反复训练模型） |
| **嵌入式（Embedded）** | L1 正则化（Lasso）、树模型的 `feature_importances_` | 训练的同时完成选择，效率高，**最常用** |

**（1）L1 正则化做特征选择**：

> 作用：用来进行特征选择，主要原因在于 **L1 正则化会使得较多的参数为 0，从而产生稀疏解**，可以将 0 对应的特征遗弃，进而用来选择特征。一定程度上 L1 正则也可以防止模型过拟合。

几何直觉：L1 的约束域 $|w_1|+|w_2|\le c$ 是**菱形**，最优解极易落在坐标轴上的**顶点**，于是某些 $w_j$ 恰好为 0。对比 L2 的约束域是**圆**，切点一般不在坐标轴上，所以只做平滑收缩、不产生精确 0。

**（2）相关系数过滤**：计算每个特征与标签（或特征之间）的相关系数 $\rho$，剔除相关性极低的特征；特征之间相关性过高（如 $|\rho|>0.9$）则考虑删掉一个，避免共线。

**（3）树模型的特征重要性**：

```python
print(dict(zip(X.columns, estimator.feature_importances_)))
```

| 特点 | 说明 |
| --- | --- |
| 依据 | 该特征在所有分裂中带来的**不纯度下降（加权）之和** |
| 优点 | 自动、能捕捉非线性关系 |
| 陷阱 | 偏向**高基数**特征（取值多的特征有更多分裂机会）；对相关特征的重要性会"分摊" |

### 2.8 特征降维

**目标**：把原始数据的维度降低。**会丢失部分信息**，所以**要保证数据的主要信息保留下来**；降维后的新特征**不再是原来的业务含义**。

| 方法 | 原理 | 特点 |
| --- | --- | --- |
| **PCA（主成分分析）** | 找方差最大的正交方向，把数据投影上去 | 线性、无监督、需标准化 |
| TSNE | 保持局部邻域结构的非线性降维 | **只适合可视化**（不保留全局距离，且慢） |
| 自编码器 | 神经网络学习压缩表示 | 非线性、需要训练 |

> **说明**：本"特征降维"只到**概念层面**（定义、会丢信息、保留主要信息），**没有展开 PCA 的数学推导与 API**。下面的 PCA 代码属于按需补充的工程实践，标注为扩展内容。

**PCA 的基本直觉**（扩展）：对标准化后的数据 $\boldsymbol{X}$（$n\times d$），计算协方差矩阵 $\boldsymbol{C}=\frac1n\boldsymbol{X}^\top\boldsymbol{X}$，求其特征值分解；取**最大的 $k$ 个特征值对应的特征向量**组成投影矩阵 $\boldsymbol{W}$（$d\times k$），新特征即 $\boldsymbol{Z}=\boldsymbol{X}\boldsymbol{W}$。保留的方差比例 = $\dfrac{\sum_{i=1}^{k}\lambda_i}{\sum_{i=1}^{d}\lambda_i}$。

**为什么 PCA 前必须标准化**：PCA 追求方差最大方向，如果不标准化，量纲大的特征方差天然大，会独占主成分，导致降维结果只反映那一个特征。

### 2.9 时间序列特征工程（把时序变成二维宽表）

这是 [10-数据挖掘案例-电力负荷预测](../06-案例与面试/10-数据挖掘案例-电力负荷预测.md) 的核心工作。原始数据只有 `time` 和 `power_load` 两列，需要展开成宽表：

| 特征类别 | 具体特征 | 构造方法 |
| --- | --- | --- |
| **时间特征（短期）** | `hour` 的 24 个 one-hot 列 | `df['time'].str[11:13]` + `pd.get_dummies` |
| **时间特征（长期）** | `month` 的 12 个 one-hot 列 | `df['time'].str[5:7]` + `pd.get_dummies` |
| **滑窗历史负荷** | 前 1 / 前 2 / 前 3 小时负荷 | `df['power_load'].shift(i)` |
| **同期历史** | 昨日同时刻负荷 | 时间字典 + `pd.to_timedelta('1d')` |
| **外部特征（扩展）** | 温度、湿度、风速、历史工业/居民用电量 | 需要外部数据源 |

**工程要点**：

| 要点 | 说明 |
| --- | --- |
| 时间格式化统一 | `pd.to_datetime(x).dt.strftime('%Y-%m-%d %H:%M:%S')`，字符串切片才不会错位 |
| 排序与去重 | `sort_values('time')` + `drop_duplicates`，保证 `shift` 语义正确 |
| 空值处理 | `shift` 与"昨日同时刻"会引入 NaN，需 `dropna(axis=0)` |
| 训练/预测特征列必须一致 | 预测时要"手工解析"出与训练时**完全相同的列名与列序** |
| 离散时间特征用 one-hot 而非序号 | 小时 23 和 0 在序号上差 23，但实际相邻；one-hot 避免引入虚假距离 |
| 禁止未来信息泄漏 | 构造滑窗时只能用**当前时刻之前**的负荷 |

## 3. 可运行示例

### 3.1 归一化 vs 标准化：数值对照

```python
# -*- coding: utf-8 -*-
"""手动实现 MinMax 与 Z-Score，并与 sklearn 结果对照"""
import numpy as np
from sklearn.preprocessing import MinMaxScaler, StandardScaler

x = np.array([[90, 2, 10, 40], [60, 4, 15, 45], [75, 3, 13, 46]], dtype=float)
print("原始数据:\n", x)

# ---- 手写归一化 ----
minmax = (x - x.min(axis=0)) / (x.max(axis=0) - x.min(axis=0))
print("\n手写 MinMax:\n", np.round(minmax, 4))

# ---- 手写标准化 ----
mu, sigma = x.mean(axis=0), x.std(axis=0) # ddof=0，与 sklearn 一致
zscore = (x - mu) / sigma
print("\n手写 Z-Score:\n", np.round(zscore, 4))

# ---- sklearn 对照 ----
mm = MinMaxScaler
print("\nsklearn MinMax:\n", np.round(mm.fit_transform(x), 4))

ss = StandardScaler
print("sklearn StandardScaler:\n", np.round(ss.fit_transform(x), 4))
print("\nmean_ =", np.round(ss.mean_, 4))
print("var_ =", np.round(ss.var_, 4))
print("scale_=", np.round(ss.scale_, 4))

# ---- 反变换 ----
print("\n反变换回原值:\n", np.round(ss.inverse_transform(ss.transform(x)), 4))
```

### 3.4 多项式特征 + 正则化：特征组合的正确姿势

```python
# -*- coding: utf-8 -*-
"""特征组合：加多项式项提升拟合能力，用正则化控制过拟合"""
import numpy as np
from sklearn.linear_model import Lasso, LinearRegression, Ridge
from sklearn.metrics import mean_squared_error
from sklearn.preprocessing import PolynomialFeatures

np.random.seed(666)
x = np.random.uniform(-3, 3, size=100)
y = 0.5 * x ** 2 + x + 2 + np.random.normal(0, 1, size=100)
X = x.reshape(-1, 1)

print("【只用 1 维特征】")
m = LinearRegression.fit(X, y)
print("MSE = %.4f（欠拟合）" % mean_squared_error(y, m.predict(X)))

print("\n【手工 hstack 加二次项】（做法）")
X2 = np.hstack([X, X ** 2])
m2 = LinearRegression.fit(X2, y)
print("MSE = %.4f（合理拟合）" % mean_squared_error(y, m2.predict(X2)))

print("\n【PolynomialFeatures(degree=10) + 不同正则化】")
poly = PolynomialFeatures(degree=10, include_bias=False)
X10 = poly.fit_transform(X)
for name, model in [("无正则 LinearRegression", LinearRegression),
("L1 Lasso(alpha=0.1)", Lasso(alpha=0.1, max_iter=10000)),
("L2 Ridge(alpha=1)", Ridge(alpha=1))]:
 model.fit(X10, y)
 coef = np.round(model.coef_, 4)
 n_zero = int((np.abs(coef) < 1e-8).sum)
 print(f"{name:26s} MSE={mean_squared_error(y, model.predict(X10)):7.4f} "
 f"零系数个数={n_zero}/10")
 # 结论：无正则时训练 MSE 最小但曲线剧烈抖动（过拟合）；
 # Lasso 把一部分高次项系数精确压成 0（特征选择）；
 # Ridge 把高次项系数压得很小但不为 0（平滑收缩）。
```

### 3.5 特征选择：三种方法实操

```python
# -*- coding: utf-8 -*-
"""特征选择：方差过滤 / 相关系数 / 树模型重要性 / L1 稀疏"""
import numpy as np
import pandas as pd
from sklearn.datasets import load_breast_cancer
from sklearn.ensemble import RandomForestClassifier
from sklearn.feature_selection import VarianceThreshold
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import StandardScaler

data = load_breast_cancer()
X = pd.DataFrame(data.data, columns=data.feature_names)
y = data.target

# ---- 方法 1：方差过滤（剔除几乎不变的常量特征）----
vt = VarianceThreshold(threshold=0.1)
X_vt = vt.fit_transform(X)
print(f"方差过滤: {X.shape[1]} -> {X_vt.shape[1]} 列")

# ---- 方法 2：相关系数过滤（剔除与标签几乎无关的特征）----
corr = X.apply(lambda col: np.corrcoef(col, y)[0, 1])
corr_abs = corr.abs.sort_values(ascending=False)
print("\n与标签相关性最高的 10 个特征：")
print(corr_abs.head(10).round(4))
print("\n相关性最低的 5 个特征（候选删除）：")
print(corr_abs.tail(5).round(4))

# ---- 方法 3：树模型特征重要性 ----
rf = RandomForestClassifier(n_estimators=200, random_state=0).fit(X, y)
imp = pd.Series(rf.feature_importances_, index=X.columns).sort_values(ascending=False)
print("\n随机森林特征重要性 Top10：")
print(imp.head(10).round(4))
print("\n重要性接近 0 的特征（候选删除）：")
print(imp[imp < 0.005].round(4))

# ---- 方法 4：L1 正则化产生稀疏解（嵌入式特征选择）----
Xs = StandardScaler.fit_transform(X)
lr = LogisticRegression(penalty="l1", solver="liblinear", C=0.1, max_iter=5000)
lr.fit(Xs, y)
n_zero = int((np.abs(lr.coef_[0]) < 1e-8).sum)
print(f"\nL1 正则（C=0.1）：{n_zero}/{X.shape[1]} 个特征系数被压成 0")
print("非零特征:", list(np.array(X.columns)[np.abs(lr.coef_[0]) > 1e-8]))
```

### 3.6 时间序列特征工程（把宽表演示清楚）

```python
# -*- coding: utf-8 -*-
"""时序 -> 二维宽表：时间 one-hot + 滑窗负荷 + 昨日同时刻负荷"""
import numpy as np
import pandas as pd

# 造一份小时级数据
times = pd.date_range("2015-07-25 00:00:00", periods=200, freq="h")
df = pd.DataFrame({
"time": times.strftime("%Y-%m-%d %H:%M:%S"),
"power_load": 600 + 100 * np.sin(np.arange(200) / 24 * 2 * np.pi) + np.random.normal(0, 5, 200),
})

def feature_engineering(data, window_size=3):
 result = data.copy(deep=True)

 # ---- 1. 时间特征 ----
 result["hour"] = result["time"].str[11:13] # 短期：小时
 result["month"] = result["time"].str[5:7] # 长期：月份
 hour_encoding = pd.get_dummies(result["hour"])
 hour_encoding.columns = ["hour_" + str(c) for c in hour_encoding.columns]
 month_encoding = pd.get_dummies(result["month"])
 month_encoding.columns = ["month_" + str(c) for c in month_encoding.columns]
 result = pd.concat([result, hour_encoding, month_encoding], axis=1)

 # ---- 2. 滑窗历史负荷（只能用过去！）----
 shift_data = pd.concat([result["power_load"].shift(i) for i in range(1, window_size + 1)], axis=1)
 shift_data.columns = ["前%d小时" % i for i in range(1, window_size + 1)]
 result = pd.concat([result, shift_data], axis=1)

 # ---- 3. 昨日同时刻负荷 ----
 time_load_dict = result.set_index("time")["power_load"].to_dict()
 result["yesterday_time"] = result["time"].apply(
 lambda x: (pd.to_datetime(x) - pd.to_timedelta("1d")).strftime("%Y-%m-%d %H:%M:%S"))
 result["yesterday_load"] = result["yesterday_time"].apply(lambda x: time_load_dict.get(x))

 # ---- 4. 剔除因滑窗/昨日产生的空值 ----
 result.dropna(axis=0, inplace=True)

 # ---- 5. 整理特征列名 ----
 feature_names = (list(hour_encoding.columns) + list(month_encoding.columns)
 + list(shift_data.columns) + ["yesterday_load"])
 return result, feature_names

if __name__ == "__main__":
 processed, feats = feature_engineering(df)
 print("原始形状:", df.shape)
 print("处理后形状:", processed.shape)
 print("特征个数:", len(feats))
 print("前 5 个特征:", feats[:5])
 print(processed[["time", "power_load", "前1小时", "前2小时", "前3小时", "yesterday_load"]].head())
```

## 4. 常见坑

| # | 坑 | 现象 | 原因 | 正确做法 |
| --- | --- | --- | --- | --- |
| 1 | 先标准化再划分数据集 | 离线指标虚高、线上掉分 | 测试集统计量泄漏进训练 | **先划分，再 `fit_transform` 训练集、`transform` 测试集** |
| 2 | 新样本预测忘了变换 | 预测结果荒谬 | 训练/推理量纲不一致 | 保存 scaler（`joblib`）或用 `Pipeline` |
| 3 | 有异常点用 MinMax | 正常点被挤到极小区间 | min/max 被异常点拉动 | 用 `StandardScaler` 或 `RobustScaler` |
| 4 | 对无序类别用 LabelEncoder | 模型学到虚假大小关系 | 整数编码隐含序关系 | 用 one-hot / DictVectorizer |
| 5 | one-hot 后不删基准列 | 线性模型系数不稳定 | 哑变量陷阱导致共线 | `drop_first=True` 或手工删一列 |
| 6 | 测试集重新 `fit` 编码器 | 列数/列序错乱 | 测试集的类别子集可能与训练集不同 | 测试集只能 `transform` |
| 7 | 决策树也强行标准化 | 白做功夫 | 树只依赖单特征排序，对单调变换不敏感 | 树模型无需标准化，但类别必须编码 |
| 8 | 生成高阶多项式后不加正则化 | 训练 MSE 很低、测试很差 | 特征维度爆炸 → 过拟合 | 正则化（L1/L2）或降维 |
| 9 | 认为降维等于特征选择 | 概念混淆，解释不出结果 | 降维后的特征**失去原含义** | 记住：降维会丢信息且改变含义，选择只是挑列 |
| 10 | 用 `feature_importances_` 直接判定因果 | 结论错误 | 重要性偏向高基数特征，且相关特征会分摊 | 结合相关系数、置换重要性交叉验证 |
| 11 | 时序滑窗数据随机划分 | 离线很好、线上崩溃 | **未来信息泄漏** | 按时间切分；滑窗只能用过去时刻 |
| 12 | 时序时间特征用序号而非 one-hot | 距离关系错误 | 小时 23 与 0 实际相邻、序号却差 23 | 离散时间特征用 one-hot |
| 13 | 忘了 `dropna` | 训练报错 `Input contains NaN` | `shift` 与"昨日同时刻"必然产生空值 | 特征工程后 `dropna(axis=0)` |
| 14 | 预测时特征列名/列序与训练不一致 | 预测结果离谱或报错 | 预测代码"手工组装"特征容易漏列 | 把特征列清单固化成常量，与训练共用 |
| 15 | 只用 PCA 降维不看解释方差比例 | 可能丢掉关键信息 | 主成分个数没依据 | 看 `explained_variance_ratio_` 累计 ≥ 85%~95% |
| 16 | 对高基数类别做 one-hot | 维度爆炸（几千列） | 类别取值太多 | 目标编码、频次编码、哈希编码或合并稀有类别 |

## 5. 面试问答

<details><summary>Q1：归一化和标准化有什么区别？什么时候用哪一个？</summary>

**参考答案**

| 维度 | 归一化 MinMaxScaler | 标准化 StandardScaler |
| --- | --- | --- |
| 公式 | $x'=\dfrac{x-\min}{\max-\min}$ | $x'=\dfrac{x-\mu}{\sigma}$ |
| 输出范围 | $[0,1]$（可指定） | 无固定范围，大致 $[-3,3]$ |
| 依赖统计量 | 最小值、最大值（极值统计量） | 均值、标准差（位置 + 离散度） |
| 对异常值 | **敏感**：一个异常点就能把正常数据压缩到极小范围 | 较稳健：均值受少量异常点影响有限 |
| 是否改变分布形状 | 线性变换，形状不变 | 线性变换，形状不变 |
| 典型用途 | 图像像素 /255、需要固定区间输入的神经网络 | **通用首选**：KNN、SVM、逻辑回归、PCA |
| 更稳健的替代 | —— | `RobustScaler`（用中位数和 IQR） |

**选择建议**：
1. **默认用标准化**——结论也是"工程开发中一般倾向使用 L2（标准化）"；
2. 数据里有明显异常点 → **`RobustScaler`**；
3. 算法要求固定输入范围（如某些神经网络、图像） → **归一化**；
4. **决策树 / 随机森林 / GBDT 都不需要**任何缩放（只依赖单特征排序）；
5. 用 **L1/L2 正则化时一定要标准化**，否则惩罚项对不同量纲的特征不公平。

**共同的前提纪律**：统计量只能从**训练集**估计。必须先划分数据集，训练集 `fit_transform`、测试集 `transform`，否则测试集信息会泄漏进训练。
</details>

<details><summary>Q2：特征选择和特征降维有什么区别？各有哪些常用方法？</summary>

**参考答案**

| 维度 | 特征选择 | 特征降维 |
| --- | --- | --- |
| 做什么 | 从原始特征中挑出**一个子集** | 把高维数据**映射到低维空间** |
| 结果特征 | **仍是原来那列**，含义不变 | 是**新构造**的特征，含义改变（如 PCA 主成分） |
| 是否丢信息 | 丢弃的是判定为不重要的列 | **会丢信息**，所以必须保证主要信息保留 |
| 可解释性 | 高（能说出留下了哪些业务字段） | 低（主成分往往无法直接命名） |
| 常见方法 | 方差过滤、相关系数、卡方、互信息、RFE、Lasso、树重要性 | PCA、TSNE、自编码器 |

**特征选择三大类**：
1. **过滤式 Filter**：`VarianceThreshold`、相关系数、卡方检验、互信息。与模型无关、速度快，但可能漏掉组合才有用的特征；
2. **包裹式 Wrapper**：递归特征消除（RFE），用模型性能作为评价，效果常更好但计算量大；
3. **嵌入式 Embedded**：**L1 正则化**（系数被压到 0 即等于做了选择）、树模型的 `feature_importances_`。训练同时完成选择，效率最高，工程上最常用。

**工程顺序建议**：先剔除常量/近常量与高度共线特征（Filter）→ 再用嵌入式（L1 或树重要性）挑出 Top-K → 若还要压缩维度且能接受可解释性下降，最后再上 PCA。
</details>

<details><summary>Q3：处理类别特征时，one-hot 编码有什么问题？高基数类别怎么办？</summary>

**参考答案**

**one-hot 的优点**：不引入虚假的大小关系，对所有模型通用，与距离/线性模型天然兼容。

**one-hot 的问题**：
1. **维度爆炸**：取值 $k$ 个就产生 $k$ 列。若"城市"有 3000 个取值，就会凭空多出 3000 列稀疏特征，训练慢、内存大、易过拟合；
2. **稀疏性**：每行只有 1 个 1，其余全 0，树模型在稀疏特征上分裂效率低、线性模型的正则化也会被稀释；
3. **哑变量陷阱**：$k$ 列之和恒为 1，与截距列完全共线，使 $\boldsymbol{X}^\top\boldsymbol{X}$ 奇异。线性模型/逻辑回归必须**删掉一个基准列**（`drop_first=True`）；树模型对共线不敏感，可保留全部；
4. **未见类别**：测试集出现了训练时没见过的取值，`transform` 时会得到全 0 行甚至报错（`handle_unknown`）。

**高基数类别的替代方案**：

| 方案 | 做法 | 适用 |
| --- | --- | --- |
| 目标编码（Target/Mean Encoding） | 用该类别的标签均值编码 | 高基数、树模型，**必须配合交叉验证防泄漏** |
| 频次编码 | 用该类别出现的次数编码 | 简单、无泄漏，但丢失类别身份 |
| 合并稀有类别 | 把出现次数 < 阈值的类别归为 `Other` | 通用前置处理 |
| 哈希编码（Hashing） | 哈希到固定维度的桶 | 类别极多、允许碰撞 |
| 嵌入（Embedding） | 训练低维稠密向量 | 深度学习场景 |

**补充**：`DictVectorizer` 与 `pd.get_dummies` 都能做 one-hot；关键纪律是**测试集只能 `transform`，不能 `fit`**，否则列会错位。使用 `OneHotEncoder(handle_unknown='ignore')` 可以优雅处理未见类别。
</details>

## 6. 自测题

<details><summary>1. 特征工程由哪五部分组成？各自是否改变原始数据的取值？</summary>

| 组成部分 | 是否改变原始数据取值 |
| --- | --- |
| 特征提取 | **是**（把非结构化/字典数据转成特征向量） |
| 特征预处理 | **是**（数值缩放，量纲改变） |
| 特征降维 | **是**（生成新的低维表示，会丢信息） |
| 特征选择 | **否**（只是挑选列，列本身的值不变） |
| 特征组合 | **是**（通过加法/乘法造出新特征） |

**记住两个易混点**：降维后的特征**不再是原来的含义**且会丢信息；特征选择**不会改变原来的数据**，只是挑出重要子集。
</details>

<details><summary>2. 数据某列取值为 $[1, 2, 3, 4, 5]$，求归一化与标准化后的结果。</summary>

- $\min=1$、$\max=5$、$\mu=3$、$\sigma=\sqrt{2}\approx1.4142$
- **归一化**（$x'=(x-1)/4$）：$[0,\ 0.25,\ 0.5,\ 0.75,\ 1.0]$
- **标准化**（$x'=(x-3)/1.4142$）：$[-1.414,\ -0.707,\ 0,\ 0.707,\ 1.414]$

**注意**：归一化后最小值为 0、最大值为 1；标准化后均值为 0、标准差为 1，但取值范围由数据分布决定，不固定在 $[0,1]$。
</details>

<details><summary>3. 为什么 KNN 和逻辑回归必须做标准化，而决策树不需要？</summary>

**KNN**：用**欧氏距离**衡量样本相似性，距离对不同特征量纲高度敏感。若一个特征取值 0~1000、另一个 0~1，距离几乎完全由前者决定，后者等于没参与。

**逻辑回归**：用**梯度下降**求解，损失函数的等高线在各特征尺度不同时会变得非常细长，梯度下降沿"之字形"缓慢前进，收敛极慢；同时 L1/L2 正则项会对不同尺度的权重施加不公平的惩罚。

**决策树（含随机森林、GBDT）**：每个节点只在**单个特征**上寻找一个切分阈值 $x_j\le s$。对特征做单调变换（$x\to ax+b$，$a>0$）只会改变最优阈值的位置，**不会改变分裂后样本的划分结果**，因此准确率完全不变。所以决策树不需要标准化。

（补充：SVM、PCA、神经网络也都需要标准化；而朴素贝叶斯、树模型一般不需要。）
</details>

<details><summary>4. 什么是哑变量陷阱？如何处理？</summary>

**哑变量陷阱（dummy variable trap）**：对取值为 $k$ 个的类别特征做全量 one-hot 后得到 $k$ 列，这 $k$ 列之和恒等于 1（每行恰好一个 1）。如果模型还有截距项（常数 1 列），就出现了**完全共线**：常数列可以由这 $k$ 列线性表出。

**后果**：设计矩阵 $\boldsymbol{X}$ 不满秩 → $\boldsymbol{X}^\top\boldsymbol{X}$ 不可逆（奇异）→ 正规方程无唯一解；用梯度下降时系数会漂移到很大的值且不稳定，可解释性下降。

**处理**：
1. **删掉一个基准列**：`pd.get_dummies(df, drop_first=True)`，保留 $k-1$ 列；代码中的 `data.drop(['gender_Male', 'Churn_No'], axis=1)` 正是这个操作；
2. 使用 `OneHotEncoder(drop='first')`；
3. **树模型不需要**处理——树的分裂只关心单特征的阈值，共线不影响结果；
4. 也可以改用带 L2 正则化的模型（岭回归/加惩罚的逻辑回归），正则项让解重新唯一。
</details>

<details><summary>5. 把时序数据变成二维宽表时，至少要构造哪几类特征？为什么不能用随机划分？</summary>

**至少三类**（以电力负荷预测为例）：
1. **时间特征**：小时（短期）与月份（长期），并做 **one-hot** 编码——因为小时 23 与 0 实际相邻，用序号会引入错误的距离关系；
2. **滑窗历史负荷特征**："前 1 / 前 2 / 前 3 小时"的负荷，用 `shift(i)` 构造，捕捉短期趋势与惯性；
3. **同期历史特征**：昨日同时刻负荷，用时间字典 + `pd.to_timedelta('1d')` 构造，捕捉日周期规律。

**还可以扩展**（改进方向）：温度、湿度、风速、历史工业用电量/居民用电量等外部特征。

**不能用随机划分的原因**：时序数据存在**时间依赖**，随机划分会把"未来"时刻的样本放进训练集、把"过去"的样本放进测试集，造成**未来信息泄漏**。这会让离线指标异常漂亮（模型甚至"记住了答案"），而线上按时间顺序预测时性能崩溃。

**正确做法**：
- 按时间先后切分（如前 70% 训练、后 30% 测试）；
- 交叉验证用 `TimeSeriesSplit`（每折的训练集都严格早于验证集）；
- 滑窗特征只能使用**当前时刻之前**的负荷；
- 推理阶段要模拟真实场景——把待预测时刻及以后的负荷"掩盖掉"，只用历史字典预测。
</details>
