# 03 - 线性回归

> **一句话总结**：线性回归用一条直线（或超平面）$h_w(x)=w_1x_1+\cdots+w_dx_d+b=\boldsymbol{w}^\top\boldsymbol{x}+b$ 拟合特征与连续标签的关系，求解思路只有两条——**正规方程**（一步解出解析解，$O(d^3)$）与**梯度下降**（迭代逼近，适合大数据）。
> **前置知识**：导数/偏导数与矩阵乘法（本文第 2.1 节会复习）、numpy 数组运算、`train_test_split` 与 `StandardScaler` 的用法（见 [01-机器学习概述与流程](../01-基础与特征工程/01-机器学习概述与流程.md)）。
> **学完能做到**：
> 1. 手动推导一元线性回归的最小二乘解，并用"求导置零"算出 $k,b$；
> 2. 写出正规方程 $\boldsymbol{w}=(\boldsymbol{X}^\top\boldsymbol{X})^{-1}\boldsymbol{X}^\top\boldsymbol{y}$，并解释每一项的含义与局限；
> 3. 区分 FGD / SGD / Mini-batch / SAG 四种梯度下降，讲清 L1 与 L2 正则化为什么能抑制过拟合。

---

## 1. 核心思想

### 1.1 从"身高预测体重"说起

已知 5 个人的身高与体重，问身高 176 cm 的人体重多少？

| 编号 | 身高 X | 体重 Y |
| --- | --- | --- |
| 1 | 160 | 56.3 |
| 2 | 166 | 60.6 |
| 3 | 172 | 65.1 |
| 4 | 174 | 68.5 |
| 5 | 180 | 75.0 |
| 6 | **176** | **？** |

**思路**：先从已知的 $(X,Y)$ 中找规律，再对新数据预测。数学上就是"用一条直线 $y=kx+b$ 去拟合这些点"，然后代入 $x=176$。

> **关键区分**：线性回归要求的是**关于参数 $w$ 是线性的**，而不是关于特征 $x$ 线性。所以 $y = w_1 x + w_2 x^2 + b$ 也是线性回归（多项式回归），因为对 $w$ 依然是一次幂。

### 1.2 一元 vs 多元

| 类型 | 公式 | 特征个数 | 几何形态 | 例子 |
| --- | --- | --- | --- | --- |
| 一元线性回归 | $y = wx + b$ | 1 | 平面上的直线 | 身高 → 体重 |
| 多元线性回归 | $y = w_1x_1+\cdots+w_dx_d+b$ | $d$ 个 | $d+1$ 维空间中的超平面 | 面积/位置/楼层/朝向 → 房价 |

向量写法（默认 $\boldsymbol{w}$、$\boldsymbol{x}$ 为列向量）：

$$h_w(\boldsymbol{x}) = \boldsymbol{w}^\top\boldsymbol{x} + b$$

### 1.3 应用场景

| 领域 | 自变量 X | 因变量 Y |
| --- | --- | --- |
| 材料 | 温度 | 钢轨伸缩长度 |
| 生物 | 天气温度 | 昆虫鸣叫次数 |
| 经济 | 国内 GDP | 双十一销售额 |
| 房产 | 面积、位置、楼层、朝向 | 房价 |
| 金融 | 月薪、存款、房产面积 | 授信额度 |

### 1.4 求解线性回归需要什么？

| 要素 | 说明 |
| --- | --- |
| 数据 | 样本由特征值 $x$ 与目标值 $y$ 组成，且假设数据分布近似线性 |
| 假设函数 | 一元 $y=kx+b$；多元 $y=\boldsymbol{w}^\top\boldsymbol{x}+b$ |
| 损失函数 | MSE（最常用，因为可导且是凸函数）、MAE |
| 优化方法 | ① 正规方程（求导/求偏导置零）；② 梯度下降（逐步逼近） |

### 1.5 三种回归评估指标速览

| 指标 | 公式 | 量纲 | 对异常值 | 适用 |
| --- | --- | --- | --- | --- |
| MAE | $\frac{1}{n}\sum\lvert y_i-\hat{y}_i\rvert$ | 与 $y$ 相同 | 不敏感 | 数据含少量异常点，想反映"真实平均误差" |
| MSE | $\frac{1}{n}\sum(y_i-\hat{y}_i)^2$ | $y$ 的平方 | 敏感（平方放大） | 需要可导损失、作为训练目标 |
| RMSE | $\sqrt{\frac{1}{n}\sum(y_i-\hat{y}_i)^2}$ | 与 $y$ 相同 | 最敏感 | 与 $y$ 可比、想强调大误差 |

## 2. 算法细节

### 2.1 数学复习（够用即可）

**标量 / 向量 / 矩阵 / 张量**

| 名称 | 定义 | 例子 |
| --- | --- | --- |
| 标量 scalar | 一个独立的数，只有大小没有方向 | $5$ |
| 向量 vector | 一列顺序排列的元素，默认列向量 | 张三的数理化成绩 $(70,80,90)^\top$ |
| 矩阵 matrix | 二维数组，$m$ 行 $n$ 列 | 张三、李四的成绩：$2\times 3$ |
| 张量 tensor | 向量与矩阵的推广（多维数组） | 一张 RGB 图片 $H\times W\times 3$ |

**范数（Norm）**

$$\|\boldsymbol{x}\|_1 = \sum_i |x_i|,\qquad \|\boldsymbol{x}\|_2 = \sqrt{\sum_i x_i^2},\qquad \|\boldsymbol{x}\|_p = \left(\sum_i |x_i|^p\right)^{1/p}$$

**常用导数**

| 公式 | 例子 |
| --- | --- |
| $(C)^\prime = 0$ | $(5)^\prime=0$ |
| $(x^\alpha)^\prime = \alpha x^{\alpha-1}$ | $(x^3)^\prime = 3x^2$ |
| $(e^x)^\prime = e^x$ | $(e^x)^\prime=e^x$ |
| $(a^x)^\prime = a^x\ln a$ | $(2^x)^\prime=2^x\ln 2$ |
| $(\ln x)^\prime = 1/x$ | $(\ln x)^\prime=1/x$ |
| $(\sin x)^\prime=\cos x$，$(\cos x)^\prime=-\sin x$ | —— |
| 复合：$\{g[h(x)]\}^\prime = g^\prime(h)\cdot h^\prime(x)$ | $(\sin 2x)^\prime = 2\cos 2x$ |

**导数与极值**：可导函数在极值点处导数为 0，即 $f^\prime(x_0)=0$。这就是"求最小值"的全部武器。

**矩阵要点**：$A\times B \neq B\times A$（不满足交换律），但 $A(BC)=(AB)C$（结合律）；$AI=IA=A$；只有方阵且行列式非零才可能有逆 $A^{-1}$。

### 2.2 损失函数：从"误差和最小"到 MSE

误差定义为 $\text{error}_i = y_i - \hat{y}_i$。**损失函数**（loss / cost / objective function）把所有样本的误差汇成一个可优化的标量。

**为什么不用"误差直接求和"？** 因为正负误差会互相抵消（$-100$ 与 $+100$ 之和为 0，却拟合得很差），所以需要平方或绝对值。

**MSE（均方误差，最小二乘的均值形式）**：

$$J(\boldsymbol{w},b) = \frac{1}{2n}\sum_{i=1}^{n}\big(y_i - (\boldsymbol{w}^\top\boldsymbol{x}_i+b)\big)^2$$

> 加 $\tfrac12$ 只是为了求导后系数变成 1，不影响最优点位置。

**MAE（平均绝对误差）**：

$$J_{\text{MAE}}(\boldsymbol{w},b)=\frac{1}{n}\sum_{i=1}^{n}\lvert y_i-\hat{y}_i\rvert$$

**MSE 与 MAE 的取舍**：MSE 处处可导、是凸函数、能直接解出解析解；MAE 在 0 点不可导，但更抗异常值（等价于中位数回归）。

### 2.3 一元线性回归的解析解（手推）

**Step 1：写出一元损失函数并展开。** 取 $J(k,b)=\sum_i (y_i - kx_i - b)^2$（常数系数不影响极值点）：

$$
\begin{aligned}
J(k,b) &= \sum_i \big(y_i - kx_i - b\big)^2\\
&= \sum_i y_i^2 - 2k\sum_i x_i y_i - 2b\sum_i y_i + k^2\sum_i x_i^2 + 2kb\sum_i x_i + nb^2
\end{aligned}
$$

**Step 2：分别对 $k$、$b$ 求偏导并置零。**

$$
\frac{\partial J}{\partial k} = 2k\sum_i x_i^2 + 2b\sum_i x_i - 2\sum_i x_i y_i = 0
\quad\Longrightarrow\quad
k\sum_i x_i^2 + b\sum_i x_i = \sum_i x_i y_i
\tag{1}
$$

$$
\frac{\partial J}{\partial b} = 2k\sum_i x_i + 2nb - 2\sum_i y_i = 0
\quad\Longrightarrow\quad
k\sum_i x_i + nb = \sum_i y_i
\tag{2}
$$

> 推导细节：对 $k$ 求偏导时，$k$ 出现在 $k^2\sum x_i^2$（导数 $2k\sum x_i^2$）、$2kb\sum x_i$（导数 $2b\sum x_i$）、$-2k\sum x_iy_i$（导数 $-2\sum x_iy_i$）三项中；对 $b$ 求偏导时，$b$ 出现在 $2kb\sum x_i$（导数 $2k\sum x_i$）、$nb^2$（导数 $2nb$）、$-2b\sum y_i$（导数 $-2\sum y_i$）三项中。其余项与待求参数无关，导数为 0。

**Step 3：代入数据求解。** 数据为 $x=\{160,166,172,174,180\}$，$y=\{56.3,60.6,65.1,68.5,75\}$，先算五个统计量：

| 统计量 | 值 |
| --- | --- |
| $\sum x$ | $852$ |
| $\sum y$ | $325.5$ |
| $\sum x^2$ | $145416$ |
| $\sum xy$ | $55683.8$ |
| $n$ | $5$ |

代入 (1)(2) 得到给出的方程组：

$$
\begin{cases}
145416\,k + 852\,b - 55683.8 = 0\\
852\,k + 5\,b - 325.5 = 0
\end{cases}
$$

解之（与 `np.linalg.lstsq` 结果一致）：

$$k = 0.9294,\qquad b = -93.2735$$

**Step 4：预测。**

$$y(176) = 0.9294\times 176 - 93.2735 = 70.30$$

> **另一个更简单的演示**：把 $b$ 固定为 $-100$（相当于强行让直线经过 $(0,-100)$），损失函数退化为一元二次函数
> $$L(k) = 145416k^2 - 281671.6k + 136496.32$$
> 求导置零：$k^\star = \dfrac{281671.6}{2\times 145416} = 0.9685$，预测 $y = 0.9685\times176 - 100 = 70.46$。
> 两次预测差 0.16，说明**截距的取值对结果影响有限**，但自由求解 $b$ 才是正确的做法。

### 2.4 多元线性回归与正规方程

**Step 1：把样本写成矩阵。** 给 $\boldsymbol{x}_i$ 前拼接一列常数 1（吸收截距 $b$），设

$$\boldsymbol{X} =
\begin{bmatrix}
1 & x_{11} & \cdots & x_{1d}\\
1 & x_{21} & \cdots & x_{2d}\\
\vdots & \vdots & & \vdots\\
1 & x_{n1} & \cdots & x_{nd}
\end{bmatrix}_{n\times(d+1)},
\qquad
\boldsymbol{y} = \begin{bmatrix}y_1\\ \vdots\\ y_n\end{bmatrix},
\qquad
\boldsymbol{w} = \begin{bmatrix}b\\ w_1\\ \vdots\\ w_d\end{bmatrix}
$$

**Step 2：损失函数的矩阵形式。**

$$J(\boldsymbol{w}) = \frac{1}{2}(\boldsymbol{y}-\boldsymbol{X}\boldsymbol{w})^\top(\boldsymbol{y}-\boldsymbol{X}\boldsymbol{w})$$

展开：

$$
\begin{aligned}
J(\boldsymbol{w}) &= \frac12\big(\boldsymbol{y}^\top\boldsymbol{y} - \boldsymbol{y}^\top\boldsymbol{X}\boldsymbol{w} - \boldsymbol{w}^\top\boldsymbol{X}^\top\boldsymbol{y} + \boldsymbol{w}^\top\boldsymbol{X}^\top\boldsymbol{X}\boldsymbol{w}\big)\\
&= \frac12\boldsymbol{y}^\top\boldsymbol{y} - \boldsymbol{w}^\top\boldsymbol{X}^\top\boldsymbol{y} + \frac12\boldsymbol{w}^\top\boldsymbol{X}^\top\boldsymbol{X}\boldsymbol{w}
\end{aligned}
$$

（用到 $\boldsymbol{y}^\top\boldsymbol{X}\boldsymbol{w} = \boldsymbol{w}^\top\boldsymbol{X}^\top\boldsymbol{y}$，二者都是标量。）

**Step 3：对 $\boldsymbol{w}$ 求梯度置零。** 用两条矩阵求导结论：$\nabla_{\boldsymbol w}(\boldsymbol{w}^\top\boldsymbol{a})=\boldsymbol{a}$，$\nabla_{\boldsymbol w}(\boldsymbol{w}^\top\boldsymbol{A}\boldsymbol{w})=2\boldsymbol{A}\boldsymbol{w}$（$\boldsymbol A$ 对称）。于是

$$\frac{\partial J}{\partial \boldsymbol{w}} = -\boldsymbol{X}^\top\boldsymbol{y} + \boldsymbol{X}^\top\boldsymbol{X}\boldsymbol{w} = 0$$

**Step 4：得到正规方程（Normal Equation）。**

$$\boxed{\boldsymbol{X}^\top\boldsymbol{X}\,\boldsymbol{w} = \boldsymbol{X}^\top\boldsymbol{y}}
\quad\Longrightarrow\quad
\boxed{\boldsymbol{w} = (\boldsymbol{X}^\top\boldsymbol{X})^{-1}\boldsymbol{X}^\top\boldsymbol{y}}$$

**每一项的解释**：

| 符号 | 含义 |
| --- | --- |
| $\boldsymbol{X}$ | $n\times(d+1)$ 的设计矩阵（特征矩阵 + 一列 1） |
| $\boldsymbol{X}^\top\boldsymbol{X}$ | $(d+1)\times(d+1)$ 的方阵，反映特征间的二阶统计量 |
| $\boldsymbol{X}^\top\boldsymbol{y}$ | $(d+1)\times1$ 向量，反映特征与标签的相关性 |
| $(\boldsymbol{X}^\top\boldsymbol{X})^{-1}$ | 方阵的逆；**存在的条件是 $\boldsymbol X$ 列满秩（特征不共线）** |

> **重要纠正**：$\boldsymbol{X}^\top\boldsymbol{X}$ **不一定可逆**。当存在完全共线的特征（如"身高(cm)"与"身高(m)"）或 $d>n$ 时它是奇异的。此时 scikit-learn 会用伪逆（`np.linalg.pinv`）得到**最小范数解**，或者应该改用岭回归。

### 2.5 梯度下降法

**思想**：把可微的损失函数想象成一座山，要找山谷最低点——**在当前位置环顾四周，朝最陡的下坡方向走一步，重复。**

**下山算法**：
1. 初始化位置 $S$（随机初始化权重）；
2. 环顾四周，若四周都比 $S$ 高，则 $S$ 是山底，结束；
3. 否则找坡度最陡的方向 $x$；
4. 沿 $x$ 向下走步长 $a$，到达 $S'$；
5. 回到第 2 步。

**梯度（gradient）**：
- 单变量函数中，梯度就是该点的导数（切线斜率）；
- 多变量函数中，梯度是由各偏导数组成的向量；
- **梯度的方向是函数值上升最快的方向**，所以下降要取负方向。

**梯度下降的更新公式**：

$$\boxed{\theta_{j} := \theta_{j} - \alpha\frac{\partial J(\theta)}{\partial \theta_j}}\qquad(\text{对所有 } j \text{ 同时更新})$$

其中 $\alpha$ 是**学习率（learning rate）/步长**，机器学习中常取 $0.001\sim0.01$。

**手算示例**：最小化 $J(\theta)=\theta^2$，$J^\prime(\theta)=2\theta$，取 $\alpha=0.4$，初值 $\theta=1$：

| 步 | 计算 | $\theta$ | $J(\theta)=\theta^2$ |
| --- | --- | --- | --- |
| 0 | 初始 | 1.0 | 1.0 |
| 1 | $1-0.4\times2\times1$ | 0.2 | 0.04 |
| 2 | $0.2-0.4\times2\times0.2$ | 0.04 | 0.0016 |
| 3 | $0.04-0.4\times0.08$ | 0.008 | $6.4\times10^{-5}$ |
| 4 | $0.008-0.4\times0.016$ | 0.0016 | $2.56\times10^{-6}$ |

**结论**：四步就基本抵达最低点 $\theta^\star=0$。这也说明：当函数是二次的且学习率合适时，梯度下降是**指数级收敛**的。

**收敛判据**：① 两次迭代的参数/损失变化小于阈值；② 达到指定迭代次数。

**学习率的选择**：

| 学习率 | 现象 |
| --- | --- |
| 太小 | 收敛极慢，迭代很多次还在半山腰 |
| 合适 | 稳定下降，几十~几百步收敛 |
| 太大 | 在最低点两侧来回震荡（错过最低点），甚至**梯度爆炸**发散 |

**银行信贷案例的标量形式**：对每个样本 $i$，$h_w(\boldsymbol{x}_i)=w_1x_{i1}+w_2x_{i2}+w_3x_{i3}+b$，损失取平方误差，则对 $w_j$ 的梯度为

$$\frac{\partial J_i}{\partial w_j} = -2\big(y_i - h_w(\boldsymbol{x}_i)\big)\,x_{ij}$$

它清楚地显示出：**误差越大，本次参数更新的步子越大**；这正是"拟合残差"的最朴素体现。

### 2.6 梯度下降的四种变体

| 算法 | 每次迭代用多少样本算梯度 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 全梯度下降 FGD（Batch GD） | **全部 $m$ 个样本** | 梯度准、方向稳、收敛曲线平滑 | 每步计算量大，大数据集训练慢 |
| 随机梯度下降 SGD | **随机 1 个样本** | 单步极快，能跳出局部最优 | 梯度噪声大、震荡、不稳定 |
| 小批量梯度下降 Mini-batch | 随机 $x$ 个样本（$1<x<m$） | 兼顾效率与稳定，**当前使用最多** | 需要调 batch_size |
| 随机平均梯度下降 SAG | 随机取 1 个样本，但用**历史梯度的均值**更新 | 收敛更快（利用历史信息） | 训练初期表现差，需额外内存 |

**联系**：batch_size $=1 \Rightarrow$ SGD；batch_size $=n \Rightarrow$ FGD；mini-batch 是二者的插值。

**API 对应**：`sklearn.linear_model.SGDRegressor`。

**SAG 的运作细节**：维护一个梯度列表，每次随机抽一个样本，计算它的梯度并**覆盖**列表里该样本的旧梯度，然后用**列表中所有梯度的均值**去更新参数。

### 2.7 正规方程 vs 梯度下降

| 对比项 | 正规方程 | 梯度下降 |
| --- | --- | --- |
| 求解方式 | 一步到位（解析解） | 迭代逼近 |
| 需要选学习率 | 不需要 | **需要**，且 $\alpha$ 影响很大 |
| 需要特征缩放 | 不需要 | 强烈建议标准化 |
| 计算复杂度 | $O(d^3)$（求逆） | 每轮 $O(nd)$ |
| 特征数很大时（$d>10^4$） | 慢，求逆不可行 | **推荐** |
| 适用场景 | 中小规模、需要精确解 | 大规模、噪声数据、各类损失函数通用 |

> **一句话**：**深度学习中几乎只用梯度下降**，因为参数动辄上亿，$O(d^3)$ 的求逆完全不可行，而且很多损失函数没有解析解。

### 2.8 欠拟合、过拟合与正则化

| 状态 | 训练集表现 | 测试集表现 | 原因 |
| --- | --- | --- | --- |
| 欠拟合 | 差 | 差 | 模型过于简单，学到的特征太少 |
| 过拟合 | 好 | 差 | 模型过于复杂、数据不纯、训练量太少 |

**代码给出的实证**（数据为 $y=0.5x^2+x+2+\varepsilon$，$x\sim U(-3,3)$，100 个点，$\varepsilon\sim N(0,1)$）：

| 设置 | 特征 | MSE |
| --- | --- | --- |
| 只用 $x$（一次） | 1 维 | 3.0750（欠拟合） |
| $x, x^2$ | 2 维 | 1.0987（基本拟合） |
| $x,\dots,x^{10}$ | 10 维 | 1.0508（训练误差更低，但曲线剧烈抖动 = 过拟合） |

> **注意这个反直觉现象**：过拟合模型在**训练集**上的 MSE（1.0508）比"正好拟合"的（1.0987）**更小**。所以"训练误差小"绝不能作为模型好的证据——必须看测试集。

**解决欠拟合**：
1. 添加其他特征项（"组合"、"泛化"、"相关性"三类特征是特征添加的重要手段）；
2. 添加多项式特征项（把线性模型通过二次、三次项变强）；
3. 减小正则化力度、换更强模型。

**解决过拟合**：
1. 重新清洗数据（处理异常点、数据不纯的地方）；
2. 增大训练数据量；
3. **正则化**（机器学习与深度学习中最常用的手段）；
4. 减少特征维度，防止维数灾难。

**正则化（regularization）的本质**：在损失函数中额外加一项惩罚，抑制参数（尤其是高次项权重）变得过大。为什么要抑制大权重？因为**某个特征的异常值会让它对应的权重变得过大/过小**：若某个异常点 $A(x_1,x_2)$ 的 $x_2$ 极大，为了拟合它，$k_2$ 就必须被压得很小，模型被这个点绑架。

**L1 正则化（Lasso）**：

$$J = J_0 + \alpha\sum_{i=1}^{n}|w_i|$$

**L2 正则化（Ridge，岭回归）**：

$$J = J_0 + \alpha\sum_{i=1}^{n}w_i^2$$

其中 $\alpha$ 叫**惩罚系数**：$\alpha$ 越大，对权重的惩罚越强，权重被压得越小。

| 对比项 | L1（Lasso） | L2（Ridge） |
| --- | --- | --- |
| 惩罚项 | $\alpha\sum\lvert w_i\rvert$ | $\alpha\sum w_i^2$ |
| 权重效果 | 趋向 0，**部分直接等于 0** | 趋向 0，**一般不等于 0** |
| 是否做特征选择 | **是**（系数为 0 即特征失效） | 否 |
| 几何解释 | 菱形约束，最优解易落在**顶点** | 圆形约束，最优解落在圆上（平滑收缩） |
| API | `sklearn.linear_model.Lasso(alpha=...)` | `sklearn.linear_model.Ridge(alpha=...)` |
| 工程建议 | 想做稀疏、筛特征时用 | **一般优先用 L2** |

> **几何直觉（补推导）**：L1 的约束域 $|w_1|+|w_2|\le c$ 是**菱形**，等高线与菱形相切的最优点极易落在菱形的**顶点**（如 $(0,c)$）上，于是产生精确的 0；L2 的约束域 $w_1^2+w_2^2\le c$ 是**圆**，切点一般不会正好在坐标轴上，所以只做平滑收缩。

**Ridge 与 SGDRegressor 的关系**：`SGDRegressor(penalty='l2', loss='squared_loss')` 与 `Ridge` 达到的效果相同，区别是前者**只能用随机梯度下降**优化，而 Ridge 的求解器选择更多。这也解释了填空答案：岭回归中 $\alpha$ 越大 → 正则化力度越大 → 所得权重系数越小；反之权重系数越大。

## 3. 可运行示例

### 3.1 身高体重：一元线性回归与手解对照

```python
# -*- coding: utf-8 -*-
"""一元线性回归：身高 -> 体重，并与手算的解析解对照"""
import numpy as np
from sklearn.linear_model import LinearRegression

x_train = [[160], [166], [172], [174], [180]]
y_train = [56.3, 60.6, 65.1, 68.5, 75.0]

estimator = LinearRegression()
estimator.fit(x_train, y_train)
print("权重 coef_ :", estimator.coef_) # [0.92942177]
print("偏置 intercept_ :", estimator.intercept_) # -93.27346938775514
print("预测 176cm 体重 :", estimator.predict([[176]])) # [70.3047619]

# ---- 手算验证：解正规方程 ----
X = np.array(x_train, dtype=float).ravel()
y = np.array(y_train)
A = np.vstack([X, np.ones_like(X)]).T # 设计矩阵 [x, 1]
w = np.linalg.solve(A.T @ A, A.T @ y) # (X'X)^-1 X'y
print("手算 k, b :", w)
```

### 3.2 波士顿房价预测（正规方程 vs 梯度下降）

> `sklearn.datasets.load_boston` 在 scikit-learn 1.2 起已被移除（伦理争议），学习笔记也给出了替代方案——直接从原始地址读取。下面使用**离线可复现**的 California Housing 数据集，流程完全一致。

```python
# -*- coding: utf-8 -*-
"""回归案例：标准化 -> 正规方程 / SGD -> MSE、RMSE、MAE 评估"""
from sklearn.datasets import fetch_california_housing
from sklearn.linear_model import LinearRegression, SGDRegressor
from sklearn.metrics import (mean_absolute_error, mean_squared_error,
root_mean_squared_error)
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

# 1. 加载数据（若网络不可用，可换成 pandas 读取本地 csv）
data = fetch_california_housing()
X, y = data.data, data.target

# 2. 划分数据集
X_train, X_test, y_train, y_test = train_test_split(
X, y, test_size=0.2, random_state=22
)

# 3. 特征工程：标准化（回归中不同特征量纲不一致会影响结果）
transfer = StandardScaler()
X_train = transfer.fit_transform(X_train)
X_test = transfer.transform(X_test)


def evaluate(name, model):
 y_pred = model.predict(X_test)
 print(f"--- {name} ---")
 print("MSE :", mean_squared_error(y_test, y_pred))
 print("RMSE:", root_mean_squared_error(y_test, y_pred))
 print("MAE :", mean_absolute_error(y_test, y_pred))


 # 4a. 正规方程
 lr = LinearRegression(fit_intercept=True)
 lr.fit(X_train, y_train)
 print("coef_ 前 5 项:", lr.coef_[:5], " intercept_:", lr.intercept_)
 evaluate("LinearRegression（正规方程）", lr)

 # 4b. 随机梯度下降
 sgd = SGDRegressor(fit_intercept=True, learning_rate="constant", eta0=0.01,
 max_iter=1000, random_state=22)
 sgd.fit(X_train, y_train)
 evaluate("SGDRegressor（梯度下降）", sgd)
```

### 3.3 欠拟合 / 正好 / 过拟合 / 正则化 四段对照

```python
# -*- coding: utf-8 -*-
"""用同一个数据集演示：欠拟合 -> 正好拟合 -> 过拟合 -> L1/L2 正则化"""
import numpy as np
from sklearn.linear_model import Lasso, LinearRegression, Ridge
from sklearn.metrics import mean_squared_error

# 1. 造数据：真实关系是二次的
np.random.seed(666)
x = np.random.uniform(-3, 3, size=100)
y = 0.5 * x ** 2 + x + 2 + np.random.normal(0, 1, size=100)
X = x.reshape(-1, 1)
X2 = np.hstack([X, X ** 2]) # 2 个特征
X10 = np.hstack([X ** k for k in range(1, 11)]) # 10 个特征


def report(name, model, Xd):
 model.fit(Xd, y)
 mse = mean_squared_error(y, model.predict(Xd))
 coef = np.round(model.coef_, 4)
 print(f"{name:26s} MSE={mse:8.4f} coef_={coef}")


 report("① 欠拟合(仅 x)", LinearRegression(), X)
 report("② 正好拟合(x, x^2)", LinearRegression(), X2)
 report("③ 过拟合(x..x^10)", LinearRegression(), X10)
 report("④ L1 正则化 Lasso(a=0.1)", Lasso(alpha=0.1), X10)
 report("⑤ L2 正则化 Ridge(a=10)", Ridge(alpha=10), X10)
```

**预期现象**：
- ① 的 MSE 最大（约 3.07），曲线是一条直线；
- ②③ 的 MSE 明显下降，③ 略低于 ②，但③ 的系数很大且曲线剧烈波动；
- ④ Lasso 会把一部分高次项系数**精确压成 0**；
- ⑤ Ridge 把高次项系数**压得很小但不为 0**。

### 3.4 sklearn 线性回归 API 速查

| API | 优化方式 | 关键参数 | 关键属性 |
| --- | --- | --- | --- |
| `LinearRegression(fit_intercept=True)` | 正规方程（闭式解） | `fit_intercept`：是否计算偏置 | `coef_`、`intercept_` |
| `SGDRegressor(loss="squared_loss", learning_rate='constant', eta0=0.01)` | 梯度下降 | `loss`、`learning_rate`（如 `'invscaling'` 时 $\eta_t=\eta_0/t^{0.25}$）、`eta0`、`penalty` | `coef_`、`intercept_` |
| `Ridge(alpha=1.0)` | L2 正则（多种求解器） | `alpha` 惩罚力度 | `coef_`、`intercept_` |
| `RidgeCV` | L2 + 内置交叉验证选 `alpha` | `alphas` | `alpha_`、`coef_` |
| `Lasso(alpha=1.0)` | L1 正则 | `alpha` 惩罚力度 | `coef_`（部分为 0） |

## 4. 常见坑

| # | 坑 | 现象 | 原因 | 正确做法 |
| --- | --- | --- | --- | --- |
| 1 | 认为 $X^\top X$ 一定可逆 | 代码报奇异矩阵 / 结果不稳定 | 特征完全共线或 $d>n$ | 删冗余特征、用 `Ridge`、或用伪逆 |
| 2 | 梯度下降前不标准化 | 收敛极慢或震荡 | 各特征尺度不同，等高线细长 | 先 `StandardScaler` |
| 3 | 学习率设太大 | 损失越来越大甚至 NaN | 步子跨过最低点 → 梯度爆炸 | 从 0.01/0.001 起调，观察损失曲线 |
| 4 | `SGDRegressor` 不设 `random_state`/`max_iter` | 结果每次不同、未收敛警告 | SGD 本身有随机性且默认迭代不足 | 固定随机种子，增大 `max_iter` |
| 5 | 只看训练集 MSE 就下结论 | 过拟合被误判为好模型 | 训练误差随复杂度单调下降 | 必须看测试集 / 交叉验证 |
| 6 | 认为多项式回归不属于线性回归 | 概念混淆 | 混淆了"对 $x$ 线性"与"对 $w$ 线性" | 记住：线性回归定义在**参数**上 |
| 7 | 正则化时对特征不做标准化 | L1/L2 惩罚不公平 | 惩罚项对量纲敏感 | 正则化前必须标准化 |
| 8 | $\alpha$ 调得过大 | 所有系数趋 0，预测恒为均值 → 欠拟合 | 惩罚过强 | 用 `RidgeCV`/`LassoCV` 或网格搜索选 $\alpha$ |
| 9 | 用 MAE 作为唯一指标却训练 MSE | 指标与目标不一致 | 训练目标与评估目标不同 | 训练/评估口径尽量一致 |
| 10 | 比较不同数据量下的 RMSE | 结论错误 | RMSE 受样本量与量纲影响 | 统一数据划分与量纲再比较 |
| 11 | `predict` 传一维列表 | 报 `Expected 2D array` | sklearn 要求二维特征 | `predict([[176]])` 或 `reshape(1, -1)` |

## 5. 面试问答

<details><summary>Q1：正规方程和梯度下降各自的适用场景是什么？为什么深度学习不用正规方程？</summary>

**参考答案**

**正规方程** $\boldsymbol{w}=(\boldsymbol{X}^\top\boldsymbol{X})^{-1}\boldsymbol{X}^\top\boldsymbol{y}$：
- 优点：**一步得到解析解**，无需调学习率、无需迭代、无需特征缩放、结果精确；
- 缺点：需要计算 $(d+1)\times(d+1)$ 矩阵的逆，复杂度 $O(d^3)$；当特征数 $d$ 很大时不可行；$\boldsymbol{X}^\top\boldsymbol{X}$ 可能不可逆。

**梯度下降**：
- 优点：复杂度每轮 $O(nd)$，适合大数据、大特征数；对各种可导损失函数都通用；天然支持 mini-batch 与在线学习；
- 缺点：需要选学习率、需要迭代、需要特征缩放。

**深度学习不用正规方程的原因**：
1. 参数量动辄百万~上亿，$O(d^3)$ 完全不可行，内存也放不下 $d\times d$ 矩阵；
2. 深度网络是非凸的，正规方程本来也不适用；
3. 很多损失函数没有闭式解；
4. mini-batch SGD 还带来了正则化效应，并且能做在线/增量训练。
</details>

<details><summary>Q2：L1 和 L2 正则化的区别是什么？为什么 L1 能产生稀疏解？</summary>

**参考答案**

**形式**：L1 加 $\alpha\sum|w_i|$（对应 Lasso），L2 加 $\alpha\sum w_i^2$（对应 Ridge）。

| | L1 | L2 |
| --- | --- | --- |
| 权重 | 部分精确为 0 | 趋近 0 但非 0 |
| 功能 | 特征选择、稀疏 | 平滑收缩、抗共线 |
| 求导 | 在 0 点不可导，需次梯度/坐标下降 | 处处可导，可用闭式解 |

**为什么 L1 稀疏（几何解释）**：带约束的等价形式是 $\min \|\boldsymbol{y}-\boldsymbol{Xw}\|^2$ s.t. $\|\boldsymbol{w}\|_1\le c$。L1 的约束域是**菱形（多面体）**，它有突出的**顶点落在坐标轴上**；损失函数的等高线（椭圆）从最小二乘解出发向外扩张，第一次接触约束域的位置**极大概率是顶点**，此时某些坐标恰好为 0。L2 的约束域是**圆/球**，边界处处光滑没有顶点，切点一般不会正好在坐标轴上，所以只把系数整体缩小。

**补充**：从贝叶斯视角看，L1 对应参数的**拉普拉斯先验**（尖峰在 0），L2 对应**高斯先验**（峰在 0 但平滑），先验越尖越容易把后验推向 0。工程上一般优先用 L2，除非确实需要稀疏/筛特征。
</details>

<details><summary>Q3：为什么回归任务中常用 MSE 作为损失函数，而评估时又常说"RMSE 更好"？</summary>

**参考答案**

**训练用 MSE** 的理由：
1. **处处可导**，梯度是线性的（$\partial J/\partial w_j = -\frac{2}{n}\sum(y_i-\hat y_i)x_{ij}$），便于梯度下降；
2. 是**凸函数**，有唯一的全局最小值，能直接解出正规方程的闭式解；
3. 对大误差惩罚强，促使模型去修正偏差最大的样本。

**评估时提 RMSE** 的理由：
1. **量纲与 $y$ 一致**（MSE 是 $y$ 的平方），"误差 3 万元"比"误差 9 万元²"直观；
2. 对**大误差更敏感**，能暴露少数预测得很差的样本。

**关键提醒**：因为 RMSE 会放大异常点和噪声，如果**直接以 RMSE 为唯一优化目标**，模型会努力把噪声也拟合进去，导致**过拟合**。的数据集二（加入 $\sin(x)e^{x/20}$ 的波动项）就展示了这一点：RMSE 接近 MAE 的两倍。因此：
- 数据含少量异常点 → 可优先看 MAE；
- 想强调大误差 → 看 RMSE；
- **两个指标要综合看**，并且不同数据量下的 RMSE 不可直接比较。
</details>

## 6. 自测题

<details><summary>1. 数据 $x=\{160,166,172,174,180\}$、$y=\{56.3,60.6,65.1,68.5,75\}$，写出最小二乘的方程组并说明 $k,b$。</summary>

统计量：$\sum x = 852$、$\sum y=325.5$、$\sum x^2=145416$、$\sum xy=55683.8$、$n=5$。

由 $\partial J/\partial k = 0$ 与 $\partial J/\partial b=0$ 得：

$$
\begin{cases}
145416k + 852b = 55683.8\\
852k + 5b = 325.5
\end{cases}
$$

解得 $k \approx 0.9294$、$b\approx -93.2735$，故 $\hat y(176) = 0.9294\times176 - 93.2735 \approx 70.30$（kg）。
</details>

<details><summary>2. 写出多元线性回归的正规方程，并说明 $X^\top X$ 可逆的条件。</summary>

$$\boldsymbol{w}=(\boldsymbol{X}^\top\boldsymbol{X})^{-1}\boldsymbol{X}^\top\boldsymbol{y}$$

其中 $\boldsymbol{X}$ 是 $n\times(d+1)$ 的设计矩阵（第一列全为 1 以吸收截距）。

$\boldsymbol{X}^\top\boldsymbol{X}$ 可逆的充要条件是 **$\boldsymbol{X}$ 列满秩**，即：
1. 各特征之间**不存在完全线性相关**（不能出现"身高 cm"和"身高 m"这种共线特征）；
2. 样本数 $n$ 大于特征数 $d+1$。

若不满足，需删除冗余特征、使用伪逆（scikit-learn 的 `LinearRegression` 内部即用 `pinv`）或改用岭回归。
</details>

<details><summary>3. 对 $J(\theta)=\theta^2$ 取 $\alpha=0.4$、初值 $\theta_0=1$，写出前三步迭代结果并说明学习率过大的后果。</summary>

更新式：$\theta \leftarrow \theta - \alpha \cdot 2\theta = (1-0.8)\theta = 0.2\theta$。

| 步 | $\theta$ |
| --- | --- |
| 0 | 1 |
| 1 | 0.2 |
| 2 | 0.04 |
| 3 | 0.008 |

**学习率过大的后果**：若 $\alpha > 1$（对本例即 $|1-2\alpha|>1$），$\theta$ 会不断变大，损失发散（梯度爆炸）；若 $\alpha$ 略大于最优值但 $|1-2\alpha|<1$，则会以震荡方式缓慢收敛。学习率太小则收敛极慢。
</details>

<details><summary>4. FGD、SGD、Mini-batch、SAG 的核心区别是什么？batch_size 与它们的关系？</summary>

| 算法 | 每步使用的样本 | 关键特点 |
| --- | --- | --- |
| FGD | 全部 $m$ 个 | 梯度准、慢 |
| SGD | 随机 1 个 | 快、震荡、易跳出局部最优 |
| Mini-batch | 随机 $x$ 个（$1<x<m$） | 兼顾稳定与效率，**最常用** |
| SAG | 随机 1 个，但用历史梯度的均值 | 利用历史信息加速；初期慢，需额外内存 |

关系：`batch_size = 1` 退化为 SGD；`batch_size = m` 退化为 FGD。
</details>

<details><summary>5. 某模型的权重系数出现了非常大的值（如 $10^6$），这是好现象还是坏现象？为什么？如何解决？</summary>

**坏现象**。权重过大通常意味着：
1. 模型在**过度拟合**训练数据中的噪声或异常点——为了穿过某个异常点，直线被迫剧烈倾斜；
2. 特征量纲差异巨大导致数值不稳定；
3. 特征之间存在高度共线性，导致系数互相抵消、绝对值膨胀。

**解决办法**：
1. 加 **L2 正则化**（Ridge），直接把 $\sum w_i^2$ 压小；
2. 加 **L1 正则化**（Lasso），把无用特征的系数直接置 0；
3. **标准化特征**，消除量纲影响；
4. 清洗异常点、做特征选择或降维（PCA）；
5. 增加训练数据量。
</details>
