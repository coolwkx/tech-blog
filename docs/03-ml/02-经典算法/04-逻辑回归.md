# 逻辑回归

> **一句话总结**：逻辑回归（Logistic Regression）名字里有"回归"，实际是**二分类的线性分类器**——它先用线性模型 $z=\boldsymbol{w}^\top\boldsymbol{x}+b$ 算出一个分数，再用 sigmoid 把它压进 $(0,1)$ 当作概率，最后用**极大似然估计**导出交叉熵损失，用梯度下降求参数。
> **前置知识**：线性回归与梯度下降（见 [03-线性回归](03-线性回归.md)）、概率的基本概念（条件概率、独立事件）、对数运算、混淆矩阵的基本直觉。
> **学完能做到**：
> 1. 推导 sigmoid 的导数 $\sigma'=\sigma(1-\sigma)$，并完整走一遍"似然 → 对数似然 → 交叉熵损失 → 梯度"的推导链；
> 2. 用 `LogisticRegression` 完成癌症预测与电信客户流失预测，并正确处理缺失值、one-hot 编码、不平衡样本；
> 3. 读懂混淆矩阵，独立计算 Precision / Recall / F1 / TPR / FPR / AUC，并解释为什么"准确率高"不等于"模型好"。

## 1. 核心思想

### 1.1 为什么线性回归不能直接做分类

分类任务的标签是 $\{0,1\}$（离散），而线性回归的输出是 $(-\infty,+\infty)$ 的连续值。直接用线性回归做分类有三个致命问题：
1. 输出无法解释为概率，可能给出 $-3$ 或 $17$ 这种"概率"；
2. 对异常点极其敏感（一个远处的样本就能把决策边界拽偏）；
3. 平方损失在分类问题上非凸，且对"已经分对但很自信"的样本仍在惩罚。

**逻辑回归的解法**：保留线性部分，但把输出**映射到概率区间**。

### 1.2 基本思想三步走

| 步骤 | 数学表达 | 说明 |
| --- | --- | --- |
| ① 线性打分 | $z = \boldsymbol{w}^\top\boldsymbol{x} + b$ | 根据特征的重要性算一个实数值 |
| ② 概率映射 | $p = \sigma(z) = \dfrac{1}{1+e^{-z}}$ | 把 $(-\infty,+\infty)$ 压到 $(0,1)$ |
| ③ 阈值决策 | $\hat y = \mathbb{1}[p \ge 0.5]$ | 默认阈值 0.5；可调（如 0.6） |

假设函数：$h_w(\boldsymbol{x}) = \sigma(\boldsymbol{w}^\top\boldsymbol{x}+b) = P(y=1\mid\boldsymbol{x};\boldsymbol{w})$

> 一句话记忆：**"线性回归的输出，作为逻辑回归的输入"**。

### 1.3 应用场景

| 场景 | 正例 | 反例 |
| --- | --- | --- |
| 预测疾病 | 阳性 | 阴性 |
| 银行信贷 | 放贷 | 不放贷 |
| 情感分析 | 正面 | 负面 |
| 广告投放 | 点击 | 不点击 |
| 客户流失 | 流失 | 不流失 |

### 1.4 sigmoid 函数一览

| 属性 | 内容 |
| --- | --- |
| 公式 | $\sigma(z)=\dfrac{1}{1+e^{-z}}$ |
| 定义域 / 值域 | $(-\infty,+\infty)$ → $(0,1)$ |
| 单调性 | 单调递增 |
| 拐点 | $(0,\ 0.5)$，即 $z=0$ 时 $p=0.5$ |
| 对称性 | $\sigma(-z)=1-\sigma(z)$ |
| 导数 | $\sigma'(z)=\sigma(z)\big(1-\sigma(z)\big)$ |
| 用 numpy | `1/(1+np.exp(-z))` |

### 1.5 分类评估指标总表（逻辑回归的核心考点）

| 指标 | 公式 | 含义 | 何时最重要 |
| --- | --- | --- | --- |
| Accuracy 准确率 | $\frac{TP+TN}{TP+TN+FP+FN}$ | 整体预测正确的比例 | 类别均衡时 |
| Precision 精确率/查准率 | $\frac{TP}{TP+FP}$ | 预测为正的里面，真正为正的比例 | 误报代价高（垃圾邮件、推荐） |
| Recall 召回率/查全率 | $\frac{TP}{TP+FN}$ | 真正为正的里面，被找出来的比例 | 漏报代价高（癌症筛查、风控） |
| F1-score | $\frac{2\cdot P\cdot R}{P+R}$ | P 与 R 的**调和平均** | 需要 P、R 兼顾 |
| TPR（=Recall） | $\frac{TP}{TP+FN}$ | 正样本被判正的概率 | ROC 纵轴 |
| FPR | $\frac{FP}{FP+TN}$ | 负样本被判正的概率 | ROC 横轴 |
| AUC | ROC 曲线下面积 | 模型对正负样本的**排序辨别能力** | 类别不平衡、需选阈值时 |

## 2. 算法细节

### 2.1 sigmoid 及其导数（手推）

$$\sigma(z) = \frac{1}{1+e^{-z}}$$

**求导**：把 $\sigma(z) = (1+e^{-z})^{-1}$ 看作复合函数，外层 $u^{-1}$、内层 $1+e^{-z}$。

$$
\begin{aligned}
\sigma'(z) &= -(1+e^{-z})^{-2}\cdot\frac{d}{dz}(1+e^{-z})\\
&= -(1+e^{-z})^{-2}\cdot(-e^{-z})\\
&= \frac{e^{-z}}{(1+e^{-z})^{2}}
\end{aligned}
$$

再把它凑成 $\sigma(1-\sigma)$ 的形式：

$$
\sigma(z)\big(1-\sigma(z)\big)
= \frac{1}{1+e^{-z}}\cdot\frac{e^{-z}}{1+e^{-z}}
= \frac{e^{-z}}{(1+e^{-z})^2}
$$

$$\boxed{\sigma'(z) = \sigma(z)\big(1-\sigma(z)\big)}$$

**为什么这个结论极其重要**：它让交叉熵损失的梯度变成非常简洁的形式（见 2.4），避免了每次都要重算指数。

### 2.2 概率复习

| 概念 | 定义 | 例子 |
| --- | --- | --- |
| 概率 | 事件发生的可能性 | 抛硬币正面概率 $\theta$ |
| 联合概率 | 多个随机变量**同时**发生的概率 | $P(A,B)=P(A)P(B)$（独立时） |
| 条件概率 | 事件 A 在 B 已发生条件下的概率 | $P(A\mid B)=\dfrac{P(A,B)}{P(B)}$ |

### 2.3 极大似然估计（Maximum Likelihood Estimation）

**核心思想**：设模型中含有待估参数 $w$，它可能取很多值。既然已经观测到了样本 $D$，那就从 $w$ 的所有可能值中，**选出使观测结果出现概率最大的那个值**作为估计值。

**抛硬币例子**：一枚不均匀硬币，正面概率为 $\theta$，抛 6 次得到 $D=\{$正, 反, 反, 正, 正, 正$\}$，各次独立，则

$$P(D\mid\theta)=\theta\cdot(1-\theta)\cdot(1-\theta)\cdot\theta\cdot\theta\cdot\theta = \theta^4(1-\theta)$$

问题转化为：**求使 $P(D\mid\theta)$ 最大的 $\theta$**。

- 取对数（把连乘变连加，单调变换不改变极值点）：$\ln L(\theta)=4\ln\theta+\ln(1-\theta)$
- 求导置零：$\dfrac{4}{\theta}-\dfrac{1}{1-\theta}=0 \Rightarrow 4(1-\theta)=\theta \Rightarrow \theta^\star=\dfrac{4}{5}=0.8$

**直观验证**：6 次里 4 次正面，"正面概率 = 4/6 = 0.8"确实就是最合理的猜测。

**为什么要取对数？**

| 原因 | 说明 |
| --- | --- |
| 把连乘变连加 | $\ln\prod p_i=\sum\ln p_i$，避免大量小数连乘导致**下溢为 0** |
| 求导更方便 | 对数的导数形式简单（$(\ln x)'=1/x$） |
| 不改变极值 | $\ln$ 是单调递增函数，$\arg\max L = \arg\max \ln L$ |

### 2.4 从似然到交叉熵损失（完整手推）

**Step 1：单个样本的"分类正确概率"。** 设某样本被分为 1 类的概率为 $p$，则分为 0 类的概率为 $1-p$。真实标签为 $y\in\{0,1\}$，则**分类正确的概率**可以写成一个统一的式子：

$$P(y\mid\boldsymbol{x}) = p^{\,y}\,(1-p)^{\,1-y}$$

验证：$y=1$ 时得 $p$；$y=0$ 时得 $1-p$。✓

**Step 2：$n$ 个样本的联合概率（似然函数）。** 假设样本独立：

$$L(\boldsymbol{w}) = \prod_{i=1}^{n} p_i^{\,y_i}(1-p_i)^{\,1-y_i},\qquad p_i = \sigma(\boldsymbol{w}^\top\boldsymbol{x}_i)$$

**Step 3：取对数（对数似然）。**

$$\ln L(\boldsymbol{w}) = \sum_{i=1}^{n}\Big[y_i\ln p_i + (1-y_i)\ln(1-p_i)\Big]$$

**Step 4：极大化 → 极小化。** 习惯上取负号，得到**对数似然损失（交叉熵损失，log loss）**：

$$\boxed{J(\boldsymbol{w}) = -\sum_{i=1}^{n}\Big[y_i\ln p_i + (1-y_i)\ln(1-p_i)\Big]},\qquad p_i=\sigma(\boldsymbol{w}^\top\boldsymbol{x}_i)$$

**Step 5：手工验证损失函数的行为。** 假设阈值为 0.6，三个样本的预测与真实如下：

| 样本 | 真实 $y$ | 预测 $p$ | 该样本损失 $-[y\ln p+(1-y)\ln(1-p)]$ |
| --- | --- | --- | --- |
| 1 | 1 | 0.4 | $-\ln 0.4 = 0.916$ |
| 2 | 0 | 0.6 | $-\ln 0.4 = 0.916$ |
| 3 | 1 | 0.41 | $-\ln 0.41 = 0.892$ |

原式的写法正是逐样本展开：`1*log0.4 + (1-1)*log(1-0.4) + 0*log0.6 + (1-0)*log(1-0.6) + ...`

**损失函数的直觉**：

> 每个样本的预测值有 A、B 两个类别，**真实类别对应的那个位置，概率值越大越好**。
> - 当 $y=1$ 时，损失是 $-\ln p$：$p\to 1$ 时损失 → 0；$p\to 0$ 时损失 → $+\infty$。
> - 当 $y=0$ 时，损失是 $-\ln(1-p)$：$p\to 0$ 时损失 → 0；$p\to 1$ 时损失 → $+\infty$。

**为什么不用平方损失？** 因为 $J=\sum(y-p)^2$ 加上 sigmoid 后**非凸**，梯度下降容易陷在局部极小；而交叉熵损失是**凸函数**，有唯一全局最优，且梯度形式极简。

**Step 6：求梯度（手推，很有价值）。** 对单个样本，$p=\sigma(z)$、$z=\boldsymbol{w}^\top\boldsymbol{x}$：

$$
\begin{aligned}
\frac{\partial}{\partial z}\Big[-\big(y\ln p+(1-y)\ln(1-p)\big)\Big]
&= -\left(\frac{y}{p} - \frac{1-y}{1-p}\right)\cdot\frac{\partial p}{\partial z}\\
&= -\left(\frac{y}{p} - \frac{1-y}{1-p}\right)\cdot p(1-p)\\
&= -\Big(y(1-p) - (1-y)p\Big)\\
&= -(y - yp - p + yp)\\
&= p - y
\end{aligned}
$$

再用链式法则 $\dfrac{\partial J}{\partial w_j} = \dfrac{\partial J}{\partial z}\cdot\dfrac{\partial z}{\partial w_j} = (p-y)\,x_j$，于是

$$\boxed{\frac{\partial J}{\partial w_j} = \big(h_w(\boldsymbol{x}) - y\big)\,x_j},\qquad \frac{\partial J}{\partial b} = h_w(\boldsymbol{x}) - y$$

**结论**：梯度 = **（预测概率 − 真实标签）× 特征值**。这与线性回归的梯度形式**完全一致**——这是广义线性模型（GLM）的一个漂亮性质。

**Step 7：参数更新。**

$$w_j := w_j - \alpha\sum_{i=1}^{n}\big(h_w(\boldsymbol{x}_i)-y_i\big)x_{ij}$$

### 2.5 混淆矩阵与指标（含完整计算示例）

**混淆矩阵（二分类）**：

| | 预测正例 | 预测反例 |
| --- | --- | --- |
| **真实正例** | TP（真正例） | FN（伪反例，漏报） |
| **真实反例** | FP（伪正例，误报） | TN（真反例） |

记忆口诀：**True/False 表示预测对不对，Positive/Negative 表示预测成了什么**。且恒有 $TP+FN+FP+TN=$ 总样本数。

**经典例子**：10 个样本，6 个恶性（正例）、4 个良性（反例）。

| 指标 | 模型 A：预测对 3 恶 4 良 | 模型 B：预测对 6 恶 1 良 |
| --- | --- | --- |
| TP / FN / FP / TN | 3 / 3 / 0 / 4 | 6 / 0 / 3 / 1 |
| Accuracy | $(3+4)/10=70\%$ | $(6+1)/10=70\%$ |
| Precision | $3/(3+0)=100\%$ | $6/(6+3)=67\%$ |
| Recall | $3/(3+3)=50\%$ | $6/(6+0)=100\%$ |
| F1 | $\frac{2\times 3}{2\times 3+3+0}=67\%$ | $\frac{2\times 6}{2\times 6+0+3}=80\%$ |

**两个关键洞察**：
1. **两个模型的准确率一模一样（都是 70%），但用途完全不同**——这直接证明"只看准确率不够"；
2. **Precision 与 Recall 是一对跷跷板**：降低阈值 → 更多样本被判为正 → Recall 上升、Precision 下降；升高阈值相反。F1 是二者的折中。

**F1 为什么用调和平均而不是算术平均？** 因为调和平均对"短板"惩罚更重：$P=1.0,R=0.1$ 时算术平均 0.55 看着还行，调和平均只有 $0.18$，更真实地反映了"召回太差"这个问题。

### 2.6 ROC 曲线与 AUC（含完整绘制过程）

**定义**：
- **TPR（True Positive Rate）= Recall**：正样本中被正确预测的比例；
- **FPR（False Positive Rate）**：负样本中被误判为正的比例。

ROC 曲线以 **FPR 为横轴、TPR 为纵轴**，把**所有可能阈值**下的表现连成一条曲线。

**四个特殊点的含义**：

| 点 $(FPR, TPR)$ | 含义 |
| --- | --- |
| $(0,0)$ | 所有样本都预测为负例 |
| $(1,0)$ | 所有样本都预测错误 —— **最差** |
| $(1,1)$ | 所有样本都预测为正例 |
| $(0,1)$ | 所有样本都预测正确 —— **完美** |

**绘制过程（广告点击例子）**：6 次展示、2 次点击，正样本 $\{1,3\}$、负样本 $\{2,4,5,6\}$。按预测概率降序排列：

| 样本 | 真实 | 预测概率 |
| --- | --- | --- |
| 1 | 1 | 0.9 |
| 3 | 1 | 0.8 |
| 2 | 0 | 0.7 |
| 4 | 0 | 0.6 |
| 5 | 0 | 0.5 |
| 6 | 0 | 0.4 |

**阈值法**：把"$\ge$ 阈值"判为正例。

| 阈值 | 判为正例的样本 | TP | FN | FP | TN | TPR | FPR |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 0.9 | {1} | 1 | 1 | 0 | 4 | $1/2=0.5$ | $0/4=0$ |
| 0.8 | {1,3} | 2 | 0 | 0 | 4 | $1.0$ | $0$ |
| 0.7 | {1,3,2} | 2 | 0 | 1 | 3 | $1.0$ | $0.25$ |
| 0.6 | {1,3,2,4} | 2 | 0 | 2 | 2 | $1.0$ | $0.5$ |
| 0.5 | {1,3,2,4,5} | 2 | 0 | 3 | 1 | $1.0$ | $0.75$ |
| 0.4 | 全部 | 2 | 0 | 4 | 0 | $1.0$ | $1.0$ |

得到坐标点：$(0,0.5),\ (0,1),\ (0.25,1),\ (0.5,1),\ (0.75,1),\ (1,1)$。

> ** PPT 中此处的数值有误**：原 PPT 在阈值 0.9 处写 "TPR = 0/2 = 0"，阈值 0.8 处写 "TPR = 1/2 = 0.5"，到 0.7 才跳到 $2/2=1$，且 FPR 从 0.7 才开始增长。按"阈值 0.9 时只有样本 1（真实为 1）被判为正"计算，正确结果是 $TPR=1/2=0.5$、$FPR=0$。本文表格已按定义修正，**结论与趋势不变**。

**AUC（Area Under the ROC Curve）**：

| 性质 | 说明 |
| --- | --- |
| 取值范围 | $[0,1]$ |
| 越大越好 | 曲线越靠近左上角 $(0,1)$，面积越大 |
| $AUC=1$ | 完美分类器（几乎不存在） |
| $AUC=0.5$ | 等价于**随机猜测**（对角线） |
| $AUC<0.5$ | 比随机猜测还差（通常说明标签或预测反了） |
| 等价含义 | 随机取一正一负样本，模型给正样本更高分的概率 |

### 2.7 API 参数详解

```python
sklearn.linear_model.LogisticRegression(penalty='l2', C=1.0, solver='lbfgs', max_iter=100)
```

| 参数 | 含义 | 常用取值 |
| --- | --- | --- |
| `penalty` | 正则化种类 | `'l2'`（默认）、`'l1'`、`'elasticnet'`、`None` |
| `C` | **正则化力度的倒数**（$C=1/\lambda$）：$C$ 越大 → 正则化越弱 → 模型越复杂 | 默认 1.0；试 `[0.01, 0.1, 1, 10, 100]` |
| `solver` | 优化算法 | `'liblinear'`（小数据集、支持 L1）、`'lbfgs'`（默认）、`'sag'/'saga'`（大数据集，`saga` 支持 L1） |
| `max_iter` | 最大迭代次数 | 不收敛时增大（如 1000） |
| `class_weight` | 类别权重 | 不平衡时用 `'balanced'` |

**solver 与 penalty 的兼容性**：

| solver | L1 | L2 | 无正则 |
| --- | --- | --- | --- |
| `liblinear` | 支持 | 支持 | 支持 |
| `lbfgs` / `newton-cg` | 不支持 | 支持 | 支持 |
| `sag` / `saga` | 仅 `saga` | 支持 | 支持 |

**默认正例的坑**：scikit-learn 的 `LogisticRegression` **默认把类别数较少的那类当作正例**。计算 Precision/Recall 时如不确定，请显式传 `pos_label`。

## 3. 可运行示例

### 3.1 手写 sigmoid 与损失函数（验证推导）

```python
# -*- coding: utf-8 -*-
"""手写 sigmoid、交叉熵损失，验证 2.1~2.4 的推导"""
import numpy as np


def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))


def log_loss(y, p):
    """交叉熵损失（对数似然损失的均值形式）"""
    eps = 1e-12 # 防止 log(0)
    p = np.clip(p, eps, 1 - eps)
    return -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))


if __name__ == "__main__":
    # 1. sigmoid 关键取值
    for z in [-5, -1, 0, 1, 5]:
        print(f"sigma({z:2d}) = {sigmoid(z):.6f}")
        print("sigma(-z) + sigma(z) =", sigmoid(-1.3) + sigmoid(1.3)) # 1.0

        # 2. 验证导数公式 sigma' = sigma(1-sigma)（数值微分对照）
        z0, h = 0.7, 1e-6
        num = (sigmoid(z0 + h) - sigmoid(z0 - h)) / (2 * h)
        ana = sigmoid(z0) * (1 - sigmoid(z0))
        print(f"数值导数={num:.8f} 解析导数={ana:.8f}")

        # 3. 损失函数行为：y=1 时 p 越大损失越小
        y1 = np.array([1.0, 1.0, 1.0])
        print("y=1, p=[0.1,0.5,0.9] -> loss =",
        [round(log_loss(y1[i:i + 1], np.array([p])), 4)
        for i, p in enumerate([0.1, 0.5, 0.9])])
        # y=0 时 p 越小损失越小
        y0 = np.array([0.0, 0.0, 0.0])
        print("y=0, p=[0.1,0.5,0.9] -> loss =",
        [round(log_loss(y0[i:i + 1], np.array([p])), 4)
        for i, p in enumerate([0.1, 0.5, 0.9])])

        # 4. 课程示例的逐样本损失（真实 y=[1,0,1]，预测 p=[0.4,0.6,0.41]）
        y = np.array([1.0, 0.0, 1.0])
        p = np.array([0.4, 0.6, 0.41])
        per_sample = -(y * np.log(p) + (1 - y) * np.log(1 - p))
        print("逐样本损失:", np.round(per_sample, 4), " 总计:", round(per_sample.sum(), 4))
```

### 3.2 癌症分类（乳腺癌数据集）

```python
# -*- coding: utf-8 -*-
"""逻辑回归：乳腺癌（Wisconsin）二分类
数据：699 条样本，11 列（第 1 列是 id，后 9 列是医学特征，最后 1 列是类别：2=良性、4=恶性）
含 16 个用 '?' 标出的缺失值
"""
import numpy as np
import pandas as pd
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import (accuracy_score, classification_report,
confusion_matrix, roc_auc_score)
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

CSV = "breast-cancer-wisconsin.csv"


def main():
    # 1. 获取数据
    data = pd.read_csv(CSV)
    print(data.info())

    # 2. 数据基本处理
    # 2.1 缺失值处理：'?' -> NaN -> 删除
    data = data.replace("?", np.nan)
    data = data.dropna()

    # 2.2 确定特征值与目标值（第 1 列 id 没有判别力，丢掉）
    x = data.iloc[:, 1:-1]
    y = data["Class"]

    # 2.3 分割数据：stratify 保持类别比例
    x_train, x_test, y_train, y_test = train_test_split(
    x, y, test_size=0.2, random_state=22, stratify=y
    )

    # 3. 特征工程：标准化（逻辑回归用梯度下降求解，需要统一量纲）
    transfer = StandardScaler()
    x_train = transfer.fit_transform(x_train)
    x_test = transfer.transform(x_test)

    # 4. 模型训练
    estimator = LogisticRegression(max_iter=1000)
    estimator.fit(x_train, y_train)

    # 5. 模型预测与评估
    y_pred = estimator.predict(x_test)
    print("混淆矩阵:\n", confusion_matrix(y_test, y_pred, labels=[2, 4]))
    print("准确率:", accuracy_score(y_test, y_pred))
    print(classification_report(y_test, y_pred, target_names=["良性(2)", "恶性(4)"]))

    # 6. 计算 AUC：必须传"正例的概率"，不能传 0/1 预测标签
    y_score = estimator.predict_proba(x_test)[:, 1]
    print("classes_:", estimator.classes_)
    print("AUC:", roc_auc_score((y_test == 4).astype(int), y_score))

    # 7. 查看系数（标准化后可直接比较特征重要性）
    print("系数:", dict(zip(x.columns, np.round(estimator.coef_[0], 3))))
    print("截距:", estimator.intercept_)


    if __name__ == "__main__":
        main()
```

> **AUC 的正确用法**：`roc_auc_score(y_true, y_score)` 要求 `y_true` 是 **0/1** 标记，`y_score` 是**概率或置信度**。代码里 `roc_auc_score(y_test, y_predict)` 传的是 0/1 预测值，这会退化成"准确率"的变体，**不是真正的 AUC**，实战中必须改为 `predict_proba`。

### 3.3 混淆矩阵、P/R/F1 与 ROC 的一体化演示

```python
# -*- coding: utf-8 -*-
"""用课程的两模型例子，把混淆矩阵到 AUC 一次性算清"""
import numpy as np
import pandas as pd
from sklearn.metrics import (confusion_matrix, f1_score, precision_score,
recall_score, roc_auc_score, roc_curve)

y_true = ["恶性"] * 6 + ["良性"] * 4
y_pred_A = ["恶性"] * 3 + ["良性"] * 3 + ["良性"] * 4
y_pred_B = ["恶性"] * 9 + ["良性"] * 1

labels = ["恶性", "良性"]
for name, y_pred in [("模型A", y_pred_A), ("模型B", y_pred_B)]:
 cm = confusion_matrix(y_true, y_pred, labels=labels)
 df = pd.DataFrame(cm, index=["真实-" + l for l in labels],
 columns=["预测-" + l for l in labels])
 acc = (cm[0, 0] + cm[1, 1]) / cm.sum()
 print(f"===== {name} =====")
 print(df)
 print("准确率 :", round(acc, 4))
 print("精确率 :", round(precision_score(y_true, y_pred, pos_label="恶性"), 4))
 print("召回率 :", round(recall_score(y_true, y_pred, pos_label="恶性"), 4))
 print("F1 :", round(f1_score(y_true, y_pred, pos_label="恶性"), 4))
 print()

 # ---- 手工绘制 ROC 曲线（课程广告点击案例）----
 y_true_click = np.array([1, 0, 1, 0, 0, 0])
 y_score_click = np.array([0.9, 0.7, 0.8, 0.6, 0.5, 0.4])
 fpr, tpr, thresholds = roc_curve(y_true_click, y_score_click)
 print("阈值 :", thresholds)
 print("FPR :", fpr)
 print("TPR :", tpr)
 print("AUC :", roc_auc_score(y_true_click, y_score_click))
```

### 3.4 电信客户流失预测（含 one-hot 与特征筛选）

```python
# -*- coding: utf-8 -*-
"""逻辑回归：电信客户流失预测（类别不平衡，用 AUC 与 F1 评估）"""
import matplotlib.pyplot as plt
import pandas as pd
import seaborn as sns
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import (accuracy_score, classification_report, f1_score,
precision_score, recall_score, roc_auc_score)
from sklearn.model_selection import train_test_split

CSV = "churn.csv"


def load_and_prepare():
    """读取数据 -> one-hot 编码 -> 删除冗余列 -> 重命名标签"""
    data = pd.read_csv(CSV)
    data = pd.get_dummies(data) # 类别型特征独热编码
    data.drop(["gender_Male", "Churn_No"], axis=1, inplace=True) # 各删一列避免完全共线
    data.rename(columns={"Churn_Yes": "flag"}, inplace=True)
    return data


def step1_basic():
    data = load_and_prepare()
    print(data.info())
    print("标签分布:\n", data.flag.value_counts())
    print("流失占比: %.2f%%" % (100 * data.flag.mean()))
    # 从上面的输出可以看出：属于标签不平衡样本（约 26% 流失）


    def step2_feature_select():
        data = load_and_prepare()
        # 用分组柱状图观察 Contract_Month 与流失的关系
        sns.countplot(data=data, x="Contract_Month", hue="flag")
        plt.title("月度签约与流失的关系")
        plt.show()


        def step3_train_and_evaluate():
            data = load_and_prepare()
            x = data[["Contract_Month", "PaymentElectronic", "internet_other"]]
            y = data["flag"]
            x_train, x_test, y_train, y_test = train_test_split(
            x, y, test_size=0.2, random_state=22, stratify=y
            )

            estimator = LogisticRegression(max_iter=1000, class_weight="balanced")
            estimator.fit(x_train, y_train)

            y_pred = estimator.predict(x_test)
            y_score = estimator.predict_proba(x_test)[:, 1]

            print("准确率:", round(accuracy_score(y_test, y_pred), 4))
            print("精确率:", round(precision_score(y_test, y_pred), 4))
            print("召回率:", round(recall_score(y_test, y_pred), 4))
            print("F1 :", round(f1_score(y_test, y_pred), 4))
            print("AUC :", round(roc_auc_score(y_test, y_score), 4))
            print(classification_report(y_test, y_pred, target_names=["不流失", "流失"]))


            if __name__ == "__main__":
                step1_basic()
```

## 4. 常见坑

| # | 坑 | 现象 | 原因 | 正确做法 |
| --- | --- | --- | --- | --- |
| 1 | 用 `predict` 的结果算 AUC | AUC 偏低且与准确率几乎相同 | `roc_auc_score` 需要**概率/置信度**，不是 0/1 | 用 `predict_proba(X)[:, 1]` |
| 2 | 类别不平衡仍只看 Accuracy | 准确率 0.74 却毫无价值 | 全预测"不流失"就有 74% 准确率 | 看 Precision/Recall/F1/AUC，用 `class_weight='balanced'` |
| 3 | 不指定 `pos_label` | Precision/Recall 与预期相反 | sklearn 默认把**少数类**当正例 | 显式传 `pos_label`，或统一把目标编码为 0/1 |
| 4 | `C` 的含义记反 | 调参方向错误 | `C` 是**正则化力度的倒数**，$C$ 越小正则越强 | 记住：`C` 小 → 简单模型；`C` 大 → 复杂模型 |
| 5 | L1 正则却用 `solver='lbfgs'` | 报错/警告 | lbfgs 不支持 L1 | 换 `solver='liblinear'` 或 `'saga'` |
| 6 | 未收敛警告 `ConvergenceWarning` | 系数不可靠 | `max_iter` 太小或未标准化 | 增大 `max_iter`，同时先标准化 |
| 7 | 逻辑回归未做标准化 | 收敛慢、系数不可比 | 梯度下降对量纲敏感 | `StandardScaler` 后再训练 |
| 8 | 阈值固定 0.5 不做调整 | 医疗场景漏诊率高 | 0.5 只是默认，不是最优 | 用 ROC/PR 曲线挑阈值，或按业务成本定制 |
| 9 | 把逻辑回归当回归模型预测连续值 | 输出只有 0/1 | 名字误导 | 需要连续输出用线性回归/其他回归模型 |
| 10 | 混淆矩阵行列顺序搞反 | 指标全错 | `confusion_matrix` 默认按标签升序 | 显式传 `labels=[...]` 并用 DataFrame 标注行列名 |
| 11 | one-hot 后不删冗余列 | 完全共线，系数不稳定 | 哑变量陷阱 | 每类删一列（如 `Churn_No`、`gender_Male`） |
| 12 | 多分类直接套二分类公式 | 结果不合理 | 逻辑回归原生是二分类 | 用 OvR 或 softmax（`multi_class='multinomial'`） |

## 5. 面试问答

<details markdown="1"><summary markdown="1">Q1：逻辑回归为什么用交叉熵损失而不用平方损失？请写出损失函数并说明其来历。</summary>

**参考答案**

**损失函数（对数似然损失 / 交叉熵）**：

$$J(\boldsymbol{w}) = -\sum_{i=1}^{n}\Big[y_i\ln p_i + (1-y_i)\ln(1-p_i)\Big],\qquad p_i=\sigma(\boldsymbol{w}^\top\boldsymbol{x}_i)$$

**来历（极大似然估计）**：
1. 单样本分类正确的概率可统一写成 $P(y\mid x)=p^y(1-p)^{1-y}$（$y=1$ 得 $p$，$y=0$ 得 $1-p$）；
2. $n$ 个独立样本的联合概率（似然）$L=\prod_i p_i^{y_i}(1-p_i)^{1-y_i}$；
3. 取对数把连乘变连加：$\ln L=\sum_i[y_i\ln p_i+(1-y_i)\ln(1-p_i)]$；
4. 极大化对数似然 ⇔ 极小化它的负数，即得交叉熵损失。

**不用平方损失的原因**：
1. **非凸性**：$J=\sum(y-\sigma(\boldsymbol{w}^\top\boldsymbol{x}))^2$ 关于 $\boldsymbol{w}$ 是非凸的，存在多个局部极小；交叉熵损失是**凸函数**，有唯一全局最优。
2. **梯度消失**：平方损失配合 sigmoid 时梯度含 $\sigma'(z)=\sigma(1-\sigma)$ 因子，当预测严重错误（$p\to 0$ 而 $y=1$）时 $\sigma'\to 0$，梯度趋近 0，学习几乎停滞；交叉熵损失的梯度是 $(\sigma(z)-y)x$，误差越大梯度越大，学习越快。
3. **概率解释**：交叉熵等价于最小化模型分布与真实分布之间的 KL 散度，是分类问题的"正确"损失。
</details>

<details markdown="1"><summary markdown="1">Q2：Precision 和 Recall 有什么区别？什么时候更看重哪一个？F1 为什么用调和平均？</summary>

**参考答案**

**定义**：
- Precision $=\dfrac{TP}{TP+FP}$：**预测为正的样本里，真正为正的比例**。衡量"误报"多少。
- Recall $=\dfrac{TP}{TP+FN}$：**真正为正的样本里，被找出来的比例**。衡量"漏报"多少。

**关注点的选择**：

| 场景 | 更看重 | 理由 |
| --- | --- | --- |
| 癌症筛查、地震预警 | **Recall** | 漏掉一个患者/一次地震的代价极高，宁可误报 |
| 垃圾邮件过滤、司法判决 | **Precision** | 误杀正常邮件/冤枉好人的代价高 |
| 搜索排序、推荐 | 视业务而定，通常 F1 | 既要相关又要覆盖 |
| 类别极不平衡（如欺诈 1%） | Precision-Recall 曲线 / F1 | 准确率失去意义 |

**F1 用调和平均**：$F1=\dfrac{2PR}{P+R}=\dfrac{2}{\frac1P+\frac1R}$。调和平均对**较小值更敏感**，起"短板惩罚"作用。例如 $P=1.0, R=0.1$：算术平均 0.55（看起来还行），调和平均 $2\times1\times0.1/1.1\approx0.18$（真实反映"召回太差"）。因此 F1 只有在 P 和 R 都高时才高。

**补充**：也可以用 $F_\beta=\dfrac{(1+\beta^2)PR}{\beta^2P+R}$，$\beta>1$ 偏向 Recall，$\beta<1$ 偏向 Precision。
</details>

<details markdown="1"><summary markdown="1">Q3：AUC 的含义是什么？为什么它比准确率更适合不平衡数据？AUC=0.5 说明什么？</summary>

**参考答案**

**定义**：AUC 是 ROC 曲线（横轴 FPR、纵轴 TPR）下方的面积。

**两个等价解释**：
1. **几何解释**：在所有阈值下，曲线越靠近左上角 $(0,1)$，面积越大，模型越好；
2. **概率解释**：随机抽取一个正样本和一个负样本，模型给正样本的预测分数高于负样本的概率。

**为什么适合不平衡数据**：
- AUC 只依赖模型输出的**排序**，不依赖具体阈值，也不依赖正负样本比例。负样本再多，只要排序不乱，AUC 就不变；
- 而 Accuracy 会被多数类"刷分"：99% 负样本时，全部预测负例就有 99% 准确率，但 AUC 只有 0.5，能立刻暴露问题。

**关键取值**：$1.0$ 完美；$0.9\sim1.0$ 优秀；$0.7\sim0.9$ 一般可用；$0.5$ **等价于随机猜测**；$<0.5$ 比随机猜测更差（通常说明预测方向反了，或标签编码有误）。

**补充**：在极度不平衡（如 1:1000）时，ROC 曲线可能过于乐观（因为 FPR 的分母 TN 极大），此时更推荐 **PR 曲线与 Average Precision**。
</details>

## 6. 自测题

<details markdown="1"><summary markdown="1">1. 推导 sigmoid 的导数，并说明它在逻辑回归中的作用。</summary>

$$\sigma(z)=\frac{1}{1+e^{-z}}=(1+e^{-z})^{-1}$$

$$
\sigma'(z)=-(1+e^{-z})^{-2}\cdot(-e^{-z})=\frac{e^{-z}}{(1+e^{-z})^2}
=\frac{1}{1+e^{-z}}\cdot\frac{e^{-z}}{1+e^{-z}}=\sigma(z)\big(1-\sigma(z)\big)
$$

**作用**：
1. 把 $(-\infty,+\infty)$ 映射到 $(0,1)$，使输出可解释为概率；
2. 它的导数形式极简，使交叉熵损失的梯度化简为 $(\sigma(z)-y)x$，这是逻辑回归能用梯度下降高效训练的关键；
3. 它单调递增、拐点在 $(0,0.5)$，所以默认阈值取 0.5 是自然的。
</details>

<details markdown="1"><summary markdown="1">2. 某二分类模型的混淆矩阵为 TP=40, FN=10, FP=20, TN=130，求 Accuracy、Precision、Recall、F1、FPR。</summary>

- Accuracy $=\dfrac{40+130}{200}=0.85$
- Precision $=\dfrac{40}{60}\approx0.667$
- Recall $=\dfrac{40}{50}=0.80$
- F1 $=\dfrac{2\times0.667\times0.80}{0.667+0.80}\approx0.727$
- FPR $=\dfrac{20}{150}\approx0.133$
</details>

<details markdown="1"><summary markdown="1">3. 逻辑回归的损失函数为什么能通过对数变换简化？取对数会不会改变最优解？</summary>

**简化原因**：似然函数是 $n$ 个概率的**连乘** $L=\prod_i p_i^{y_i}(1-p_i)^{1-y_i}$，直接求导要用乘法法则，极其繁琐，并且大量概率（均小于 1）连乘会**数值下溢**为 0。取对数后变成**连加** $\ln L=\sum_i[\cdot]$，求导只需逐项处理，且数值稳定。

**会不会改变最优解**：不会。因为 $\ln$ 是**单调递增**函数，若 $\theta_1$ 是 $L$ 的最大值点，则对任意 $\theta$ 有 $L(\theta)\le L(\theta_1)\Rightarrow \ln L(\theta)\le \ln L(\theta_1)$，所以 $\theta_1$ 同样是 $\ln L$ 的最大值点。即

$$\arg\max_\theta L(\theta)=\arg\max_\theta \ln L(\theta)$$
</details>

<details markdown="1"><summary markdown="1">4. 为什么说"准确率 70% 的两个模型可能完全不同"？请用例子说明。</summary>

在 6 恶性 + 4 良性的例子中：

| | 模型 A | 模型 B |
| --- | --- | --- |
| 预测对 | 3 恶 + 4 良 | 6 恶 + 1 良 |
| Accuracy | 70% | 70% |
| Precision | 100% | 67% |
| Recall | 50% | 100% |

两个模型准确率完全相同，但：
- **模型 A** 从不误报（Precision=100%），却漏掉了一半癌症患者（Recall=50%）；
- **模型 B** 不漏诊（Recall=100%），但会误报 3 个良性为恶性（Precision=67%）。

**医疗筛查应选 B**（漏诊代价远大于误报），**垃圾邮件过滤应选 A**（误杀正常邮件代价大）。这说明准确率单独无法反映业务价值。
</details>

<details markdown="1"><summary markdown="1">5. 在 scikit-learn 中，`LogisticRegression` 的 `C` 参数增大时，模型会变得更简单还是更复杂？为什么？</summary>

**更复杂**。

`C` 是正则化强度的**倒数**（$C = 1/\lambda$）。目标函数是

$$J(\boldsymbol{w}) = \underbrace{-\sum_i\big[y_i\ln p_i+(1-y_i)\ln(1-p_i)\big]}_{\text{数据拟合项}} + \underbrace{\frac{1}{2C}\|\boldsymbol{w}\|^2}_{\text{正则项}}$$

- $C$ 增大 → $1/C$ 减小 → 正则项权重变小 → 模型更自由地拟合训练数据 → **复杂度上升，容易过拟合**；
- $C$ 减小 → 正则项权重变大 → 权重被压小 → **模型更简单，可能欠拟合**。

注意这与 `Ridge/Lasso` 的 `alpha` 方向**相反**：`alpha` 越大正则越强（模型越简单），`C` 越大正则越弱（模型越复杂）。
</details>
