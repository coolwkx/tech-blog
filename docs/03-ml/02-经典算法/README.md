## 本章要回答的问题

**01 KNN 算法**
- 手算欧氏距离、曼哈顿距离、切比雪夫距离与闵氏距离，并说明它们的关系；
- 说清 $K$ 值大小的利弊，并使用 `GridSearchCV` 为 KNN 选出较优的 `n_neighbors`；
- 独立完成"鸢尾花分类"与"手写数字识别"两个案例，并解释为什么 KNN 前必须做标准化。

**02 线性回归**
- 手动推导一元线性回归的最小二乘解，并用"求导置零"算出 $k,b$；
- 写出正规方程 $\boldsymbol{w}=(\boldsymbol{X}^\top\boldsymbol{X})^{-1}\boldsymbol{X}^\top\boldsymbol{y}$，并解释每一项的含义与局限；
- 区分 FGD / SGD / Mini-batch / SAG 四种梯度下降，讲清 L1 与 L2 正则化为什么能抑制过拟合。

**03 逻辑回归**
- 推导 sigmoid 的导数 $\sigma'=\sigma(1-\sigma)$，并完整走一遍"似然 → 对数似然 → 交叉熵损失 → 梯度"的推导链；
- 用 `LogisticRegression` 完成癌症预测与电信客户流失预测，并正确处理缺失值、one-hot 编码、不平衡样本；
- 读懂混淆矩阵，独立计算 Precision / Recall / F1 / TPR / FPR / AUC，并解释为什么"准确率高"不等于"模型好"。

**04 决策树**
- 手算信息熵、条件熵、信息增益、信息增益率、基尼指数，并据此选出分裂特征；
- 手算 CART 回归树的最优切分点，说明为什么叶子输出取均值；
- 用 `DecisionTreeClassifier/Regressor` 完成泰坦尼克号生存预测与"线性回归 vs 回归树"对比，并说清预剪枝与后剪枝的利弊。
