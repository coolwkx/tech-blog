> **一句话总结**：激活函数给神经网络注入非线性，并在反向传播中充当每层梯度的缩放因子 $f'(z)$；损失函数定义"错得有多离谱"并把误差变成可导的训练信号；两者的搭配方式直接决定模型能否收敛、多快收敛。
>
> **前置知识**：线性判别函数、Logistic/Softmax 回归、梯度下降、链式法则与反向传播、伯努利分布与交叉熵。
>
> **学完能做到**：1. 从 $z=w^Tx+b$ 出发独立推导 σ、tanh、Softplus、Swish 的导数，并判断任意激活函数的饱和性与零中心化性质。2. 说清"分类为什么用交叉熵而不用 MSE"，写出交叉熵对 logits 的梯度化简结果。3. 正确使用 `nn.CrossEntropyLoss` / `nn.BCEWithLogitsLoss` / `nn.NLLLoss`，避开 logits 与概率混用、重复 softmax 等误用。

## 1. 核心思想

**神经元两段式结构**：先仿射变换得净输入（net input，也叫净活性值 net activation），再经过非线性函数得活性值 $z=\sum_{i=1}^{d}w_ix_i+b=w^Tx+b,\ a=f(z)$。没有 $f$，多层线性变换复合仍是线性变换，网络再深也等价于一个线性模型——激活函数是"深度"本身的价值来源。

**激活函数需要具备的三条性质**（教材 4.1 节）：

1. **连续并可导（允许少数点不可导）的非线性函数**。可导才能直接用数值优化方法学参数。注意"少数点不可导"这一豁免条款：ReLU 在 $x=0$ 处不可导，实践中框架取次梯度即可（PyTorch 中 `relu'(0) = 0`）。
2. **函数及其导函数尽可能简单**，以提高计算效率——这一条解释了 Hard-Logistic 这类分段线性近似为何出现在实际系统里。
3. **导函数的值域要落在合适的区间内**，不能太大也不能太小，否则影响训练效率与稳定性。太小 → 梯度消失；太大 → 梯度爆炸。

**饱和性的数学定义**：若 $x\to-\infty$ 时 $f'(x)\to0$ 称**左饱和**；$x\to+\infty$ 时 $f'(x)\to0$ 称**右饱和**；两者都满足称**两端饱和**。Sigmoid 型函数（Logistic、Tanh）两端饱和；ReLU 只是**左饱和**（负半轴导数恒 0），正半轴导数恒 1，永不饱和。

饱和为何致命？误差项递推为 $\delta^{(l)}=f'(z^{(l)})\odot(W^{(l+1)})^T\delta^{(l+1)}$，每层都要**乘上该层激活函数的导数**；饱和区 $f'\approx0$，误差每前传一层衰减一次，层数一深就彻底消失——这就是梯度消失问题（vanishing gradient problem）。

**激活函数总览对比表**：
| 激活函数 | 表达式 | 值域 | 导数 | 饱和性 | 零中心化 | 主要优缺点 |
|---|---|---|---|---|---|---|
| Logistic (Sigmoid) | $\sigma(x)=\dfrac{1}{1+e^{-x}}$ | $(0,1)$ | $\sigma(x)(1-\sigma(x))\in(0,0.25]$ | 两端饱和 | 否 | 优：输出即概率、可做软门；缺：梯度上限仅 0.25 且两端衰减，深网梯度消失 |
| Tanh | $\dfrac{e^x-e^{-x}}{e^x+e^{-x}}$ | $(-1,1)$ | $1-\tanh^2(x)\in(0,1]$ | 两端饱和 | 是 | 优：零中心化，梯度上限比 Logistic 大 4 倍；缺：仍两端饱和 |
| Hard-Logistic | $\max(\min(0.25x+0.5,1),0)$ | $[0,1]$ | 分段常数 $\{0,0.25,1\}$ | 两端硬饱和 | 否 | 优：只需加法与比较；缺：导数不连续 |
| Hard-Tanh | $\max(\min(x,1),-1)$ | $[-1,1]$ | 分段常数 $\{0,1\}$ | 两端硬饱和 | 是 | 优：极省算力（`nn.Hardtanh`）；缺：分段线性，表达能力略降 |
| ReLU | $\max(0,x)$ | $[0,+\infty)$ | $\mathbf{1}(x>0)$ | 左饱和 | 否 | 优：高效、生物合理性、约 50% 稀疏、缓解梯度消失；缺：非零中心化、Dying ReLU |
| LeakyReLU | $\max(\alpha x,x),\alpha\approx0.01$ | $(-\infty,+\infty)$ | $\mathbf{1}(x>0)+\alpha\mathbf{1}(x\le0)$ | 无 | 否 | 优：负半轴保留梯度，缓解 Dying ReLU；缺：$\alpha$ 需调 |
| PReLU | $\max(0,x)+\gamma_i\min(0,x)$ | $(-\infty,+\infty)$ | $\mathbf{1}(x>0)+\gamma_i\mathbf{1}(x\le0)$ | 无 | 否 | 优：斜率可学习、每神经元独立；缺：增加参数，小数据易过拟合 |
| ELU | $\max(0,x)+\min(0,\alpha(e^x-1))$ | $(-\alpha,+\infty)$ | $\mathbf{1}(x>0)+\alpha e^x\mathbf{1}(x\le0)$ | 左饱和（到 $-\alpha$） | 近似 | 优：负半轴有饱和下界、均值近 0、抗噪；缺：含 `exp` 较慢 |
| Softplus | $\log(1+e^x)$ | $(0,+\infty)$ | $\sigma(x)$ | 左饱和 | 否 | 优：ReLU 的平滑版、导数恰为 Logistic；缺：**无稀疏性**、更贵 |
| Swish / SiLU | $x\cdot\sigma(\beta x)$ | 约 $[-0.28,\infty)$ | $\sigma(\beta x)+\beta x\sigma(\beta x)(1-\sigma(\beta x))$ | 左饱和 | 否 | 优：自门控、非单调、平滑，深层常优于 ReLU；缺：含 exp |
| GELU | $x\cdot\Phi(x)$ | 约 $[-0.17,\infty)$ | $\Phi(x)+x\phi(x)$ | 左饱和 | 否 | 优：Transformer 标准、处处光滑；缺：需 `erf` 或 tanh 近似，最重 |
| Maxout | $\max_{k\in[1,K]}(w_k^Tx+b_k)$ | $(-\infty,+\infty)$ | 取到最大值那一路的 $w_k$ | 无 | 否 | 优：可拟合任意凸函数的分段线性近似；缺：$K$ 倍参数、有限点不可微 |

## 2. 算法细节

### 2.1 Sigmoid 家族：Logistic 与 Tanh 的导数（完整推导）

$$\sigma(x)=\frac{1}{1+e^{-x}}=(1+e^{-x})^{-1}.$$

链式法则（令 $u=1+e^{-x}$）得 $\dfrac{d\sigma}{dx}=-(1+e^{-x})^{-2}\cdot(-e^{-x})=\dfrac{e^{-x}}{(1+e^{-x})^2}$。把分子 $e^{-x}$ 写成 $(1+e^{-x})-1$：

$$\frac{e^{-x}}{(1+e^{-x})^2}=\frac{(1+e^{-x})-1}{(1+e^{-x})^2}=\frac{1}{1+e^{-x}}-\frac{1}{(1+e^{-x})^2}=\sigma(x)-\sigma(x)^2
\quad\Longrightarrow\quad \boxed{\sigma'(x)=\sigma(x)\bigl(1-\sigma(x)\bigr)\in(0,\,0.25].}$$

**导数可由自身表示**，反向传播时无需重算 $\exp$；最大值 0.25 在 $x=0$ 处取到，意味着**梯度每穿过一层 Logistic 至多缩水到 1/4**，10 层即 $0.25^{10}\approx10^{-6}$——梯度消失的定量解释。$\sigma$ 的两个工程含义（教材 4.1.1 节）：①**输出可看作概率**，直接当后验概率 $P(y=1\mid x)=\sigma(w^Tx)$ 用；②**可看作软性门（soft gate）**，$\sigma\in(0,1)$ 作 0/1 之间的连续开关控制信息通过量——LSTM 的三个门、GRU 的更新门、Swish/GELU 的门控都是这一思想。

**Tanh** 定义为 $\tanh(x)=\dfrac{e^{x}-e^{-x}}{e^{x}+e^{-x}}$。由 $\sigma(2x)=\dfrac{1}{1+e^{-2x}}=\dfrac{e^{2x}}{e^{2x}+1}$ 得

$$2\sigma(2x)-1=\frac{2e^{2x}}{e^{2x}+1}-1=\frac{e^{2x}-1}{e^{2x}+1}\ \xrightarrow{\ \times e^{-x}/e^{-x}\ }\ \frac{e^{x}-e^{-x}}{e^{x}+e^{-x}}=\tanh(x)\quad\Longrightarrow\quad\boxed{\tanh(x)=2\sigma(2x)-1.}$$

**导数**：$\tanh'(x)=2\cdot\sigma'(2x)\cdot2=4\sigma(2x)\bigl(1-\sigma(2x)\bigr)$。代入 $\sigma(2x)=\frac{1+\tanh x}{2}$、$1-\sigma(2x)=\frac{1-\tanh x}{2}$，得 $\tanh'(x)=1-\tanh^2(x)\in(0,1]$。上限是 **1** 而非 0.25，故同分布下 Tanh 的梯度比 Logistic 大最多 4 倍。

### 2.2 零中心化（Bias Shift）与 Hard-Sigmoid 近似

Tanh 输出零中心化（zero-centered），Logistic 输出恒 $>0$，是**非零中心化**的。第 $l$ 层权重梯度为 $\dfrac{\partial\mathcal{L}}{\partial w^{(l)}}=\delta^{(l)}(a^{(l-1)})^T$：若 $a^{(l-1)}$ 每个分量都同号（Logistic 输出全为正），则对固定神经元 $j$，梯度行向量与 $\delta_j^{(l)}$ 成比例、所有分量同号，**该神经元的所有输入权重只能朝同一方向更新**。几何图像：最优更新方向本来是斜的，梯度却被锁在一个"象限"里，只能沿坐标轴方向走折线，形成锯齿状（zig-zag）轨迹，需要更多迭代才到极小点——教材称为偏置偏移（bias shift）。Tanh 输出可正可负，分量符号能相互抵消，故无此约束。

> 教材习题 4-1 是同一现象在输入侧的体现：对神经元 $\sigma(w^Tx+b)$，若输入 $x$ 恒大于 0，收敛会比零均值化的输入更慢。**实践结论：隐藏层优先用 Tanh/ReLU 系，Logistic 主要留给输出层概率建模和门控。**

**Hard-Logistic / Hard-Tanh**：在 0 附近做一阶泰勒展开（Taylor expansion）得 $\sigma(x)\approx\sigma(0)+x\sigma'(0)=0.5+0.25x$，用它替换线性段并让两端钳位到饱和值：

$$\text{hard-logistic}(x)=\max\bigl(\min(0.25x+0.5,\ 1),\ 0\bigr),\qquad \text{hard-tanh}(x)=\max\bigl(\min(x,\ 1),\ -1\bigr).$$

Hard-Tanh 的线性段即 $\tanh(x)\approx\tanh(0)+x\tanh'(0)=x$（中间斜率 1）。两者只含加法、乘法、比较，没有 `exp`，移动端推理很受欢迎（MobileNetV3 的 h-swish 同理：用 $\text{ReLU6}(x+3)/6$ 近似 Sigmoid 门）。

### 2.3 ReLU 家族

$$\text{ReLU}(x)=\max(0,x),\qquad \text{ReLU}'(x)=\mathbf{1}(x>0).$$

**优点**（教材 4.1.2 节）：①只需加、乘、比较，**计算高效**，导数非 0 即 1；②**生物合理性**（biological plausibility）——单侧抑制、宽兴奋边界，人脑同一时刻仅约 1%~4% 神经元活跃；③**稀疏性**——Sigmoid 型导致非稀疏网络，而 ReLU 约 50% 神经元激活（负半轴严格输出 0）；④**缓解梯度消失**——左饱和但正半轴导数恒 1，误差可原样回传。

**缺点**：①**非零中心化**，输出恒 $\ge0$，同样引入 bias shift；②**Dying ReLU（死亡 ReLU）**——若某次不当更新让某神经元**在所有训练样本上**净输入都 $\le0$，它的梯度永远为 0，参数再也无法更新，该神经元永久死亡（输出恒 0，相当于被剪掉）。注意死因是"在所有样本上都负"，而非偶尔为负。

| 变种 | 表达式 | 关键性质 |
|---|---|---|
| LeakyReLU | $\max(\alpha x,x)$，$\alpha$ 常取 0.01 | 负半轴保留小梯度，非激活时仍可更新，避免永久死亡；$\alpha<1$ 时等价于一个简单的 maxout 单元 |
| PReLU | $\max(0,x)+\gamma_i\min(0,x)$ | $\gamma_i$ **可学习**且每神经元可不同（也可整组共享）；$\gamma_i=0$ 退化为 ReLU，很小时近似 LeakyReLU；非饱和函数 |
| ELU | $\max(0,x)+\min(0,\alpha(e^x-1))$ | 负半轴饱和到 $-\alpha$，**近似零中心化**，输出均值被拉向 0；$\alpha\ge0$ 控制负半轴饱和曲线；抗噪但含 `exp` |
| Softplus | $\log(1+e^x)$ | ReLU 的**平滑版本**，导数恰为 Logistic：$\frac{d}{dx}\log(1+e^x)=\frac{e^x}{1+e^x}=\sigma(x)$；有单侧抑制与宽兴奋边界，但**无稀疏激活性** |

Softplus 把两条线连了起来：$\frac{d}{dx}\text{Softplus}=\sigma$，所以它是 Logistic 的"积分"版本；$x\gg0$ 时 $\approx x$（ReLU），$x\ll0$ 时 $\approx e^x\to0$。

### 2.4 Swish 与 GELU：门控型激活函数

**Swish 是自门控（self-gated）激活函数**：$\text{swish}(x)=x\cdot\sigma(\beta x)$，$\beta$ 是可学习参数或固定超参数。$\sigma(\beta x)\in(0,1)$ 是**软性门控**：门开（$\to1$）时输出近似 $x$ 本身，门关（$\to0$）时输出近似 0。$\beta$ 的极限行为（教材 4.1.3 节）：$\beta=0$ 时 $\sigma(0)=0.5$，退化为**线性函数** $x/2$；$\beta=1$ 时 $x>0$ 近似线性、$x<0$ 近似饱和，且有**非单调性**（这是与 ReLU 单调不减的本质区别：Swish 在负半轴先降后升，$x\approx-1.28$ 处取最小值约 $-0.278$）；$\beta\to+\infty$ 时 $\sigma(\beta x)$ 趋向离散 0-1 阶跃，Swish 近似为 **ReLU**。所以 Swish 是**线性函数与 ReLU 之间的非线性插值**。$\beta=1$ 固定时它有个更常见的名字 **SiLU**（PyTorch `nn.SiLU`）。**导数**（教材习题 4-4，乘积法则）：

$$\text{swish}'(x)=\sigma(\beta x)+\beta x\,\sigma(\beta x)\bigl(1-\sigma(\beta x)\bigr).$$

**GELU 与 Swish 类似，但门换成标准正态分布的累积分布函数**：

$$\text{GELU}(x)=x\cdot\Phi(x),\qquad \Phi(x)=P(X\le x),\ X\sim\mathcal{N}(\mu,\sigma^2),$$

一般取 $\mu=0,\sigma=1$。由于正态 CDF 本身是 S 型函数，可写成 $x\cdot\sigma(1.702x)$——此时 GELU **等价于一种特殊的 Swish**。实现中为避免 `erf` 开销常用 tanh 近似：

$$\text{GELU}(x)\approx0.5x\left(1+\tanh\left(\sqrt{\tfrac{2}{\pi}}\left(x+0.044715x^3\right)\right)\right).$$

曲线与 Swish 很像（最小值约 $-0.17$），但它是 Transformer 的事实标准（BERT、GPT 系列）。PyTorch 中 `nn.GELU` 默认用 erf 精确版，`approximate='tanh'` 用上式。

### 2.5 Maxout 单元

前面所有激活函数的输入都是**标量净输入**；Maxout 的输入是**上一层神经元的全部原始输出向量** $x=[x_1;\dots;x_d]$。它有 $K$ 组权重 $w_k\in\mathbb{R}^d$ 与偏置 $b_k$：

$$z_k=w_k^Tx+b_k,\quad 1\le k\le K,\qquad \boxed{\text{maxout}(x)=\max_{k\in[1,K]}z_k.}$$

要点：①它不是净输入到输出的非线性映射，而是整体学习输入到输出的非线性映射关系；②可以看作**任意凸函数的分段线性近似**（有限个仿射函数取 max 得到凸的分段线性函数，反之任意凸分段线性函数都可写成有限个仿射函数的上确界）；③在有限点上不可微（多个 $z_k$ 相等处），用次梯度即可；④LeakyReLU 在 $\alpha<1$ 时就是 $K=2$ 的简单 maxout；⑤代价是参数与计算量变为 $K$ 倍。

### 2.6 损失函数：平方、交叉熵、负对数似然、Hinge

**平方损失**（用于回归）：$\mathcal{L}=\frac12(y-f(x;\theta))^2$。教材明确指出**平方损失一般不适用于分类问题**（习题 2-1）。

**交叉熵**（用于分类）：设 $y\in\{1,\dots,C\}$，one-hot 标签 $y$，模型输出 $\hat y_c=P(y=c\mid x;\theta)$，

$$\mathcal{L}(y,\hat y)=-y^T\log\hat y=-\sum_{c=1}^{C}y_c\log\hat y_c\ \overset{\text{one-hot}}{=}\ -\log\hat y_{y}.$$

$\hat y_y$ 就是真实类别的预测概率，也即该样本的**似然**，所以**交叉熵损失就是负对数似然损失（Negative Log-Likelihood, NLL）**：最小化交叉熵等价于最大化对数似然（最大似然估计）；又因 $H(p,q)=H(p)+\mathrm{KL}(p\|q)$ 且 $H(p)$ 与参数无关，它也等价于最小化 $\mathrm{KL}(p\|q)$。

**二分类交叉熵（BCE）**：$y\in\{0,1\}$，$\hat y=\sigma(z)$，$\mathcal{L}=-[y\log\hat y+(1-y)\log(1-\hat y)]$。

**Hinge 损失**（最大间隔分类／SVM）：$y\in\{-1,+1\}$，判别值 $f=w^Tx+b$，$\mathcal{L}_{\text{hinge}}=\max\bigl(0,1-yf\bigr)=[1-yf]_+$。它只惩罚间隔不足 1 的样本，$yf\ge1$ 时梯度为 0，故解**只由支持向量决定**，天然稀疏；感知器用的则是 $\max(0,-yf)$（间隔固定为 0）。

### 2.7 为什么分类用交叉熵而不用 MSE（重点推导）

**(A) Logistic + MSE：梯度里多出一个 $\sigma'$ 因子。** 设 $\hat y=\sigma(z)$，$\mathcal{L}_{\text{MSE}}=\frac12(\hat y-y)^2$，

$$\frac{\partial\mathcal{L}}{\partial z}=(\hat y-y)\cdot\underbrace{\sigma(z)(1-\sigma(z))}_{\le0.25}.$$

当模型"自信地错"（$y=1,z=-6$，$\hat y\approx0.0025$）时误差 $(\hat y-y)\approx-1$ 很大，但 $\sigma'(z)\approx0.0025$ 几乎为 0，乘积仅 $\approx-0.0025$：**误差越大梯度越小**，最需要纠正的地方反而几乎不动。

**(B) Logistic + 交叉熵：梯度化简为 $\hat y-y$。** $\mathcal{L}=-y\log\hat y-(1-y)\log(1-\hat y)$。逐项对 $z$ 求导：

$$\frac{\partial}{\partial z}\bigl(-y\log\sigma(z)\bigr)=-y\cdot\frac{\sigma'(z)}{\sigma(z)}=-y\bigl(1-\sigma(z)\bigr),$$

$$\frac{\partial}{\partial z}\bigl(-(1-y)\log(1-\sigma(z))\bigr)=-(1-y)\cdot\frac{-\sigma'(z)}{1-\sigma(z)}=(1-y)\sigma(z).$$

两项相加：

$$\boxed{\frac{\partial\mathcal{L}_{\text{CE}}}{\partial z}=\sigma(z)-y=\hat y-y.}$$

$\sigma'$ **被完全约掉**，梯度就是"预测减真值"，误差多大梯度就多大，饱和区也不会被压制——这就是分类任务用交叉熵的根本原因。教材 3.2.1 节把同一结论写成凸性语言（$\mathcal{R}(w)$ 连续可导且为凸函数），而 4.6.1 节用 $\hat y=\sigma(w_2\sigma(w_1x))$ 说明深层网络上两种损失都是非凸的，但交叉熵的梯度性质更好。

**(C) 多分类：Softmax + 交叉熵同样干净。** 用 $\partial\hat y_c/\partial z_j=\hat y_c(\delta_{cj}-\hat y_j)$ 代入 $\mathcal{L}=-\sum_c y_c\log\hat y_c$：

$$\frac{\partial\mathcal{L}}{\partial z_j}=-\sum_c\frac{y_c}{\hat y_c}\hat y_c(\delta_{cj}-\hat y_j)=-\sum_c y_c(\delta_{cj}-\hat y_j)=-y_j+\hat y_j\sum_c y_c=\hat y_j-y_j .$$

（末步用 one-hot 的 $\sum_c y_c=1$。）Softmax 还有两个注意点：①**平移不变性**——各分量同加常数输出不变，故 $C$ 组权重冗余（教材 3.3.1 节指出需用正则化约束参数），工程上据此做数值稳定：计算前先减 $\max_j z_j$；②正因平移不变，Softmax + 交叉熵的 Hessian 奇异，需权重衰减定解。

### 2.8 PyTorch 三个损失函数的关系

| API | 输入要求 | target 形式 | 内部是否含激活 | 数值稳定性 |
|---|---|---|---|---|
| `nn.CrossEntropyLoss` | **logits**（未归一化得分） | 类别索引 `LongTensor`，形状 $(N,)$ | 是（等价 `LogSoftmax` + `NLLLoss`） | 高（log-sum-exp） |
| `nn.NLLLoss` | **log 概率**（须先 `log_softmax`） | 类别索引 | 否 | 取决于是否用了 `log_softmax` |
| `nn.BCEWithLogitsLoss` | **logits** | 浮点标签，同形 | 是（内部 Sigmoid+BCE） | 高（log-sum-exp） |
| `nn.BCELoss` | **概率**（须先 `Sigmoid`） | 浮点标签 | 否 | 低（易 $\log0$） |

恒等关系（高频考点）：`CrossEntropyLoss(logits, y) ≡ NLLLoss(log_softmax(logits), y)`；`BCEWithLogitsLoss` ≡ `BCELoss(sigmoid(logits))` 但前者更稳。

**为何 `BCEWithLogitsLoss` 更稳**：把 $\hat y=\sigma(z)$ 代入 BCE，$y=1$ 得 $\log(1+e^{-z})$、$y=0$ 得 $\log(1+e^{z})$，统一写成

$$\mathcal{L}=\max(z,0)-zy+\log\bigl(1+e^{-|z|}\bigr),$$

指数参数恒 $\le0$，**绝不溢出**；而直接算 $\log(\sigma(z))$，$z$ 很负时 $\sigma(z)$ 下溢为 0，取对数得 $-\infty$。`CrossEntropyLoss` 内部同理用 log-sum-exp 避免 $e^z$ 上溢。

**最经典的三个误用**：①末层加了 `nn.Softmax` 又用 `nn.CrossEntropyLoss` → softmax 算了两次，概率被压平、梯度信号被削弱；②用 `nn.NLLLoss` 却没先 `log_softmax` → 对负数取对数得 NaN；③用 `nn.BCELoss` 却不先 `Sigmoid`（或过了 Sigmoid 又用 `BCEWithLogitsLoss`）→ 梯度链条断裂或二次压缩。

**接口为什么必须搭配设计**：输出层由损失函数给出 $\partial\mathcal{L}/\partial z^{(L)}$（交叉熵 → 干净的 $\hat y-y$，MSE+Sigmoid → 被 $\sigma'$ 污染的乘积），隐藏层每层乘 $f'(z^{(l)})$。所以隐藏层激活导数的绝对值**期望接近 1** 才好，这一"信号守恒"诉求正是 He 初始化（配 ReLU，方差 $\propto2/n_{in}$）与 Xavier 初始化（配 Tanh）的由来。

## 3. 可运行示例

代码做三件事：(1) 验证 `CrossEntropyLoss` 等价于手写 `log_softmax` + NLL；(2) 证明 MSE+Sigmoid 在饱和区梯度塌缩而交叉熵不会；(3) 用同一份数据训练两个分类器，观察 MSE 收敛更慢。

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

torch.manual_seed(0)

# ===== 1. CrossEntropyLoss == log_softmax + NLL == 手写公式 =====
logits = torch.tensor([[2.0, 0.5, -1.0], [-0.3, 1.2, 0.1], [0.0, 0.0, 3.0]])
target = torch.tensor([0, 2, 2]) # 类别索引，不是 one-hot

loss_api = nn.CrossEntropyLoss(logits, target)
loss_manual = F.nll_loss(F.log_softmax(logits, dim=1), target)
loss_formula = (torch.logsumexp(logits, 1)
- logits.gather(1, target[:, None]).squeeze(1)).mean
print(f"[1] CrossEntropyLoss={loss_api:.6f} NLL={loss_manual:.6f} 手写={loss_formula:.6f}")
assert torch.allclose(loss_api, loss_manual) and torch.allclose(loss_api, loss_formula)

loss_wrong = nn.CrossEntropyLoss(F.softmax(logits, dim=1), target) # 误用：又乘了一次 softmax
print(f" [误用] 对概率再算 CE = {loss_wrong:.6f} <- 值不对, 梯度被压平")

# ===== 2. 饱和区梯度对比: MSE vs 交叉熵 =====
y = torch.tensor([1.0])
z = torch.tensor([-6.0], requires_grad=True) # 真值 1, 但模型自信地错
loss_mse = 0.5 * (torch.sigmoid(z) - y) ** 2
g_mse = torch.autograd.grad(loss_mse, z)[0]

z2 = torch.tensor([-6.0], requires_grad=True)
loss_bce = F.binary_cross_entropy_with_logits(z2, y)
g_bce = torch.autograd.grad(loss_bce, z2)[0]

print(f"\n[2] z=-6, y=1 (饱和区, 自信地错)")
print(f" MSE loss={loss_mse.item:.6f} dL/dz={g_mse.item:.6f} <- 梯度几乎为 0")
print(f" BCE loss={loss_bce.item:.6f} dL/dz={g_bce.item:.6f} <- 梯度 = p - y")
print(f" 手算 p - y = {torch.sigmoid(torch.tensor(-6.0)).item - 1:.6f}")

# ===== 3. 同一份数据: CrossEntropy 收敛快于 MSE =====
def make_data(n=1024, d=20, seed=42):
 g = torch.Generator.manual_seed(seed)
 X, w = torch.randn(n, d, generator=g), torch.randn(d, 3, generator=g)
 return X, (X @ w).argmax(dim=1)

def train(use_mse, steps=300, lr=0.1):
 X, y = make_data
 model = nn.Sequential(nn.Linear(20, 32), nn.Tanh, nn.Linear(32, 3))
 opt = torch.optim.SGD(model.parameters, lr=lr)
 onehot = F.one_hot(y, 3).float
 for _ in range(steps):
 opt.zero_grad
 out = model(X)
 if use_mse: # 关键: MSE 作用在 softmax 概率上, 梯度带 softmax 的饱和因子
 loss = 0.5 * ((torch.softmax(out, 1) - onehot) ** 2).sum(1).mean
 else:
 loss = F.cross_entropy(out, y) # 直接吃 logits
 loss.backward
 opt.step
 with torch.no_grad:
 final = model(X)
 # 统一用交叉熵度量泛化前的拟合程度, 这样两种训练目标的数字才可比
 ce = F.cross_entropy(final, y).item
 acc = (final.argmax(1) == y).float.mean.item
 return ce, acc

 print
 for name, flag in [("CrossEntropy", False), ("MSE", True)]:
 for lr in (0.1, 1.0):
 ce, a = train(flag, lr=lr)
 print(f"[3] {name:12s} lr={lr:<4} 统一CE={ce:.4f} train acc={a:.4f}")
```

**参考输出**（在 torch 2.11 CPU 上实测；因框架版本不同，`sigmoid` 的浮点细节会让 `[2]` 的末位略有差异）：

```
[1] CrossEntropyLoss=0.626118 NLL=0.626118 手写=0.626118
 [误用] 对概率再算 CE = 0.852121 <- 值不对, 梯度被压平

[2] z=-6, y=1 (饱和区, 自信地错)
 MSE loss=0.497530 dL/dz=-0.002460 <- 梯度几乎为 0
 BCE loss=6.002476 dL/dz=-0.997527 <- 梯度 = p - y
 手算 p - y = -0.997527

[3] CrossEntropy lr=0.1 统一CE=0.1246 train acc=0.9873
[3] CrossEntropy lr=1.0 统一CE=0.0156 train acc=1.0000
[3] MSE lr=0.1 统一CE=0.3150 train acc=0.9688
[3] MSE lr=1.0 统一CE=0.0627 train acc=0.9990
```

**怎么读这三段输出**：`[1]` 说明 `CrossEntropyLoss` 的数值与手写 log-sum-exp 完全一致（`allclose` 通过），而对概率再算一次 CE 会得到错误的 `0.852`。`[2]` 直接展示核心差异：同在饱和区犯大错，MSE 的梯度只有 $-0.0025$（几乎不动），交叉熵的梯度是 $-0.9975$（几乎满格）。`[3]` 用**同一个统一指标**（都取 `F.cross_entropy`，否则 MSE 与 CE 的数值不可比）对比两种训练目标：lr=0.1 时 MSE 的 CE 为 0.315、准确率 96.88%，交叉熵的 CE 为 0.125、准确率 98.73%；lr=1.0 时前者 0.0627/99.90%，后者 0.0156/100%。**MSE 收敛更慢不是"loss 数值更大"，而是"同等步数下达不到同样的拟合程度"**——步数加到几千步差距会缩小，但在大模型、小学习率下会显著放大。二分类推荐写法：`nn.BCEWithLogitsLoss(logit, label.float)`，而非 `nn.BCELoss(torch.sigmoid(logit), label.float)`。

## 4. 常见坑

| 坑 | 表现 | 原因 | 解法 |
|---|---|---|---|
| 用 MSE 训练分类器 | loss 下降但准确率长期中庸；饱和样本几乎不更新 | MSE+Sigmoid 梯度带 $\sigma'(z)$ 因子，$|z|$ 大时 $\sigma'\to0$，误差越大梯度越小 | 改用交叉熵（`CrossEntropyLoss`/`BCEWithLogitsLoss`），梯度化简为 $\hat y-y$ |
| `CrossEntropyLoss` 前又加 `Softmax` | loss 虚高、梯度被压平，训练极慢甚至不收敛 | 该 loss 内部已含 `LogSoftmax`，重复归一化二次压缩概率差异 | 末层**直接输出 logits**，删掉 `nn.Softmax` |
| `nn.NLLLoss` 前忘 `log_softmax` | loss 变 `nan`，或提示对负数取对数 | `NLLLoss` 把输入当**对数概率**，负 logits 取对数为 NaN | 显式 `F.log_softmax(logits, dim=1)`，或直接用 `CrossEntropyLoss` |
| target 传成 one-hot 给 `CrossEntropyLoss` | 形状/类型报错，或结果完全无意义 | 它要求 `LongTensor` 类别索引，形状 $(N,)$ | 传 `y.argmax(1)`；需 soft label 时用标签平滑 |
| `Sigmoid`+`BCELoss` 数值爆炸 | 训练中偶发 `inf`/`nan`，多出现在 $|z|$ 大时 | $\sigma(z)$ 下溢为 0 后 $\log0=-\infty$ | 用 `nn.BCEWithLogitsLoss`（内部 $\max(z,0)-zy+\log(1+e^{-|z|})$） |
| 隐藏层全用 Logistic 且输入未零均值化 | 收敛慢、loss 曲线锯齿振荡 | 非零中心化 → bias shift，同号输入锁死更新方向，走 zig-zag | 隐藏层换 Tanh/ReLU 系；输入做标准化；Logistic 留给输出层 |
| 深层网络出现 Dying ReLU | loss 停滞，某层活跃神经元数逐层递减到近 0 | 部分 ReLU 神经元在所有样本上净输入 $\le0$，梯度恒 0，永久失活 | 换 LeakyReLU/PReLU/ELU/GELU；调小学习率；加 batch normalization；用 He 初始化 |
| 大学习率配 ReLU 成片失活 | 训练初期一次大更新后 loss 直接卡住 | 过大更新把大批神经元 bias 推入负区，成片死亡 | 降低学习率、加 warmup、用 Adam 等自适应优化器 |
| Swish/GELU 用在浅层小网络反而不如 ReLU | 精度没提升，训练还更慢 | 其优势主要体现在**深层**网络；`exp`/`erf` 开销在小网络上不划算 | 浅层/移动端用 ReLU 或 h-swish；深层 Transformer 用 GELU，深层 CNN 可试 SiLU |
| Maxout 直接使用导致 OOM | 显存和参数量突然变为 $K$ 倍 | 每个单元有 $K$ 组 $w_k,b_k$ | 减小 $K$（常取 2~5）、缩小隐藏层宽度，或改用 PReLU |
| 手写 Softmax 数值上溢 | logits 含大值（如 100）时输出 `nan` | 直接算 $e^{z_c}$ 溢出 | 先减最大值，或直接用 `F.log_softmax`/`nn.CrossEntropyLoss` |
| Softmax 权重不加正则化 | 训练不稳定，权重范数持续变大 | 平移不变性使 $C$ 组权重冗余、最优解不唯一 | 加 `weight_decay` 或 $\ell_2$ 正则，并利用平移不变性做数值稳定 |

## 5. 面试问答

**Q1：分类任务为什么用交叉熵而不用 MSE？请写出梯度推导。**
<details><summary>参考答案</summary>

差异出在**输出层误差项对 logits 的导数**上。

（1）**Logistic + MSE**：$\hat y=\sigma(z)$，$\mathcal{L}=\frac12(\hat y-y)^2$，

$$\frac{\partial\mathcal{L}}{\partial z}=(\hat y-y)\sigma'(z)=(\hat y-y)\sigma(z)\bigl(1-\sigma(z)\bigr).$$

梯度被乘上 $\sigma'(z)\le0.25$。当模型"自信地错"（$y=1,z=-6$）时 $(\hat y-y)\approx-1$ 虽大，但 $\sigma'(z)\approx0.0025$，乘积 $\approx-0.0025$，**梯度几乎消失，模型学不动**。

（2）**Logistic + 交叉熵**：$\mathcal{L}=-y\log\hat y-(1-y)\log(1-\hat y)$，

$$\frac{\partial\mathcal{L}}{\partial z}=\hat y-y .$$

推导要点：$\frac{\partial}{\partial z}(-y\log\sigma(z))=-y\frac{\sigma'}{\sigma}=-y(1-\sigma)$，第二项对称给出 $(1-y)\sigma$，相加时 $\sigma'$ **恰好约掉**。梯度就是"预测减真值"，误差越大梯度越大。多分类同理用 $\partial\hat y_c/\partial z_j=\hat y_c(\delta_{cj}-\hat y_j)$ 得 $\partial\mathcal{L}/\partial z_j=\hat y_j-y_j$。

（3）其他角度：交叉熵等价于负对数似然，最小化它即最大似然估计；它度量两个概率分布的 KL 散度，与"输出概率分布"的分类语义天然匹配，而 MSE 隐含高斯噪声假设、适合回归；在单层 Logistic 回归上交叉熵是凸函数而 MSE 不是。
</details>
**Q2：Sigmoid、Tanh、ReLU 各自的问题是什么？为什么隐藏层更推荐 ReLU 系？**
<details><summary>参考答案</summary>

- **Logistic**：$\sigma'=\sigma(1-\sigma)\in(0,0.25]$。①**两端饱和**，饱和区导数趋于 0，深层反向传播每层乘 $\le0.25$ 的因子，10 层衰减到 $10^{-6}$；②**非零中心化**（输出恒正），后一层输入符号全同、更新方向被锁死（bias shift），走出 zig-zag，收敛慢。
- **Tanh**：$\tanh'=1-\tanh^2\in(0,1]$。解决了零中心化，梯度上限也从 0.25 提到 1（同分布下大 4 倍），但**仍两端饱和**，深网照样梯度消失。
- **ReLU**：$\max(0,x)$，正半轴导数恒 1，**有效缓解梯度消失**；只含加/乘/比较，**计算高效**；负半轴输出 0，带来约 50% **稀疏激活**与生物合理性。问题：①**非零中心化**依旧；②**Dying ReLU**——若某神经元在所有样本上净输入都 $\le0$，梯度恒 0，参数永久冻结。

故隐藏层首选 ReLU，若观察到大量神经元死亡改 LeakyReLU/PReLU/ELU/GELU，并配 He 初始化（方差 $\propto2/n_{in}$）与 batch normalization。输出层按任务选：二分类用 Sigmoid 或（推荐）直接输出 logits 配 `BCEWithLogitsLoss`，多分类输出 logits 配 `CrossEntropyLoss`，回归不加激活。**不要用 ReLU 做输出层**——无上界且会把负值截断为 0，无法表达概率。
</details>
**Q3：什么是饱和？Swish 和 GELU 的门控机制怎么回事？Maxout 为什么能逼近任意凸函数？**
<details><summary>参考答案</summary>

**饱和**：$x\to-\infty$ 时 $f'(x)\to0$ 称**左饱和**，$x\to+\infty$ 时 $f'(x)\to0$ 称**右饱和**，两者都满足称**两端饱和**。Sigmoid/Tanh 两端饱和，ReLU 只左饱和（右半轴恒 1），ELU 左饱和（到 $-\alpha$）。饱和有害是因为反向传播每层要乘 $f'(z^{(l)})$，饱和区 $f'\approx0$ 使梯度逐层衰减至消失。

**Swish 自门控**：$\text{swish}(x)=x\sigma(\beta x)$，$\sigma(\beta x)\in(0,1)$ 是**软门**——门开输出 $\approx x$，门关输出 $\approx0$。$\beta$ 控制门的陡峭度：$\beta=0$ 退化为线性 $x/2$，$\beta\to+\infty$ 趋向 ReLU，$\beta=1$ 时介于两者之间且在负半轴**非单调**（最小值约 $-0.278$），所以它是"线性函数到 ReLU 的非线性插值"。

**GELU 门控**：$\text{GELU}(x)=x\Phi(x)$，门是标准正态 CDF，可用 $\sigma(1.702x)$ 近似（此时等价于特殊 Swish）或 tanh 式 $0.5x(1+\tanh(\sqrt{2/\pi}(x+0.044715x^3)))$ 实现。两者都靠"乘一个 0~1 的门"实现非线性，区别只在门的形状（Logistic vs 正态 CDF），都处处光滑且非单调。

**Maxout**：输出 $K$ 个仿射函数 $w_k^Tx+b_k$ 的逐点最大值。有限个仿射函数取 max 得到**凸的分段线性函数**；反过来任意凸分段线性函数都可写成有限个仿射函数的上确界，故 Maxout 可看作任意凸函数的分段线性近似。代价是 $K$ 倍参数与算力，且在多个 $z_k$ 相等处不可微（用次梯度）。
</details>

## 6. 自测题

**T1** 写出 $\sigma(x)$ 的导数并用自身表示，指出值域。8 个隐藏层全用 Logistic，若各层导数都取最大 0.25，梯度从输出传回第一层衰减到原来的多少倍？

<details><summary>参考答案</summary>

$\sigma'(x)=\sigma(x)(1-\sigma(x))$，值域 $(0,0.25]$，在 $x=0$ 处取最大值 0.25。

推导：$\sigma=(1+e^{-x})^{-1}$，$\sigma'=-(1+e^{-x})^{-2}\cdot(-e^{-x})=\frac{e^{-x}}{(1+e^{-x})^2}$；把分子写成 $(1+e^{-x})-1$ 得 $\frac{1}{1+e^{-x}}-\frac{1}{(1+e^{-x})^2}=\sigma-\sigma^2=\sigma(1-\sigma)$。

8 层全部取最大值时衰减 $0.25^8=2^{-16}\approx1.53\times10^{-5}$。这是最乐观估计（实际往往更小），足以说明深层 Sigmoid 网络无法训练——这正是 ReLU（正半轴导数恒 1）被提出的直接动机。
</details>
**T2** 证明 $\tanh(x)=2\sigma(2x)-1$，并说明"零中心化"为什么能让收敛更快。

<details><summary>参考答案</summary>

**证明**：$\sigma(2x)=\frac{1}{1+e^{-2x}}=\frac{e^{2x}}{e^{2x}+1}$，故 $2\sigma(2x)-1=\frac{2e^{2x}}{e^{2x}+1}-1=\frac{e^{2x}-1}{e^{2x}+1}$；分子分母同乘 $e^{-x}$ 得 $\frac{e^x-e^{-x}}{e^x+e^{-x}}=\tanh(x)$。∎

**为什么零中心化更快**：第 $l$ 层权重梯度 $\frac{\partial\mathcal{L}}{\partial W^{(l)}}=\delta^{(l)}(a^{(l-1)})^T$。若 $a^{(l-1)}$ 分量全部同号（Logistic 输出恒 $>0$），则对固定神经元 $j$，梯度行向量各分量符号都由 $\delta_j^{(l)}$ 统一决定，权重只能朝一个方向走，无法实现分量相互抵消的斜向更新，于是产生锯齿轨迹、收敛变慢（bias shift）。Tanh 输出可正可负，梯度分量能异号，更新方向更贴近最优方向。教材习题 4-1（输入恒大于 0 时收敛更慢）是同一现象在输入侧的体现。
</details>
**T3** 三元分类，某样本 logits 为 $z=[2.0,0.5,-1.0]$，真实类别 0。手算交叉熵损失，并说明 `nn.CrossEntropyLoss` 接收什么。

<details><summary>参考答案</summary>

用平移不变性减去最大值 2.0：$z-2=[0,-1.5,-3]$，$e^0=1$、$e^{-1.5}\approx0.22313$、$e^{-3}\approx0.04979$，和 $\approx1.27292$。

$$\hat y\approx[0.78560,\ 0.17529,\ 0.03912].$$

真实类别 0，$\mathcal{L}=-\log(0.78560)\approx0.24133$。等价地 $\mathcal{L}=\text{logsumexp}(z)-z_y=\log1.27292-2.0=0.24133$。

**PyTorch**：`nn.CrossEntropyLoss` 接收**未归一化 logits**（形状 $(N,C)$）与**类别索引 `LongTensor`**（形状 $(N,)$），内部先 `LogSoftmax` 再取负对数似然（等价 log-sum-exp），**绝不要自己先过 Softmax**。`F.cross_entropy(logits, target)` 与 `nn.CrossEntropyLoss(logits, target)` 结果一致。
</details>
**T4** 二分类交叉熵与 Hinge 损失有什么区别？各适用什么场景？

<details><summary>参考答案</summary>

设 $y\in\{\pm1\}$，判别值 $f=w^Tx+b$。

- **Logistic + 交叉熵**：等价于 $\log(1+e^{-yf})$，**永远不为 0**，只要 $yf$ 有限就有梯度，倾向把 $yf$ 推得尽可能大；输出可解释为**概率**，是概率模型（最大似然）。
- **Hinge**：$[1-yf]_+$，在 $yf\ge1$ 时**严格为 0**，只惩罚间隔不足的样本。故解**只由支持向量**（$yf=1$ 附近）决定，对远离边界且已正确分类的样本完全不敏感，天然稀疏、对离群点更鲁棒（软间隔 SVM）。

**场景**：需要校准概率、做排序/多标签/概率推理 → 交叉熵；追求最大间隔、数据有离群点、希望解稀疏 → Hinge/SVM。教材表 3.1 与图 3.7 对比了这些损失（含感知器 $\max(0,-yf)$ 与平方损失），结论是**除平方损失外其他损失都较适合二分类**——平方损失在 $yf<0$ 且很大时梯度反而变小，对大错惩罚不足。
</details>
**T5** 下面代码有什么问题？指出并修正。

```python
model = nn.Sequential(nn.Linear(10, 8), nn.Sigmoid, nn.Linear(8, 3), nn.Sigmoid)
criterion = nn.CrossEntropyLoss
loss = criterion(model(x), target) # target: (N,) LongTensor
```

<details><summary>参考答案</summary>

**两个问题**：①**输出层多加 `Sigmoid`，与 `CrossEntropyLoss` 冲突**——该 loss 内部已含 `LogSoftmax`，要求输入是未归一化 logits；先过 Sigmoid 会把分量压到 $(0,1)$ 再被 Softmax 归一化，等于对概率做两次非线性压缩，类间差异被抹平、梯度被削弱（症状：loss 看似下降但准确率上不去）。②**隐藏层用 Sigmoid 不理想**——非零中心化且导数 $\le0.25$，继续加深会迅速梯度消失，应换 Tanh/ReLU 系。

**修正**：

```python
model = nn.Sequential(nn.Linear(10, 8), nn.ReLU, nn.Linear(8, 3)) # 输出层不加激活
loss = nn.CrossEntropyLoss(model(x), target)
```

附加提醒：`target` 必须是 `LongTensor` 类别索引 $(N,)$，不能是 one-hot；需要概率输出只在**推理阶段**用 `F.softmax(logits, dim=1)`，训练时一律传 logits。
</details>
