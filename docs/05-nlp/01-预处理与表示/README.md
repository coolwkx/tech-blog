## 本章要回答的问题

**01 NLP 概述与文本预处理**
- 说清 NLP 在 AI 体系中的位置、发展脉络与典型应用，并解释「规则派 / 统计派 / 深度学习派」的差别。
- 独立完成一套中文文本预处理流水线：分词 → 词性标注 / 实体识别 → 去停用词 → n-gram → 定长填充。
- 用标签分布、句子长度分布、词频词云三张图诊断语料问题，并据此确定 `max_len`、是否做数据增强。

**02 文本预处理与分词全流程**
- 看一眼乱码文本，就判断出是编码问题、归一化问题还是分词问题；
- 手写可运行的 BPE 训练 + 编码器，并说清 WordPiece、Unigram 与它的差异；
- 正确配置 `padding` / `truncation` / `attention_mask`，避开 padding 侧与 `max_length` 的坑；

**03 中文分词与子词分词**
- 说清 jieba 精确 / 全模式 / 搜索引擎三种模式的差别，并会用自定义词典修正领域专名。
- 把分词与 NER、词性标注统一理解为「序列标注」问题，写出 B/M/E/S 标签序列。
- 手写一个 BPE 合并流程，并解释 BPE、WordPiece、Unigram 三者目标函数的差异。

**04 文本表示：词袋与 TF-IDF**
- 手写词袋与 TF-IDF 的计算过程，并解释 `TF × IDF` 里每一项的作用。
- 说清 sklearn `TfidfVectorizer` 的 `smooth_idf`、`sublinear_tf`、L2 归一化到底做了什么。
- 用 `/max_features`、`min_df`、`max_df`、停用词把特征维度压到可训练规模，并给出选型理由。

**05 词向量：Word2Vec 与 FastText**
- 手推 CBOW 与 Skip-gram 的网络结构、输入输出维度，并说清两者的取舍。
- 解释负采样为什么把 $O(V)$ 的 softmax 降成 $O(k)$ 的二分类，并写出其损失函数。
- 用 gensim / fastText 训练词向量，做相似度与词向量类比的定量评估，并说明 FastText 处理 OOV 的原理。
