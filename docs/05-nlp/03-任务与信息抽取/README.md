## 本章要回答的问题

**3.1 文本分类实战**
- 独立完成一条文本分类流水线：数据体检 → 预处理 → 特征 → 基线 → 评估 → 错误分析。
- 说清 accuracy / macro-F1 / weighted-F1 的差异，并在类别不均衡时选对指标。
- 用混淆矩阵定位「哪两类容易混」，并把结论转化为可执行的改进项。

**3.2 序列标注与实体识别**
- 写出 BIO / BIOES 标签体系，并把一段文本标注成合法标签序列。
- 说清 HMM 的两个假设、三大问题与维特比递推，并解释「生成式 vs 判别式」带来的准确率差异。
- 说明 BiLSTM-CRF 中发射分数、转移分数与 CRF 解码层各自的职责，以及为什么必须用实体级 F1 评估。

**3.3 文本相似度与语义匹配**
- 说清编辑距离、Jaccard、TF-IDF 余弦、BM25、词向量平均、Sentence-BERT、Cross-Encoder 各自适用什么场景。
- 正确选择与使用余弦 / 点积 / 欧氏距离，并解释 embedding 归一化为什么让余弦与内积等价。
- 搭出一个「先用双塔召回、再用交叉编码器精排」的两阶段语义匹配系统。

**3.4 NLP 项目实战：情感分析**
- 完整走通中文情感分析项目：数据体检 → 预处理 → 三档模型对比 → 评估 → 错误分析 → 上线封装。
- 针对「否定词、程度副词、转折句」设计专项特征或数据增强，并用量化实验验证收益。
- 说清情感分析特有的坑（极性翻转、标注主观性、领域迁移）并给出处理方案。

**3.5 NLP 项目实战：医疗文本分类**
