## 本章要回答的问题

**1.1 Attention 机制详解**
- 忘记除以 $\sqrt{d_k}$
- 除成 $d_k$
- softmax 前不减最大值

**1.2 大模型基础与演进**
- 把 N-gram 概率直接连乘
- 用最大似然估计硬算未见组合
- 混淆 BLEU 与 ROUGE 方向

**1.3 Transformer 与注意力机制**
- 忘记除以 $\sqrt{d_k}$
- 多头维度不整除
- 多头切分时维度顺序写错

**1.4 主流大模型对比**
- 用英文词表模型做中文任务
- 把 ChatGLM 当 LLaMA 分支
- 认为 ChatGLM 的 decoder 是完全单向的
