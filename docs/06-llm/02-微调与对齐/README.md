## 本章要回答的问题

**01 微调基础与决策**
- 拿到一个业务需求，能在 10 分钟内给出"该不该微调、走哪条路线"的决策结论，并说明理由。
- 说清全参微调、PEFT、提示微调三种范式在可训练参数量、显存、推理延迟、适用数据量上的差异。
- 写出参数量与可训练参数占比的估算代码，并识别"数据量太少还硬上微调"这类典型误判。

**02 全参微调与显存账本**
- 拿到任意参数量与配置，手算出 fp32 / bf16 / 混合精度下的显存明细，指出哪一项是瓶颈。
- 说清 ZeRO-1/2/3 与 FSDP 各切什么、省的是哪一项、通信代价在哪里。
- 用本篇的 Python 脚本一键输出显存估算明细，并据此决定需要几张卡。

**03 LoRA 原理与工程实践**
- 自己手写一个 LoRA 线性层，包括零初始化、前向公式、merge/unmerge，并验证合并前后输出一致。
- 根据任务类型选择 $r$、$\alpha$、dropout 与 `target_modules`，并说明每个超参的作用。
- 判断什么场景该合并权重、什么场景该保留 adapter，以及为什么。

**04 QLoRA 与量化微调**
- 说清 NF4 为什么按正态分位数分桶、分块量化与双重量化分别省了多少字节（能推算出 4.5 bits/参数 → 4.127 bits/参数）。
- 写出可运行的 `BitsAndBytesConfig` + PEFT 配置，并说明每一项配置的作用与硬件前提。
- 判断什么时候该用 QLoRA、什么时候该用 GPTQ/AWQ，以及为什么量化后的基座不能直接 merge adapter。

**05 SFT 训练循环与框架**
- 从原始 instruction 数据出发，写出"chat template → tokenize → label masking → collator → Trainer"的完整可运行管线，并解释每一步在做什么。
- 手写 label masking（把 prompt 部分置为 -100），并说清不掩码会发生什么。
- 根据 loss 曲线形状、梯度范数和显存表现，定位"数据 bug / 学习率过大 / 过拟合 / 灾难性遗忘"。

**06 指令数据构造与清洗**
- 模板与分词器不匹配
- Verbalizer 词表外 token
- 标签词长度超 `max_label_len`

**07 微调效果评估与灾难性遗忘**
- 只报目标指标
- 验证集泄漏
- 用训练 loss 判断效果

**08 微调面试专题**
- 基线太弱
- 忘了 loss mask
- 只调 r 不调 alpha
