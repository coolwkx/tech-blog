## 本章要回答的问题

**3.1 对齐概览与 RLHF**
- KL 系数过小
- KL 系数过大
- 奖励模型过拟合标注集

**3.2 奖励模型与偏好数据**
- 偏好对跨 prompt 配对
- 长度未匹配
- 标注指南过粗

**3.3 DPO 与免强化学习对齐**
- 正负样本质量差
- 正负样本差异过大
- 跨 prompt 配对

**3.4 GRPO 与推理模型后训练**
- 奖励稀疏
- 组内全对或全错
- 组大小太小
