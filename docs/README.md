## 🧭 建议的复习节奏

1. **定位**：读目标领域的 `README.md`，挑出讲不清楚的系列。
2. **读**：重点看「常见坑」与「面试问答」两节。
3. **跑**：把「可运行示例」在本地跑通，改参数看输出变化。
4. **测**：合上笔记做「自测题」，错题记成 issue。
5. **沉淀**：把新的理解补进对应笔记，或写进速查表。
