# 面向过程 vs 面向对象

> **学习目标**：能够解释「面向过程 vs 面向对象」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：函数与参数传递（02 篇）、可变 vs 不可变类型与对象身份 `id`（01 篇）、元组拆包。
>
> **所属主题**：面向对象编程 · 核心概念

## 本次只学这一点

| 维度 | 面向过程 | 面向对象 |
| --- | --- | --- |
| 关注点 | 步骤/流程 | 对象及其职责 |
| 代码组织 | 一串函数互相调用 | 数据 + 操作数据的方法打包成类 |
| 扩展方式 | 改流程、加分支 | 加子类、重写方法 |
| 适合 | 简单的线性任务 | 需求复杂、会长期演化的系统 |

Python 两种都支持。**面向对象不是"更高级"，而是当"数据"和"操作数据的行为"需要长期绑在一起时才更划算**。
