# 类与对象：模板与实例

>

## 本次只学这一点

| 概念 | 说明 | 代码 |
| --- | --- | --- |
| 类 class | 抽象模板，描述"这类事物有什么" | `class Car: ...` |
| 对象 / 实例 object | 按模板造出的具体实体 | `car = Car` |
| 属性 attribute | 对象的固有特征（用变量表示） | `self.color = "red"` |
| 方法 method | 对象的行为（定义在类里的函数） | `def run(self): ...` |
| 实例化 | 调用类名创建对象的过程 | `Car` 内部会调用 `__init__` |

`self` 是**第一个形参**，Python 在调用 `obj.method(...)` 时自动把 `obj` 作为第一个实参传进去。所以：

- 类外部访问属性：`对象名.属性名`；
- 类内部访问属性/方法：`self.属性名` / `self.方法名`；
- `self` 的名字是约定，不是关键字，但**强烈建议不要改**。
