# 属性：类属性 vs 实例属性

> **学习目标**：能够解释「属性：类属性 vs 实例属性」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：函数与参数传递（02 篇）、可变 vs 不可变类型与对象身份 `id`（01 篇）、元组拆包。
>
> **所属主题**：面向对象编程 · 核心概念

## 本次只学这一点

| 维度 | 类属性 | 实例属性 |
| --- | --- | --- |
| 定义位置 | 类体里、方法外 | 通常在 `__init__` 中用 `self.x = ...` |
| 存放位置 | `类.__dict__` | `实例.__dict__` |
| 共享性 | 所有实例共享一份 | 每个实例各一份 |
| 读取顺序 | 先查实例 `__dict__`，没有才查类 | 同上 |
| 写入 | `类名.属性 = v` 改的是类 | `self.属性 = v` **新建**实例属性 |
```python
class Person:
    count = 0 # 类属性
    def __init__(self, name):
        self.name = name
        Person.count += 1

        a, b = Person("A"), Person("B")
        a.count = 99 # 注意：这是在实例上新建属性，没有改类属性
        print(Person.count, a.count, b.count) # 2 99 2
```
**结论**：想改"共享的"值必须写 `类名.属性 = v`；`self.属性 = v` 永远只影响当前实例。这一条也是"可变类属性"风险最大的地方（见常见坑）。
