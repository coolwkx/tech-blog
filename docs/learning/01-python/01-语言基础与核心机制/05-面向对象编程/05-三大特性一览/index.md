# 三大特性一览

> **学习目标**：能够解释「三大特性一览」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：函数与参数传递（02 篇）、可变 vs 不可变类型与对象身份 `id`（01 篇）、元组拆包。
>
> **所属主题**：面向对象编程 · 核心概念

## 本次只学这一点

| 特性 | 一句话 | 实现手段 | 好处 |
| --- | --- | --- | --- |
| 封装 encapsulation | 把数据和行为打包，隐藏实现细节 | `_x` 约定私有、`__x` 名称改写、`@property` | 简化调用、防止误改、便于重构 |
| 继承 inheritance | 子类复用父类的属性和方法 | `class Son(Father)` | 减少重复代码（is-a 关系） |
| 多态 polymorphism | 同一调用形式，不同对象给出不同行为 | 方法重写 + 父类"接口" | 解耦、可扩展 |
