# 赋值 / 浅拷贝 / 深拷贝

>

>

## 本次只学这一点

三种"复制"的差别只在一件事上：**内层子对象是否也被复制**。

| 操作 | 代码 | 第 1 层 | 第 2 层及更深 | 内存开销 |
| --- | --- | --- | --- | --- |
| 赋值（别名） | `b = a` | 同一个对象 | 共享 | 0 |
| 浅拷贝 | `copy.copy(a)` / `a.copy` / `a[:]` | 新对象 | **共享** | 小 |
| 深拷贝 | `copy.deepcopy(a)` | 新对象 | **递归新建** | 大 |
```python
import copy

inner = [1, 2, 3]
c = [6, 7, inner]

shallow = copy.copy(c)
deep = copy.deepcopy(c)

print(c is shallow, c is deep) # False False 第 1 层都是新对象
print(c[2] is shallow[2], c[2] is deep[2]) # True False 第 2 层：浅拷贝共享，深拷贝独立

inner[0] = 99
print(c, shallow, deep)
# [6, 7, [99, 2, 3]] [6, 7, [99, 2, 3]] [6, 7, [1, 2, 3]]
```
**一个容易被忽略的细节**：`copy.copy` 对**不可变对象**（如 `tuple`、`str`、`int`）通常直接返回原对象本身，因为既然不可变就没有复制的必要 —— 所以 `copy.copy((1,2,3)) is (1,2,3)` 往往为 `True`。深拷贝对不可变对象同样"就地引用"。这说明拷贝函数的策略是"**只对可能被改动的部分下功夫**"。
