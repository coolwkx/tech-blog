# open 的模式：一张表说清

> **学习目标**：能够解释「open 的模式：一张表说清」的机制或步骤，并用本节材料验证理解。

## 本次只学这一点

| 模式 | 含义 | 文件不存在 | 文件存在 | 可读 | 可写 |
| --- | --- | --- | --- | --- | --- |
| `r` | 只读（默认） | `FileNotFoundError` | 从头读 | ✅ | ❌ |
| `w` | 只写 | 创建 | **清空** | ❌ | ✅ |
| `a` | 追加 | 创建 | 指针移到末尾 | ❌ | ✅ |
| `x` | 独占创建 | 创建 | `FileExistsError` | ❌ | ✅ |
| `r+` | 读写 | `FileNotFoundError` | 不清空 | ✅ | ✅ |
| `w+` | 读写 | 创建 | **清空** | ✅ | ✅ |
| `a+` | 读写 | 创建 | 指针在末尾 | ✅ | ✅ |

在模式字符串后加 `b` 表示**二进制模式**（`rb` / `wb`），加 `t` 是文本模式（默认）。二进制模式下 `read` 返回 `bytes`，且**不能指定 `encoding`**。

| 文本模式 `t` | 二进制模式 `b` |
| --- | --- |
| 读写 `str` | 读写 `bytes` |
| 需要 `encoding` | 禁止 `encoding` |
| 自动处理平台换行符（`\n` ↔ `\r\n`） | 原样读写，不转换 |
| 适合 txt / csv / json | 适合图片、音频、压缩包、pickle |
