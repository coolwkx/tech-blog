# 读写方法对比

> **学习目标**：能够解释「读写方法对比」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：函数与作用域（02 篇）、可变/不可变类型（01 篇）、类与魔法方法 `__enter__` / `__exit__`（03 篇）。
>
> **所属主题**：文件与异常处理 · 核心概念

## 本次只学这一点

| 方法 | 返回 | 内存 | 适用 |
| --- | --- | --- | --- |
| `f.read` | 整个文件内容（str/bytes） | 全量载入 | 小文件 |
| `f.read(n)` | 最多 n 个字符/字节 | 可控 | 分块处理 |
| `f.readline()` | 一行（含 `\n`） | 一行 | 逐行 |
| `f.readlines()` | 所有行的 list | 全量载入 | 小文件、需要列表 |
| `for line in f:` | 每次一行 | ⭐ 最小 | **大文件首选** |
```python
# 大文件唯一推荐写法：惰性迭代，内存里始终只有一行
with open("big.log", "r", encoding="utf-8") as f:
    for line in f:
        process(line.rstrip("\n")) # 用 rstrip 去掉行尾换行
```
写入方法：

| 方法 | 说明 |
| --- | --- |
| `f.write(s)` | 写入字符串，返回写入的字符数；**不会自动换行** |
| `f.writelines(seq)` | 逐个写入序列中的字符串，**也不会自动加换行** |
| `print(..., file=f)` | 会加换行，适合快速写日志 |
