# 并发 vs 并行

> **学习目标**：能够解释「并发 vs 并行」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：函数与参数（02 篇）、`if __name__ == "__main__"` 与模块（05 篇）、竞态与锁的直觉（`try/finally`，04 篇）。
>
> **所属主题**：并发编程：进程与线程 · 核心概念

## 本次只学这一点

| 概念 | 定义 | 硬件前提 | 例子 |
| --- | --- | --- | --- |
| 并发 concurrency | 一段时间内**交替**执行多个任务 | 单核即可 | 单核 CPU 上用时间片轮转跑 3 个软件 |
| 并行 parallelism | 同一时刻**真正同时**执行多个任务 | 需要多核 | 16 核 CPU 同时跑 4 个计算任务 |
| 多任务 multitasking | 同一时间内执行多个任务（给人感觉） | — | 操作系统同时开浏览器和音乐播放器 |

**关键点**：单核只能并发，不能并行。并发是"看起来同时"，并行是"真的同时"。它们不是对立的，而是"多任务"的两种实现层次 —— 现代系统里两者同时存在（多核并行 + 每核上并发）。
