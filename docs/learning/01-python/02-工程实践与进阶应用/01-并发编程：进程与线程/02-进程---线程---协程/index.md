# 进程 / 线程 / 协程

> **学习目标**：能够解释「进程 / 线程 / 协程」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：函数与参数（02 篇）、`if __name__ == "__main__"` 与模块（05 篇）、竞态与锁的直觉（`try/finally`，04 篇）。
>
> **所属主题**：并发编程：进程与线程 · 核心概念

## 本次只学这一点

| 维度 | 进程 Process | 线程 Thread | 协程 Coroutine |
| --- | --- | --- | --- |
| 定位 | 资源分配的最小单位 | CPU 调度的最小单位 | 用户态协作式任务 |
| 内存空间 | **独立**（各自一份） | **共享**同一进程内存 | 共享 |
| 创建开销 | 大（要拷贝/初始化资源） | 小 | 极小 |
| 通信方式 | IPC（Queue / Pipe / 共享内存 / socket） | 直接读写共享变量 | 直接共享 |
| 切换成本 | 高 | 中 | 极低 |
| 能否用多核 | ✅（绕过 GIL） | ❌（受 GIL 限制） | ❌ |
| 稳定性 | 一个进程崩溃不影响其他进程 | 一个线程崩溃可能拖垮整个进程 | 同线程 |
| 适用 | CPU 密集型 | I/O 密集型 | 高并发 I/O（`asyncio`） |

**进程与线程的 6 条关系（值得记住）**：

1. 线程依附在进程里，没有进程就没有线程；
2. 一个进程默认提供一条线程（主线程），进程可以创建多条线程；
3. 进程之间不共享全局变量，线程之间共享全局变量；
4. 创建进程的资源开销比创建线程大；
5. 进程是操作系统资源分配的基本单位，线程是 CPU 调度的基本单位；
6. 线程不能独立执行，必须依存于进程。
