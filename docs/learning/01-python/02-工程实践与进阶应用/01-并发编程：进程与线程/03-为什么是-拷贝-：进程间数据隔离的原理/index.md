# 为什么是"拷贝"：进程间数据隔离的原理

> **学习目标**：能够解释「为什么是"拷贝"：进程间数据隔离的原理」的机制或步骤，并用本节材料验证理解。

>
> **所属主题**：并发编程：进程与线程 · 核心概念

## 本次只学这一点

创建子进程时，操作系统让子进程拥有**独立的地址空间**。可以这样理解："子进程是主进程的一个副本，好比一对双胞胎"。

实测：
```text
主进程 g_list = ['主进程']
子进程 append('子进程')
子进程退出后，主进程看到的 g_list: ['主进程'] ← 没变
子线程 append('子线程')
主线程看到的 g_list: ['子线程'] ← 变了
```
- **进程**：每个进程操作的是自己的 `g_list`，名字相同但内存不同，所以互不影响；
- **线程**：所有线程共用同一个进程的堆和全局变量，所以立刻可见。

> 结论：想在进程之间传数据，必须走 IPC（`multiprocessing.Queue` / `Pipe` / `Manager` / 共享内存 / socket）；想在进程之间"共享一个计数器"，用普通全局变量是无效的。
