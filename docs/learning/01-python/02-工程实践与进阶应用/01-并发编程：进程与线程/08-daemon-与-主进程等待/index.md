# daemon 与"主进程等待"

> **学习目标**：能够解释「daemon 与"主进程等待"」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：函数与参数（02 篇）、`if __name__ == "__main__"` 与模块（05 篇）、竞态与锁的直觉（`try/finally`，04 篇）。
>
> **所属主题**：并发编程：进程与线程 · 核心概念

## 本次只学这一点

| 行为 | 表现 |
| --- | --- |
| 默认 | 主进程/主线程会**等待所有子进程/子线程结束**才退出 |
| `daemon=True` | 主进程/主线程退出时，子进程/子线程被**强制终止** |
| `p.terminate` | 手动强制结束子进程，不推荐（可能留下僵尸进程、不清理资源） |

**为什么默认要等待？** 因为子进程可能需要把结果写回文件/数据库，直接杀掉会丢数据。daemon 适用于"纯背景任务"（心跳、监控、刷新缓存），它们的消失不影响正确性。

注意：**daemon 进程不能创建子进程**，否则会抛 `AssertionError: daemonic processes are not allowed to have children`。
