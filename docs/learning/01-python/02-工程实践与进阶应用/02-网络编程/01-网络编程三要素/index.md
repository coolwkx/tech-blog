## 本次只学这一点

| 要素 | 作用 | 类比 | 查看/命令 |
| --- | --- | --- | --- |
| IP 地址 | 网络中**设备**的唯一标识 | 小区门牌号 | `ipconfig`（Windows）/ `ifconfig`（Linux/macOS） |
| 端口号 | 设备上**进程**的标识，0~65535 | 教室的门 | `netstat -ano`（Windows）/ `netstat -anp`（Linux） |
| 协议 | 通信双方遵守的规则 | 都说普通话 | — |

**端口号分区**：

| 区段 | 名称 | 说明 |
| --- | --- | --- |
| 0 ~ 1023 | 知名端口 / 特权端口 | 已被系统或标准服务占用（80 HTTP、443 HTTPS、22 SSH），普通程序不加权限用不了 |
| 1024 ~ 49151 | 注册端口 | 常见第三方服务 |
| 49152 ~ 65535 | 动态/私有端口 | 客户端临时端口通常从这里分配，自己练习推荐用这一段或直接用 8000+ |

**IP 的特殊地址**：`127.0.0.1` 是本地回环（loopback），永远指向本机，用来做本机测试；`0.0.0.0` 在 `bind` 时表示"监听所有网卡"；`bind` 时传空字符串 `""` 等价于 `0.0.0.0`。
