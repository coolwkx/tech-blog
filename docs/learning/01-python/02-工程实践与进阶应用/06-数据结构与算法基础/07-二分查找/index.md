# 二分查找

> **学习目标**：能够解释「二分查找」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：列表与字典的复杂度直觉（01 篇）、函数与递归（02 篇）、类与对象（03 篇）。
>
> **所属主题**：数据结构与算法基础 · 核心概念

## 本次只学这一点

**前提缺一不可**：① 必须**顺序存储**（能直接地址偏移定位，`O(1)` 随机访问）；② 必须按关键字**有序排列**。

**思路**：把数组分成"中值前 / 中值 / 中值后"，待查找值与中值比较：小于去前半部分，大于去后半部分，等于则返回。

| 版本 | 关键代码 | 复杂度 |
| --- | --- | --- |
| 非递归 | `while start <= end:` + `mid=(start+end)//2` + 调整 `start/end` | 时间 `O(log n)`，空间 `O(1)` |
| 递归 | `binary_search(alist[:mid], item)` | 时间 `O(log n)`，但**切片每次复制 `O(n)`**，实际退化，空间 `O(n)` |

两个细节：循环条件必须是 `start <= end`（用 `<` 会漏掉"区间只剩一个元素"）；教材的递归版写 `alist[0:mid]` 只为讲清思路，生产代码应传下标区间。
