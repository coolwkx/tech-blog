## 本次只学这一点

| 术语 | 含义 | | 术语 | 含义 |
| --- | --- | --- | --- | --- |
| 节点的度 | 该节点的子节点个数 | | 节点的层次 | 根为第 1 层，依次递增 |
| 树的度 | 树中最大的节点度 | | 树的高度/深度 | 节点的最大层次 |
| 叶节点 | 度为 0 的节点 | | 森林 | m（m≥0）棵互不相交的树的集合 |

| 树的种类 | 特点 / 用途 |
| --- | --- |
| 哈夫曼树 | 带权路径最短的二叉树，用于信息编码 |
| B 树 | 读写优化的自平衡多路查找树（数据库索引） |
| 完全二叉树 | 除最后一层外都满，最后一层从左到右紧密排列 |
| 满二叉树 | 所有叶节点都在最底层的完全二叉树 |
| 平衡二叉树（AVL） | 任何节点两棵子树高度差 ≤ 1；**防止树退化成链表** |
| 排序二叉树（BST） | 左子树全部小于根、右子树全部大于根；**中序遍历得到有序序列** |

**应用场景**：XML/HTML 解析器、路由协议、MySQL 索引、文件系统目录结构、AI 搜索、决策树。

| 二叉树的 5 条性质 |
| --- |
| 1. 第 `i` 层至多有 `2^(i-1)` 个结点 |
| 2. 深度为 `k` 的二叉树至多有 `2^k - 1` 个结点 |
| 3. 叶结点数 `N0` 与度为 2 的结点数 `N2` 满足 `N0 = N2 + 1` |
| 4. `n` 个结点的完全二叉树深度为 `⌊log₂n⌋ + 1` |
| 5. 完全二叉树按层编号（从 1 起），结点 `i` 的左孩子 `2i`、右孩子 `2i+1`、父节点 `i//2` |

> 性质 5 是"完全二叉树可用数组存储"的理论基础（若从 0 开始编号：左 `2i+1`、右 `2i+2`、父 `(i-1)//2`）。存储方式上，顺序存储遍历快但浪费空间（非主流），链式存储（左右指针）便于找父子关系，是常见做法。

| 遍历 | 顺序 | 口诀 |
| --- | --- | --- |
| 先序（前序） | 根 → 左 → 右 | 根左右 |
| 中序 | 左 → 根 → 右 | 左根右 |
| 后序 | 左 → 右 → 根 | 左右根 |
| 层序（广度优先） | 逐层从左到右，用**队列**实现 | — |

先序/中序/后序属于**深度优先**（递归或栈），层序属于**广度优先**（队列，能找到最短路径）。**由遍历结果还原二叉树必须给出中序 + (先序或后序)**：先序定根、中序分左右子树，再递归；只给先序和后序无法唯一确定。
