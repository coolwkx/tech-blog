# SQL 语句基本规则

> **学习目标**：能够解释「SQL 语句基本规则」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：会启动 MySQL（或用提供的虚拟机）、能用 DataGrip 或命令行连上数据库；理解"表 = 行 + 列"。
>
> **所属主题**：-MySQL基础与SQL语法 · 核心概念

## 本次只学这一点

| 规则 | 说明 |
| --- | --- |
| 大小写 | SQL **不区分大小写**，约定**关键字大写、其他小写** |
| 换行缩进 | 一条语句可写一行或多行，缩进空格只为可读性 |
| 语句结束 | 以分号 `;` 结束 |
| 注释 | `-- 单行`（`--` 后**必须有空格**）、`# 单行`、`/* 多行 */` |
