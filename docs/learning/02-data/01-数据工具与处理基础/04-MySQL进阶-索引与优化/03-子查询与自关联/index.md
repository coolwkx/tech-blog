# 子查询与自关联

>

## 本次只学这一点

| 概念 | 说明 |
| --- | --- |
| 子查询 | 一个查询的**条件**依赖另一个查询的**结果**；里层叫子查询，外层叫父查询（主查询） |
| 使用位置 | 可出现在 `where` 中（最常见），也可作为"套表"出现在 `from` 中 |
| 自关联 | **同一张表自己和自己关联**；典型是树形/层级数据（省—市—区） |

自关联的经典设计——用**一张表**存省市区，靠 `pid` 指向父级，避免建三张表：

| id | title | pid |
| --- | --- | --- |
| 410000 | 河南省 | 0 |
| 410100 | 郑州市 | 410000 |
| 410700 | 新乡市 | 410000 |
| 410101 | 二七区 | 410100 |
| 410721 | 新乡县 | 410700 |
