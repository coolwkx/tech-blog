# 为什么学 Matplotlib

## 本次只学这一点

可视化是数据挖掘的关键辅助工具：把数据**直观呈现**，一眼看出趋势、异常与分布；让结论更**客观有说服力**；还能**反哺分析方法**——看图发现异常点后回头调整策略。Matplotlib 是 Python 中使用最多的绘图库，专做 2D（含 3D）图表，入口模块是 `matplotlib.pyplot`（提供一系列类似 MATLAB 的函数）。
