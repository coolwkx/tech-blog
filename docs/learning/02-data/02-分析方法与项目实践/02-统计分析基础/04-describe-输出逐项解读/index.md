## 本次只学这一点

`df.describe` 一次给出 `count`、`mean`、`std`、`min`、`25%`、`50%`、`75%`、`max`：

| 行 | 含义 | 怎么用 |
| --- | --- | --- |
| `count` | 非空值个数 | 与总行数比较，**立刻看出缺失情况** |
| `mean` | 均值 | 与 `50%`（中位数）比较：差得远说明**分布偏斜或存在离群值** |
| `std` | 标准差 | 衡量波动；数值列的离散程度 |
| `min` | 最小值 | 发现异常下限（如订单金额为 0 或 0.1） |
| `25%` / `50%` / `75%` | 下四分位数 / 中位数 / 上四分位数 | 看**数据集中在哪一段**；也用来定分箱边界 |
| `max` | 最大值 | 发现异常上限（如订单金额 174900 这类极值） |

**四分位距 IQR** = `75% − 25%`，是"中间一半数据"的跨度，不受两端极值影响。常用经验法则：小于 `25% − 1.5×IQR` 或大于 `75% + 1.5×IQR` 的点视为**离群点（outlier）**。

阅读 `describe` 的三个判断技巧：

| 观察 | 结论 | 后续动作 |
| --- | --- | --- |
| `mean` 明显大于 `50%` | 右偏（存在大的极值） | 用中位数描述中心；考虑对数变换或截断极值 |
| `max` 远大于 `75%` | 存在极端离群点 | 与业务确认是否有效（如"一次性采购大量商品"有效、"0.1 元优惠券订单"无效） |
| `min` 为 0 或负数 | 可疑数据 | 结合业务判断是否为缺失值的错误编码 |
| `25%`、`50%`、`75%` 三者相等 | 数据高度集中在同一个值 | 该变量几乎无区分度（如购买频次大多为 1） |
