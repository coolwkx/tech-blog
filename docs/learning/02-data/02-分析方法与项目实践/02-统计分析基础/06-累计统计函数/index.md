## 本次只学这一点

| 函数 | 作用 |
| --- | --- |
| `cumsum` | 计算前 1/2/3/…/n 个数的**和** |
| `cummax` | 计算前 1/2/3/…/n 个数的**最大值**（常用于看"历史新高"） |
| `cummin` | 计算前 1/2/3/…/n 个数的**最小值**（看"历史新低"） |
| `cumprod` | 计算前 1/2/3/…/n 个数的**积**（看复利/累计收益率） |

使用前提：序列必须有正确的顺序（时间序列要先 `sort_index` 排序），否则累计结果没有意义。累计结果常用 `.plot` 直接出图观察走势。
