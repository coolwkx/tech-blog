## 本次只学这一点

把每个维度二分为"高/低"（以中位数或某阈值为界），得 2×2×2 = 8 类：

| R | F | M | 用户类别 | 特征速记 |
| --- | --- | --- | --- | --- |
| 高 | 高 | 高 | **重要价值用户** | 最近买、常买、买得多——最优质客户 |
| 高 | 低 | 高 | **重要发展用户** | 最近买、金额高，但频率低——提频即可增值 |
| 低 | 高 | 高 | **重要保持用户** | 曾经常买且金额高，但最近没来——有流失风险 |
| 低 | 低 | 高 | **重要挽留用户** | 金额高但久未购买且频率低——重点挽回 |
| 高 | 高 | 低 | **一般价值用户** | 活跃但消费低——提升客单价 |
| 高 | 低 | 低 | **一般发展用户** | 新客或低频低额——培育 |
| 低 | 高 | 低 | **一般保持用户** | 频次尚可但已沉默——激活 |
| 低 | 低 | 低 | **一般挽留用户** | 各维度都差——最后考虑 |
