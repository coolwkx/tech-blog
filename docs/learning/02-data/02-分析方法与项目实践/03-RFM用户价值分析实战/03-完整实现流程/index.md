# 完整实现流程

> **学习目标**：能够解释「完整实现流程」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：[06-Pandas数据清洗](../../../../../02-data/02-NumPy与Pandas/06-Pandas数据清洗.md)（`dropna`、`concat`、`dt` 时间属性）；[07-Pandas分组聚合与透视](../../../../../02-data/02-NumPy与Pandas/07-Pandas分组聚合与透视.md)（`groupby + agg`）；[09-统计分析基础](../../../../../02-data/03-可视化与统计/09-统计分析基础.md)（`describe` 与分位数）。
>
> **所属主题**：-RFM用户价值分析实战 · 核心概念

## 本次只学这一点

| 步骤 | 做什么 | 关键 API / 要点 |
| --- | --- | --- |
| ① 设置截止时间节点 | 选定基准日期（如 `2024-05-01`） | `pd.to_datetime('2024-05-01')` |
| ② 获取原始数据集 | 取固定周期（如近 1 年）的会员 ID、订单时间、订单金额 | 一个会员可能有多条订单 |
| ③ 数据预处理 | 删缺失值、去异常（金额过小） | `dropna`、布尔筛选 |
| ④ 计算 R/F/M 原始值 | R = 距截止节点的**最近**订单间隔；F = 订单**条数**；M = 金额**求和** | 一次 `groupby.agg({'日期':'max','订单号':'count','金额':'sum'})` |
| ⑤ 看数据分布 | 用 `describe` 观察 R/F/M 分布，为定边界做准备 | 关注 `mean` 与 `50%` 的差距、`min`/`max` 的极端性 |
| ⑥ 离散化打分 | 用 `pd.cut` 按边界切成 1~5 分或 1~3 分 | R 的 labels 要**倒序** |
| ⑦ 组合得分 | 加权求和 或 三维度字符串拼接 | `w = R*0.2 + F*0.2 + M*0.6`；`"312"` 这种组合 |
| ⑧ 结果应用 | 导出 Excel / 写入数据库 / 出图分析 | `to_excel`、`to_sql`、`plot`/`pyecharts` |
