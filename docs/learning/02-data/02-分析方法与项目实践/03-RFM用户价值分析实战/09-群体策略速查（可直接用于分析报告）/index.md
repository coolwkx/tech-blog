## 本次只学这一点

| 群体 | 规模 | 特征 | 建议策略 |
| --- | --- | --- | --- |
| `212` 可发展的一般性群体 | 大（>10%） | 新近度、金额一般，频率低 | 常规礼品兑换、购物社区活动、签到、免运费，维持并提升消费状态 |
| `211` 可发展的低价值群体 | 大 | 金额比 212 更差 | 组合商品优惠券、积分购买商品等与订单相关的刺激 |
| `312` 有潜力的一般性群体 | 大 | 最近买过、频率低、金额中等 | 基于上次购买商品做定制推荐，用向上销售提升频次与客单 |
| `112` 可挽回的一般性群体 | 大 | 久未购买、频率低、金额中等 | 邮件/短信多渠道触达召回，发放流失用户专享优惠券 |
| `213` 可发展的高价值群体 | 大 | 金额高但频率低 | 节日活动、每周新品推送、高价值客户专享商品 |
| `111` 各维度都差 | 中 | 全面偏弱 | 放在其他群体之后，用大额优惠+热销商品先促成一次消费 |
| `333` 绝对忠诚的高价值群体 | 极少 | 三维度全优 | 倾斜资源：VIP 服务、专享服务、绿色通道、高价值附加服务推荐 |
