## 本次只学这一点

案例在规划阶段把 R、F、M 三个维度**分别离散化成 3 个区间**：用户群体最多 3×3×3 = **27 个**；区间过多不利于群体拆分且业务要配套的策略数量爆炸；区间过少可能导致每个特征上的用户区分不显著。最终依据是**业务方能投入多少资源**——资源有限时划 2 档（最多 8 组）更易落地。这说明"建模参数"往往由**业务资源**而非纯技术指标决定。
