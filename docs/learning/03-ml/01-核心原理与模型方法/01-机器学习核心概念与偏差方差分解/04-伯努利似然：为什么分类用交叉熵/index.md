# 伯努利似然：为什么分类用交叉熵

> **学习目标**：能够解释「伯努利似然：为什么分类用交叉熵」的机制或步骤，并用本节材料验证理解。
>

>
> **所属主题**：机器学习核心概念与偏差方差分解 · 核心思想

## 本次只学这一点

二分类里 $y\in\{0,1\}$，模型输出 $h_\theta(x)$ 表示 $P(Y=1\mid x)$，似然是伯努利分布：

$$-\log L(\theta)=-\sum_{i=1}^{n}\Big[y_i\log h_\theta(x_i)+(1-y_i)\log\big(1-h_\theta(x_i)\big)\Big]=\text{二元交叉熵}$$

多分类把伯努利换成 categorical 分布、把 sigmoid 换成 softmax，就得到 softmax 交叉熵。三个关键点：

1. **模型与数据匹配**：0/1 目标不是高斯变量，用高斯似然描述它等于假设了一个方差随均值变化的错误模型。
2. **梯度性质**：logistic + 交叉熵的 $\frac{\partial \ell}{\partial z}=h-y$，错得越离谱梯度越大；logistic + MSE 的 $\frac{\partial \ell}{\partial z}=(h-y)h(1-h)$，$h$ 饱和到 0 或 1 时梯度趋近 0（"错得最狠的样本几乎不产生梯度"），且损失关于 $z$ 非凸。
3. **信息论解释**：交叉熵 = 经验标签分布与预测分布之间的 KL 散度 + 常数。但要诚实说明：对概率输出用平方损失（Brier score）的最小化点同样是 $\eta(x)$，它也是 proper scoring rule；差别在于交叉熵对"自信地犯错"施加无界惩罚，而平方损失有界、对标签噪声更稳健，所以标签噪声很重时会见到 label smoothing 或 Brier 类替代损失。
