# 偏差-方差权衡（bias-variance tradeoff）

> **学习目标**：能够解释「偏差-方差权衡（bias-variance tradeoff）」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：条件期望 $E[Y\mid X]$、方差、极大似然估计、矩阵最小二乘（正规方程）、训练/验证集切分与交叉验证。
>
> **所属主题**：机器学习核心概念与偏差方差分解 · 深入机制

## 本次只学这一点

以容量（阶数、树深、网络宽度）为横轴，bias² 单调下降、variance 单调上升，两者之和呈 U 型，最优容量满足 $\partial\,\mathrm{Bias}^2/\partial C=-\partial\,\mathrm{Var}/\partial C$。理论学习给出同一幅图：近似误差随 $\mathcal H$ 变大而下降，估计误差上界随 $\mathcal H$ 的复杂度（VC 维、Rademacher 复杂度）上升而上升、随 $n$ 上升而下降。工程上更常用的等价旋钮是正则强度 $\lambda$：$\lambda$ 小 = 容量大，$\lambda$ 大 = 容量小，调 $\lambda$ 与调模型大小动的是同一个东西。

一个必须知道的现代修正：**双下降（double descent）**。上述 U 型曲线的前提是容量通过固定假设空间或显式正则来控制；当模型参数量远超样本量（过参数化区间）时，测试误差在插值阈值附近先升后降，出现第二个下降段（Belkin 等, 2019；Nakkiran 等, 2019）。所以在深度学习里"参数越多越容易过拟合"不是普适规律；但第一段 U 型，以及"小样本 + 高容量 = 高方差"的结论依然成立。
