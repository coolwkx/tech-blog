# 正则化的统一视角

> **学习目标**：能够解释「正则化的统一视角」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：条件期望 $E[Y\mid X]$、方差、极大似然估计、矩阵最小二乘（正规方程）、训练/验证集切分与交叉验证。
>
> **所属主题**：机器学习核心概念与偏差方差分解 · 深入机制

## 本次只学这一点

所有正则化方法都在做同一件事：**限制模型对训练集噪声的敏感度**，用一点 bias² 换更多的方差下降。对 $B$ 个两两相关性为 $\rho$ 的模型取平均（bagging 类方法）时 $\mathrm{Var}=\rho\sigma^2+\frac{1-\rho}{B}\sigma^2$，可见增大 $B$ 只压低第二项、偏差不变。

| 手段 | 数学形式 | 主要压什么 | 代价 | 使用注意 |
| --- | --- | --- | --- | --- |
| L2 / weight decay | $\lambda\|\theta\|_2^2$ | variance：缩小权重范数、改善条件数 | 系数整体等比收缩，不产生 0 | 特征需标准化；共线性强时首选 |
| L1 / Lasso | $\lambda\|\theta\|_1$ | variance + 特征选择（稀疏） | 有偏；相关特征只随机留一个 | 需标准化；想兼顾用 ElasticNet |
| 早停 | 迭代步数 $T$ 当容量旋钮 | variance：限制参数离初始点的距离 | 训练不充分会引入偏差 | 平方损失 + 梯度下降下与 L2 渐近等价 |
| Dropout | 训练时随机置零、推理缩放 | variance：近似模型平均/集成 | 有效容量下降、训练变慢 | 全连接层常用；与 BatchNorm 组合要小心 |
| 数据增强 | 用保持标签的变换扩大有效 $n$ | variance：直接增大有效样本量，并编码不变性先验 | 错误变换会抬高 bias² | 增强必须保持标签语义 |
| Bagging / 集成 | 平均多个模型 | variance：$\rho\sigma^2+\frac{1-\rho}{B}\sigma^2$ | 计算与存储成本 | 高方差低偏差模型收益最大 |

岭回归强度扫描（$n=30$、9 阶，复用 §3 的 `fit_poly` 与 4.2 节的 `decompose`）：

```python
# 复用上面的 decompose / fit_poly（fit_poly 已支持 lam）
print(f"{'lambda':>8} | {'bias^2':>8} | {'variance':>9} | {'total':>8} | {'empirical EPE':>13}")
for lam in (0.0, 1e-6, 1e-4, 1e-3, 1e-2, 3e-2, 1e-1):
 b, v, e = decompose(degree=9, n=30, lam=lam)
 print(f"{lam:>8.0e} | {b:>8.4f} | {v:>9.4f} | {b + v + SIGMA ** 2:>8.4f} | {e:>13.4f}")
```

| 0 | 0.0733 | 37.9193 | 38.0826 | 38.0984 |
| $10^{-6}$ | 0.0661 | 32.6065 | 32.7626 | 32.7780 |
| $10^{-4}$ | 0.0028 | 2.7058 | 2.7985 | 2.8042 |
| $10^{-3}$ | 0.0009 | 0.7774 | 0.8684 | 0.8705 |

| $10^{-1}$ | 0.0011 | 0.0745 | 0.1656 | 0.1656 |

从 $\lambda=0$ 到 $10^{-1}$，variance 降了约 500 倍，bias² 只从 0.0733 变到 0.0011，总误差单调下降。原因是这个实验里真函数在假设空间内（9 阶多项式足以逼近 sin），正则几乎不引入偏差，属于"白拿"。**反例很重要**：若用 1 阶模型去拟合 sin，再加 L2 就只会抬高 bias²、让误差变差——正则从来不免费，它只是把误差预算从方差挪到偏差。

L1 的稀疏性（真模型只有 3 个非零系数，$n=50,d=9$）：

```python
import numpy as np

def soft_threshold(z, t):
    return np.sign(z) * np.maximum(np.abs(z) - t, 0.0)

def lasso_cd(X, y, lam, iters=1000):
    """min_w (1/(2n)) * ||y - Xw||^2 + lam * ||w||_1，坐标下降 + 软阈值。"""
    n, d = X.shape
    w = np.zeros(d)
    col_sq = (X ** 2).sum(axis=0)
    for _ in range(iters):
        for j in range(d):
            r = y - X @ w + X[:, j] * w[j] # 去掉第 j 个坐标后的残差
            w[j] = soft_threshold(X[:, j] @ r, lam * n) / col_sq[j]
            return w

        rng = np.random.default_rng(3)
        X = rng.normal(size=(50, 9)) # 50 个样本、9 个特征
        w_true = np.zeros(9)
        w_true[[0, 2, 5]] = [2.0, -1.5, 1.0] # 真模型只用了 3 个特征
        y = X @ w_true + rng.normal(0.0, 0.2, 50)

        w_ols = np.linalg.lstsq(X, y, rcond=None)[0]
        print(f"OLS 非零系数={int((np.abs(w_ols) > 1e-8).sum)} w={np.round(w_ols, 3)}")
        for lam in (0.02, 0.05, 0.1, 0.4):
            w = lasso_cd(X, y, lam)
            print(f"Lasso lam={lam:<5} 非零系数={int((np.abs(w) > 1e-8).sum)} w={np.round(w, 3)}")
```

Lasso lam=0.05 非零系数=4 w=[ 1.936 0.011 -1.434 -0. 0. 0.881 0. 0. -0. ]

$\lambda=0.1$ 时非零系数恰好 3 个，且支撑集 $\{0,2,5\}$ 就是真支撑；继续增大 $\lambda$ 不再提高稀疏度，只是把系数继续收缩（2.018 → 1.411），这就是偏差被主动引入的过程。
