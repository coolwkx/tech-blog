# 可操作的诊断流程

> **学习目标**：能够解释「可操作的诊断流程」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：条件期望 $E[Y\mid X]$、方差、极大似然估计、矩阵最小二乘（正规方程）、训练/验证集切分与交叉验证。
>
> **所属主题**：机器学习核心概念与偏差方差分解 · 深入机制

## 本次只学这一点

| 现象 | 判断 | 具体动作 |
| --- | --- | --- |
| 训练误差高、验证误差也高且接近 | 欠拟合（bias 主导） | 加特征/特征交叉、提高容量、降正则、延长训练；**加数据无效** |
| 训练误差低、验证误差高，验证曲线随 $n$ 仍下降 | 过拟合（variance 主导，数据不足） | 加数据/增强 → 加正则（L2、早停、Dropout）→ 集成 → 降容量 |
| 训练误差低、验证误差高，验证曲线已走平 | 过拟合但数据不是瓶颈 | 加正则、降容量、特征选择、集成；采数据优先级低 |
| 两条曲线都高，验证误差在某平台走平 | 噪声地板 / bias 地板 | 粗估 $\sigma^2$（同一样本重复标注或重复测量的方差）；检查标签噪声，确认问题本身可学 |
| 训练误差低、验证误差高，gap 不随 $n$ 收窄（两线平行） | 分布不一致或泄漏 | 查切分：时间序列用时间切分、分组数据用 `GroupKFold`、特征是否含未来信息 |
| 验证指标方差极大，或指标长期不涨只随换模型小幅涨 | 评估协议不稳 / 已接近可观测量上限 | K 折 + 多次重复并报均值与标准差；转向数据质量、特征、目标定义而非继续调参 |

**"先加数据、先加特征，还是先加模型复杂度"的决策顺序**（不看学习曲线无法回答，但看曲线后的顺序是固定的）：

1. **先固定评估协议**：独立测试集（只在最后用一次）+ 交叉验证 + 明确基线（多数类、随机、上一版模型）。没有基线，"验证误差高"没有意义。
2. **再看学习曲线**，用 4.5 节的四象限表定位 bias 主导还是 variance 主导。
3. **variance 主导**时按性价比排序：数据/增强 → 正则 → 集成 → 降容量。因为加数据同时改善后续所有选择的可靠性，而正则要额外调超参。
4. **bias 主导**时按信息量排序：加新特征/特征交叉 → 换更强的假设空间 → 降正则。此时加数据是把钱扔进平台里。
5. **两者都高、验证误差贴在平台上**时，先查标签与切分，再考虑换问题定义。这一步经常能解释"怎么调都不涨"。
6. **只有训练误差本身也高**（欠拟合）时，"加模型复杂度"才是正确动作；训练误差低而验证误差高时加容量只会让 gap 更大。
