# 三大概念与包含关系

> **学习目标**：能够解释「三大概念与包含关系」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：Python 基础语法、numpy 数组与 pandas DataFrame 的基本操作、一点点高中函数与坐标系概念。
>
> **所属主题**：机器学习概述与流程 · 核心思想

## 本次只学这一点

| 概念 | 英文 | 一句话定义 | 与相邻概念的关系 |
| --- | --- | --- | --- |
| 人工智能 | Artificial Intelligence, AI | 研究与构建"能智能行动的计算主体"的学科 | 最大的集合 |
| 机器学习 | Machine Learning, ML | 让计算机**无需显式编程**就能从数据中获得能力 | AI 的一种实现途径 |
| 深度学习 | Deep Learning, DL | 用多层神经元堆叠模拟复杂函数的机器学习方法 | ML 的一种具体方法 |

$$\text{AI} \supset \text{ML} \supset \text{DL}$$

- 机器学习识别车：**从数据中获取规律**，来一张新图 → 产生一个新预测。
- 人类识别车：**从经验中归纳特征**，来一张新图 → 靠记忆与常识判断。
- 深度学习：大脑仿生，一层层神经元去逼近任意复杂函数。
