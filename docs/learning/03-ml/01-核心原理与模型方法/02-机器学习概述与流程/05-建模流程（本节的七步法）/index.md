# 建模流程（本节的七步法）

> **学习目标**：能够解释「建模流程（本节的七步法）」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：Python 基础语法、numpy 数组与 pandas DataFrame 的基本操作、一点点高中函数与坐标系概念。
>
> **所属主题**：机器学习概述与流程 · 核心思想

## 本次只学这一点

```
① 获取数据 → ② 数据基本处理 → ③ 特征工程 → ④ 模型训练 → ⑤ 模型评估 → ⑥ 模型调优 → ⑦ 模型应用
```

| 阶段 | 主要工作 | 常见动作 | 产出 |
| --- | --- | --- | --- |
| ① 获取数据 | 明确数据源、字段含义、规模 | 读 CSV/数据库/API | DataFrame |
| ② 数据基本处理 | 缺失值、异常值、重复值、类型转换 | `dropna` / `fillna(mean)` / 去重 / one-hot | 干净的数据 |
| ③ 特征工程 | 提取、预处理、降维、选择、组合 | `StandardScaler`、`get_dummies`、`PCA`、`SelectKBest` | 特征矩阵 $X$ |
| ④ 模型训练 | 选算法、拟合参数 | `estimator.fit(X_train, y_train)` | 训练好的模型 |
| ⑤ 模型评估 | 用与训练无关的数据衡量 | MSE/RMSE/MAE、混淆矩阵、AUC、CH | 数值指标 |
| ⑥ 模型调优 | 调超参数、缓解过拟合 | `GridSearchCV`、正则化、剪枝、早停 | 最优超参数 |
| ⑦ 模型应用 | 部署、预测、监控 | `joblib.dump/load`、`predict` | 线上服务 |

**划分数据集的经验比例**：训练 : 测试 = 8 : 2 或 7 : 3。数据量大（百万级）时可以用 98 : 2；数据量很小（几百条）时必须配合交叉验证。
