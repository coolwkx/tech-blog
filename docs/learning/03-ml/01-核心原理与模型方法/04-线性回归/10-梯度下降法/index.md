# 梯度下降法

> **学习目标**：能够解释「梯度下降法」的机制或步骤，并用本节材料验证理解。
>

>
> **所属主题**：线性回归 · 算法细节

## 本次只学这一点

**思想**：把可微的损失函数想象成一座山，要找山谷最低点——**在当前位置环顾四周，朝最陡的下坡方向走一步，重复。**

**下山算法**：
1. 初始化位置 $S$（随机初始化权重）；
2. 环顾四周，若四周都比 $S$ 高，则 $S$ 是山底，结束；
3. 否则找坡度最陡的方向 $x$；
4. 沿 $x$ 向下走步长 $a$，到达 $S'$；
5. 回到第 2 步。

**梯度（gradient）**：
- 单变量函数中，梯度就是该点的导数（切线斜率）；
- 多变量函数中，梯度是由各偏导数组成的向量；
- **梯度的方向是函数值上升最快的方向**，所以下降要取负方向。

**梯度下降的更新公式**：

$$\boxed{\theta_{j} := \theta_{j} - \alpha\frac{\partial J(\theta)}{\partial \theta_j}}\qquad(\text{对所有 } j \text{ 同时更新})$$

其中 $\alpha$ 是**学习率（learning rate）/步长**，机器学习中常取 $0.001\sim0.01$。

**手算示例**：最小化 $J(\theta)=\theta^2$，$J^\prime(\theta)=2\theta$，取 $\alpha=0.4$，初值 $\theta=1$：

| 步 | 计算 | $\theta$ | $J(\theta)=\theta^2$ |
| --- | --- | --- | --- |
| 0 | 初始 | 1.0 | 1.0 |
| 1 | $1-0.4\times2\times1$ | 0.2 | 0.04 |
| 2 | $0.2-0.4\times2\times0.2$ | 0.04 | 0.0016 |
| 3 | $0.04-0.4\times0.08$ | 0.008 | $6.4\times10^{-5}$ |
| 4 | $0.008-0.4\times0.016$ | 0.0016 | $2.56\times10^{-6}$ |

**结论**：四步就基本抵达最低点 $\theta^\star=0$。这也说明：当函数是二次的且学习率合适时，梯度下降是**指数级收敛**的。

**收敛判据**：① 两次迭代的参数/损失变化小于阈值；② 达到指定迭代次数。

**学习率的选择**：

| 学习率 | 现象 |
| --- | --- |
| 太小 | 收敛极慢，迭代很多次还在半山腰 |
| 合适 | 稳定下降，几十~几百步收敛 |
| 太大 | 在最低点两侧来回震荡（错过最低点），甚至**梯度爆炸**发散 |

**银行信贷案例的标量形式**：对每个样本 $i$，$h_w(\boldsymbol{x}_i)=w_1x_{i1}+w_2x_{i2}+w_3x_{i3}+b$，损失取平方误差，则对 $w_j$ 的梯度为

$$\frac{\partial J_i}{\partial w_j} = -2\big(y_i - h_w(\boldsymbol{x}_i)\big)\,x_{ij}$$

它清楚地显示出：**误差越大，本次参数更新的步子越大**；这正是"拟合残差"的最朴素体现。
