# 正规方程 vs 梯度下降

> **学习目标**：能够解释「正规方程 vs 梯度下降」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：导数/偏导数与矩阵乘法（本文第 2.1 节会复习）、numpy 数组运算、`train_test_split` 与 `StandardScaler` 的用法（见 [01-机器学习概述与流程](../../../../../03-ml/01-基础与特征工程/01-机器学习概述与流程.md)）。
>
> **所属主题**：线性回归 · 算法细节

## 本次只学这一点

| 对比项 | 正规方程 | 梯度下降 |
| --- | --- | --- |
| 求解方式 | 一步到位（解析解） | 迭代逼近 |
| 需要选学习率 | 不需要 | **需要**，且 $\alpha$ 影响很大 |
| 需要特征缩放 | 不需要 | 强烈建议标准化 |
| 计算复杂度 | $O(d^3)$（求逆） | 每轮 $O(nd)$ |
| 特征数很大时（$d>10^4$） | 慢，求逆不可行 | **推荐** |
| 适用场景 | 中小规模、需要精确解 | 大规模、噪声数据、各类损失函数通用 |

> **一句话**：**深度学习中几乎只用梯度下降**，因为参数动辄上亿，$O(d^3)$ 的求逆完全不可行，而且很多损失函数没有解析解。
