## 本次只学这一点

| 属性 | 内容 |
| --- | --- |
| 公式 | $\sigma(z)=\dfrac{1}{1+e^{-z}}$ |
| 定义域 / 值域 | $(-\infty,+\infty)$ → $(0,1)$ |
| 单调性 | 单调递增 |
| 拐点 | $(0,\ 0.5)$，即 $z=0$ 时 $p=0.5$ |
| 对称性 | $\sigma(-z)=1-\sigma(z)$ |
| 导数 | $\sigma'(z)=\sigma(z)\big(1-\sigma(z)\big)$ |
| 用 numpy | `1/(1+np.exp(-z))` |
