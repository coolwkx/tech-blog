>

## 本次只学这一点

| 指标 | 公式 | 含义 | 何时最重要 |
| --- | --- | --- | --- |
| Accuracy 准确率 | $\frac{TP+TN}{TP+TN+FP+FN}$ | 整体预测正确的比例 | 类别均衡时 |
| Precision 精确率/查准率 | $\frac{TP}{TP+FP}$ | 预测为正的里面，真正为正的比例 | 误报代价高（垃圾邮件、推荐） |
| Recall 召回率/查全率 | $\frac{TP}{TP+FN}$ | 真正为正的里面，被找出来的比例 | 漏报代价高（癌症筛查、风控） |
| F1-score | $\frac{2\cdot P\cdot R}{P+R}$ | P 与 R 的**调和平均** | 需要 P、R 兼顾 |
| TPR（=Recall） | $\frac{TP}{TP+FN}$ | 正样本被判正的概率 | ROC 纵轴 |
| FPR | $\frac{FP}{FP+TN}$ | 负样本被判正的概率 | ROC 横轴 |
| AUC | ROC 曲线下面积 | 模型对正负样本的**排序辨别能力** | 类别不平衡、需选阈值时 |
