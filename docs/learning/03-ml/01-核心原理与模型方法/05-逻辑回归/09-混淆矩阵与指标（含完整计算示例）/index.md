## 本次只学这一点

**混淆矩阵（二分类）**：

| | 预测正例 | 预测反例 |
| --- | --- | --- |
| **真实正例** | TP（真正例） | FN（伪反例，漏报） |
| **真实反例** | FP（伪正例，误报） | TN（真反例） |

记忆口诀：**True/False 表示预测对不对，Positive/Negative 表示预测成了什么**。且恒有 $TP+FN+FP+TN=$ 总样本数。

**经典例子**：10 个样本，6 个恶性（正例）、4 个良性（反例）。

| 指标 | 模型 A：预测对 3 恶 4 良 | 模型 B：预测对 6 恶 1 良 |
| --- | --- | --- |
| TP / FN / FP / TN | 3 / 3 / 0 / 4 | 6 / 0 / 3 / 1 |
| Accuracy | $(3+4)/10=70\%$ | $(6+1)/10=70\%$ |
| Precision | $3/(3+0)=100\%$ | $6/(6+3)=67\%$ |
| Recall | $3/(3+3)=50\%$ | $6/(6+0)=100\%$ |
| F1 | $\frac{2\times 3}{2\times 3+3+0}=67\%$ | $\frac{2\times 6}{2\times 6+0+3}=80\%$ |

**两个关键洞察**：
1. **两个模型的准确率一模一样（都是 70%），但用途完全不同**——这直接证明"只看准确率不够"；
2. **Precision 与 Recall 是一对跷跷板**：降低阈值 → 更多样本被判为正 → Recall 上升、Precision 下降；升高阈值相反。F1 是二者的折中。

**F1 为什么用调和平均而不是算术平均？** 因为调和平均对"短板"惩罚更重：$P=1.0,R=0.1$ 时算术平均 0.55 看着还行，调和平均只有 $0.18$，更真实地反映了"召回太差"这个问题。
