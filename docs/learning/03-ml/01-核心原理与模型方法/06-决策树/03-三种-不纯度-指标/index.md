# 三种"不纯度"指标

> **学习目标**：能够解释「三种"不纯度"指标」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：概率与信息论中"熵"的直观含义、对数运算 $\log_2$、pandas 的缺失值处理与 `get_dummies`（见 [01-机器学习概述与流程](../../../../../03-ml/01-基础与特征工程/01-机器学习概述与流程.md)）。
>
> **所属主题**：决策树 · 核心思想

## 本次只学这一点

| 指标 | 公式 | 取值 | 直观含义 |
| --- | --- | --- | --- |
| 信息熵 Entropy | $H(D)=-\sum_{k=1}^{K}p_k\log_2 p_k$ | $[0,\log_2 K]$ | 随机变量不确定度的度量；越大越混乱 |
| 基尼值 Gini | $\operatorname{Gini}(D)=1-\sum_{k=1}^{K}p_k^2$ | $[0,1-1/K]$ | 从 $D$ 中随机抽两个样本、类别**不一致**的概率 |
| 分类误差率 | $1-\max_k p_k$ | —— | 最简单但不可导、对概率变化不敏感，**很少用作分裂准则** |

> **记忆锚点**：熵和基尼都是"纯度"的反面。**纯度高 → 熵小、基尼小**。分类要达到的目标就是让子节点尽量纯。
