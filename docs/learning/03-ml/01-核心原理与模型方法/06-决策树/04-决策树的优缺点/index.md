## 本次只学这一点

| 优点 | 缺点 |
| --- | --- |
| 逻辑直观，**可解释性极强**，可画图 | 极易过拟合（不加限制可以长到每个叶子只有 1 个样本） |
| **不需要量化与标准化**，能混合处理数值/类别特征 | 对数据扰动敏感，样本稍变树结构就大变（高方差） |
| 能自动做特征选择（靠近根的更重要） | 单棵树预测精度通常不如集成模型 |
| 对缺失值、异常值相对稳健 | 处理连续特征时倾向于做大量二分（阶梯状拟合） |
| 训练与预测都很快（$O(\text{深度})$ 预测） | 不适合高维稀疏数据（如文本 one-hot） |
