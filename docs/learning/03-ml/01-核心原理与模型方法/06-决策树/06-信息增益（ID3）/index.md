# 信息增益（ID3）

> **学习目标**：能够解释「信息增益（ID3）」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：概率与信息论中"熵"的直观含义、对数运算 $\log_2$、pandas 的缺失值处理与 `get_dummies`（见 [01-机器学习概述与流程](../../../../../03-ml/01-基础与特征工程/01-机器学习概述与流程.md)）。
>
> **所属主题**：决策树 · 算法细节

## 本次只学这一点

**定义**：特征 $A$ 对训练集 $D$ 的信息增益是集合 $D$ 的熵与"给定 $A$ 条件下 $D$ 的条件熵"之差：

$$\boxed{g(D,A) = H(D) - H(D\mid A)}$$

**条件熵**（按特征 $A$ 的每个取值 $a_i$ 划分子集 $D_i$，再对各子集的熵做样本量加权平均）：

$$H(D\mid A) = \sum_{i=1}^{n}\frac{|D_i|}{|D|}H(D_i)
= -\sum_{i=1}^{n}\frac{|D_i|}{|D|}\sum_{k=1}^{K}\frac{|D_{ik}|}{|D_i|}\log_2\frac{|D_{ik}|}{|D_i|}$$

**含义**：$g(D,A)$ 表示**由于特征 $A$ 而使得对数据 $D$ 的分类不确定性减少的程度**。增益越大，该特征的分类能力越强。

**ID3 构建流程**：
1. 计算每个特征的信息增益；
2. 用信息增益最大的特征把数据集 $D$ 拆分成子集；
3. 用该特征作为决策树的一个节点；
4. 对子集重复 1~3，直到无法继续（子集纯或特征用尽）。

#### 手算例 1（原例，6 个样本）

| 特征 a | 目标值 |
| --- | --- |
| α | A |
| α | A |
| β | B |
| α | A |
| β | B |
| α | B |

- 整体：3 个 A、3 个 B → $H(D) = -\tfrac36\log_2\tfrac36\times2 = 1.0$
- $a=\alpha$ 的子集（4 个样本：3A+1B）：$H(D_\alpha) = -\tfrac34\log_2\tfrac34-\tfrac14\log_2\tfrac14 = 0.811$
- $a=\beta$ 的子集（2 个样本：0A+2B）：$H(D_\beta) = -1\log_2 1 = 0$
- 条件熵：$H(D\mid a) = \tfrac46\times0.811 + \tfrac26\times0 = 0.541$
- **信息增益**：$g(D,a) = 1.0 - 0.541 = 0.459$

#### 手算例 2（论坛客户流失，15 条样本，5 正 / 10 负）

**基准熵**：

$$H(D) = -\frac{5}{15}\log_2\frac{5}{15}-\frac{10}{15}\log_2\frac{10}{15} = 0.9183$$

**按"性别"分裂**（假设男 8 条中 3 正 5 负、女 7 条中 2 正 5 负）：

$$H(D\mid\text{性别}) = \frac{8}{15}\Big[-\frac38\log_2\frac38-\frac58\log_2\frac58\Big] + \frac{7}{15}\Big[-\frac27\log_2\frac27-\frac57\log_2\frac57\Big] \approx 0.8880$$

$$g(D,\text{性别}) = 0.9183 - 0.8880 = 0.0303$$

**按"活跃度"分裂**（假设高活跃 6 条中 4 正 2 负、低活跃 9 条中 1 正 8 负）：

$$H(D\mid\text{活跃度}) = \frac{6}{15}\Big[-\frac46\log_2\frac46-\frac26\log_2\frac26\Big] + \frac{9}{15}\Big[-\frac19\log_2\frac19-\frac89\log_2\frac89\Big] \approx 0.4523$$

$$g(D,\text{活跃度}) = 0.9183 - 0.4523 = 0.4660$$

**结论**：$g(\text{活跃度}) \gg g(\text{性别})$，说明**活跃度对用户流失的影响远大于性别**，ID3 会先按活跃度分裂。

> 这里的"性别/活跃度"分组人数来自图示（PPT 中为图片），具体数字以表格为准；关键是掌握"总熵 − 加权条件熵"的计算套路。
