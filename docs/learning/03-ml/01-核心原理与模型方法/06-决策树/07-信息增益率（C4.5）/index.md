# 信息增益率（C4.5）

> **学习目标**：能够解释「信息增益率（C4.5）」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：概率与信息论中"熵"的直观含义、对数运算 $\log_2$、pandas 的缺失值处理与 `get_dummies`（见 [01-机器学习概述与流程](../../../../../03-ml/01-基础与特征工程/01-机器学习概述与流程.md)）。
>
> **所属主题**：决策树 · 算法细节

## 本次只学这一点

**ID3 的缺陷**：**偏向于选择取值种类多的特征**。极端情况——用"身份证号"作为特征，每个取值只对应 1 个样本，条件熵为 0，信息增益达到最大，但这棵树毫无泛化能力。

**解决**：用特征的"内在信息（固有值）"做惩罚。

$$\boxed{\text{Gain\_Ratio}(D,A) = \frac{g(D,A)}{IV(A)}},\qquad IV(A) = -\sum_{i=1}^{n}\frac{|D_i|}{|D|}\log_2\frac{|D_i|}{|D|}$$

**本质**：信息增益 ÷ 特征的内在信息，相当于给信息增益加了一个**惩罚系数**：
- 特征取值个数**多** → $IV$ 大 → 惩罚系数大 → 增益率被压低；
- 特征取值个数**少** → $IV$ 小 → 惩罚系数小。

"惩罚参数是数据集 $D$ 以特征 $A$ 作为随机变量的熵的倒数"。

#### 手算（例，同一张 6 样本表）

| 特征 | 信息增益 | 内在信息 $IV$ | 信息增益率 |
| --- | --- | --- | --- |
| **a**（2 个取值：4 个 α、2 个 β） | $1-0.5408=0.459$ | $-\tfrac46\log_2\tfrac46-\tfrac26\log_2\tfrac26 = 0.9183$ | $0.459/0.9183 = \mathbf{0.500}$ |
| **b**（6 个取值：每值 1 个样本） | $1-0 = 1.0$ | $-\tfrac16\log_2\tfrac16\times6 = 2.5850$ | $1.0/2.5850 = \mathbf{0.387}$ |

**结论**：按**信息增益**会选 b（1.0 > 0.459），按**信息增益率**则选 a（0.5 > 0.387）。这正好体现了 C4.5 对"多取值特征"的惩罚——**这也是这道题的考点**。
