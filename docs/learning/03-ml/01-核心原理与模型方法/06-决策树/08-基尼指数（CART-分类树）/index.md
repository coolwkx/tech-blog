# 基尼指数（CART 分类树）

> **学习目标**：能够解释「基尼指数（CART 分类树）」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：概率与信息论中"熵"的直观含义、对数运算 $\log_2$、pandas 的缺失值处理与 `get_dummies`（见 [01-机器学习概述与流程](../../../../../03-ml/01-基础与特征工程/01-机器学习概述与流程.md)）。
>
> **所属主题**：决策树 · 算法细节

## 本次只学这一点

$$\operatorname{Gini}(D) = 1-\sum_{k=1}^{K}p_k^2,\qquad
\boxed{\operatorname{Gini\_index}(D,A) = \sum_{i=1}^{n}\frac{|D_i|}{|D|}\operatorname{Gini}(D_i)}$$

**注意方向**：信息增益、信息增益率**越大越好**；**基尼指数越小越好**。

#### 手算例：是否拖欠贷款（10 个样本：7 个 no、3 个 yes）

**（a）按"是否有房"分裂**：

- 有房（样本 1、4、7，共 3 个，3 no / 0 yes）：$\operatorname{Gini} = 1 - (0/3)^2 - (3/3)^2 = 0$
- 无房（样本 2、3、5、6、8、9、10，共 7 个，4 no / 3 yes）：$\operatorname{Gini} = 1 - (3/7)^2 - (4/7)^2 = 0.4898$
- 加权：

$$\operatorname{Gini\_index}(D,\text{是否有房}) = \frac{3}{10}\times0 + \frac{7}{10}\times0.4898 = 0.343$$

**（b）按"婚姻状况"分裂**——对多取值特征，CART 会枚举所有二分方式：

| 二分方式 | 左子集 Gini | 右子集 Gini | 加权基尼指数 |
| --- | --- | --- | --- |
| $\{married\}\mid\{single,divorced\}$ | 0（4 个样本全 no） | $1-(\tfrac36)^2-(\tfrac36)^2=0.5$ | $\tfrac4{10}\times0+\tfrac6{10}\times0.5=\mathbf{0.300}$ |
| $\{single\}\mid\{married,divorced\}$ | 0.5 | $1-(\tfrac16)^2-(\tfrac56)^2=0.278$ | $\tfrac4{10}\times0.5+\tfrac6{10}\times0.278=0.367$ |
| $\{divorced\}\mid\{single,married\}$ | 0.5 | $1-(\tfrac28)^2-(\tfrac68)^2=0.375$ | $\tfrac2{10}\times0.5+\tfrac8{10}\times0.375=0.400$ |

取最小：**0.300**，分裂点为 $\{married\}\mid\{single,divorced\}$。

**（c）按"年收入"（连续特征）分裂**：先把数值升序排列，**取相邻两个值的均值作为候选分裂点**：65、72.5、80、87.7、92.5、97.5、110、122.5、172.5。以 65 为例：

$$\operatorname{Gini\_index}(D,65) = \frac1{10}\times0 + \frac9{10}\Big[1-\Big(\frac69\Big)^2-\Big(\frac39\Big)^2\Big] = 0.400$$

逐个算完，**最小基尼指数为 0.300（分裂点 97.5）**。

**第一轮结果对比**：

| 特征 | 最优分裂点 | 基尼指数 |
| --- | --- | --- |
| 是否有房 | 有/无 | 0.343 |
| 婚姻状况 | married / 其他 | **0.300** |
| 年收入 | 97.5 | **0.300** |

最小基尼指数并列，随机选一个（假设选婚姻状况）。**第 2 轮**：左子节点（样本 2、4、6、9）全部为 no，纯度已达最高，停止分裂；右子节点（1、3、5、7、8、10，4 no + 2 yes）纯度不足，需在该子集上重新计算各特征的基尼指数继续分裂。反复进行直到每个叶子纯度达标。
