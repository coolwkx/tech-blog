## 本次只学这一点

**集成学习（Ensemble Learning）** 是一种思想：**通过多个模型的组合形成一个精度更高的模型**，参与组合的模型称为**弱学习器（weak learner）**。训练时用训练集依次训练出这些弱学习器；预测时用它们**联合**给出结果。

生活类比：三个臭皮匠顶个诸葛亮；或者"多个专家会诊"比单个医生更可靠。
