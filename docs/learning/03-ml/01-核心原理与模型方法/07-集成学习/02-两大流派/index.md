## 本次只学这一点

| 对比维度 | **Bagging** | **Boosting** |
| --- | --- | --- |
| 数据采样 | 对数据进行**有放回采样（bootstrap）**训练 | 使用**全部样本**，根据前一轮学习结果调整**数据的重要性（权重）** |
| 投票方式 | 所有学习器**平权投票**（回归取平均） | 对学习器进行**加权投票** |
| 学习顺序 | **并行**，每个学习器没有依赖关系 | **串行**，学习有先后顺序 |
| 主要作用 | 降低**方差**（variance） | 降低**偏差**（bias） |
| 代表算法 | **随机森林** | **AdaBoost、GBDT、XGBoost、LightGBM** |
| 对噪声 | 相对稳健（投票平均掉噪声） | 对噪声较敏感（会一直关注难分的样本，包括异常点） |
| 过拟合风险 | 树越多通常越好，不易过拟合 | 树太多容易过拟合，需要早停/学习率 |

**Boosting 的生活举例**（原例）：滚球兽 → 亚古兽 → 暴龙兽 → 机械暴龙兽 → 战斗暴龙兽。**随着学习的积累从弱到强，每新加入一个弱学习器，整体能力就提升一点。**
