# 为什么"组合"能提升效果（数学直觉）

## 本次只学这一点

设 $n$ 个**相互独立**的弱学习器，单个错误率为 $p<0.5$，则多数投票的错误率随 $n$ 指数下降（二项分布尾部）。以 $p=0.3$、$n=5$ 为例，$P(\text{多数错}) = C_5^3p^3(1-p)^2+C_5^4p^4(1-p)+p^5 \approx 0.163$，远低于 0.3。

**但前提是"弱学习器之间要有差异"**。这正是随机森林要做"样本随机 + 特征随机"的根本原因：

| 随机化的两个来源 | 目的 |
| --- | --- |
| 有放回采样（bootstrap）训练集 | 让每棵树看到不同的数据子集，**降低树之间的相关性** |
| 每次分裂随机挑选 $n$ 个特征（$n<$ 总特征数） | 进一步打破树之间的相似性，尤其当少数特征非常强时 |

**两个思考题（原题）**：

| 问题 | 答案 |
| --- | --- |
| 为什么要随机抽样训练集？ | 如果不随机抽样，每棵树的训练集都一样，最终训练出的树分类结果也完全一样，投票失去意义 |
| 为什么要有放回地抽样？ | 如果**不放回**，每棵树的训练样本互不相交，每棵树都是"有偏的"（只看数据的一部分），差异过大；有放回抽样使各棵树的训练样本**既有交集也有差异**，更容易发挥投票表决效果 |
