# 提升树（Boosting Decision Tree）：拟合残差

> **学习目标**：能够解释「提升树（Boosting Decision Tree）：拟合残差」的机制或步骤，并用本节材料验证理解。

>

## 本次只学这一点

**思想**：**通过拟合残差来进行提升**。残差 = 真实值 − 预测值。

**生活例子（原例）**：预测某人的年龄为 100 岁。
1. 第 1 次预测：预测成 80 岁 → 残差 $100-80=20$
2. 第 2 次预测：把上一轮残差 20 作为目标值，预测成 16 岁 → 残差 $20-16=4$
3. 第 3 次预测：把上一轮残差 4 作为目标值，预测成 3.2 岁 → 残差 $4-3.2=0.8$

**把三次预测串起来**：$80+16+3.2 = 99.2$，非常接近 100。

> 这就是提升树最朴素的思想：**每个新学习器只负责纠正前面所有学习器"还没搞定的那部分"**。

**提升树的模型形式**：

$$f_M(x) = \sum_{m=1}^{M}T(x;\Theta_m),\qquad T(x;\Theta_{m}) \text{ 拟合残差 } r_{m,i}=y_i - f_{m-1}(x_i)$$
