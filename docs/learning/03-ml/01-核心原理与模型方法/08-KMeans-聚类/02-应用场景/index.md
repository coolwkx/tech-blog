# 应用场景

> **学习目标**：能够解释「应用场景」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：欧氏距离与标准化（见 [02-KNN算法](../../../../../03-ml/02-经典算法/02-KNN算法.md)）、`make_blobs` 造数据、pandas 与 matplotlib 基础。
>
> **所属主题**：KMeans 聚类 · 核心思想

## 本次只学这一点

| 领域 | 具体应用 |
| --- | --- |
| 用户运营 | 用户画像、广告推荐、Data Segmentation（客户分群） |
| 搜索引擎 | 流量推荐、新闻聚类与筛选排序、恶意流量识别 |
| 位置服务 | 基于位置信息的商业推送 |
| 图像与识别 | 图像分割、降维、识别 |
| 风控 | 离群点检测、信用卡异常消费 |
| 生物信息 | 发掘相同功能的基因片段 |
