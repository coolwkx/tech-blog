# 三个指标的对比与选用

> **学习目标**：能够解释「三个指标的对比与选用」的机制或步骤，并用本节材料验证理解。
>

>
> **所属主题**：KMeans 聚类 · 算法细节

## 本次只学这一点

| 维度 | SSE | SC | CH |
| --- | --- | --- | --- |
| 关注 | 簇内聚 | 簇内聚 + 簇间离 | 簇内聚 + 簇间离 + 质心个数 |
| 方向 | 越小越好 | 越大越好（$[-1,1]$） | 越大越好 |
| 能否直接选 $K$ | **不能**（$K$ 越大 SSE 越小，需配肘部法） | **能** | **能** |
| 计算成本 | 最低 | 高（需两两距离） | 中 |

**工程实践建议**：
1. 先用 **肘部法 + SC + CH 三条曲线**交叉验证，若三者都指向同一个 $K$，可信度高；
2. 再用**业务可解释性**做最后裁决；
3. 聚类前**必须标准化**，否则大量纲特征会独占欧氏距离。
