# 什么是特征工程

> **学习目标**：能够解释「什么是特征工程」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：pandas 的 `groupby`/`get_dummies`/缺失值处理、numpy 的数组拼接（`hstack`）、距离与量纲的影响（见 [02-KNN算法](../../../../../03-ml/02-经典算法/02-KNN算法.md)）。
>
> **所属主题**：特征工程 · 核心思想

## 本次只学这一点

从两个角度看"特征"：

| 视角 | 特征是什么 |
| --- | --- |
| 数据集角度 | **一列一列的数据**就是特征 |
| 模型训练角度 | **对预测结果有用的属性**才是特征 |

**特征工程的定义**：利用专业背景知识和技巧处理数据，**让机器学习算法效果最好**的过程。

> 引用的经典论断：
> "Coming up with features is difficult, time-consuming, requires expert knowledge. 'Applied machine learning' is basically feature engineering."
> 意思是：特征工程困难、耗时、需要专业知识，**应用机器学习的本质就是特征工程**。

**为什么它决定上限**：模型能学到的信息全部来自特征。如果特征里不含区分样本所必需的信息（如用"身高、体重"预测"会不会写 Python"），再强的模型也无法突破信息量的天花板；反之只要特征有判别力，简单模型也能取得好效果。
