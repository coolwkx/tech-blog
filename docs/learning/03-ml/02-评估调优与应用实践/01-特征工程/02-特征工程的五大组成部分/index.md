# 特征工程的五大组成部分

> **学习目标**：能够解释「特征工程的五大组成部分」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：pandas 的 `groupby`/`get_dummies`/缺失值处理、numpy 的数组拼接（`hstack`）、距离与量纲的影响（见 [02-KNN算法](../../../../../03-ml/02-经典算法/02-KNN算法.md)）。
>
> **所属主题**：特征工程 · 核心思想

## 本次只学这一点

| 组成部分 | 定义 | 是否改变原始数据取值 | 代表工具 |
| --- | --- | --- | --- |
| **特征提取** | 从原始数据中提取与任务相关的特征，构成特征向量 | 是（把非结构化变成结构化） | `DictVectorizer`、`CountVectorizer` |
| **特征预处理** | 把不同量纲的特征转换到同一范围，使各特征对模型影响一致 | 是（数值缩放） | `MinMaxScaler`、`StandardScaler` |
| **特征降维** | 把原始数据的维度降低 | **会丢失部分信息**，保留主要信息 | `PCA`、`TSNE` |
| **特征选择** | 从原始特征中选出一个重要子集 | **不会改变原来的数据**（只是挑列） | 相关系数、`VarianceThreshold`、`Lasso`、`feature_importances_` |
| **特征组合** | 把多个特征合并成一个特征（加法、乘法等） | 增加新列 | `PolynomialFeatures`、手工交叉 |

> **三个易混点的关键区别**：
> 1. **降维 vs 选择**：降维后的新特征**不再是原来的含义**（如 PCA 主成分），选择后的特征**仍是原来那列**；
> 2. **降维会丢信息**（要保证主要信息保留），选择只是丢弃不重要的列；
> 3. **组合是"造新特征"**，选择是"删旧特征"。
