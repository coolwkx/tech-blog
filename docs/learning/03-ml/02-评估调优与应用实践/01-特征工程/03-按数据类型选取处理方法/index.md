# 按数据类型选取处理方法

> **学习目标**：能够解释「按数据类型选取处理方法」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：pandas 的 `groupby`/`get_dummies`/缺失值处理、numpy 的数组拼接（`hstack`）、距离与量纲的影响（见 [02-KNN算法](../../../../../03-ml/02-经典算法/02-KNN算法.md)）。
>
> **所属主题**：特征工程 · 核心思想

## 本次只学这一点

| 数据类型 | 例子 | 处理方法 |
| --- | --- | --- |
| 数值型（连续） | 年龄、收入、身高 | 标准化 / 归一化 / 分箱 / 对数变换 |
| 类别型（无序） | 性别、城市、支付方式 | one-hot 编码、`pd.get_dummies`、`DictVectorizer` |
| 类别型（有序） | 学历、红酒品质等级 | 序数编码（LabelEncoder）或 one-hot |
| 文本 | 评论、新闻标题 | 分词 + `CountVectorizer` / `TfidfVectorizer` |
| 时间 | 时间戳 | 提取小时、月份、星期、是否工作日、滑窗、同比/环比 |
| 图像 | 图片 | 像素展平、颜色直方图、CNN 特征 |
