## 本次只学这一点

以示例数据 `x = [[90, 2, 10, 40], [60, 4, 15, 45], [75, 3, 13, 46]]` 为例：

| 特征列 | 原始范围 | 归一化后 | 标准化后 |
| --- | --- | --- | --- |
| 第 1 列（90/60/75） | 60~90 | 1.0 / 0.0 / 0.5 | 1.069 / −1.069 / 0.0 |
| 第 2 列（2/4/3） | 2~4 | 0.0 / 1.0 / 0.5 | −1.0 / 1.0 / 0.0 |
| 第 3 列（10/15/13） | 10~15 | 0.0 / 1.0 / 0.6 | −1.069 / 1.069 / 0.0 |
| 第 4 列（40/45/46） | 40~46 | 0.0 / 0.833 / 1.0 | −0.928 / 0.464 / 0.464 |

**观察**：归一化把所有列压到 $[0,1]$，但**列内的相对间距被 min/max 差异扭曲**（第 4 列 45 和 46 几乎靠在一起）；标准化保留了"离均值多少个标准差"的信息，因此更适合统计模型。
