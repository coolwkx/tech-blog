# 特征组合与多项式特征

> **学习目标**：能够解释「特征组合与多项式特征」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：pandas 的 `groupby`/`get_dummies`/缺失值处理、numpy 的数组拼接（`hstack`）、距离与量纲的影响（见 [02-KNN算法](../../../../../03-ml/02-经典算法/02-KNN算法.md)）。
>
> **所属主题**：特征工程 · 算法细节

## 本次只学这一点

**原理**：把多个特征通过加法、乘法合并成一个特征。对线性模型而言，**加入 $x_1x_2$、$x^2$ 可以让它拟合非线性关系**（因为线性回归的线性是关于**参数** $w$ 的，不是关于特征 $x$ 的）。

$$y = w_0 + w_1x_1 + w_2x_2 \ \longrightarrow\ y = w_0 + w_1x_1 + w_2x_2 + w_3x_1x_2 + w_4x_1^2 + w_5x_2^2$$

| 做法 | 代码 |
| --- | --- |
| 手工拼接（做法） | `X2 = np.hstack([X, X ** 2])` |
| 自动生成 | `PolynomialFeatures(degree=2, include_bias=False)` |

**代价**：$d$ 个特征生成 2 阶多项式后有 $O(d^2)$ 列，**极易过拟合**（实验中加 $x,\dots,x^{10}$ 后训练 MSE 反而更低但曲线剧烈抖动）。所以多项式扩展后**必须配正则化**（L1/L2）或降维。
