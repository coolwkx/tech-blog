## 本次只学这一点

**目标**：从原始特征中选出对任务最有用的子集，**不改变数据本身的取值**。

| 方法族 | 具体做法 | 特点 |
| --- | --- | --- |
| **过滤式（Filter）** | 方差过滤 `VarianceThreshold`、相关系数、卡方检验、互信息 | 与模型无关、计算快；可能漏掉"单独弱但组合强"的特征 |
| **包裹式（Wrapper）** | 递归特征消除 RFE | 效果常更好，但计算量大（要反复训练模型） |
| **嵌入式（Embedded）** | L1 正则化（Lasso）、树模型的 `feature_importances_` | 训练的同时完成选择，效率高，**最常用** |

**（1）L1 正则化做特征选择**：

> 作用：用来进行特征选择，主要原因在于 **L1 正则化会使得较多的参数为 0，从而产生稀疏解**，可以将 0 对应的特征遗弃，进而用来选择特征。一定程度上 L1 正则也可以防止模型过拟合。

几何直觉：L1 的约束域 $|w_1|+|w_2|\le c$ 是**菱形**，最优解极易落在坐标轴上的**顶点**，于是某些 $w_j$ 恰好为 0。对比 L2 的约束域是**圆**，切点一般不在坐标轴上，所以只做平滑收缩、不产生精确 0。

**（2）相关系数过滤**：计算每个特征与标签（或特征之间）的相关系数 $\rho$，剔除相关性极低的特征；特征之间相关性过高（如 $|\rho|>0.9$）则考虑删掉一个，避免共线。

**（3）树模型的特征重要性**：

```python
print(dict(zip(X.columns, estimator.feature_importances_)))
```

| 特点 | 说明 |
| --- | --- |
| 依据 | 该特征在所有分裂中带来的**不纯度下降（加权）之和** |
| 优点 | 自动、能捕捉非线性关系 |
| 陷阱 | 偏向**高基数**特征（取值多的特征有更多分裂机会）；对相关特征的重要性会"分摊" |
