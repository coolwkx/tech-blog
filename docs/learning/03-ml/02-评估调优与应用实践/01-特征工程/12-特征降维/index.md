# 特征降维

> **学习目标**：能够解释「特征降维」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：pandas 的 `groupby`/`get_dummies`/缺失值处理、numpy 的数组拼接（`hstack`）、距离与量纲的影响（见 [02-KNN算法](../../../../../03-ml/02-经典算法/02-KNN算法.md)）。
>
> **所属主题**：特征工程 · 算法细节

## 本次只学这一点

**目标**：把原始数据的维度降低。**会丢失部分信息**，所以**要保证数据的主要信息保留下来**；降维后的新特征**不再是原来的业务含义**。

| 方法 | 原理 | 特点 |
| --- | --- | --- |
| **PCA（主成分分析）** | 找方差最大的正交方向，把数据投影上去 | 线性、无监督、需标准化 |
| TSNE | 保持局部邻域结构的非线性降维 | **只适合可视化**（不保留全局距离，且慢） |
| 自编码器 | 神经网络学习压缩表示 | 非线性、需要训练 |

> **说明**：本"特征降维"只到**概念层面**（定义、会丢信息、保留主要信息），**没有展开 PCA 的数学推导与 API**。下面的 PCA 代码属于按需补充的工程实践，标注为扩展内容。

**PCA 的基本直觉**（扩展）：对标准化后的数据 $\boldsymbol{X}$（$n\times d$），计算协方差矩阵 $\boldsymbol{C}=\frac1n\boldsymbol{X}^\top\boldsymbol{X}$，求其特征值分解；取**最大的 $k$ 个特征值对应的特征向量**组成投影矩阵 $\boldsymbol{W}$（$d\times k$），新特征即 $\boldsymbol{Z}=\boldsymbol{X}\boldsymbol{W}$。保留的方差比例 = $\dfrac{\sum_{i=1}^{k}\lambda_i}{\sum_{i=1}^{d}\lambda_i}$。

**为什么 PCA 前必须标准化**：PCA 追求方差最大方向，如果不标准化，量纲大的特征方差天然大，会独占主成分，导致降维结果只反映那一个特征。
