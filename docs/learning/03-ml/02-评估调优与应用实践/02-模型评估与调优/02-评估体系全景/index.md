# 评估体系全景

> **学习目标**：能够解释「评估体系全景」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：线性回归的 MSE/RMSE/MAE（见 [03-线性回归](../../../../../03-ml/02-经典算法/03-线性回归.md)）、混淆矩阵与 ROC/AUC（见 [04-逻辑回归](../../../../../03-ml/02-经典算法/04-逻辑回归.md)）、KNN 的交叉验证与网格搜索（见 [02-KNN算法](../../../../../03-ml/02-经典算法/02-KNN算法.md)）。
>
> **所属主题**：模型评估与调优 · 核心思想

## 本次只学这一点

| 任务类型 | 常用指标 | 方向 | 关键前提 |
| --- | --- | --- | --- |
| **回归** | MAE、MSE、RMSE、$R^2$ | MAE/MSE/RMSE **越小越好**；$R^2$ 越大越好 | 量纲要与 $y$ 可比时用 MAE/RMSE |
| **二分类** | 混淆矩阵、Accuracy、Precision、Recall、F1、ROC-AUC | Accuracy/P/R/F1/AUC **越大越好** | 不平衡数据看 F1/AUC，不看 Accuracy |
| **多分类** | 宏平均（macro）、加权平均（weighted）、micro-F1 | 越大越好 | 类别不平衡时用 weighted，均衡时看 macro |
| **聚类** | SSE、轮廓系数 SC、CH 指数、肘部法 | SSE **越小**；SC/CH **越大** | 均不需要标签 |
