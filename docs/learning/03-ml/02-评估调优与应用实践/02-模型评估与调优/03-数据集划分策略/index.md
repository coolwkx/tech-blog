# 数据集划分策略

> **学习目标**：能够解释「数据集划分策略」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：线性回归的 MSE/RMSE/MAE（见 [03-线性回归](../../../../../03-ml/02-经典算法/03-线性回归.md)）、混淆矩阵与 ROC/AUC（见 [04-逻辑回归](../../../../../03-ml/02-经典算法/04-逻辑回归.md)）、KNN 的交叉验证与网格搜索（见 [02-KNN算法](../../../../../03-ml/02-经典算法/02-KNN算法.md)）。
>
> **所属主题**：模型评估与调优 · 核心思想

## 本次只学这一点

| 策略 | 做法 | 适用 |
| --- | --- | --- |
| 留出法（hold-out） | 训练 : 测试 = 8:2 或 7:3 | 数据量大（十万级以上） |
| 训练 / 验证 / 测试 | 6:2:2 或 8:1:1 | 需要调超参数时 |
| **K 折交叉验证** | 训练集切 $K$ 份，轮流用 1 份做验证 | 数据量小（几百~几千） |
| **分层 K 折（StratifiedKFold）** | 折分时保持各类别比例 | **类别不平衡**时必用 |
| 留一法（LOO） | 每次留 1 个样本做验证 | 数据极少，代价是训练 $n$ 次 |
| 时间序列切分 | 按时间先后切，**不能随机打乱** | 时序预测（见 [10-数据挖掘案例-电力负荷预测](../../../../../03-ml/06-案例与面试/10-数据挖掘案例-电力负荷预测.md)） |

> **最重要的一条纪律**：**测试集只能用来做最终评估，绝不能参与调参**。一旦你根据测试集分数反复调整，测试集就变成了验证集，分数会乐观偏置。
