# 回归评估指标

> **学习目标**：能够解释「回归评估指标」的机制或步骤，并用本节材料验证理解。

>
> **所属主题**：模型评估与调优 · 算法细节

## 本次只学这一点

设真实值为 $y_i$、预测值为 $\hat y_i$，样本数 $n$。

**（1）MAE（Mean Absolute Error，平均绝对误差）**

$$\text{MAE} = \frac{1}{n}\sum_{i=1}^{n}\lvert y_i - \hat y_i\rvert$$

- 量纲与 $y$ **相同**，最直观；
- 对**大小误差一视同仁**，对异常值**不敏感**；
- 对应**中位数**意义下的最优拟合。

**（2）MSE（Mean Squared Error，均方误差）**

$$\text{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat y_i)^2$$

- 量纲是 $y$ 的**平方**，不直观；
- 处处可导、是凸函数，**适合作训练损失**（配合正规方程有解析解）。

**（3）RMSE（Root Mean Squared Error，均方根误差）**

$$\text{RMSE} = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat y_i)^2}$$

- 量纲与 $y$ **相同**，但与 MSE 同源，**对大误差极其敏感**。

**（4）$R^2$（决定系数）**

$$R^2 = 1 - \frac{\sum(y_i-\hat y_i)^2}{\sum(y_i-\bar y)^2}$$

- 表示"模型解释了目标变量多少比例的方差"，$R^2=1$ 完美，$R^2=0$ 等于只用均值预测，$R^2<0$ 还不如均值。

#### MAE vs RMSE 的数学关系（为什么 RMSE ≥ MAE）

对任意实数序列，**均方根 ≥ 算术平均**（柯西-施瓦茨 / 幂平均不等式）：

$$\sqrt{\frac{1}{n}\sum z_i^2}\ \ge\ \frac{1}{n}\sum|z_i|\quad\Longleftrightarrow\quad \text{RMSE}\ge\text{MAE}$$

**等号成立条件**：所有 $|z_i|$ 相等。

**数值例**：两个误差 1 和 3

$$\text{MAE} = \frac{1+3}{2}=2,\qquad \text{RMSE} = \sqrt{\frac{1^2+3^2}{2}}=\sqrt{5}\approx2.236$$

**结论**：
- RMSE 公式里有**平方项**，大误差被平方后放大，所以**大多数情况下 RMSE > MAE**；
- **RMSE 会放大预测误差较大样本的影响，MAE 只给出平均误差**；
- 误差分布越不均匀（有极端大误差），RMSE 与 MAE 的差距就越大。

**第二个例子**：在 $y=2x+5$ 上加一项波动 $\sin(x)e^{x/20}$ 后，所有指标都变大，**RMSE 几乎是 MAE 的两倍**，正是因为它对误差大的点敏感。

#### 一个重要的反问（原题）

> **"一直按 RMSE 指标训练模型，如果 RMSE 降得非常低，说明什么？"**
> 说明模型**对异常点（噪声）也拟合得非常好**——这正是**过拟合**的信号。所以**评价指标要综合看**。

| 场景 | 更该看 |
| --- | --- |
| 数据含少量偏差很大的异常点 | **MAE**（用 RMSE 可能会选出过拟合的模型） |
| 想强调"最坏情况"、想要平滑梯度 | **RMSE / MSE** |
| 两个模型的数据量不同 | **不适合直接比较 RMSE** |
