## 本次只学这一点

**混淆矩阵（二分类）**：

| | 预测正例 | 预测反例 |
| --- | --- | --- |
| **真实正例** | TP（真正例） | FN（伪反例，漏报） |
| **真实反例** | FP（伪正例，误报） | TN（真反例） |

$$\text{Accuracy}=\frac{TP+TN}{TP+TN+FP+FN},\quad
\text{Precision}=\frac{TP}{TP+FP}$$

$$\text{Recall}=\frac{TP}{TP+FN},\quad
F_1 = \frac{2\cdot P\cdot R}{P+R},\quad
\text{TPR}=\text{Recall},\quad \text{FPR}=\frac{FP}{FP+TN}$$

**经典对比（6 恶性 + 4 良性）**：

| 指标 | 模型 A（对 3 恶 4 良） | 模型 B（对 6 恶 1 良） |
| --- | --- | --- |
| TP / FN / FP / TN | 3 / 3 / 0 / 4 | 6 / 0 / 3 / 1 |
| Accuracy | 70% | 70% |
| Precision | 100% | 67% |
| Recall | 50% | 100% |
| F1 | 67% | 80% |

**两个模型准确率完全相同，但适用场景完全不同**：医疗筛查选 B（不能漏诊），垃圾邮件过滤选 A（不能误杀）。

**多分类的两种平均方式（ API 说明）**：

| 平均方式 | 计算 | 适用 |
| --- | --- | --- |
| `macro avg`（宏平均） | 各类别指标**直接平均**，不考虑样本数权重 | **数据集比较平衡**时 |
| `weighted avg`（加权平均） | 按各类别**样本数加权**平均 | **数据集不平衡**时 |

**AUC 速查**：$[0,1]$，$1$ 完美，$0.5$ 随机猜测，$<0.5$ 说明方向反了。AUC 只依赖**排序**，与阈值和类别比例无关，因此最适合不平衡数据；但它对正负样本的**绝对概率校准**不敏感。
