# 交叉验证（Cross Validation）

> **学习目标**：能够解释「交叉验证（Cross Validation）」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：线性回归的 MSE/RMSE/MAE（见 [03-线性回归](../../../../../03-ml/02-经典算法/03-线性回归.md)）、混淆矩阵与 ROC/AUC（见 [04-逻辑回归](../../../../../03-ml/02-经典算法/04-逻辑回归.md)）、KNN 的交叉验证与网格搜索（见 [02-KNN算法](../../../../../03-ml/02-经典算法/02-KNN算法.md)）。
>
> **所属主题**：模型评估与调优 · 算法细节

## 本次只学这一点

**做法**：把**训练集**切成 $n$ 份（$n$ 即折数，常用 5 或 10），每次拿其中 1 份作验证集、其余 $n-1$ 份作训练集，重复 $n$ 次。

以 $n=5$ 为例：

| 轮次 | 训练用 | 验证用 |
| --- | --- | --- |
| 1 | 第 2,3,4,5 份 | 第 1 份 |
| 2 | 第 1,3,4,5 份 | 第 2 份 |
| 3 | 第 1,2,4,5 份 | 第 3 份 |
| 4 | 第 1,2,3,5 份 | 第 4 份 |
| 5 | 第 1,2,3,4 份 | 第 5 份 |

**最终得分 = 5 次验证得分的平均值。**

**描述的完整流程**：
1. 把数据集划分为 `cv=10` 份；
2. 第一次：第一份做验证集，其他做训练；
3. 第二次：第二份做验证集，其他做训练；
4. ……以此类推，总共训练 10 次、评估 10 次；
5. 取 10 次评估的**平均值**作为该超参数组合的交叉验证得分；
6. **若 $k=5$ 模型得分最好，再使用「全部训练集（训练+验证）」对 $k=5$ 的模型重新训练一遍**，最后用测试集评估。

**为什么需要交叉验证**：

| 好处 | 说明 |
| --- | --- |
| 每个样本都参与过验证 | 评估更充分，不浪费数据 |
| 得分更稳定 | 单次留出法的评估方差大，CV 取平均降低了随机性 |
| 能估计模型稳定性 | 各折得分的标准差本身就是"稳不稳"的度量 |

**常见的 CV 变体**：

| 类 | 用途 |
| --- | --- |
| `KFold(n_splits, shuffle)` | 普通 K 折 |
| `StratifiedKFold(n_splits, shuffle)` | **分层** K 折，保持各类别比例（分类/不平衡数据必用） |
| `LeaveOneOut` | 留一法 |
| `TimeSeriesSplit(n_splits)` | 时序数据，**只用过去预测未来**，禁止打乱 |
| `cross_val_score(estimator, X, y, cv)` | 快速得到 CV 得分数组 |
