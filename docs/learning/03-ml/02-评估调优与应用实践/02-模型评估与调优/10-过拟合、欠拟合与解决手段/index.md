# 过拟合、欠拟合与解决手段

> **学习目标**：能够解释「过拟合、欠拟合与解决手段」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：线性回归的 MSE/RMSE/MAE（见 [03-线性回归](../../../../../03-ml/02-经典算法/03-线性回归.md)）、混淆矩阵与 ROC/AUC（见 [04-逻辑回归](../../../../../03-ml/02-经典算法/04-逻辑回归.md)）、KNN 的交叉验证与网格搜索（见 [02-KNN算法](../../../../../03-ml/02-经典算法/02-KNN算法.md)）。
>
> **所属主题**：模型评估与调优 · 算法细节

## 本次只学这一点

**概念**：

| 状态 | 训练集 | 测试集 | 本质 |
| --- | --- | --- | --- |
| 欠拟合 | 差 | 差 | 偏差大，模型过于简单 |
| 良好 | 好 | 好 | 偏差方差平衡 |
| 过拟合 | 好 | 差 | 方差大，模型过于复杂/数据太脏/数据太少 |

**偏差-方差分解**（完整推导见 [01-机器学习概述与流程](../../../../../03-ml/01-基础与特征工程/01-机器学习概述与流程.md)）：

$$\mathbb{E}\big[(y-\hat f)^2\big] = \text{Bias}^2[\hat f] + \text{Var}[\hat f] + \sigma^2$$

**诊断表**：

| 现象 | 训练误差 | 验证误差 | 二者差距 | 诊断 | 处方 |
| --- | --- | --- | --- | --- | --- |
| A | 高 | 高（≈训练） | 小 | 欠拟合 | 加特征、加复杂度、减小正则化 |
| B | 低 | 高 | **大** | 过拟合 | 加数据、正则化、降复杂度、剪枝、早停 |
| C | 低 | 低 | 小 | 理想 | 可以上线 |

**欠拟合的解决办法**（从数据、模型、算法三个角度）：

| 手段 | 说明 |
| --- | --- |
| 添加其他特征项 | "组合"、"泛化"、"相关性"三类特征是特征添加的重要手段 |
| 添加多项式特征项 | 把线性模型通过二次/三次项变强（如 $X\to[X, X^2]$） |
| 更换更强的模型 | 线性回归 → 决策树 → 集成模型 |
| 减小正则化力度 | $\alpha\downarrow$ / $C\uparrow$ |
| 减少早停的严格程度 | 允许训练更久 |

**过拟合的解决办法**：

| 手段 | 具体做法 | 代表参数 |
| --- | --- | --- |
| 重新清洗数据 | 处理异常点、数据不纯的地方 | —— |
| 增大训练数据量 | 增加数据量会缓解"训练得太过了" | —— |
| **正则化** | L1（Lasso）/ L2（Ridge）/ Dropout | `alpha`、`C`、`penalty` |
| 减少特征维度 | 防维数灾难；特征多、样本少时学习不充分 | PCA、特征选择 |
| 降低模型复杂度 | 决策树剪枝、限制深度、限制叶子样本数 | `max_depth`、`min_samples_leaf` |
| 早停（early stopping） | 验证集误差不再下降就停 | `early_stopping_rounds`（XGBoost） |
| 集成 | Bagging 天然降方差 | 随机森林 |

**早停的定义（原题）**：`Early stopping` 是当模型训练到某个**固定的验证错误率阈值**（或验证误差不再改善）时，及时停止模型训练。
