## 本次只学这一点

**时间序列预测**：根据**历史时间序列数据**来预测未来值的方法。

任务听起来简单，但引用了几句话来提醒难度："预测非常困难，特别是关于未来。—— 尼尔斯·波尔"；"我可以算准天体的运行轨迹，但算不清人性的复杂。—— 牛顿"。

**关键洞察**：不论是传统机器学习还是深度学习，**解决方案主要是把时序数据处理成二维的结构化数据集**，再训练模型。所以这个项目的核心工作量不在模型，而在**特征工程**。
