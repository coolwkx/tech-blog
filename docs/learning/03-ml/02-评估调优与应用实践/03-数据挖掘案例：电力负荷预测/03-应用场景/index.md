# 应用场景

> **学习目标**：能够解释「应用场景」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：pandas 时间序列操作（`str` 切片、`shift`、`to_timedelta`）、特征工程五大组成（见 [09-特征工程](../../../../../03-ml/01-基础与特征工程/09-特征工程.md)）、XGBoost 与网格搜索（见 [06-集成学习](../../../../../03-ml/04-集成与无监督/06-集成学习.md)、[08-模型评估与调优](../../../../../03-ml/03-评估与调优/08-模型评估与调优.md)）。
>
> **所属主题**：数据挖掘案例：电力负荷预测 · 核心思想

## 本次只学这一点

| 领域 | 具体场景 |
| --- | --- |
| 金融 | 股票价格预测、汇率预测、利率预测；企业资金流量预测、金融机构资金流动性预测；GDP 预测、CPI 预测 |
| 交通 | 交通流量预测、行驶速度预测、交通运行指数预测 |
| 能源 | **电力负荷预测**、风力/光伏发电功率预测、工业/居民能源消费预测、电力市场价格预测、能源商品交易量预测 |
| 环境 | 空气质量（PM2.5、PM10、二氧化硫、氮氧化物）预测、气象（气温、气压、风速、风向、湿度）预测；水质变化、河流水文（流量、水位、流速）预测 |

## 验证理解

- 合上正文，用自己的话解释本知识点解决的问题及适用边界。
- 若本节含代码、公式或流程，先预测结果，再运行、推导或逐步追踪；项目片段需要沿用原文的依赖与数据。
- 如果缺少变量、术语或完整代码，请查阅[综合原文](../../../../../03-ml/06-案例与面试/10-数据挖掘案例-电力负荷预测.md)；代码片段不等同于独立可运行项目。
