## 本次只学这一点

| 类别 | 代表方法 | 特点 |
| --- | --- | --- |
| **基于统计学的经典时序算法** | 统计朴素法、简单平均法、移动平均法、简单指数平滑法、Holt 线性趋势法、AR、MA、**ARIMA** | 需要**平稳性检验**，模型本身有平稳性与白噪声假设，**存在局限性，准确性通常低于机器学习模型** |
| **传统机器学习算法** | 线性回归、决策树、随机森林、**XGBoost**、LightGBM、SVM 等所有回归模型 | 核心是把时序处理成二维结构化数据集；工程落地最常用 |
| **深度学习算法** | RNN 类（LSTM、GRU）、基于大模型的 iTransformer | 通常使用编解码结构（seq2seq）；适合长序列、大数据量 |

**统计学方法速览（了解即可）**：

| 方法 | 预测值 = | 一句话说明 |
| --- | --- | --- |
| 统计朴素法 | 昨天的值 | 今天等于明天，适用于短期稳定序列 |
| 简单平均法 | 历史上**所有**值的平均 | 适用于"小幅波动但均值稳定" |
| 移动平均法 | 最近**一个时间窗口**内的平均 | 适用于有明显升降趋势、不能全用历史 |
| 简单指数平滑法 | 历史值的**指数加权**平均 | 近期权重更大，远期权重指数下降 |
| Holt 线性趋势法 | 水平方程 $L_t$ + 趋势方程 $B_t$ | 显式建模线性增长/下降趋势 |
| AR 自回归 | 过去值的线性组合 | 假设当前值可由自身过去值线性表示 |
| MA 移动平均（模型） | 均值 + 白噪声项 | 假设当前值可由**过去的白噪声（误差）**线性表示 |
| ARIMA$(p,d,q)$ | 自回归 + 差分 + 移动平均 | $p$ 自回归项数、$d$ 差分阶数、$q$ 滑动平均项数 |
