# 需求分析与技术选型

> **学习目标**：能够解释「需求分析与技术选型」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：pandas 时间序列操作（`str` 切片、`shift`、`to_timedelta`）、特征工程五大组成（见 [09-特征工程](../../../../../03-ml/01-基础与特征工程/09-特征工程.md)）、XGBoost 与网格搜索（见 [06-集成学习](../../../../../03-ml/04-集成与无监督/06-集成学习.md)、[08-模型评估与调优](../../../../../03-ml/03-评估与调优/08-模型评估与调优.md)）。
>
> **所属主题**：数据挖掘案例：电力负荷预测 · 算法细节

## 本次只学这一点

| 项目 | 内容 |
| --- | --- |
| **业务需求** | 根据某电力企业的历史负荷数据，预测**下一小时**的电力负荷 |
| **功能需求** | 基于历史电力负荷数据，尽可能充分挖掘特征，对未来下一个时间步（1 小时）的负荷进行预测 |
| **数据源** | 包含 `time`（时间）与 `power_load`（电力负荷）两个字段的历史电力负荷数据 |
| **技术栈** | pandas、matplotlib、sklearn、xgboost |
| **实现方法** | 将**时序特征**与**时间特征**整合成特征矩阵，把待预测指标作为目标值，处理成二维结构化数据集，训练机器学习模型预测 |
| **任务类型** | 多变量单步 |

**为什么选 XGBoost**：它是 GBDT 的改进版（目标函数含正则化、二阶泰勒展开），在表格型数据上表现强悍、训练快、支持网格搜索调参，是工业时序预测的常用首选。
