## 本次只学这一点

对 $L=(wx+b-y)^2$，前向执行展开成：

```text
 x w b y
 \ | | |
 [ * ] <--------+ | 前向 1: t1 = w * x
 \ | |
 [ + ] <---+ | 前向 2: t2 = t1 + b
 \ |
 [ - ] <-------+ 前向 3: t3 = t2 - y
 \
 [ ** 2 ] 前向 4: L = t3 ** 2
 \
 ( L )
 反向：从根出发按「逆拓扑序」倒着走，每步入账 = 上游梯度 × 局部导数
 L_bar = 1
 t3_bar += L_bar * 2 * t3 t2_bar += t3_bar * 1
 y_bar += t3_bar * (-1) t1_bar += t2_bar * 1
 b_bar += t2_bar * 1 w_bar += t1_bar * x
 x_bar += t1_bar * w
 要点：1) 节点收到的是所有下游路径之和 → 必须用 +=
 2) 等所有下游写完才能继续往上游传 → 必须逆拓扑序
```
