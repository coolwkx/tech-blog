## 本次只学这一点

| 分析方法 | 看什么 | 得出的决策 |
|----------|--------|------------|
| 标签数量分布 | 各类别样本数是否接近 1:1 | 若严重不均衡 → 数据增强 / 删减 / 换评估指标 |
| 句子长度分布 | 长度的均值、方差与分位数 | 取 `mean + 2*std` 或 95 分位数作为 `max_len` |
| 词频统计与词云 | 高频词里有没有脏数据 | 人工审核清洗，或补充停用词 |
