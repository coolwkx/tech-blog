# 为什么主流方案放弃了词级分词

> **学习目标**：能够解释「为什么主流方案放弃了词级分词」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：Python 字符串与 `re` 模块；正则表达式；神经网络需要整数 id（embedding 查表）；Transformer 的 `attention_mask` 概念。
>
> **所属主题**：文本预处理与分词全流程 · 核心思想

## 本次只学这一点

1. **OOV 无解**：开放词表永远装不下所有词；子词把未见词拆成已知片段（`un` + `happy` + `ness`），至少保留部分语义。
2. **词表大小与覆盖率解耦**：子词用 3 万 ~ 20 万 token 就能覆盖几乎任意文本，且与语言数量无关。
3. **形态学友好**：`play / plays / played / playing` 共享 `play`，参数共享，长尾也能学到。
4. **多语言共享一套词表**：mBERT / XLM-R 覆盖 100+ 语言，靠的就是子词片段。
5. **免去语言学预处理**：不用词典、不用分词标准、不依赖空格，中日泰文一视同仁 —— 这是 SentencePiece 的核心卖点。
6. **效率折中**：相比字符级，子词把序列缩短 2~3 倍，注意力 O(n²) 与推理成本显著下降。
