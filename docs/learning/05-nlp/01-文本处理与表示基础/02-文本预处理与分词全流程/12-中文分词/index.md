## 本次只学这一点

中文没有空格，且**分词标准不唯一**：`研究生物` 可以是 `研究/生物` 也可以是 `研究生/物`，`南京市长江大桥`、`乒乓球拍卖完了` 都是经典歧义。所以中文分词本质是一个**序列标注 / 词图寻优**问题。

```python
import jieba
import jieba.posseg as pseg

text = "我来到北京清华大学"
print("精确模式 :", list(jieba.cut(text))) # 默认，适合大多数下游任务
print("全模式 :", list(jieba.cut(text, cut_all=True))) # 所有可能词，有冗余，适合特征提取
print("搜索引擎模式:", list(jieba.cut_for_search(text))) # 长词再切细，提高召回，适合检索
jieba.add_word("杭研大厦") # 自定义词典：领域新词必须加，否则必被切错
print("加词典后:", list(jieba.cut("他来到了网易杭研大厦")))
print("词性标注:", [(w, flag) for w, flag in pseg.cut("深度学习模型部署")])
```

jieba 官方 README 的对照输出：`精确模式` = 我/ 来到/ 北京/ 清华大学；`全模式` = 我/ 来到/ 北京/ 清华/ 清华大学/ 华大/ 大学；`搜索引擎模式` = 我/ 来到/ 北京/ 清华/ 华大/ 大学/ 清华大学。

**jieba 的内部思路**：用前缀词典构建句子的 **DAG（有向无环图）**，枚举所有可能成词的切分；再用**动态规划**找「词频概率乘积」最大的路径，处理已知词与歧义；对 DAG 里未登录的单字片段，用 **HMM**（状态集 `B/M/E/S`，即 Begin/Middle/End/Single）跑 **Viterbi** 解码，处理新词。

**CRF 路线**：把分词、词性、NER 统一成序列标注，用线性链 CRF 建模标签转移（`B` 后不能直接接 `S` 这类约束天然被建模），配合特征模板做全局最优解码；深度时代则用 **BiLSTM-CRF / BERT-CRF**，CRF 层负责保证标签序列合法。

**中文为什么也需要子词分词**：词典方案永远有未登录词（网络新词、专有名词、中英混排），而 subword 天然兜底；分词错误会**传播**到所有下游任务，而子词切分不需要语言学正确，只需统计上高效；多语言模型想共用一套词表，就必须放弃「按中文词典切词」；实践中 `bert-base-chinese` 直接按字切效果已经不差，说明中文 token 粒度不一定要到「词」。
