# jieba 的三种模式

> **学习目标**：能够解释「jieba 的三种模式」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：第 01 篇的文本预处理流水线、序列标注的基本概念、Python 正则与字典操作。
>
> **所属主题**：中文分词与子词分词 · 核心概念

## 本次只学这一点

jieba 的三种模式目标函数不同，输出粒度也不同：

| 模式 | API | 目标 | 粒度 | 典型用途 |
|------|-----|------|------|----------|
| 精确模式 | `jieba.lcut(s)` | 最精确地切开，无冗余 | 中 | 文本分析、分类、向量化（默认推荐） |
| 全模式 | `jieba.lcut(s, cut_all=True)` | 扫描出所有可能成词 | 细（含冗余） | 召回优先，后续用规则再筛 |
| 搜索引擎模式 | `jieba.lcut_for_search(s)` | 精确模式基础上对长词再切 | 中 + 细 | 搜索索引，提高长词的部分匹配召回 |

对同一句话「教育是一家上市公司，旗下有品牌」：

| 模式 | 输出（节选） | 观察 |
|------|--------------|------|
| 精确 | / 教育 / 是 / 一家 / 上市公司 / ，/ 旗下 / 有 / / 程序员 / 品牌 | 「上市公司」保留为长词 |
| 全模式 | 传 / 智 / 教育 / 是 / 一家 / 上市 / 上市公司 / 公司 / 旗下 / 下有 / / 程序 / 程序员 / 品牌 | 长词被拆开且与整体同时出现，标点也成词 |
| 搜索 | / 教育 / 是 / 一家 / 上市 / 公司 / 上市公司 / 旗下 / 有 / / 程序 / 程序员 / 品牌 | 在精确结果上补充子词，无冗余标点 |

一个常被忽略的能力：jieba 支持**中文繁体**分词，不需要额外转换（如「煩惱即是菩提，我暫且不提」→ 煩惱 / 即 / 是 / 菩提 / ，/ 我 / 暫且 / 不 / 提）。
