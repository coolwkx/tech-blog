>
> **所属主题**：中文分词与子词分词 · 核心概念

## 本次只学这一点

专有名词是分词错误的重灾区。jieba 允许加载自定义词典，格式为：

```
词语 词频 词性
```

词频与词性都可省略。加载后 jieba 会优先考虑词典中的词。工程上有三种用法：

| 方式 | 代码 | 生效范围 |
|------|------|----------|
| 加载词典文件 | `jieba.load_userdict("userdict.txt")` | 全局，适合领域词表 |
| 动态加一个词 | `jieba.add_word("自然语言处理")` | 运行期临时补充 |
| 动态删一个词 | `jieba.del_word("的的")` | 去掉误切出来的词 |
