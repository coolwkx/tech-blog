# 分词 = 序列标注

> **学习目标**：能够解释「分词 = 序列标注」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：第 01 篇的文本预处理流水线、序列标注的基本概念、Python 正则与字典操作。
>
> **所属主题**：中文分词与子词分词 · 核心概念

## 本次只学这一点

把分词、词性标注（POS）、命名实体识别（NER）统一到「给每个 token 打标签」的框架下，就能复用同一套模型（见第 06 篇）：

| 任务 | 输入 | 输出标签 | 标签体系 |
|------|------|----------|----------|
| 分词 | 字序列 | 每个字是否词的边界 | B / M / E / S |
| 词性标注 | 词序列 | 每个词的词性 | n / v / a / r … |
| NER | 词或字序列 | 每个 token 的实体位置与类型 | B-PER / I-PER / O / B-LOC … |

B/M/E/S 含义：B = 词首（Begin）、M = 词中（Middle）、E = 词尾（End）、S = 单字成词（Single）。例如「我喜欢自然语言处理」的字级标签为：

```
我(B) 喜(B) 欢(E) 自(B) 然(M) 语(M) 言(M) 处(M) 理(E)
```

解码后得到「我 / 喜欢 / 自然语言处理」。**分词在数学上等价于序列标注**——这是把分词接入 BiLSTM-CRF 的关键洞察。
