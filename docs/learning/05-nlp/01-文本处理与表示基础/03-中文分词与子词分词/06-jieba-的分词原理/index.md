# jieba 的分词原理

## 本次只学这一点

jieba 走的是「词典 + 统计」的混合路线：

1. **构建前缀词典**（DAG）：基于词典把所有可能的成词路径建成有向无环图。
2. **动态规划求最大概率路径**：对 DAG 上每条路径计算 $\prod P(w_i)$，取概率最大的路径。词的概率来自语料统计，未登录词则回退到 HMM 识别。
3. **HMM 处理未登录词**：对 DAG 中无法切分的连续单字串，用 HMM（状态为 B/M/E/S）做维特比解码。

这解释了为什么自定义词典有效——它直接改变了 DAG 的边和路径概率。
