# Unigram LM 的删减思路

> **学习目标**：能够解释「Unigram LM 的删减思路」的机制或步骤，并用本节材料验证理解。

>

## 本次只学这一点

Unigram 走**自顶向下**路线，与 BPE 方向相反：

1. 初始化一个**过大**的候选子词表（例如所有字 + 高频 n-gram）。
2. 用当前词表，对语料中每个词计算所有可能切分的概率，取概率最大的切分（用维特比）。
3. 计算每个子词的**损失贡献**：假设把它从词表中删掉，语料总似然会下降多少。
4. 删掉损失贡献最小（最没用）的一批子词（例如删 10%–20%）。
5. 重复 2–4，直到词表降到目标大小。

最终保留的是一个带概率的子词表，编码时用维特比找**概率最大**的切分，而不是按顺序贪心合并。这类「子词有概率、切分可搜索」的特性，是 SentencePiece 的基础。
