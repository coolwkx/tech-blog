# 中文场景下的选型建议

> **学习目标**：能够解释「中文场景下的选型建议」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：第 01 篇的文本预处理流水线、序列标注的基本概念、Python 正则与字典操作。
>
> **所属主题**：中文分词与子词分词 · 方法细节

## 本次只学这一点

| 场景 | 建议 | 理由 |
|------|------|------|
| 传统机器学习（TF-IDF + 树模型） | 字级或 jieba 词级 | 特征稀疏，字级词表更小、更稳；jieba 词级可解释性好 |
| FastText 分类 | jieba 词级 + char n-gram | FastText 自带 subword，词级提供语义单元，n-gram 补 OOV |
| BERT 等预训练模型 | 直接用模型自带 tokenizer | BERT-base-chinese 就是字级，强行分词反而破坏与预训练的一致性 |
| 多语言 / 含大量英文与符号 | SentencePiece（BPE 或 Unigram） | 语言无关，无需预分词，天然处理空格 |
| 领域术语密集（医疗、法律） | 自定义词典 + 字级兜底 | 词典保术语完整，字级保未知词 |

**最重要的一条**：使用预训练模型时，不要自己先分词再喂给 tokenizer。模型在预训练阶段看过的是特定粒度的文本，自己分词会造成训练与推理的分布不一致（train-test mismatch）。
