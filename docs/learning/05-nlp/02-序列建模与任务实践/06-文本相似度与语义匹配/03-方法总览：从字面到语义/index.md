# 方法总览：从字面到语义

> **学习目标**：能够解释「方法总览：从字面到语义」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：第 03 篇的 TF-IDF 与余弦相似度、第 04 篇的词向量、第 08 篇的 attention、第 09 篇的 BERT 与句对任务。
>
> **所属主题**：文本相似度与语义匹配 · 核心概念

## 本次只学这一点

| 方法 | 依赖 | 语义能力 | 速度 | 适用 |
|------|------|----------|------|------|
| 编辑距离（Levenshtein） | 字符 | 无（纯字面） | $O(mn)$ | 拼写纠错、短字符串模糊匹配 |
| Jaccard / Dice | 词集合 | 无（字面重合） | 快 | 集合去重、标题相似度快速筛 |
| TF-IDF + 余弦 | 词袋 | 无同义（但 IDF 有判别力） | 快 | 强基线、关键词类检索 |
| BM25 | 词袋 + 长度归一 | 无同义 | 快 | 传统检索的经典基线，至今难被完全替代 |
| 词向量平均 / SIF | word2vec / FastText | 弱同义 | 快 | 快速近似，无上下文 |
| Sentence-BERT | BERT + 句对微调 | 强同义、句子级 | 中（可离线编码） | 双塔召回、语义去重、聚类 |
| CoSENT | BERT + 排序损失 | 强 | 中 | 中文句相似度（比 SBERT 更稳定） |
| SimCSE | BERT + 对比学习 | 强 | 中 | 无标注/少标注场景的句向量 |
| Cross-Encoder（BERT 句对） | BERT | 最强 | 慢 | 精排、最终判定 |
