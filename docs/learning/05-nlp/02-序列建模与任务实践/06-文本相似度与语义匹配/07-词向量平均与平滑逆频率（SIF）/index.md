# 词向量平均与平滑逆频率（SIF）

> **学习目标**：能够解释「词向量平均与平滑逆频率（SIF）」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：第 03 篇的 TF-IDF 与余弦相似度、第 04 篇的词向量、第 08 篇的 attention、第 09 篇的 BERT 与句对任务。
>
> **所属主题**：文本相似度与语义匹配 · 方法细节

## 本次只学这一点

最简单的方法：把句子里所有词的向量取平均作为句向量。缺陷很明显：

1. **高频虚词主导**：the / 的 贡献了大量方向，稀释了实词。
2. **没有词序**：「猫追狗」和「狗追猫」平均后完全相同。

改进手段：

- **加权平均**：用 IDF 或 SIF 权重 $w=\dfrac{a}{a+p(w)}$（$a$ 常取 $10^{-3}$，$p(w)$ 是词频）加权，压掉高频词。
- **去主成分**：对句向量矩阵做 PCA，减去第一主成分（SIF 论文的做法），可显著提升相似度任务表现。

即便有这些改进，静态词向量平均仍然无法处理否定和语序，只能作为快速近似。
