# ChatGLM 的 GLM 训练目标

> **学习目标**：能够解释「ChatGLM 的 GLM 训练目标」的机制或步骤，并用本节材料验证理解。

>

## 本次只学这一点

**原理**：在输入文本中随机挖去一些**连续的**文本片段（span），然后训练模型**按照任意顺序**重建这些片段。
GLM 把 NLU 任务转化为「包含任务描述的完形填空问题」，可以通过自回归生成的方式回答。

| 机制 | 做法 |
|---|---|
| 片段替换 | 把被挖掉的 span 用 `[MASK]` 标志替换（`[M]`），并打乱 span 顺序，以捕捉跨度之间的内在联系 |
| 片段标记 | 输入时片段前加 `[S]`（start），输出时片段后加 `[E]`（end） |
| 二维位置编码 | 用两组位置 id 分别表示**片段内位置**与**片段间位置**关系 |
| 自注意力掩码 | Part A 的词可以自我看到，但不能看到 Part B；Part B 的词可以看到 Part A 和 Part B 中**前面**的词 |
| 位置编码 | 去除绝对位置编码，采用 RoPE |
| 激活函数 | 把 ReLU 替换为 GeGLU（GLU 门控 + GELU） |
| 归一化 | 采用基于 DeepNorm 的 Post-LayerNorm |
| 稳定性 | 缩减 embedding 层梯度 10 倍，减小梯度范数 |
