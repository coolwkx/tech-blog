# MLA：把 KV cache 压到 1/10 量级

> **学习目标**：能够解释「MLA：把 KV cache 压到 1/10 量级」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：Transformer 与注意力机制（见《02-Transformer与注意力机制》）、模型参数量与显存的基本换算、量化概念。
>
> **所属主题**：-主流大模型对比 · 核心概念

## 本次只学这一点

**要解决的问题**：传统 MHA 在推理时要把每步的 K、V 缓存下来，巨大的 KV cache 存储限制了输入长度与句子长度，
也就是推理性能受限。假设单个 block 有 $n_h$ 个头、每个 K/V 的维度为 $d_h$，则每步需缓存的参数量为
$2 \cdot n_h \cdot d_h \cdot L$（$L$ 为 block 数）。

**已有方案的思路**（MQA / GQA / MGA）：直接减少需要存储的 K/V 数量——多个 query 头共享一套 K/V，
或让 K/V 不再是「多头」。

**MLA 的思路**：不减少头的数量，而是通过**低秩联合压缩**把 K/V 压成一个压缩隐向量。
直觉类比：一个 $d \times d$ 的矩阵可以分解为两个 $d \times d_c$ 的矩阵相乘，而 $d_c \ll d$。
具体做法是对 K 和 V 做低秩联合压缩，得到维度远小于原始多头 K/V 的隐向量，
推理时**只缓存这个压缩隐向量**，再用两个升维矩阵还原出 K 和 V。每步缓存量由此大幅下降。
此外，为了降低训练时的激活内存，MLA 对 query 也做了低秩压缩。

**位置编码解耦**：由于 K/V 已被压缩，直接在压缩表示上应用位置编码不再等价于在完整 K/V 上应用位置编码
（压缩可能丢失位置相关信息）。MLA 的做法是设计**两个额外的变量**存储旋转位置编码信息，
把「信息存储」与「旋转编码」解耦，最后把四段变量分别拼接，形成「带信息压缩的 K/V」与「带位置信息的 K/V」。

结论：MLA 相比 MHA 与 MQA 在明显降低 KV cache 的同时效果更好；MQA 虽然也降低缓存，但效果不如 MLA。
