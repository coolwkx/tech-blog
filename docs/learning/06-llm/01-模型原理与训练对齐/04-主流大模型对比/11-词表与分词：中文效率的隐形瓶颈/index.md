# 词表与分词：中文效率的隐形瓶颈

> **学习目标**：能够解释「词表与分词：中文效率的隐形瓶颈」的机制或步骤，并用本节材料验证理解。

>
> **所属主题**：-主流大模型对比 · 关键机制

## 本次只学这一点

| 模型 | 分词算法 | 词表大小 | 中文表现 |
|---|---|---|---|
| LLaMA | BPE | 32000 | 差：中文 token 仅几百个，一个汉字切多 token |
| Chinese-LLaMA | SentencePiece 中文词表 + 原词表合并 | 49953 | 显著改善 |
| Baichuan-7B | BPE | 64000 | 好（中英双语设计） |
| ChatGLM-6B | 自研分词器（中英双语） | 130528 | 好 |
| Qwen2.5 | BPE（多语言） | 151936 | 好 |
| LLaMA3 | BPE | 128000 | 明显改善 |
| BLOOM | BPE（多语种） | 250880 | 多语言覆盖（46 种自然语言 + 13 种编程语言） |

**为什么词表大小重要**：同样的中文句子，词表越小 → token 数越多 → 有效上下文越短、训练与推理成本越高。
这也是 LLaMA3 把词表从 32K 扩到 128K、并宣称「更高效地编码语言，从而大大提高模型性能」的原因。
