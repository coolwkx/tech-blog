# 采样参数如何影响输出

> **学习目标**：能够解释「采样参数如何影响输出」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：Transformer 与注意力机制（见《02-Transformer与注意力机制》）、模型参数量与显存的基本换算、量化概念。
>
> **所属主题**：-主流大模型对比 · 关键机制

## 本次只学这一点

| 参数 | 含义 | 调大 | 调小 |
|---|---|---|---|
| `temperature` | 对 logits 的缩放，控制随机性 | 更发散、更有创意，也更容易跑偏 | 更确定、更保守，趋近贪心 |
| `top_p`（nucleus） | 只在累计概率达 `top_p` 的最小词集合中采样 | 候选词更多、更随机 | 候选词更少、更确定 |
| `max_tokens` | 生成上限 | 可能更完整，也更慢更贵 | 可能被截断 |
| `stream` | 是否流式返回 | 首字延迟低、体验好 | 需等全部生成完 |
| `frequency_penalty` | 按已出现次数惩罚词 | 减少重复用词 | 允许重复 |
| `presence_penalty` | 只要出现过就惩罚 | 鼓励引入新话题 | 允许围绕同一话题展开 |
| `stop` | 命中即停止 | — | 必须与输出格式约定一致 |

经验：需要稳定结构化输出（如 JSON 抽取）时用 `temperature=0`；需要创意写作时 0.7~1.0 并配合 `top_p=0.8~0.95`。
**不要同时大幅调低 `temperature` 和 `top_p`**，否则输出会过度坍缩、重复。
