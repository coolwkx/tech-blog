# 优化器的状态开销

> **学习目标**：能够解释「优化器的状态开销」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：反向传播与计算图；PyTorch 的优化器状态概念；Transformer 层的结构（注意力矩阵的形状 $b\times a\times s\times s$）；LoRA 的参数量公式（见 [03 篇](../../../../../06-llm/02-微调与对齐/03-LoRA原理与工程实践.md)）。
>
> **所属主题**：全参微调与显存账本 · 核心概念

## 本次只学这一点

| 优化器 | 每可训练参数的状态 | 每参数状态字节（fp32 状态） | 备注 |
| --- | --- | --- | --- |
| SGD | 无 | 0 | 显存最省，收敛慢 |
| SGD + momentum | 1 × 动量 | 4 | 少量改进 |
| Adam / AdamW | 2 ×（$m$, $v$） | 8 | 默认选择，显存大户 |
| AdamW + 混合精度（AMP） | fp32 主权重 + $m$ + $v$ | **12** | 加上 fp16 权重与梯度，合计 16 B/参数 |
| Adafactor | 分解的二阶矩 | ≈ 4～6 | 省显存，需调参 |
| 8-bit Adam（bitsandbytes） | 量化后的 $m$, $v$ | ≈ 2 | 有精度损失，适合 LoRA 场景 |
