# 并行策略对比表

> **学习目标**：能够解释「并行策略对比表」的机制或步骤，并用本节材料验证理解。
>

>
> **所属主题**：全参微调与显存账本 · 核心概念

## 本次只学这一点

| 策略 | 切的是什么 | 解决什么问题 | 代价 |
| --- | --- | --- | --- |
| DP / DDP | **数据**（每卡一份完整模型） | 提高吞吐 | **不省显存**；梯度 all-reduce 通信 |
| ZeRO-1 | 数据 + 优化器状态分片 | 砍掉最大的一块（12 B/参数） | 参数更新需要 gather/scatter |
| ZeRO-2 | 数据 + 优化器状态 + 梯度分片 | 再砍梯度 | 反向时 reduce-scatter |
| ZeRO-3 / FSDP | 数据 + 优化器状态 + 梯度 + **参数**分片 | 单卡放不下模型也能训 | 每次前向都要 all-gather 参数，通信量随层数放大 |
| TP（张量并行） | **单个矩阵乘法的维度**（列切 / 行切） | 单层放不下时把一层拆到多卡 | 每层两次 all-reduce，**必须**高带宽互联（NVLink） |
| PP（流水线并行） | **层**（不同 stage 放不同层） | 放不下深模型 | 流水线气泡，气泡率约 $\frac{p-1}{m+p-1}$（$p$ 为 stage 数，$m$ 为 micro-batch 数） |
| SP（序列并行） | 序列维度 | 在 TP 之上进一步砍激活 | 实现复杂度高，需与 TP 配合 |
| CPU / NVMe offload | 把优化器状态（或参数）搬到 CPU / 磁盘 | 用时间换显存 | 通信瓶颈，吞吐显著下降 |

工程上的常见组合是 **3D 并行**：TP（卡内高带宽）× PP（跨节点）× DP（其余），再加上 ZeRO 的分片能力。
