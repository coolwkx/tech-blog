## 本次只学这一点

| 符号 | 含义 |
| --- | --- |
| $P$ | 模型总参数量 |
| $P_{\text{train}}$ | 可训练参数量（全参微调时 $P_{\text{train}}=P$） |
| $b$ | micro-batch size（单卡单次前向的样本数） |
| $s$ | 序列长度（token 数） |
| $h$ | 隐藏维度 |
| $L$ | Transformer 层数 |
| $a$ | 注意力头数 |
| $N$ | 数据并行 / 分片的卡数 |
| $b_w,b_g,b_o$ | 权重、梯度、优化器状态的每参数字节 |
