# 分块量化与常量开销（推导）

## 本次只学这一点

分块量化的存储由两部分组成：

1. **量化后的权重**：$k$ bit/参数（$k=4$）；
2. **每块的缩放常量**：块大小 $B=64$，每个块一个 fp32 absmax，即 $32$ bit / $64$ 参数 $= 0.5$ bit/参数。

于是**没有双重量化时**：

$$
\text{总开销} = 4 + 0.5 = 4.5\ \text{bit/参数} = 0.5625\ \text{字节/参数}
$$

7B 上：$4.5\times7\times10^9 / 8 = 3.94\times10^9$ 字节 $\approx 3.94$ GB。
