# 为什么要把分类改写成完形填空

> **学习目标**：能够解释「为什么要把分类改写成完形填空」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：BERT/MLM 预训练目标、Tokenizer 与词表（vocab）、`[MASK]` token 与 MLM Head、交叉熵损失、基本的分类任务指标（acc / P / R / F1）。
>
> **所属主题**：-指令数据构造与清洗 · 核心概念

## 本次只学这一点

传统做法（Fine-Tuning 范式）：文本送进 BERT，取 `[CLS]` 向量，接一个随机初始化的全连接层，输出 N 类 logits。PET 做法（完形填空范式）：把文本塞进一句自然语言模板，让模型按 MLM 填空，再把填出来的**词**映射回**类别**。

```
原始样本：  手机	这个手机也太卡了。
传统微调：  [CLS] 这个手机也太卡了。 [SEP] → Linear(768, 10) → 手机
PET 样本：  这是一条[MASK][MASK]评论：这个手机也太卡了。 → MLM Head → 预测出 "手机"
```

三个直接后果：

1. **预训练任务与下游任务不再有 gap**。BERT 预训练学的就是「根据上下文猜被遮住的词」，PET 让下游任务保持同一形式，模型不需要重学「怎么用 [CLS] 做分类」。
2. **不引入随机初始化的新参数**。那个 `Linear(768, 10)` 是随机初始化的，小样本下它自己就会过拟合；PET 直接复用预训练好的 MLM Head。
3. **标签以「词」的形式被复用**。`手机` 在预训练语料里出现过无数次，词向量已携带语义；而「第 6 类」这个 one-hot 不携带任何语义。

一句话概括：**PET 把「给句子打标签」变成了「让句子读起来通顺」**，模型只需判断哪个词填入后整句话最自然。
