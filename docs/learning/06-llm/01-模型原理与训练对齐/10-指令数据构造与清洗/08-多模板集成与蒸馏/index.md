# 多模板集成与蒸馏

> **学习目标**：能够解释「多模板集成与蒸馏」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：BERT/MLM 预训练目标、Tokenizer 与词表（vocab）、`[MASK]` token 与 MLM Head、交叉熵损失、基本的分类任务指标（acc / P / R / F1）。
>
> **所属主题**：-指令数据构造与清洗 · PET 详解：把分类任务改写成完形填空

## 本次只学这一点

PET 单模板的问题在论文里写得很清楚：**人工模板稳定性差，同一样本换一个 Pattern，准确率可以相差近 20 个百分点**。原因有三：

- 模板把数据分布强行「投影」到一个特定形式上，这个形式未必靠近预训练分布；
- 模板里多一个字少一个字，MASK 位置要预测的词就变了；
- MLM 预训练时并没有见过 `[MASK]` 出现在这种句法位置。

PET 论文给出的解法是**集成 + 蒸馏**：

```
① 为同一任务人工设计 K 个（论文中常用 3~5 个）不同 Pattern，各自独立训练一个模型；
② 用这 K 个模型对同一批「无标注数据」打软标签（soft label），把 K 个概率分布加起来归一化；
③ 用一个（可以更小的）模型去拟合这批软标签 —— 这就是蒸馏；
④ 蒸馏得到的单模型，效果通常超过任何一个单模板模型，也明显超过直接用少量标注数据训练。
```

这套流程的工程含义：**模板数量本身是超参**（不是越多越好，模板之间要「换句式、换位置、换连接词」而不是同义改写）；**软标签比硬标签信息量大**（`{手机: 0.7, 平板: 0.2, 电脑: 0.1}` 比 `手机` 更能告诉学生模型「这几个类本来就容易混」）；**无标注数据在这里是免费的**——电商评论里 99% 没有标签，集成+蒸馏正好把这部分利用起来，这也是它样本效率高的主要来源之一。
