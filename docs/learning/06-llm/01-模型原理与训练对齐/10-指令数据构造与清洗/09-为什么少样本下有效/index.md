# 为什么少样本下有效

> **学习目标**：能够解释「为什么少样本下有效」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：BERT/MLM 预训练目标、Tokenizer 与词表（vocab）、`[MASK]` token 与 MLM Head、交叉熵损失、基本的分类任务指标（acc / P / R / F1）。
>
> **所属主题**：-指令数据构造与清洗 · PET 详解：把分类任务改写成完形填空

## 本次只学这一点

| 原因 | 机理 |
|---|---|
| 零新参数 | 复用预训练 MLM Head，没有随机初始化的分类头，小样本下少了一整个过拟合来源 |
| 任务与预训练同构 | 输出层学的是「词表分布」，而不是「新定义的类别编号」 |
| 先验知识注入 | Pattern 与 Verbalizer 是人类先验，等于免费给模型提供了任务结构 |
| 标签词自带语义 | `手机` 的词向量与评论文本在同一语义空间，模型可以「就近匹配」 |

代价是：

- **模板设计人力密集、方差大**；
- **对「超多分类」不友好**：类别数到几十上百时，为每一类都找自然、可预测的标签词非常困难；
- **不擅长结构化任务**：「判断两句话的逻辑关系」很难写成一句自然的完形填空；
- **推理时要查表**，必须处理「预测词不在映射表里」的兜底情况——这是线上事故的高发点。
