# 从人工标注生成

> **学习目标**：能够解释「从人工标注生成」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：BERT/MLM 预训练目标、Tokenizer 与词表（vocab）、`[MASK]` token 与 MLM Head、交叉熵损失、基本的分类任务指标（acc / P / R / F1）。
>
> **所属主题**：-指令数据构造与清洗 · 通用指令数据的构造方式

## 本次只学这一点

实际项目里最高质量的数据仍然来自人工，但直接让标注员写「指令+回答」成本极高。常用降本手段：

- **先跑一遍模型，让人改而不是让人写**（修改成本远低于创作成本）；
- **定义 rubric**：把「好回答」拆成可判定的 5~8 条标准，标注员逐条打勾；
- **双人交叉 + 仲裁**，并对 Kappa 系数低于阈值的批次重训标注员；
- **保留困难样本**：模型答对的不必再标，优先标模型答错的（主动学习）。
