# 三种构造方式的取舍

> **学习目标**：能够解释「三种构造方式的取舍」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：BERT/MLM 预训练目标、Tokenizer 与词表（vocab）、`[MASK]` token 与 MLM Head、交叉熵损失、基本的分类任务指标（acc / P / R / F1）。
>
> **所属主题**：-指令数据构造与清洗 · 通用指令数据的构造方式

## 本次只学这一点

| 方式 | 成本 | 质量 | 多样性 | 主要风险 |
|---|---|---|---|---|
| Self-Instruct 自造 | 极低 | 中 | 高 | 同质化、幻觉被蒸馏进模型、标签不平衡 |
| 文档生成 | 低 | 中高 | 中 | 覆盖不到文档外的意图；格式单一 |
| 人工标注 | 高 | 最高 | 取决于题库设计 | 慢、贵、标注员偏好漂移 |
| 完形填空（PET 式） | 低（但需设计模板） | 高（标签准确） | 低（只覆盖分类） | 模板过拟合、无法覆盖生成任务 |

实践中的常见配比是「人工数据做骨架、模型数据做规模、PET 式数据补小样本冷启动」。
