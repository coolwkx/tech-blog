# 语义去重

> **学习目标**：能够解释「语义去重」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：BERT/MLM 预训练目标、Tokenizer 与词表（vocab）、`[MASK]` token 与 MLM Head、交叉熵损失、基本的分类任务指标（acc / P / R / F1）。
>
> **所属主题**：-指令数据构造与清洗 · 数据清洗清单

## 本次只学这一点

精确去重搞不定的「换了个说法」的重复，需要语义去重：把文本编码成向量、归一化后做贪心合并——保留第一条，之后每条与已保留集合的最大余弦相似度低于阈值就保留，否则丢弃（实现见 5.7 的 `semantic_dedup`）。阈值选择经验：**0.95 以上偏保守**（几乎只删改写句），**0.90 左右开始有误伤**（同主题不同意图会被合并）。建议先在 200 条上人工抽查误删率再定。
