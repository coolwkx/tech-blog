# 长度过滤

> **学习目标**：能够解释「长度过滤」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：BERT/MLM 预训练目标、Tokenizer 与词表（vocab）、`[MASK]` token 与 MLM Head、交叉熵损失、基本的分类任务指标（acc / P / R / F1）。
>
> **所属主题**：-指令数据构造与清洗 · 数据清洗清单

## 本次只学这一点

不同任务的合理长度区间差别极大，不要照搬：分类短文本建议 3 ~ 512 token（少于 3 token 基本是脏数据）；单轮指令问答 5 ~ 1024（超长回答常是模型跑飞或复制粘贴）；多轮对话单轮 5 ~ 2048 且总长不超过模型窗口的 80%（超长截断会破坏最后的 assistant 轮）。

**长度截断一定要「保头还是保尾」想清楚**：多轮对话如果从尾部保留会丢掉 system prompt，从头部保留会丢掉最后一个用户问题（而它才是要回答的）。正确做法是按轮切割、丢弃最老的轮次，而不是按 token 硬切。
