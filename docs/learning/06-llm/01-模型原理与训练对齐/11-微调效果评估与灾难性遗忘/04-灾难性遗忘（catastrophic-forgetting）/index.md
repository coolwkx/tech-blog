# 灾难性遗忘（catastrophic forgetting）

> **学习目标**：能够解释「灾难性遗忘（catastrophic forgetting）」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：监督微调（SFT）的基本流程、LoRA 等参数高效微调方法、分类与生成的常用指标（acc / P / R / F1 / ROUGE / 通过率）、训练集-验证集切分与交叉验证。
>
> **所属主题**：-微调效果评估与灾难性遗忘 · 核心概念

## 本次只学这一点

**定义**：模型在学习新任务的过程中，丢失了预训练阶段（或此前微调阶段）已经获得的知识与能力。

**典型表现**（按出现频率排序）：

| 表现 | 例子 |
|---|---|
| 通用知识与常识下降 | 问答基准分掉 10+ 分；日期、常识、数学计算出错增多 |
| 语言能力退化 | 中文表达变得生硬、出现英文夹杂、重复句式 |
| 指令遵循能力下降 | 不再遵守「不要解释」「只输出 JSON」这类格式指令 |
| 拒答与安全行为削弱 | 对敏感问题的拒绝率下降 |
| 多语言能力下降 | 用中文数据微调后，英文能力明显退化 |

**根本原因：参数漂移。** 预训练得到的权重编码了一整套「语言 + 世界知识」的表示，微调时用一批高度同质、领域集中的数据去做梯度更新，会把权重推离原位置。偏差积累到一定程度，原本依赖这些权重才能完成的任务就失败了。具体机制上有几条常见的解释：

1. **分布偏移 + 灾难性干扰**：新任务的梯度方向与旧任务的最优方向冲突，参数更新沿着新任务的方向走，旧任务的解被覆盖；
2. **表示坍缩**：低资源、窄领域的数据会让模型的表示空间收缩到该领域的子空间，通用表示被挤压；
3. **过拟合到表层模式**：模型学到的是「这个训练集的模板」，而不是任务本身，于是遇到别的任务就用这个模板回应；
4. **输出分布改变**：SFT 让模型输出的概率分布整体偏移（比如变得更啰嗦或更简短），连带改变了其他任务的输出质量。

**为什么参数高效微调天然更抗遗忘**：全参微调让所有参数都有机会移动，旧任务的解没有任何「锚点」；而 LoRA 把更新限制在一个低秩子空间里、只训部分层冻结其余部分，等于给优化过程加了一个强约束——**可表达的变化本身就有限**。这也是「PEFT 在低数据环境下优于全参微调」这一常见结论的部分原因：不是 PEFT 更强，而是全参在小数据上更容易跑偏。

不过要明确一点：**LoRA 不是遗忘免疫**。当秩很大、epoch 很多、学习率很高、领域数据极度同质时，LoRA 同样会出现明显的通用能力退化。它降低的是遗忘的概率与幅度，不是消除。
