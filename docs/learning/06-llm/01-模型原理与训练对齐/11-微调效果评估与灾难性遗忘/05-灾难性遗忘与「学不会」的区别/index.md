# 灾难性遗忘与「学不会」的区别

> **学习目标**：能够解释「灾难性遗忘与「学不会」的区别」的机制或步骤，并用本节材料验证理解。
>

>
> **所属主题**：-微调效果评估与灾难性遗忘 · 核心概念

## 本次只学这一点

这两个现象容易混淆，但处理方式完全相反：

| 维度 | 学不会（欠拟合） | 灾难性遗忘 |
|---|---|---|
| 训练 loss | 降不下去或降得很少 | 正常下降到很低 |
| 目标任务指标 | 低，且提升缓慢 | 通常达标甚至很好 |
| 通用基准 | 基本不变 | **明显下降** |
| 输出风格 | 还是原来的风格，只是答不准 | 风格被新数据「带跑」 |
| 修复方向 | 加容量（r、target_modules）、加数据、加 epoch | 加回放、降容量、降学习率、减 epoch |

**判断方法**：同时跑目标任务评测和通用基准回测。目标任务达标 + 通用基准下降 = 遗忘；两者都不达标 = 欠拟合。只有先分清是哪一种，后续动作才不会是反的——给遗忘的模型「加 r 提升效果」是最常见的反向操作。
