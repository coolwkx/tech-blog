# 过拟合的识别信号

> **学习目标**：能够解释「过拟合的识别信号」的机制或步骤，并用本节材料验证理解。

>

## 本次只学这一点

过拟合是遗忘的「近亲」，但它的信号更早、更便宜就能发现：

| 信号 | 具体表现 | 采集方式 |
|---|---|---|
| 泛化 gap | 验证 loss 开始上升而训练 loss 继续下降 | 训练日志按步记录两条曲线 |
| 指标回落 | 验证指标在某个 epoch 达到峰值后持续下降 | 记录 best_epoch 与 best 之后的步数 |
| 复述训练样本 | 输出中直接出现训练集的长片段 | n-gram 重合率统计（如 13-gram） |
| 对措辞过度敏感 | 同义改写的提问，模型就答不对了 | 扰动集测试（换词、换语序、加错别字） |
| 输出长度坍缩 | 回答长度分布明显变窄 | 统计输出 token 数的分布 |

**早停的正确姿势**：不要用「最后一个 epoch 的模型」，而是记录验证指标最好时的 checkpoint。如果 best_epoch 明显早于训练结束（例如 10 个 epoch 里最好的是第 3 个），说明后面的训练只是在过拟合，应当直接缩短训练轮数。
