# 实验设计模板

> **学习目标**：能够解释「实验设计模板」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：监督微调（SFT）的基本流程、LoRA 等参数高效微调方法、分类与生成的常用指标（acc / P / R / F1 / ROUGE / 通过率）、训练集-验证集切分与交叉验证。
>
> **所属主题**：-微调效果评估与灾难性遗忘 · 怎么设计微调对比实验

## 本次只学这一点

| 项 | 要求 |
|---|---|
| 固定变量 | 基座模型版本、tokenizer、最大序列长度、评测代码、解码参数（temperature/top_p/max_new_tokens）、评测集划分 |
| 自变量 | 每组只改一个：是否微调、微调方法、LoRA 的 r/α、数据配比、学习率 |
| 因变量 | 四维指标 + 训练成本（GPU 小时、峰值显存）+ 推理成本（延迟、显存） |
| 重复次数 | ≥ 3 个随机种子，报告均值 ± 标准差 |
| 显著性 | 对分类任务用配对检验；对生成任务用 bootstrap 置信区间 |
| 记录 | 数据版本哈希、代码 commit、随机种子、超参全量 |
