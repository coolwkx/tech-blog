# Q4. 低秩假设（low-rank hypothesis）为什么成立？LoRA 为什么有效？

> **学习目标**：能够解释「Q4. 低秩假设（low-rank hypothesis）为什么成立？LoRA 为什么有效？」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：Transformer 基本结构、SFT 流程、LoRA/QLoRA 的原理、显存构成（权重/梯度/优化器状态/激活/KV cache）、常用评测指标。
>

## 本次只学这一点

<details markdown="1">
<summary markdown="1">参考答案</summary>

**30 秒版**：微调带来的权重变化 `ΔW` 本身是低秩的（intrinsic dimension 很低），所以用 `W + BA`（`B ∈ R^{d×r}`、`A ∈ R^{r×k}`、`r ≪ min(d,k)`）就能近似它。这既大幅减少了可训练参数，又因为冻住主干而自带正则效果。

**展开版**：

1. **经验依据**：微调后的权重变化矩阵的秩远小于原始权重矩阵的秩，且把随机投影降到很低维度再微调，效果依然接近全参微调——说明「适应下游任务」所需的有效自由度很小。
2. **数学形式**：

   ```
   h = Wx + ΔWx = Wx + (alpha / r) * B A x
   A: d × r，Kaiming 均匀初始化
   B: r × k，零初始化   ← 训练起点 ΔW = 0，保证初始等同于原模型
   ```

3. **为什么有效**：
   - 参数效率：可训练参数从 `d×k` 降到 `r×(d+k)`；
   - 正则效应：低秩约束把更新限制在一个小子空间里，抑制过拟合，也因此**减少灾难性遗忘**；
   - 无推理延迟（合并后）；
   - 可插拔：一个基座 + 多个 LoRA 权重（每个几 MB 到几百 MB），便于多任务切换。

4. **实践中的加餐**：`B` 零初始化是必须的，否则训练初期模型输出会突变。同理，LoRA 常配合更大的学习率（1e-4 ~ 3e-4，比全参的 1e-5 ~ 5e-5 高一到两个数量级），因为只有少量参数在更新。

**追问预判**：
- *「r 和 alpha 谁在控制更新的幅度？」* —— `alpha / r` 是缩放因子。约定俗成的做法是调 r 时同步把 alpha 设为 `2r`，让缩放保持常数，把「表达力」和「更新幅度」两个因素解耦开。
- *「LoRA 加在哪些模块上？」* —— 常见做法是 `q_proj`、`v_proj`（最省参数），实践中 `q/k/v/o + gate/up/down` 全部加通常效果更好但参数更多。可训练参数与「加的范围」成正比。
