# Q16. 训练过程中你盯哪些指标？loss 不降怎么办？

## 本次只学这一点

<details markdown="1">
<summary markdown="1">参考答案</summary>

**30 秒版**：盯四个数——训练 loss、验证集指标、学习率曲线、梯度范数。loss 不降先分三类：根本没动（学习率/数据问题）、动了又卡住（容量或数据问题）、在震荡（学习率过大或 batch 太小）。

**展开版**——先分类，再对症：

| 现象 | 最可能原因 | 验证方法 | 修复 |
|---|---|---|---|
| loss 从第一步就几乎不变 | 学习率太小；标签被 mask 光了；数据格式错（标签没对上） | 打印一个 batch 的 labels，确认非 `-100` 的位置存在；把 lr 乘 10 试跑 50 步 | 修数据管线；提高 lr |
| loss 前几步正常，之后平台 | 容量不足（r 太小、覆盖面太窄）；任务超出模型能力 | 加大 r / 扩 target_modules 试跑 | 扩容量；或改用全参 |
| loss 震荡不收敛 | lr 过大；batch 太小；warmup 不足 | 看梯度范数是否尖峰；看 loss 曲线周期 | 降 lr、加 warmup、加梯度累积 |
| 训练 loss 降但验证指标不升 | 过拟合；数据分布不一致；评测口径有问题 | 对比验证集与训练集的输入分布；检查评测脚本 | 早停、增数据、加 dropout/weight decay |
| loss 降到极低但输出很差 | 数据里有重复样本被记住了；或者评测解码参数不对 | 算复述率；人工看 20 条输出 | 去掉重复数据、减少 epoch |

**必看的四个量**：

1. **训练 loss 的滑动平均**（不要看单步，噪声太大）；
2. **验证集指标随步数的曲线**（选模型唯一依据）；
3. **学习率曲线**（确认 warmup 生效、没有提前衰减到 0）；
4. **梯度范数**（尖峰通常预示不稳定，需剪裁或降 lr）。

**追问预判**：
- *「warmup 为什么必要？」* —— 训练初期 Adam 的二阶动量估计不准，直接上大学习率容易发散；warmup 让学习率从接近 0 开始爬升，通常取总步数的 3%~10%。
- *「梯度剪裁设多少？」* —— 常用 `max_grad_norm=1.0`。它不改善收敛速度，但显著提升稳定性，几乎总是建议开。
