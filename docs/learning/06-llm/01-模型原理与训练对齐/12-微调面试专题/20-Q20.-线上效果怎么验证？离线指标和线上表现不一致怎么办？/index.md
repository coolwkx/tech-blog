# Q20. 线上效果怎么验证？离线指标和线上表现不一致怎么办？

> **学习目标**：能够解释「Q20. 线上效果怎么验证？离线指标和线上表现不一致怎么办？」的机制或步骤，并用本节材料验证理解。
>

## 本次只学这一点

<details markdown="1">
<summary markdown="1">参考答案</summary>

**30 秒版**：离线只是筛选，线上才是验收。用影子模式或小流量 A/B，盯业务指标（任务完成率、人工采纳率、投诉率）与工程指标（延迟、成本、格式失败率）。离线-线上不一致的头号原因是测试集泄漏或分布漂移。

**展开版**——线上验证的四步：

```
① 影子模式（shadow）：新老模型同时跑，只记录不生效。看输出差异分布与格式失败率
② 小流量 A/B：5% 流量，跑足统计周期，看业务指标与工程指标
③ 灰度扩大：50% → 100%，同时保留一键回滚
④ 上线后监控：分布漂移、格式失败率、用户反馈（badcase 回流）
```

**离线-线上不一致的四种根因**：

| 根因 | 表现 | 修复 |
|---|---|---|
| 测试集泄漏 | 离线虚高 5~20 点，线上几乎没动 | 按外部键分组切分；评测集独立采集 |
| 分布漂移 | 离线好、线上差，且随时间变差 | 训练数据覆盖真实长尾；建立线上 badcase 回流机制 |
| 指标口径不同 | 离线用 macro-F1，线上关注「用户是否采纳」 | 尽量让离线指标与业务指标对齐，或至少建立映射 |
| 工程因素 | 模型答对了但超时、被截断、格式解析失败 | 监控延迟、max_new_tokens、格式失败率 |

**建议必建的三个线上监控**：

1. **格式失败率**（有硬上限，超标告警）；
2. **输出分布漂移**（长度、重复率、拒答率的日环比）；
3. **badcase 回流闭环**（用户投诉/人工标记 → 进回归集 → 下次训练前必须过）。

**追问预判**：
- *「A/B 要跑多久？」* —— 由最小可检测效应和方差决定，通常至少一周以覆盖工作日/周末的行为差异。业务指标波动大的场景需要更长。
- *「线上指标掉了但要快速定位，你会先看什么？」* —— 先分「模型变了」和「输入变了」：对比近 7 天的输入分布（长度、意图占比）与输出分布，再决定是回滚模型还是处理数据漂移。
