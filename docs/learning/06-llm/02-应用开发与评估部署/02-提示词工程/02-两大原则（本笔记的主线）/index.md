# 两大原则（本笔记的主线）

> **学习目标**：能够解释「两大原则（本笔记的主线）」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：大模型基本概念、In-context learning（见《01-大模型基础与演进》）、Python 字符串格式化与 JSON 解析。
>
> **所属主题**：-提示词工程 · 核心概念

## 本次只学这一点

| 原则 | 含义 | 落地技巧 |
|---|---|---|
| ① 写清晰的指令 | 清晰、具体地表达需求，提供充足上下文 | 分隔符、结构化输出、参考示例、角色扮演 |
| ② 给模型充足的思考时间 | 不要让它「匆忙下结论」 | 指定步骤、指导模型先自行求解再对比 |

> 为什么这两条就够了？因为 LLM 的能力**已经存在于参数里**，prompt 的作用是**把任务精确定位**（原则一）
> 与**引导它把中间推理展开**（原则二）。前者解决「对齐意图」，后者解决「复杂任务算错」。
