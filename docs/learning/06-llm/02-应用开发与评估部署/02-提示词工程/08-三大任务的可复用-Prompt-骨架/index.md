# 三大任务的可复用 Prompt 骨架

> **学习目标**：能够解释「三大任务的可复用 Prompt 骨架」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：大模型基本概念、In-context learning（见《01-大模型基础与演进》）、Python 字符串格式化与 JSON 解析。
>
> **所属主题**：-提示词工程 · 关键机制

## 本次只学这一点

三个任务的 prompt 共用同一套骨架：**角色/任务说明 + 封闭输出空间 + few-shot 示例 + 待处理输入**。

| 任务 | 骨架要点 | `<Bot>` 示例答案 |
|---|---|---|
| 分类 | 「你是一个文本分类器，需按照要求将我给你的句子分类到：['新闻报道','公司公告','财务公告','分析师报告'] 类别中」 | `新闻报道` |
| 抽取 | 先给 schema（如 `{'金融': ['日期','股票名称','开盘价','收盘价','成交量']}`），再约定「按 JSON 输出、缺失信息用『原文中未提及』、多值用『,』分隔」 | `{"日期":["2023-01-10"], ...}` |
| 匹配 | 「当我给你两个句子时，你需要回答这两句话语义是否相似。只需要回答是否相似，不要做多余的回答」 | `是` / `不是` |

> 注意：示例中 `<Bot>` 的内容都是**人工预先写好的**（few-shot 的示范答案），不是模型真实输出；
> 它的作用是告诉模型「看到类似 `<User>` 的输入时，应当作出什么形式的回答」。
