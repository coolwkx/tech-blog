# 三种答题模板

> **学习目标**：能够解释「三种答题模板」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：本目录 01~11 篇。
>
> **所属主题**：-大模型面试题库 · 核心概念

## 本次只学这一点

| 题型 | 模板 | 例子 |
|---|---|---|
| 概念题（「什么是 X」） | **定义 → 为什么需要 → 关键机制 → 局限** | 什么是 RAG / 什么是 LoRA |
| 对比题（「X 与 Y 的区别」） | **先给一句话本质区别 → 表格化对比 → 各自适用场景** | BLEU vs ROUGE、LLaMA vs ChatGLM、RAG vs 微调 |
| 设计题（「怎么设计 X」） | **目标 → 整体流程 → 关键参数与取舍 → 如何评估** | 设计一个企业知识库问答系统 |

**贯穿全部回答的原则**：任何技术点都要落到**「它解决什么问题 + 代价是什么 + 什么时候不该用」**——
只背定义的回答通常拿不到高分。

## 验证理解

- 合上正文，用自己的话解释本知识点解决的问题及适用边界。
- 若本节含代码、公式或流程，先预测结果，再运行、推导或逐步追踪；项目片段需要沿用原文的依赖与数据。
- 如果缺少变量、术语或完整代码，请查阅[综合原文](../../../../../06-llm/09-面试专题/12-大模型面试题库.md)；代码片段不等同于独立可运行项目。
