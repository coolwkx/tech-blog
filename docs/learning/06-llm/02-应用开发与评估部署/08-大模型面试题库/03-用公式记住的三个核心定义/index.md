# 用公式记住的三个核心定义

## 本次只学这一点

| 概念 | 公式 | 一句话解释 |
|---|---|---|
| 语言模型 | $P(W_1..W_n)=\prod_{i=1}^{n}P(W_i\mid W_1..W_{i-1})$ | 生成 = 逐词采样，打分 = 概率连乘（取 log 相加） |
| 缩放点积注意力 | $\mathrm{softmax}(QK^{\top}/\sqrt{d_k})V$ | 除以 $\sqrt{d_k}$ 防止 softmax 饱和、梯度消失 |
| 困惑度 | $\mathrm{PPL}=\exp(-\frac{1}{N}\sum\ln p(w_i))$ | 近似「平均在多少个词之间犹豫」，越小越好 |

**面试小技巧**：被问到「为什么除以 $\sqrt{d_k}$」，如果能补一句「点积方差随维度线性增长，softmax 会落入饱和区」
就明显高于只答「为了归一化」的水平。
