# 高频对比题的「一句话本质区别」

> **学习目标**：能够解释「高频对比题的「一句话本质区别」」的机制或步骤，并用本节材料验证理解。
>

>
> **所属主题**：-大模型面试题库 · 关键机制（高频题精讲）

## 本次只学这一点

| 对比 | 一句话本质区别 |
|---|---|
| BLEU vs ROUGE | BLEU 基于**精确率**（生成得准不准），ROUGE 基于**召回率**（覆盖全不全） |
| GPT vs BERT | GPT 是**单向 decoder、会生成**；BERT 是**双向 encoder、会理解** |
| MHA vs MQA vs GQA | 都是「几个 query 共享一套 K/V」的问题：MHA 不共享、MQA 全共享、GQA 分组共享 |
| Fine-tuning vs ICL | Fine-tuning **更新参数**，ICL **只改 prompt 不更新参数** |
| Hard Prompt vs Soft Prompt | 硬模板是**真实文本、人工设计**；软模板是**可训练向量、自动学习** |
| RAG vs 微调 | RAG **外置知识、可更新可溯源**；微调**内化能力、更新代价高** |
| 向量检索 vs BM25 | 向量检索匹配**语义**，BM25 匹配**词面**，二者互补构成混合检索 |
| 父子切分 | 子块**检索**（精度高），父块**返回**（上下文全） |
| Prompt Tuning vs P-Tuning v2 | 前者只在**输入层**加前缀，后者在**每一层**都加前缀 |
| `retrieval_k` vs `candidate_m` | 前者是**召回**宽度（宁多勿漏），后者是**精选**条数（宁精勿滥） |
