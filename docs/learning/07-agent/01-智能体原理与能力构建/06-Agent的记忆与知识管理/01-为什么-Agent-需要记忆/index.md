# 为什么 Agent 需要记忆

## 本次只学这一点

给出的原因非常直接：

> 大模型本身不具备上下文的概念，它并不保存上次交互的内容，ChatGPT 之所以能够和人正常沟通对话，因为它**进行了一层封装，将历史记录回传给了模型**。

也就是说，所谓「对话记忆」并不是模型记住了什么，而是**每次请求都把历史重新拼进 prompt**。这带来两个直接后果：

1. **记忆是有成本的**：历史越长，每次请求的 token 越多，费用与延迟越高；
2. **记忆是有上限的**：模型的上下文窗口有限，超出就必须裁剪或压缩。
