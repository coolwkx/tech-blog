## 本次只学这一点

| 状态 | 索引表写法 |
| --- | --- |
| 事实被证伪 | `已退役`，一句话结论改为「原结论：……；已证伪，见文末说明」 |
| 被取代 | `已退役`，一句话结论改为「已被 XXX 取代」，并附上取代者的条目链接 |
| 长期停滞 | `已退役`，一句话结论保留，状态注明停滞起始时间 |
| 已沉淀 | `已退役`，一句话结论后附「已沉淀至某篇文档」，并附该文档链接 |
