# 打分锚点

> **学习目标**：能够解释「打分锚点」的机制或步骤，并用本节材料验证理解。
>
> **前置知识**：先了解本主题的基本术语；示例环境与背景见综合原文。
>
> **所属主题**：新技术评估框架 · D1 技术机制（25%）

## 本次只学这一点

| 分 | 描述 |
| --- | --- |
| 5 | 新增一个可复用的层或范式，并能说清它替换掉了原来的哪一步 |
| 4 | 在原范式内提出关键改动，效果与原理的因果链清晰 |
| 3 | 组合式创新，思路成立但缺少独立验证 |
| 2 | 主要是工程优化或封装，原理无新意 |
| 1 | 机制未披露，无法判断 |
