## 本次只学这一点

| 纪律 | 说明 |
| --- | --- |
| 先定分再论证 | 先独立打五个分，再写理由；避免理由反过来拉升分数 |
| 每个分数必须指回来源 | 分数旁标注来源级别（A/B/C），C 级来源不能支撑 4 分以上 |
| 官方自评降一档 | 只有官方数据时，D2 最高 3 分 |
| 总分不一致以公式为准 | 直觉与公式冲突时记录差异，不修改公式去迁就直觉 |
| 每季度重算 | 成熟度与工程可用性会随时间上升，D1/D2 是稳定的 |
| 保留历史评分 | 不覆盖旧分数，追加一行「重算日期 + 变化原因」，这样能看出技术在往哪个方向走 |
