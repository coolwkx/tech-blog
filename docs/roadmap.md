# 跨领域学习路线

> 这些分区不是八门独立的课，而是**一条链**：
> Python 是表达工具 → 数据与统计是分析基础 → 机器学习教你如何评估 → 深度学习教你如何端到端优化 →
> NLP 与 LLM 是同一套序列建模范式的演进 → Agent 把模型变成系统 → 项目实战把一切串起来。

## 一、依赖关系图

```text
 ┌──────────────┐
 │ 01-python │ 语言与工程能力：所有代码的地基
 └──────┬───────┘
 │
 ┌──────▼───────┐
 │ 02-data │ Linux / SQL / NumPy / Pandas / 统计
 └──────┬───────┘
 │
 ┌──────▼───────┐
 │ 03-ml │ 评估方法论：指标、交叉验证、偏差方差
 └──────┬───────┘
 │
 ┌──────▼───────┐
 │ 04-dl │ 优化与架构：梯度、训练工程、CNN/注意力
 └───┬──────┬───┘
 │ │
 ┌────────▼──┐ ┌─▼────────────┐
 │ 05-nlp │→│ 06-llm │ 文本与序列 → 规模化与对齐
 └───────────┘ └──────┬───────┘
 │
 ┌──────▼────────┐
 │ 07-agent │ 系统化：工具、记忆、多智能体
 └──────┬────────┘
 │
 ┌──────▼────────┐
 │ 08-project │ 把知识落成作品
 └───────────────┘
```

**容易被忽略的横向依赖**：

| 依赖 | 说明 |
| --- | --- |
| 02-data → 03-ml | 不会清洗与聚合数据，模型再好也白搭 |
| 03-ml → 04-dl | 不懂过拟合与验证集，无法判断深度模型是真变好还是记住了数据 |
| 04-dl → 06-llm | 不会反向传播与显存核算，就只能照抄训练脚本 |
| 06-llm → 07-agent | Agent 的失败大多不是框架问题，而是模型能力边界与上下文管理 |
| 01-python → 全部 | 异步、类型、性能这些工程能力决定你能不能把实验变成服务 |

## 二、24 周系统路线（每周 5-6 小时）

| 阶段 | 周次 | 分区 | 内容 | 本周产出（必须动手） |
| --- | --- | --- | --- | --- |
| 第一阶段 · 语言与工具 | 第 1-2 周 | `01-python` | Python 基础与语法、数据模型、函数与装饰器 | 能手写符合协议的类；解释 `is`/`==`、可变默认参数、闭包延迟绑定 |
| 第一阶段 · 语言与工具 | 第 3 周 | `01-python` | 面向对象、类型系统与工程化、标准库 | 能用 dataclass/Protocol 设计模块；会用 ruff+mypy 管住代码质量 |
| 第一阶段 · 语言与工具 | 第 4 周 | `01-python` | 并发与异步、性能优化、CPython 内部机制 | 能判断该用线程/进程/协程；能用 profiling 找到真实瓶颈 |
| 第二阶段 · 数据与统计 | 第 5 周 | `02-data` | Linux 基础命令、MySQL 与 SQL 语法 | 能独立部署服务、写出带 JOIN/子查询的 SQL 并解释执行计划 |
| 第二阶段 · 数据与统计 | 第 6 周 | `02-data` | NumPy、Pandas 数据清洗与分组聚合 | 能把脏数据清洗成可分析表；用向量化替代循环提速一个数量级 |
| 第二阶段 · 数据与统计 | 第 7 周 | `02-data` | 数据可视化、统计分析基础、RFM 实战 | 能选对图表类型；独立完成一份 RFM 用户价值分析报告 |
| 第三阶段 · 机器学习 | 第 8 周 | `03-ml` | 机器学习概述、特征工程、KNN、线性/逻辑回归 | 拿到数据集能说出评估方案与基线；手推梯度下降 |
| 第三阶段 · 机器学习 | 第 9 周 | `03-ml` | 决策树、集成学习、KMeans 聚类 | 能解释 GBDT 的加法模型与偏差-方差分解 |
| 第三阶段 · 机器学习 | 第 10 周 | `03-ml` | 模型评估与调优、数据挖掘案例 | 能诊断欠拟合/过拟合并给出针对性动作 |
| 第四阶段 · 深度学习 | 第 11 周 | `04-dl` | 神经网络基础、激活与损失、反向传播 | 白纸推导两层网络的反向传播；手写微型 autograd |
| 第四阶段 · 深度学习 | 第 12 周 | `04-dl` | 优化器与正则化、CNN、RNN 与序列模型 | 能解释为什么用 AdamW、BatchNorm 解决了什么问题 |
| 第五阶段 · NLP | 第 13 周 | `05-nlp` | NLP 概述、文本预处理、分词、文本表示 | 手写极简 BPE；解释为什么放弃词级分词 |
| 第五阶段 · NLP | 第 14 周 | `05-nlp` | 词向量、RNN/LSTM、Attention、Transformer | 手写缩放点积注意力；说清 BERT 与 GPT 的目标差异 |
| 第五阶段 · NLP | 第 15 周 | `05-nlp` | 文本分类、序列标注、语义匹配项目 | 完成一个端到端文本分类项目并做误差分析 |
| 第六阶段 · 大语言模型 | 第 16 周 | `06-llm` | 大模型基础与演进、主流模型对比、提示词工程 | 能对比主流模型的能力/成本/上下文取舍 |
| 第六阶段 · 大语言模型 | 第 17 周 | `06-llm` | API 调用实践、本地部署与 Ollama | 能本地跑起一个开源模型并接入自己的程序 |
| 第六阶段 · 大语言模型 | 第 18 周 | `06-llm` | 向量数据库、LangChain、RAG 构建与评估 | 搭一个可跑的 RAG 并给出召回率/忠实度评估 |
| 第七阶段 · Agent | 第 19 周 | `07-agent` | Agent 基础范式、工具调用与执行 | 不用框架手写一个带工具注册与重试的 Agent |
| 第七阶段 · Agent | 第 20 周 | `07-agent` | 规划与分解、记忆管理、多智能体协作 | 能设计短期/长期记忆方案并说明冲突处理策略 |
| 第七阶段 · Agent | 第 21 周 | `07-agent` | 评估与可观测性、工程化、安全与可靠性 | 能设计轨迹评估指标；给出越权与提示注入的防御方案 |
| 第八阶段 · 项目实战 | 第 22-24 周 | `08-project` | RAG 问答系统、医疗问诊机器人、GPT2 聊天机器人、黄金价格监控 Agent | 复现至少两个项目；写出架构说明与踩坑复盘 |

## 四、每条线的验收标准

学完一条线，应该能**不看**做到：

| 分区 | 验收标准 |
| --- | --- |
| 01-python | 解释 `is` 与 `==`、可变默认参数、GIL 对 CPU/IO 任务的不同影响 |
| 02-data | 独立写多表 JOIN + 窗口函数；用 Pandas 完成清洗到聚合全流程 |
| 03-ml | 拿到数据集能说出评估方案、基线，以及当前欠拟合还是过拟合 |
| 04-dl | 白纸推导两层网络反向传播；给出模型的显存与算力估算 |
| 05-nlp | 手写 BPE；说清 BERT 与 GPT 的训练目标差异及其后果 |
| 06-llm | 手写注意力；说清 LoRA/DPO/量化各自的收益与代价 |
| 07-agent | 从零写出带工具注册与错误重试的 Agent，并说明它会在哪里失败 |
| 08-project | 能画出项目架构图，讲清关键决策与踩过的坑 |

## 五、每周固定动作（照抄即可）

1. **周一**：读目标章节的 `README.md`，把「本章要回答的问题」抄成待办。
2. **周三**：跑通所有可运行示例，把报错记进 issue。
3. **周五**：合上笔记做自测题，答不出的回读并补一份自己的解释。
4. **周日**：把可复用片段挪进 `90-cheatsheet/cheatsheet.md`，术语补进 `glossary.md`。
5. **月末**：回顾本页进度，写一条 changelog。
